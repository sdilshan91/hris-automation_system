# TC-RPT-001-02: Department filter restricts the report to that department only (alternative path)

## 1. Test Objective
Verify that applying a department filter ("Engineering") to the Headcount Summary returns only
employees belonging to that department (and, per FR-2, its sub-departments via the hierarchy
multi-select), and that the totals/charts reflect the filtered subset. Validates AC-2's filter
behavior and the Test Hint "filter by a specific department; verify only employees in that
department are included".

## 2. Related Requirements
- User Story: US-RPT-001
- Acceptance Criteria: AC-2
- Functional Requirements: FR-2 (department multi-select with hierarchy), FR-1, FR-4

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Reports.View.All`.
- Engineering department has known sub-departments (e.g. Backend, Frontend) and a known active
  headcount (e.g. 12); other departments hold the remaining employees.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | headcount_summary | |
| department_ids | [Engineering] | multi-select; hierarchy includes Backend, Frontend |
| expected filtered active | 12 | Engineering + sub-departments |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Generate Headcount Summary with no department filter; note tenant total | Total = full tenant active count |
| 2 | Re-generate with department filter = Engineering | Total headcount = 12 (Engineering + sub-departments only) |
| 3 | Inspect the by-sub-department bar chart | Only Engineering sub-departments (Backend, Frontend) appear; no other department's bars |
| 4 | Switch to the table view (FR-4) | Tabular rows list only Engineering-scoped employees/aggregates |
| 5 | Add a second department to the multi-select (e.g. Sales) | Totals expand to Engineering + Sales only; hierarchy of each included |
| 6 | Toggle back to chart view | Chart and table show identical, consistent figures |

## 6. Postconditions
- Report scoped strictly to selected departments and their sub-departments.
