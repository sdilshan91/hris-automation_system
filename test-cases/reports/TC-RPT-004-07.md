# TC-RPT-004-07: Audit every export -- record captures report type, filters, row count, format, actor (FR-9; assert action name)

## 1. Test Objective
Verify that EVERY export action writes an audit record (via the US-NTF-004 audit trail) capturing the
report type, the filters applied, the row count, the format, and the actor; that the audit action
string is asserted verbatim; and that audit rows are tenant-scoped. Validates FR-9, AC-2/AC-3/AC-4
(audit applies to all formats).

## 2. Related Requirements
- User Story: US-RPT-004
- Acceptance Criteria: AC-2, AC-3, AC-4
- Functional Requirements: FR-9 (audit: report type, filters, row count, format, actor)
- Dependencies: US-NTF-004 (audit trail)

> ACTION-NAME ASSERTION: assert the export audit action string verbatim against the implementation's
> documented constant (e.g. `"Report.Export"` / `"ReportExport"` -- confirm the exact value used by
> the handler). Do not accept an unexplained/lowercased variant; the audit consumer relies on the
> exact action key (consistent with US-RPT-003 "PayrollReport.ViewSensitive" handling).

## 3. Preconditions
- Tenant A active; `hr1` has `Reports.Export`; audit log accessible (US-NTF-004 audit-logs endpoint).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | headcount_summary | logged in audit |
| format | csv | logged in audit |
| filters | {as_of:2026-06-01, department:"Sales"} | logged in audit |
| actor | hr1 | logged in audit |
| expected audit action | Report.Export (assert exact impl constant) | FR-9 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, export headcount_summary to CSV with filters {as_of, department:"Sales"} | Export accepted; rowCount returned |
| 2 | Query the audit log (US-NTF-004) filtered to Tenant A | A new audit row exists for the export, actor=hr1, tenant=A, timestamp ~now |
| 3 | Inspect the audit row detail | Captures: report type=headcount_summary, format=csv, filters={as_of, department:"Sales"}, row count, actor=hr1 (FR-9) |
| 4 | Assert the audit action string | Matches the impl's exact export action constant verbatim (not a lowercased/arbitrary variant) |
| 5 | Export the SAME report to PDF, then to xlsx | Each export writes its OWN audit row (every export audited, not just the first) with the matching format |
| 6 | Confirm tenant scoping of audit rows | Audit rows are Tenant A only; not visible to other tenants |

## 6. Postconditions
- Each export (csv/pdf/xlsx) produced a tenant-scoped audit row with type/filters/rowCount/format/actor.
