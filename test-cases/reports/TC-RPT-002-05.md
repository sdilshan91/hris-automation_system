# TC-RPT-002-05: Overtime Report — hours exceeding shift standard for 3 employees match seeded excess (BR-3, FR-1)

## 1. Test Objective
Verify the Overtime Report calculates per-employee overtime as attendance-log hours exceeding the
shift's standard hours (BR-3), and that totals and per-department aggregates match seeded data.
Validates FR-1 (Overtime Report), BR-3, and the Test Hint "3 employees with hours exceeding shift
standard; verify correct excess hours".

## 2. Related Requirements
- User Story: US-RPT-002
- Acceptance Criteria: AC-3 (overtime by department)
- Functional Requirements: FR-1, FR-2 (shift filter), FR-3
- Business Rules: BR-3 (overtime = hours over shift standard)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Reports.View.All`.
- A shift with standard hours = 8/day configured.
- 3 employees with known excess: empA worked 10h (2h OT), empB worked 9.5h (1.5h OT), empC worked 12h on one day (4h OT). Total OT = 7.5h.
- A 4th employee worked exactly 8h (0 OT) as a negative anchor — must NOT appear in overtime.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | overtime_report | |
| shift standard | 8h/day | BR-3 baseline |
| empA OT | 2.0h | 10 − 8 |
| empB OT | 1.5h | 9.5 − 8 |
| empC OT | 4.0h | 12 − 8 |
| total OT | 7.5h | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, open Overtime tab; Generate for the period | Report renders |
| 2 | Read per-employee overtime | empA=2.0h, empB=1.5h, empC=4.0h — each = logged hours minus shift standard (BR-3) |
| 3 | Read total overtime | 7.5h |
| 4 | Confirm the 8h-exactly employee | Shows 0 OT (or is absent from the overtime list) — only EXCESS over standard counts |
| 5 | Apply shift filter (FR-2) to a single shift | Only that shift's overtime is included; totals recompute accordingly |
| 6 | Cross-check overtime-by-department against AC-3 Attendance Summary | Per-dept overtime is consistent between the Overtime report and the Attendance Summary bar chart |
| 7 | Confirm tenant-scoped, read-only | Tenant A only; no data mutated |

## 6. Postconditions
- Overtime correctly computed as excess over shift standard; no data mutated.
