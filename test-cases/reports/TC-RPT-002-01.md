# TC-RPT-002-01: Leave Utilization for Q1 2026 — totals/avg-per-dept/top-10/donut match seeded data (happy path)

## 1. Test Objective
Verify that an HR Officer with `Reports.View.All` can generate the "Leave Utilization" report for a
period (Q1 2026) and that the rendered figures match the seeded data: total leave days taken by type
(bar chart), average leave utilization per department (grouped bar), employees with highest
consumption (top-10 table), and leave-type distribution (donut). Validates AC-1, FR-3, and the Test
Hint "10 employees with varied leave consumption; verify totals and chart data match".

## 2. Related Requirements
- User Story: US-RPT-002
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-2, FR-3, FR-5
- Business Rules: BR-1 (entitlement basis for utilization %), BR-5 (leave-year)

## 3. Preconditions
- Tenant A active; HR Officer `hr1` authenticated with `Reports.View.All`.
- 10 employees across 2-3 departments with KNOWN, varied leave consumption in Q1 2026, e.g.:
  Annual leave total = 42 days, Sick = 11 days, Casual = 7 days (sums known per type).
- Each employee has a known entitlement per type so utilization % is computable (FR-3).
- Reporting module enabled for Tenant A's plan.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | leave_utilization | valid leave report key |
| date_from | 2026-01-01 | Q1 start |
| date_to | 2026-03-31 | Q1 end |
| expected total Annual | 42 days | sum across 10 employees |
| expected total Sick | 11 days | |
| expected total Casual | 7 days | |
| top consumer | emp with highest total | heads the top-10 table |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, navigate to Leave & Attendance Reports > Leave Utilization tab | Tabbed nav shows Leave Utilization / Leave Balance / Attendance Summary / Overtime / Absenteeism (UI/UX) |
| 2 | Set date_from=2026-01-01, date_to=2026-03-31; Generate | Report renders within SLA (NFR-1) |
| 3 | Read the "total leave days by type" bar chart | Annual=42, Sick=11, Casual=7 — match seeded totals exactly |
| 4 | Read the average leave utilization per department (grouped bar) | Each dept's avg = (consumed / entitlement) averaged over its employees; matches hand-computed value per FR-3 |
| 5 | Read the top-10 consumers table | Rows sorted descending by total days; the known highest consumer is row 1; at most 10 rows |
| 6 | Read the leave-type distribution donut | Segment proportions = type totals / grand total (Annual 42 / 60 = 70%, etc.) |
| 7 | Toggle to data-table view (FR-5 chart/table toggle) | Same numbers presented tabularly |
| 8 | Confirm all figures tenant-scoped and report read-only | Only Tenant A data; no business records mutated (BR-1) |

## 6. Postconditions
- Report rendered; figures match seeded data; no data mutated.
