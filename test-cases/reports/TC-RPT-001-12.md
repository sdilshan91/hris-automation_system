# TC-RPT-001-12: Charts have alt text + table-view alternative for screen readers; responsive 360px-4K (NFR-5, NFR-4)

## 1. Test Objective
Verify the report UI meets WCAG 2.1 AA: every chart exposes a text alternative (alt text / ARIA
description) and a togglable tabular data view (FR-4) that screen readers can navigate; the UI is
keyboard-operable and responsive from 360px to 4K with charts resizing dynamically. Anchored to the
Test Hints on accessibility and responsiveness.

## 2. Related Requirements
- User Story: US-RPT-001
- Acceptance Criteria: AC-2, AC-3, AC-4
- Functional Requirements: FR-3 (charts), FR-4 (chart + table views togglable)
- Non-Functional: NFR-4 (responsive 360px-4K), NFR-5 (WCAG 2.1 AA: alt text + data tables)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Reports.View.All`; a report with charts is generated.
- Screen reader (NVDA/VoiceOver) and axe-core available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | demographics | has pie, histogram, stacked bar, location chart |
| viewport widths | 360px, 768px, 1920px, 4K | responsive range |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run axe-core on the rendered report view | Zero WCAG 2.1 AA violations (contrast, names/roles, focus order) |
| 2 | Inspect each chart for a text alternative | Each chart exposes alt text / aria-label / aria-describedby summarizing the data; not an unlabeled canvas |
| 3 | Toggle to table view (FR-4) | An equivalent data table is available; screen reader reads it as a proper table (row/column headers) |
| 4 | Navigate the report using keyboard only (Tab/Shift+Tab/Enter) | All controls (filter bar, generate, view switcher, refresh, print) reachable and operable; visible focus indicator |
| 5 | Navigate charts/table with a screen reader | The chart's text alternative and the table convey the same data a sighted user sees |
| 6 | Resize viewport 360px -> 768px -> 1920px -> 4K | Charts resize dynamically; at <768px charts stack single-column and tables become horizontally scrollable; no clipping/overlap (NFR-4) |
| 7 | Verify the tenant brand-color chart palette still meets contrast at AA | Multi-series palette is distinguishable and meets contrast (not color-only encoding) |

## 6. Postconditions
- Charts have text alternatives + table equivalents; UI keyboard-operable and responsive; AA clean.
