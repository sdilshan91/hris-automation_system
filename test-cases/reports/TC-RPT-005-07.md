# TC-RPT-005-07: Pending Approvals widget counts only items assigned to the logged-in user, not all tenant-pending items (AC-2, FR-7, BR-3)

## 1. Test Objective
Verify that the Manager dashboard's Pending Approvals widget counts ONLY leave/attendance approval items
ASSIGNED to the logged-in approver -- not every pending item in the tenant. Two managers in the same tenant
must each see only their own assigned approvals. Validates AC-2, FR-7, BR-3.

## 2. Related Requirements
- User Story: US-RPT-005
- Acceptance Criteria: AC-2
- Functional Requirements: FR-7 (Quick Actions / approvals for managers)
- Business Rules: BR-3 (pending approvals = items assigned to the logged-in user only)

## 3. Preconditions
- Tenant A active with two managers `mgrA` and `mgrB`.
- Pending approval items in Tenant A: 3 assigned to `mgrA`, 4 assigned to `mgrB`, 2 assigned to a third approver.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| approvals assigned to mgrA | 3 | BR-3 |
| approvals assigned to mgrB | 4 | BR-3 |
| approvals assigned to others | 2 | must NOT appear for mgrA or mgrB |
| tenant total pending | 9 | NOT the value any single manager sees |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `mgrA`, load dashboard; read `pending_approvals` | `value == 3`; `items[]` are only the 3 approvals assigned to `mgrA` (BR-3) |
| 2 | As `mgrB`, load dashboard; read `pending_approvals` | `value == 4`; only `mgrB`'s assigned items (BR-3) |
| 3 | Confirm neither manager's count equals the tenant total | neither shows 9; the third approver's 2 items appear for neither (BR-3) |
| 4 | As `mgrA`, approve one item from the widget Quick Actions | the item is approved; `pending_approvals` for `mgrA` drops to 2 (FR-7) |
| 5 | Re-read `mgrB`'s widget after `mgrA`'s action | `mgrB`'s count is unchanged (== 4); approvals are per-approver (BR-3) |

## 6. Postconditions
- Pending-approval counts are correctly partitioned by assigned approver; quick action mutated only the targeted item.
