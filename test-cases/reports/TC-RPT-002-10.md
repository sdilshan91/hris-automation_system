# TC-RPT-002-10: Boundaries — 0 employees, single-day range, full leave-year (BR-5), terminated incl. historical / excl. current balance (BR-6)

## 1. Test Objective
Verify edge-case behaviour: an empty population renders an empty (not erroring) report; a single-day
date range works; a full leave-year range respects the tenant's configured leave-year start (BR-5);
and terminated employees are INCLUDED in historical leave/attendance reports but EXCLUDED from the
current Leave Balance report (BR-6). Validates AC-2, AC-3, BR-5, BR-6.

## 2. Related Requirements
- User Story: US-RPT-002
- Acceptance Criteria: AC-2, AC-3
- Functional Requirements: FR-2 (date range), FR-4
- Business Rules: BR-5 (leave-year start), BR-6 (terminated incl. historical, excl. current balance)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Reports.View.All`.
- Tenant A configured with a custom fiscal leave-year start (e.g. April 1) to exercise BR-5.
- An empty department `deptEmpty` with 0 employees.
- A terminated employee `empTerm` who had leave/attendance activity in a PAST period and was
  terminated before today.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| empty filter | department_ids=[deptEmpty] | 0 employees |
| single-day range | date_from = date_to = a working day | 1-day window |
| leave-year start | 2026-04-01 | custom fiscal (BR-5) |
| empTerm | terminated before today | active in a past period |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Generate Leave Utilization filtered to deptEmpty (0 employees) | Report renders an empty state (zeroed totals / "no data"), no error/crash |
| 2 | Generate Attendance Summary with date_from = date_to = one working day | Working days = 1; metrics computed over that single day; no divide-by-zero |
| 3 | Generate a full-leave-year Leave Utilization | The leave-year window starts at the tenant's configured start (2026-04-01), NOT Jan 1 (BR-5) |
| 4 | Generate a HISTORICAL report covering empTerm's active period (Leave Utilization / Attendance) | empTerm's data IS included (BR-6 — terminated included in historical) |
| 5 | Generate the CURRENT Leave Balance report (as of today) | empTerm is EXCLUDED — no current balance row for a terminated employee (BR-6) |
| 6 | Submit an inverted range (date_from > date_to) | Rejected/validation error, or normalized per documented behaviour; never silent wrong results |

## 6. Postconditions
- Empty/single-day/leave-year/terminated edge cases handled per BR-5/BR-6; no crashes.
