# TC-RPT-002-07: Invalid report_type and out-of-tenant filter ids (dept/employee/leaveType/shift) rejected (FR-2, negative)

## 1. Test Objective
Verify invalid input is rejected: an unknown `report_type` returns a validation error (not a partial
or default report), and filter ids that belong to ANOTHER tenant (department, employee, leave type,
shift) never pull cross-tenant data — they are treated as not-found/empty within the caller's tenant.
Validates FR-2 filter validation and the AC-5 tenant boundary at the input layer.

> PLATFORM NOTE: foreign resource ids are constrained by the EF Core global query filter; a foreign
> id resolves to zero in-tenant matches (not-found/empty), and a direct single-resource fetch of a
> foreign id returns 404 (existence not disclosed), NOT 403. RLS is deferred defense-in-depth.

## 2. Related Requirements
- User Story: US-RPT-002
- Acceptance Criteria: AC-1, AC-5
- Functional Requirements: FR-2 (filter validation), FR-7 (tenant context)
- Non-Functional: NFR-2 (tenant isolation)

## 3. Preconditions
- Tenant A and Tenant B active; `hrA` authenticated in Tenant A.
- Tenant B owns: deptB1, empB1, leaveTypeB1, shiftB1 (all foreign to A).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| invalid report_type | "totally_made_up" | not a valid report key |
| foreign department_id | deptB1 | Tenant B |
| foreign employee_id | empB1 | Tenant B |
| foreign leave_type_id | leaveTypeB1 | Tenant B |
| foreign shift_id | shiftB1 | Tenant B |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hrA`, request a report with report_type="totally_made_up" | Rejected with a validation error (e.g. 400); no report generated; no default substituted |
| 2 | Request Leave Utilization with department_ids=[deptB1] | EF filter scopes to Tenant A; deptB1 yields zero in-tenant matches/empty; no Tenant B data returned |
| 3 | Request with employee_id=empB1 | Treated as not-found within A; no Tenant B employee data; a direct drill-down fetch of empB1 -> 404 (not 403) |
| 4 | Request with leave_type_ids=[leaveTypeB1] | No Tenant B leave-type data; empty/not-found within A |
| 5 | Request Overtime with shift_ids=[shiftB1] | No Tenant B shift data; empty/not-found within A |
| 6 | Confirm none of steps 2–5 disclose Tenant B names, counts, or existence | Zero cross-tenant disclosure in any response body |

## 6. Postconditions
- Invalid report_type rejected; foreign filter ids never return cross-tenant data.
