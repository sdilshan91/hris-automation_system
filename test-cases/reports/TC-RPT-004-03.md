# TC-RPT-004-03: PDF export -- title, filters, data tables, pagination, tenant-name footer branding (BR-5); chart-as-image DEFERRED (AC-3, FR-4)

## 1. Test Objective
Verify that selecting "PDF" generates a branded PDF (QuestPDF) containing the report title, the filters
applied, the data table(s), and page numbers / pagination, with a "Generated by [Tenant Name] via HRM
SaaS" footer + timestamp (BR-5). The chart-rendered-as-image element is DEFERRED infra and is asserted
CONDITIONALLY -- its absence MUST NOT fail this case; the table + branding + pagination portion is
in-scope and binding. Validates AC-3, FR-4, BR-5.

## 2. Related Requirements
- User Story: US-RPT-004
- Acceptance Criteria: AC-3
- Functional Requirements: FR-4 (QuestPDF branded PDF), FR-5 (async via Hangfire)
- Business Rules: BR-5 (tenant-name footer + timestamp)

> CONDITIONAL / DEFERRED INFRA: AC-3 / FR-4 also require charts rendered as PNG images (server-side
> via SkiaSharp or headless capture -- S10 assumption). Chart-as-image is DEFERRED. Assert the
> chart-image step (step 6) ONLY if chart-image rendering is wired; otherwise record it pending and
> PASS on the in-scope title + filters + data tables + pagination + branding. Do NOT relax any other
> expectation to compensate.

## 3. Preconditions
- Tenant A active with a configured tenant display name (e.g. "Acme Corp"); `hr1` has `Reports.Export`.
- A report generated with a known filter set; Hangfire worker running.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | headcount_summary | valid key |
| format | pdf | PDF |
| tenant display name | Acme Corp | for footer (BR-5) |
| filters | {as_of:2026-06-01} | shown in PDF |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, select PDF | Export accepted; `{exportId, status, format:"pdf"}` returned (async via Hangfire if >=1000 rows, else may be sync) |
| 2 | Open the produced PDF | Renders without corruption in a standard PDF viewer |
| 3 | Inspect the document head | Report title is present and matches the report |
| 4 | Inspect the metadata block | The filters applied (as_of=2026-06-01) are listed |
| 5 | Inspect the body | Data table(s) render with column headers and report rows |
| 6 | (CONDITIONAL -- chart-image wired) Inspect for chart images | Applicable charts appear as embedded PNG images. If chart-image rendering is NOT wired, mark pending -- do NOT fail the case |
| 7 | Inspect the footer on every page | "Generated by Acme Corp via HRM SaaS" + a timestamp (BR-5); footer carries the TENANT name, not a hardcoded brand |
| 8 | Inspect multi-page output | Page numbers / pagination present across pages |

## 6. Postconditions
- A branded, paginated PDF with title/filters/tables/footer produced; chart-image step recorded pending if deferred.
