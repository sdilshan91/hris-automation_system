# TC-RPT-005-10: Module-enablement hides widgets when a module is disabled (BR-5) -- DEFERRED/CONDITIONAL (no tenant module flag today; assume-all-on)

## 1. Test Objective
Verify the intended behavior of BR-5: when a module (e.g. Payroll) is disabled for the tenant, widgets that
depend on that module are hidden from the dashboard. There is currently NO per-tenant module-enablement flag
in the platform, so this case is CONDITIONAL/DEFERRED: with all modules assumed ON, assert that every
role-appropriate widget IS present and renders; the disable-and-hide steps are recorded as PENDING and do
NOT fail the case until a tenant module-flag exists. Validates BR-5 (deferred).
