# TC-RPT-002-02: Leave Balance = entitlement + carryforward − consumed − pending; color bands correct (AC-2, BR-1)

## 1. Test Objective
Verify the Leave Balance report computes each employee's per-leave-type balance per BR-1
(entitlement + carry forward − consumed − pending approval) and applies the correct color band:
green (>50% remaining), yellow (25–50%), red (<25%). Validates AC-2, BR-1, and the Test Hint
"entitlement 20, consumed 8, pending 2 = balance 10".

## 2. Related Requirements
- User Story: US-RPT-002
- Acceptance Criteria: AC-2
- Functional Requirements: FR-1, FR-3
- Business Rules: BR-1, BR-5

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Reports.View.All`.
- Seeded employees with known per-type balances spanning all three color bands:
  - empGreen: Annual entitlement 20, carryforward 0, consumed 8, pending 2 -> balance 10 (50%); set to >50% with carryforward 2 -> balance 12 (54.5%) GREEN.
  - Test-Hint case empMid: entitlement 20, carryforward 0, consumed 8, pending 2 -> balance 10 -> 50% (YELLOW boundary, inclusive of 25-50%).
  - empRed: entitlement 20, consumed 16, pending 1 -> balance 3 -> 15% RED.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | leave_balance | |
| as_of | today (default date_to) | "as of today" per AC-2 |
| Test-Hint balance | 20 + 0 − 8 − 2 = 10 | entitlement/carryforward/consumed/pending |
| band thresholds | >50% green, 25–50% yellow, <25% red | per AC-2 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, open Leave Balance tab; Generate as of today | Table shows each employee, each leave type, with balance per BR-1 |
| 2 | Locate the Test-Hint employee/type (entitlement 20, consumed 8, pending 2) | Balance cell = 10 (= 20 + 0 − 8 − 2), exactly per BR-1 |
| 3 | Verify the 50% case color | Remaining 10/20 = 50% -> YELLOW (25–50% band is inclusive at 50) |
| 4 | Verify empGreen (>50%) | Cell colored GREEN |
| 5 | Verify empRed (<25%) | Cell colored RED |
| 6 | Verify carryforward is included | An employee with carryforward shows balance increased by exactly the carryforward amount (BR-1) |
| 7 | Verify pending-approval is subtracted | Increasing pending by 1 reduces displayed balance by 1 |
| 8 | Confirm read-only and tenant-scoped | No balance records mutated; only Tenant A employees listed (BR-1) |

## 6. Postconditions
- Balances and color bands correct; no data mutated.
