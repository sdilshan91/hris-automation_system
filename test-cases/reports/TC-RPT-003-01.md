# TC-RPT-003-01: Payroll Run Summary (March 2026) — totals/statutory-vs-voluntary/net/count match sum of payslips (happy path)

## 1. Test Objective
Verify that an HR Officer with `Payroll.Export` (held by HR Officer / Tenant Admin, the report
consumers) can generate the "Payroll Run Summary" for a period (March 2026) and that the rendered
figures match the sum of the underlying finalized payslips: total gross pay, total deductions broken
down into statutory vs voluntary, total net pay, and employee-count processed. Amounts render in the
tenant's configured currency (BR-2). Validates AC-1, FR-1, and the Test Hint "50 employees;
totals match sum of individual payslips".

## 2. Related Requirements
- User Story: US-RPT-003
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-2, FR-5, FR-8
- Business Rules: BR-1 (finalized only), BR-2 (tenant currency)

## 3. Preconditions
- Tenant A active; HR Officer `hr1` authenticated with `Payroll.Export`.
- A FINALIZED payroll run exists for 2026-03 covering 50 employees with KNOWN payslip figures, e.g.:
  sum(gross)=250,000.00, sum(statutory deductions)=37,500.00, sum(voluntary deductions)=7,500.00,
  sum(net)=205,000.00 (gross − statutory − voluntary = net).
- Tenant A's configured currency and decimal format are known.
- Payroll + Reporting modules enabled for Tenant A's plan.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | PayrollSummary / payroll_run_summary | valid payroll report key |
| payroll_period | 2026-03 | YYYY-MM |
| expected total gross | 250,000.00 | sum of 50 payslips |
| expected statutory deductions | 37,500.00 | statutory subtotal |
| expected voluntary deductions | 7,500.00 | voluntary subtotal |
| expected total net | 205,000.00 | gross − total deductions |
| expected employee count | 50 | processed in the run |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, open Payroll Reports > Run Summary tab | Tabbed nav shows Run Summary / Salary Distribution / Statutory / Bank Advice / CTC Analysis (UI/UX §8) |
| 2 | Set payroll_period=2026-03; Generate | Report renders within SLA (NFR-1) |
| 3 | Read the Total Gross KPI card | 250,000.00 in tenant currency with correct symbol/decimals (BR-2) |
| 4 | Read the Total Deductions card and its statutory/voluntary split | Statutory=37,500.00, Voluntary=7,500.00; sum=45,000.00 (AC-1 split) |
| 5 | Read the Total Net Pay card | 205,000.00 (= 250,000.00 − 45,000.00) |
| 6 | Read the Employee Count card | 50 employees processed |
| 7 | Cross-check each KPI against the manual sum of the 50 finalized payslips | Every total equals the sum of payslip-level values exactly |
| 8 | Confirm the report is read-only and tenant-scoped | No payroll records mutated; only Tenant A data shown (BR-1) |

## 6. Postconditions
- Run Summary rendered; all KPIs equal the sum of finalized payslips; no data mutated.
