# TC-RPT-001-01: Generate Headcount Summary for current month; total matches active-employee count (happy path)

## 1. Test Objective
Verify that an HR Officer with `Reports.View.All` can select "Headcount Summary", apply the
default current-month filter, generate the report, and that the rendered total headcount and
active count exactly match the count of active employees (status `active` or `probation`) in the
tenant. Validates the primary success path (AC-2) and the Test Hint "total matches the count of
active employees".

## 2. Related Requirements
- User Story: US-RPT-001
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-1, FR-2, FR-3, FR-4, FR-7
- Business Rules: BR-1 (read-only), BR-4 (active classification)

## 3. Preconditions
- Tenant A is active; HR Officer `hr1` is authenticated with `Reports.View.All`.
- Tenant A has a known seeded population, e.g. 50 employees: 40 `active`, 3 `probation`,
  5 `terminated`, 2 `resigned` (so active-by-BR-4 = 43, separated = 7).
- Employment-type mix is known: e.g. 30 full-time, 8 part-time, 4 contract, 1 intern among active.
- Reporting module is enabled for Tenant A's plan.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | headcount_summary | valid pre-built key |
| date_from | (default) start of current month | per Data Requirements default |
| date_to | (default) today | per Data Requirements default |
| department_ids | (none) | full tenant |
| expected total active | 43 | active(40) + probation(3) per BR-4 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, navigate to Reports > HR Reports | Report catalog lists Headcount Summary, Employee Turnover, Demographics, Joiners & Leavers, Department Distribution, Employment Type Breakdown; each with description, icon, Generate button (AC-1) |
| 2 | Click "Generate" on Headcount Summary without changing filters | Filters default to date_from = start of current month, date_to = today |
| 3 | Observe the rendered report | Report shows total headcount, active vs inactive counts, breakdown by employment type, and a bar chart of headcount by sub-department (AC-2) |
| 4 | Read the "active" figure | Active count = 43 (matches the seeded active+probation population per BR-4) |
| 5 | Sum the employment-type breakdown (full-time + part-time + contract + intern) | Sum equals the reported active/total figure used by the breakdown; no rows double-counted |
| 6 | Confirm all figures are tenant-scoped | Only Tenant A employees are counted; no other tenant's rows contribute (FR-7) |
| 7 | Confirm the report did not mutate any business data | No employee/department records changed (BR-1) |

## 6. Postconditions
- Report rendered correctly; no business data modified.
