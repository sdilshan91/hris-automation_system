# TC-RPT-002-04: Absenteeism counts only unauthorized absences; approved leave excluded (BR-4, AC-3)

## 1. Test Objective
Verify the absenteeism calculation per BR-4 excludes days covered by APPROVED leave and counts only
unauthorized absences. An employee on approved leave must NOT inflate the absenteeism rate, while an
unauthorized no-show must. Validates BR-4 and the absenteeism portion of AC-3 / FR-4.

## 2. Related Requirements
- User Story: US-RPT-002
- Acceptance Criteria: AC-3
- Functional Requirements: FR-4
- Business Rules: BR-2 (working days), BR-4 (absenteeism excludes approved leave)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Reports.View.All`.
- Working calendar with 20 working days in the period.
- empLeave: 3 days APPROVED leave, 0 unauthorized absences, 17 present.
- empUnauth: 2 days UNAUTHORIZED absence (no leave request / rejected), 18 present.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | attendance_summary | |
| working days | 20 | BR-2 |
| empLeave unauthorized | 0 | 3 days approved leave excluded (BR-4) |
| empUnauth unauthorized | 2 | counted (BR-4) |
| empLeave absenteeism rate | 0% | approved leave not absence |
| empUnauth absenteeism rate | 10% | 2 / 20 × 100 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, generate Attendance Summary for the period | Report renders |
| 2 | Inspect empLeave's absenteeism contribution | 0% — the 3 approved-leave days are NOT counted as absence (BR-4) |
| 3 | Inspect empUnauth's absenteeism contribution | 10% (= 2 unauthorized / 20 working × 100) |
| 4 | Change empUnauth's 2 days to APPROVED leave; regenerate | empUnauth absenteeism drops to 0% — confirms approved leave is excluded |
| 5 | Reject one previously-approved leave day for empLeave; regenerate | That day now counts as unauthorized absence -> absenteeism rises accordingly |
| 6 | Confirm dept-level absenteeism rate aggregates only unauthorized days | Dept line-chart value reflects unauthorized absences only |

## 6. Postconditions
- Absenteeism reflects only unauthorized absences; approved leave excluded.
