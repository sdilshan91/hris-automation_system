# TC-RPT-003-04: Statutory Deductions Report — monthly totals + YTD cumulative across fiscal year; match payslip deductions (AC-3, BR-5)

## 1. Test Objective
Verify the "Statutory Deductions Report" lists all statutory deduction types (tax, social security,
pension fund, etc.) with MONTHLY totals and YEAR-TO-DATE cumulative amounts aggregated across the
tenant's fiscal year (BR-5), and that the totals reconcile exactly with payslip-level statutory
deductions. Validates AC-3, FR-1, BR-5, and the Test Hint "configure 3 statutory deduction types;
verify report totals match payslip-level deductions".

## 2. Related Requirements
- User Story: US-RPT-003
- Acceptance Criteria: AC-3
- Functional Requirements: FR-1, FR-2
- Business Rules: BR-1 (finalized only), BR-3 (statutory categories per tenant jurisdiction), BR-5 (fiscal-year aggregation)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Payroll.Export`.
- 3 statutory deduction types configured for Tenant A (per its jurisdiction, BR-3): Income Tax,
  Social Security, Pension Fund.
- FINALIZED runs exist for the fiscal months so far, with KNOWN per-type monthly totals, e.g. for
  the current month (2026-03): Income Tax=20,000, Social Security=10,000, Pension Fund=7,500.
- Tenant A's fiscal-year start is known (e.g. April or January) so YTD window is computable.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | StatutoryDeduction / statutory_deductions | valid key |
| payroll_period | 2026-03 | current month |
| Income Tax monthly | 20,000 | matches payslips |
| Social Security monthly | 10,000 | |
| Pension Fund monthly | 7,500 | |
| Income Tax YTD | sum of fiscal-year months to date | BR-5 cumulative |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, open Statutory tab; select current fiscal year; Generate | Report renders within SLA |
| 2 | Inspect the table rows | One row per statutory type (Income Tax, Social Security, Pension Fund) |
| 3 | Read the MONTHLY total column for 2026-03 | Income Tax=20,000, Social Security=10,000, Pension Fund=7,500 |
| 4 | Read the YEAR-TO-DATE cumulative column | Each YTD = sum of that type across all finalized months from fiscal-year start to current (BR-5) |
| 5 | Cross-check monthly totals against the sum of statutory line items on the month's payslips | Exact match — report = sum of payslip-level statutory deductions |
| 6 | Confirm draft/in-progress runs are excluded from monthly + YTD | Non-finalized runs contribute 0 (BR-1; see TC-RPT-003-09) |
| 7 | Confirm the report is downloadable for statutory submission | Download/export action available (export detail in US-RPT-004; here verify the affordance + format note) |

## 6. Postconditions
- Statutory report shows correct monthly + YTD figures reconciling to payslip deductions.
