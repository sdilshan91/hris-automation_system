# TC-RPT-003-10: Negative + boundary — invalid report_type / period format / out-of-tenant filters; 0 / single / full-fiscal-year runs

## 1. Test Objective
Verify input validation and boundary behavior for payroll reports: unknown report_type rejected
(400), malformed `payroll_period` rejected (400), out-of-tenant `department_ids`/`payroll_run_id`
treated as not-found (no leakage), and empty/edge populations handled gracefully — zero finalized
runs, exactly one run, and a full fiscal year of statutory aggregation. Validates AC-1/AC-3 input
validation (Data Requirements §7), FR-2, BR-5, and the boundary Test Hints.

## 2. Related Requirements
- User Story: US-RPT-003
- Acceptance Criteria: AC-1, AC-3, AC-5 (out-of-tenant filter handling)
- Functional Requirements: FR-1, FR-2 (filters), FR-4
- Business Rules: BR-1, BR-5 (fiscal-year aggregation boundary)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Payroll.Export`.
- A tenant/period with ZERO finalized runs available for the empty-state check (e.g. 2025-01).
- A period with exactly ONE finalized run (2026-03).
- A full fiscal year of finalized runs for the statutory YTD boundary.
- A `department_id` and a `payroll_run_id` that belong to a DIFFERENT tenant (Tenant B).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| invalid report_type | "totallyNotAReport" | → 400 (Data Req §7 valid key) |
| malformed payroll_period | "2026/03", "March", "2026-13" | → 400 (format YYYY-MM) |
| out-of-tenant department_id | uuid of Tenant B dept | → not-found / empty, no leakage |
| out-of-tenant payroll_run_id | uuid of Tenant B run | → not-found |
| empty period | 2025-01 (0 finalized runs) | empty-state |
| single run period | 2026-03 (1 run) | boundary |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, request report_type="totallyNotAReport" | 400 Bad Request, "Unknown report type"; no report produced |
| 2 | Request Run Summary with payroll_period="2026/03" then "2026-13" | 400 — period must match YYYY-MM with a valid month |
| 3 | Request Run Summary with empty/0-finalized-run period (2025-01) | Empty-state: zeros / "no finalized runs", NO error, NO previous-month error (MoM degrades gracefully) |
| 4 | Pass an out-of-tenant `department_id` (Tenant B dept) as a filter | Treated as not-found / yields empty — NEVER returns Tenant B salary data (AC-5; see TC-RPT-ISO-010) |
| 5 | Pass an out-of-tenant `payroll_run_id` (Tenant B run) | Not-found; no Tenant B data surfaced |
| 6 | Generate Run Summary for the single-run period | Renders with that one run; MoM comparison handles "no prior finalized month" gracefully |
| 7 | Generate Statutory report for a FULL fiscal year | YTD equals the sum across all 12 finalized months; fiscal-year start/end honored (BR-5) |

## 6. Postconditions
- Invalid inputs rejected; out-of-tenant filters leak nothing; empty/single/full-year boundaries handled.
