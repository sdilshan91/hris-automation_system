# TC-RPT-004-06: Tenant-scoped download -- Tenant B downloading Tenant A's export -> 403; signed-URL 15-min expiry DEFERRED (AC-5, FR-6/7, NFR-3/4)

## 1. Test Objective
Verify the implemented isolation on `GET /api/v1/reports/exports/{exportId}/download`: a user from
Tenant B requesting Tenant A's exportId is rejected (cross-tenant access denied), the file is stored
in a tenant-isolated path, and a legitimate Tenant A user with `Reports.Export` succeeds. The
cryptographic signed-URL with 15-minute expiry (FR-7 / NFR-4) is DEFERRED -- assert the
authenticated tenant-scoped endpoint behavior that IS implemented; assert the signed/expiry steps
CONDITIONALLY. Validates AC-5, FR-6, NFR-3, and (conditionally) FR-7 / NFR-4.

## 2. Related Requirements
- User Story: US-RPT-004
- Acceptance Criteria: AC-5
- Functional Requirements: FR-6 (tenant-isolated storage path), FR-7 (signed URL -- deferred)
- Non-Functional: NFR-3 (cross-tenant -> 403), NFR-4 (15-min signed expiry -- deferred)

> CONDITIONAL / DEFERRED INFRA: FR-7 cryptographic signed URLs + NFR-4 15-minute expiry are DEFERRED.
> What IS implemented today is an AUTHENTICATED, tenant-scoped `/exports/{exportId}/download` endpoint
> (auth + tenant context + `Reports.Export`) plus the BR-3 7-day retention purge. Assert the
> tenant-403 + retention behavior. Steps 5-6 (15-min signed-URL expiry) are run ONLY if signed URLs
> are wired; otherwise mark pending. Do NOT relax the tenant-403 expectation to compensate.

## 3. Preconditions
- Tenant A and Tenant B active. `hrA` (Tenant A, `Reports.Export`) and `hrB` (Tenant B, `Reports.Export`).
- An export generated in Tenant A with exportId `EXP-A-1`, file stored under `{tenantA}/exports/...` (FR-6).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| exportId | EXP-A-1 | belongs to Tenant A |
| storage path | {tenantA}/exports/headcount_summary/2026/06/EXP-A-1.csv | tenant-isolated (FR-6) |
| expected cross-tenant | 403 (or 404 if existence hidden) | NFR-3 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hrA`, `GET /api/v1/reports/exports/EXP-A-1/download` | 200; the correct file streams (own-tenant happy path) |
| 2 | As `hrB`, `GET /api/v1/reports/exports/EXP-A-1/download` (Tenant A's id) | Rejected -- 403 Forbidden (NFR-3); no bytes of A's file returned |
| 3 | Inspect the stored object path for EXP-A-1 | Begins with Tenant A's id segment: `{tenantA}/exports/...` (FR-6 tenant-isolated storage) |
| 4 | As `hrB`, confirm A's export is invisible in B's history | `GET /reports/exports` for `hrB` does NOT list EXP-A-1 |
| 5 | (CONDITIONAL -- signed URLs wired) Tamper/alter the signed URL token for EXP-A-1 | Download rejected (invalid signature). Pending if signed URLs not wired |
| 6 | (CONDITIONAL -- expiry wired, NFR-4) Wait > 15 min, retry the signed URL | 410 Gone / link-expired. Pending if expiry not wired -- do NOT fail the case |

## 6. Postconditions
- Cross-tenant download blocked (403); file stored tenant-isolated; signed-URL/expiry steps recorded pending if deferred.
