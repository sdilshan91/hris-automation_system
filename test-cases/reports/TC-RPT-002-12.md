# TC-RPT-002-12: Charts have alt text + table alternative; keyboard nav; responsive 360px–4K with sticky first column (NFR-4, NFR-5)

## 1. Test Objective
Verify the Leave & Attendance report UI meets WCAG 2.1 AA (NFR-5): every chart (bar/grouped-bar/
donut/line, calendar heat-map) exposes a text alternative AND a togglable data-table view; the UI is
keyboard-navigable with visible focus; color-coded balance bands are not conveyed by color alone; and
the layout is responsive 360px–4K (NFR-4) with charts stacking and tables horizontally scrollable with
a sticky first column (employee name) on mobile.

> PLATFORM NOTE / CONDITIONAL: WCAG verification needs the built UI + an axe/keyboard pass. Run on
> built artifacts; if the UI isn't built yet these are forward-looking acceptance criteria.

## 2. Related Requirements
- User Story: US-RPT-002
- Acceptance Criteria: AC-1, AC-2, AC-3
- Functional Requirements: FR-5 (chart + data-table toggle)
- Non-Functional: NFR-4 (responsive 360px–4K), NFR-5 (WCAG 2.1 AA)

## 3. Preconditions
- The Leave & Attendance Reports UI is built and reachable as `hr1` (Reports.View.All).
- An axe (or equivalent) a11y scanner and a screen reader available; viewport-resizing tooling available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| viewports | 360px, 768px, 1280px, 4K | NFR-4 range |
| charts under test | leave-type bar, dept grouped-bar, leave-type donut, absenteeism line, calendar heat-map | AC-1/AC-3 + UI/UX |
| color bands | green/yellow/red balance cells | AC-2 — must not rely on color alone |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run an automated a11y scan on each report tab | No WCAG 2.1 AA violations (contrast, names, roles, ARIA) |
| 2 | Inspect each chart for a text alternative | Each chart has an accessible name/description (alt text / aria-label / summary) conveying its data |
| 3 | Toggle the data-table view for each chart (FR-5) | A semantic data table presents the same data as a non-visual alternative |
| 4 | Verify balance color bands aren't color-only (AC-2) | Each green/yellow/red cell also carries text/icon/aria (e.g. "12 (54%)") so the band is perceivable without color |
| 5 | Navigate the whole report (tabs, filters, drill-down panel) with keyboard only | All controls reachable/operable; focus order logical; focus visible; slide-out drill-down is keyboard-dismissible |
| 6 | Verify with a screen reader | Chart names, table headers, and filter labels are announced meaningfully |
| 7 | Resize to 360px | Charts stack vertically; tables become horizontally scrollable; first column (employee name) is STICKY (UI/UX, NFR-4) |
| 8 | Resize across 768px, 1280px, 4K | Layout adapts cleanly with no clipping/overflow at any width |

## 6. Postconditions
- Report UI is accessible and responsive; charts have alt text + table alternative; bands not color-only.
