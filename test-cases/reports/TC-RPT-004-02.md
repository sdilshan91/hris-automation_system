# TC-RPT-004-02: Excel async (>=1000 rows) -- Hangfire .xlsx via ClosedXML; header (title+filters+timestamp) + formatted table; SignalR ready notification (AC-2, FR-3/5/8)

## 1. Test Objective
Verify that selecting "Excel" for a report with >= 1000 rows routes to ASYNC generation: a Hangfire
background job builds an .xlsx via ClosedXML containing a header block with report title, the filters
applied, and a generation timestamp, plus a formatted data table with column headers; and that on
completion the user receives an in-app SignalR notification carrying a download link. Validates AC-2,
FR-3, FR-5 (async routing), FR-8.

## 2. Related Requirements
- User Story: US-RPT-004
- Acceptance Criteria: AC-2
- Functional Requirements: FR-3 (ClosedXML .xlsx), FR-5 (>=1000 rows -> async), FR-8 (SignalR notify)
- Business Rules: BR-6 ("Filters Applied" header)
- Dependencies: US-NTF-001 (SignalR), Hangfire

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Reports.Export`; a SignalR connection established.
- A report exists with KNOWN row count >= 1000 (e.g. 1,500 employees) and a known filter set.
- Hangfire worker running.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | headcount_summary | valid key |
| format | xlsx | Excel |
| row_count | 1500 | >=1000 -> async (FR-5) |
| filters | {as_of:2026-06-01, location:"HQ"} | shown in header (BR-6) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, select Excel on the 1,500-row report | `POST /reports/headcount_summary/export {format:"xlsx",...}` returns `{exportId, status:"Queued", rowCount:1500, format:"xlsx"}` (FR-5 async) |
| 2 | Inspect the job backend | A Hangfire job is enqueued for the export (not generated inline) |
| 3 | UI state while queued | A progress indicator "Generating export..." is shown (UI/UX S8); the report view stays interactive (NFR-6) |
| 4 | Wait for job completion; observe the SignalR channel | A `ReceiveNotification` push arrives for `hr1` with a message like "Your Excel export is ready" + a download link (FR-8) |
| 5 | Open the produced .xlsx (ClosedXML) header block | Contains report title, a "Filters Applied" section listing as_of=2026-06-01 + location=HQ (BR-6), and a generation timestamp |
| 6 | Inspect the data sheet | A formatted table: bold/styled column headers + 1,500 data rows matching the report |
| 7 | Confirm includeCharts handling | If `includeCharts:true` and a chart applies, a chart sheet is present; if not applicable, table-only (AC-2 "if applicable") |

## 6. Postconditions
- .xlsx generated async via Hangfire/ClosedXML; SignalR ready notification delivered with a download link.
