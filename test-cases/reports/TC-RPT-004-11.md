# TC-RPT-004-11: Performance -- sync CSV <2s (NFR-1); async export <60s @ 50k rows (NFR-2); export does not degrade interactive viewing (NFR-6)

## 1. Test Objective
Verify export performance budgets: a synchronous CSV export of a < 1000-row report completes within
2 seconds (NFR-1); an asynchronous export of 50,000 rows completes within 60 seconds end-to-end
(enqueue -> file ready -> SignalR notify) (NFR-2); and triggering exports does not degrade interactive
report viewing because work runs in Hangfire (NFR-6). Validates NFR-1, NFR-2, NFR-6.

## 2. Related Requirements
- User Story: US-RPT-004
- Acceptance Criteria: AC-2, AC-4
- Non-Functional: NFR-1 (<2s sync CSV <1000), NFR-2 (<60s async @ 50k), NFR-6 (no viewer degradation)

> CONDITIONAL / ENVIRONMENT: NFR thresholds require a perf-representative environment. On a dev box,
> record indicative numbers and flag as conditional -- do NOT relax the 2s / 60s thresholds to make a
> slow dev box pass (consistent with prior Reports perf TCs).

## 3. Preconditions
- Tenant A with a 999-row dataset and a 50,000-row dataset; `hr1` has `Reports.Export`.
- Hangfire worker running; perf-representative environment (else mark conditional).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| sync CSV rows | 999 | <1000 (NFR-1) |
| async rows | 50,000 | NFR-2 budget |
| sync budget | <= 2s | NFR-1 |
| async budget | <= 60s end-to-end | NFR-2 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, export the 999-row report to CSV; time request->file | Completes within 2s (NFR-1) |
| 2 | Export the 50,000-row report (async); time enqueue->SignalR-ready | Completes within 60s end-to-end (NFR-2) |
| 3 | While the 50k async job runs, interact with the report view (filter/page) | Interactive viewing stays responsive; no UI block (NFR-6) |
| 4 | Repeat the sync export a few times; record P95 | P95 within budget (NFR-1) |
| 5 | (CONDITIONAL) On a dev box, record indicative timings | Numbers logged; thresholds NOT relaxed; flagged pending a perf env |

## 6. Postconditions
- Sync CSV within 2s, async 50k within 60s on a representative env; viewer unaffected during export.
