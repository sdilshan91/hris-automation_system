# TC-RPT-005-12: A11y -- ARIA landmarks + screen-reader-announced metric values (NFR-5); responsive 1/2/4-col grid at 360/768/1280/1920px (NFR-4)

## 1. Test Objective
Verify WCAG 2.1 AA accessibility and responsiveness of the dashboard: widget cards expose ARIA landmarks/roles,
screen readers announce each metric's label + value + trend (trend not conveyed by color/arrow alone), the
greeting and Refresh control are keyboard-reachable, and the widget grid adapts from 1 column (mobile) to 2
(tablet) to 4 (desktop) across 360/768/1280/1920px. Validates AC-1, AC-2, AC-3, FR-2, NFR-4, NFR-5.

## 2. Related Requirements
- User Story: US-RPT-005
- Acceptance Criteria: AC-1, AC-2, AC-3
- Functional Requirements: FR-2 (mini visualizations)
- Non-Functional: NFR-4 (responsive 360px-4K, 1/2/4-col grid), NFR-5 (WCAG 2.1 AA, ARIA, SR-friendly metric values)
- UI/UX: S8 (grid breakpoints; sparkline/donut/progress)

## 3. Preconditions
- Tenant A active; HR Officer `hr1` authenticated on the dashboard with a populated widget set.
- Screen reader (NVDA/VoiceOver) and axe-core/Lighthouse available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| breakpoints | 360 / 768 / 1280 / 1920 px | mobile / tablet / desktop / large |
| grid columns | 1 / 2 / 4 / 4 | NFR-4 / UI/UX S8 |
| trend cue | text + icon (not color-only) | NFR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run axe-core/Lighthouse on the dashboard | no WCAG 2.1 AA violations; contrast ratios pass for KPI values and trend indicators (NFR-5) |
| 2 | Inspect widget cards in the a11y tree | each card has an ARIA landmark/role and an accessible name (label) (NFR-5) |
| 3 | Navigate with a screen reader | each widget announces its label + numeric value + trend (e.g. "Total Headcount, 50, up 10 percent") -- value not conveyed by chart alone (NFR-5) |
| 4 | Confirm trend is not color-only | up/down is conveyed by text/icon + accessible name, not solely the green/red arrow (NFR-5) |
| 5 | Tab through the dashboard | greeting, Refresh button, and clickable widgets are keyboard-reachable with visible focus; Enter activates click-through (NFR-5) |
| 6 | Resize to 360px | single-column stacked grid (NFR-4 / UI/UX S8) |
| 7 | Resize to 768px | 2-column grid (NFR-4) |
| 8 | Resize to 1280px and 1920px | 4-column grid at both; no clipping/overflow at 1920px (NFR-4) |
| 9 | Spot-check Chrome, Edge, Firefox, Safari | layout + announcements consistent cross-browser |

## 6. Postconditions
- Dashboard meets WCAG 2.1 AA and adapts grid 1/2/4 columns across the tested breakpoints.
