# TC-RPT-003-08: Cost-to-Company (CTC) Analysis includes employer contributions on top of gross (BR-6)

## 1. Test Objective
Verify the "Cost-to-Company Analysis" report computes CTC as gross pay PLUS employer contributions
(employer-side pension, insurance, etc.), so CTC exceeds the employee-facing gross. Validates BR-6,
FR-1 (CTC report), and AC-1's currency/format expectations.

## 2. Related Requirements
- User Story: US-RPT-003
- Acceptance Criteria: AC-1 (CTC is part of the payroll-report suite per FR-1; CTC formula per BR-6)
- Functional Requirements: FR-1, FR-2, FR-5
- Business Rules: BR-1 (finalized only), BR-2 (currency), BR-6 (CTC = gross + employer contributions)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Payroll.Export`.
- A FINALIZED 2026-03 run with KNOWN gross and KNOWN employer-side contributions, e.g.:
  total gross=250,000.00; employer pension=20,000.00; employer insurance=10,000.00;
  expected total CTC=280,000.00.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | Ctc / cost_to_company | valid key |
| payroll_period | 2026-03 | |
| total gross | 250,000.00 | employee-facing |
| employer pension | 20,000.00 | employer contribution (BR-6) |
| employer insurance | 10,000.00 | employer contribution (BR-6) |
| expected total CTC | 280,000.00 | gross + employer contributions |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, open CTC Analysis tab; payroll_period=2026-03; Generate | Report renders |
| 2 | Read total CTC | 280,000.00 (= 250,000.00 gross + 30,000.00 employer contributions, BR-6) |
| 3 | Inspect the CTC breakdown | Shows gross PLUS each employer-side contribution line (employer pension 20,000, employer insurance 10,000) |
| 4 | Confirm CTC is strictly GREATER than gross | 280,000.00 > 250,000.00 — employer contributions added, not subtracted |
| 5 | Verify employee deductions do NOT reduce CTC | Statutory/voluntary employee deductions are NOT subtracted from CTC (they are inside gross→net, separate from employer cost) |
| 6 | Confirm figures use tenant currency and exclude non-finalized runs | Correct symbol/decimals (BR-2); draft runs excluded (BR-1) |

## 6. Postconditions
- CTC = gross + employer contributions; breakdown correct; finalized-only.
