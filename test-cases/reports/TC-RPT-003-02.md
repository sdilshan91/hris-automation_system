# TC-RPT-003-02: Run Summary month-over-month comparison — variance highlighting increase=red / decrease=green (AC-1, FR-3)

## 1. Test Objective
Verify the Payroll Run Summary shows a month-over-month comparison (current vs previous period) and
that variance is highlighted per FR-3: an INCREASE renders red, a DECREASE renders green. The
comparison bar chart shows current and previous month side by side, and the KPI cards carry a
comparison arrow (up/down). Validates AC-1 (comparison chart), FR-3, and the Test Hint "two
consecutive months → correct variances".

## 2. Related Requirements
- User Story: US-RPT-003
- Acceptance Criteria: AC-1
- Functional Requirements: FR-3, FR-5
- Business Rules: BR-1, BR-2

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Payroll.Export`.
- Two consecutive FINALIZED runs with KNOWN, DIFFERENT totals:
  - 2026-02: gross=240,000.00, net=198,000.00, count=49.
  - 2026-03: gross=250,000.00, net=205,000.00, count=50.
- Net pay went UP month-over-month (+7,000.00); use a deduction figure that goes DOWN to exercise the
  green path (e.g. voluntary deductions 8,200.00 → 7,500.00).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| payroll_period (current) | 2026-03 | |
| previous period (derived) | 2026-02 | system computes prior month |
| gross variance | +10,000.00 | increase → RED |
| net variance | +7,000.00 | increase → RED |
| voluntary deduction variance | −700.00 | decrease → GREEN |
| count variance | +1 | up arrow |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, generate Run Summary for 2026-03 | Report renders; previous-period column = 2026-02 |
| 2 | Inspect the dual/side-by-side comparison bar chart | Two series shown: current (2026-03) and previous (2026-02) for each metric |
| 3 | Read the Total Gross variance indicator | +10,000.00 increase highlighted RED (FR-3) with an up arrow |
| 4 | Read the Total Net variance indicator | +7,000.00 increase highlighted RED with an up arrow |
| 5 | Read the Voluntary Deductions variance indicator | −700.00 decrease highlighted GREEN (FR-3) with a down arrow |
| 6 | Read the Employee Count comparison arrow | +1 up arrow vs previous month |
| 7 | Verify the previous-month figures equal the 2026-02 finalized run | 240,000.00 / 198,000.00 / 49 exactly |
| 8 | Verify color is not the ONLY signal (icon/text accompanies) | Increase/decrease conveyed by arrow + sign too (a11y, see TC-RPT-003-12) |

## 6. Postconditions
- MoM comparison rendered with correct variance values and red/green highlighting.
