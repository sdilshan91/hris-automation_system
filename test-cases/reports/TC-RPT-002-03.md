# TC-RPT-002-03: Attendance Summary — attendance rate = present/working×100 (18/20 = 90%); late/early counts (AC-3, FR-4)

## 1. Test Objective
Verify the Attendance Summary report computes total working days, attendance rate
(= present days / working days × 100), late-arrival count, early-departure count, overtime hours by
department (bar), and absenteeism rate per department (line). Validates AC-3, FR-4, and the Test
Hint "20 working days, 18 present, 2 absent -> attendance rate = 90%".

## 2. Related Requirements
- User Story: US-RPT-002
- Acceptance Criteria: AC-3
- Functional Requirements: FR-1, FR-4, FR-5
- Business Rules: BR-2 (working days from working calendar), BR-3 (overtime), BR-4 (absenteeism)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Reports.View.All`.
- A working calendar configured (BR-2): the current month has 20 working days (weekends/holidays excluded).
- Seeded employee `empAtt`: 18 present days, 2 absent days within the 20 working days.
- Known late arrivals and early departures (e.g. 3 late, 1 early) and known overtime hours per dept.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | attendance_summary | |
| period | current month | per AC-3 |
| working days | 20 | from working calendar (BR-2) |
| present days | 18 | seeded |
| expected attendance rate | 90% | 18 / 20 × 100 (FR-4) |
| late arrivals | 3 | seeded |
| early departures | 1 | seeded |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, open Attendance Summary tab; Generate for current month | Report renders within SLA |
| 2 | Read total working days | 20 (matches working calendar; weekends/holidays excluded per BR-2) |
| 3 | Read attendance rate | 90% (= 18 / 20 × 100 per FR-4) |
| 4 | Read late-arrivals count | 3 (matches seeded) |
| 5 | Read early-departures count | 1 (matches seeded) |
| 6 | Read the overtime-hours-by-department bar chart | Per-dept overtime = sum of hours exceeding shift standard (BR-3); matches seeded totals |
| 7 | Read the absenteeism-rate-per-department line chart | Per-dept absenteeism excludes approved leave (BR-4); only unauthorized absences counted |
| 8 | Toggle data-table view; confirm tenant-scoped, read-only | Same numbers tabularly; Tenant A only; no data mutated |

## 6. Postconditions
- Attendance metrics correct; no data mutated.
