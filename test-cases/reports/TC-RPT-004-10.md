# TC-RPT-004-10: Negative -- invalid format, invalid report_type, missing/expired download, no Reports.Export -> 403 (FR-1/2, AC-5)

## 1. Test Objective
Verify defensive handling of bad export input and authorization: an unsupported `format` is rejected
(400), an unknown `report_type` is rejected (400/404 valid-key validation), a download for a missing
or expired exportId returns gone/expired (404/410), and a user WITHOUT `Reports.Export` is denied
(403) on both the export-trigger and download endpoints. Validates the negative paths around FR-1
(three formats only), the report-type validation (Data Req), and AC-5 authorization.

## 2. Related Requirements
- User Story: US-RPT-004
- Acceptance Criteria: AC-1, AC-5
- Functional Requirements: FR-1 (csv/xlsx/pdf only)
- Data Requirements: report_type must be a valid report key; format in {csv,xlsx,pdf}

## 3. Preconditions
- Tenant A active. `hr1` has `Reports.Export`; `viewer1` has `Reports.View` but NOT `Reports.Export`.
- A valid generated report exists for legitimate-trigger checks.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| invalid format | "txt" / "json" | not in {csv,xlsx,pdf} |
| invalid report_type | "not_a_report" | not a valid key |
| missing exportId | "EXP-DOES-NOT-EXIST" | never created |
| denied user | viewer1 | lacks Reports.Export |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, `POST /reports/headcount_summary/export {format:"txt"}` | 400 Bad Request -- unsupported format; error names allowed set {csv,xlsx,pdf} (FR-1) |
| 2 | As `hr1`, `POST /reports/not_a_report/export {format:"csv"}` | 400/404 -- invalid report_type rejected (valid-key validation) |
| 3 | As `hr1`, `GET /reports/exports/EXP-DOES-NOT-EXIST/download` | 404 Not Found (missing export) |
| 4 | As `hr1`, attempt download of an EXPIRED/purged exportId | Gone/expired (404/410) -- no stale file served |
| 5 | As `viewer1` (no Reports.Export), `POST /reports/headcount_summary/export` | 403 Forbidden -- export permission required |
| 6 | As `viewer1`, `GET /reports/exports/{anyId}/download` | 403 Forbidden -- download also gated on Reports.Export |
| 7 | Confirm no partial/empty file is produced on any rejected request | No artifact created for invalid/denied requests |

## 6. Postconditions
- Bad format/type and missing/expired downloads rejected; users without Reports.Export denied (403).
