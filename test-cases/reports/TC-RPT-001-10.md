# TC-RPT-001-10: Date-range and empty-population boundaries (single day, full fiscal year, 0 employees)

## 1. Test Objective
Verify report behavior at boundary conditions: a single-day date range, a full fiscal-year range
respecting the tenant's fiscal-year start (BR-6), and a tenant/filter combination that yields 0
employees. Confirms no off-by-one on range edges, no divide-by-zero in turnover when average
headcount is 0, and a clean empty-state rendering.

## 2. Related Requirements
- User Story: US-RPT-001
- Acceptance Criteria: AC-2, AC-3, AC-4
- Functional Requirements: FR-2 (date range filter), FR-3, FR-4
- Business Rules: BR-3 (turnover formula), BR-6 (fiscal year start)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Reports.View.All`.
- Tenant A fiscal year start is configured (e.g. April 1).
- A known hire/separation falls exactly on a boundary date for the single-day test.
- A department/filter combination exists that matches zero employees (e.g. an empty department).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| single-day range | date_from = date_to = 2026-03-31 | inclusive both ends |
| fiscal-year range | 2025-04-01 .. 2026-03-31 | per BR-6 fiscal start April 1 |
| empty filter | department = "Empty Dept" | 0 matching employees |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Generate Headcount Summary with date_from = date_to = a single day | Report computes for that one day inclusively; an event ON that date is included (no off-by-one); no error |
| 2 | Generate Employee Turnover for the full fiscal year (2025-04-01..2026-03-31) | Period boundaries honor the tenant's fiscal-year start (BR-6); start and end days both inclusive; annual comparison anchored to fiscal start |
| 3 | Generate Employee Turnover for a period where average headcount = 0 | No divide-by-zero error; rate shown as 0% or "N/A" with separations = 0 (defined, graceful) |
| 4 | Generate any report filtered to the empty department (0 employees) | Clean empty state: charts show "no data"/empty, table shows zero rows, totals = 0; no crash or NaN |
| 5 | Generate Demographics with 0 matching employees | Empty charts render gracefully; no NaN percentages in the gender pie |
| 6 | Set date_from > date_to (inverted range) | Validation error / rejected; not silently swapped or returning bogus data |

## 6. Postconditions
- Boundary ranges and empty populations handled without errors or off-by-one/divide-by-zero defects.
