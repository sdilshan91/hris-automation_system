# TC-RPT-004-12: Accessibility -- export button/menu keyboard operable + screen-reader labelled; overflow menu < 768px; async progress + ready toast announced (NFR-5)

## 1. Test Objective
Verify WCAG 2.1 AA for the export UI: the Export button and its format dropdown are fully keyboard
operable (focus, Enter/Space, arrow navigation, Esc to close) with correct ARIA roles/labels and
visible focus; on mobile (< 768px) the export action is reachable via the three-dot overflow menu; and
the async "Generating export..." progress state and the completion toast ("Your [format] export is
ready. [Download]") are announced to assistive tech. Validates NFR-5, AC-1, AC-2 (notify UX),
UI/UX S8.

## 2. Related Requirements
- User Story: US-RPT-004
- Acceptance Criteria: AC-1, AC-2
- Non-Functional: NFR-5 (WCAG 2.1 AA; responsive + accessible)
- UI/UX: S8 (overflow menu < 768px; progress indicator; completion toast with download link)

## 3. Preconditions
- Tenant A active; `hr1` has `Reports.Export`; a generated report open.
- Keyboard-only and screen-reader (NVDA/VoiceOver) test setups; viewport switchable to 360px.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| mobile breakpoint | < 768px | overflow (three-dot) menu |
| min viewport | 360px | responsive floor |
| toast text | "Your [format] export is ready. [Download]" | accessible link |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Tab to the Export button using keyboard only | Receives visible focus; exposed as a button with an accessible name (NFR-5) |
| 2 | Press Enter/Space | Dropdown opens; focus moves into the menu; options have role/menuitem semantics |
| 3 | Arrow-navigate CSV/Excel/PDF; press Enter on one; press Esc on reopen | Arrow keys move focus; Enter selects + triggers export; Esc closes and returns focus to the button |
| 4 | Run a screen reader over the menu | Each format option announces its name + type (not icon-only / not color-only) |
| 5 | Resize viewport below 768px | Export button collapses into the three-dot overflow menu; export still reachable + keyboard operable (UI/UX S8) |
| 6 | Trigger an async export; observe the progress state | "Generating export..." status is announced (aria-live / role=status), not visual-only |
| 7 | On completion, observe the toast | "Your [format] export is ready. [Download]" announced; the Download link is keyboard-focusable + activatable |
| 8 | Check contrast of button/menu/toast + focus indicators down to 360px | Meets WCAG 2.1 AA contrast; no horizontal clipping at 360px |

## 6. Postconditions
- Export UI keyboard + screen-reader accessible; overflow menu works < 768px; progress/ready announced.
