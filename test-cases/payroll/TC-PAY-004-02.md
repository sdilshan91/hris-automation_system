# TC-PAY-004-02: Download a single payslip PDF and "Download All" -> ZIP archive of all run payslips (AC-3, FR-6)

## 1. Test Objective
Verify AC-3 and FR-6: after payslips are generated, HR can download an individual employee's payslip PDF via the single-download endpoint, and "Download All" produces a ZIP archive containing every generated payslip for the run. The ZIP entries use the BR-5 filename format, the single-download returns the correct PDF with `Content-Type: application/pdf`, and the bulk download is offered as an async job whose result link is delivered to HR (per UI/UX notes); the enqueue + completion are asserted, delivery via the Notification System is CONDITIONAL.

## 2. Related Requirements
- User Story: US-PAY-004
- Acceptance Criteria: AC-3
- Functional Requirements: FR-6
- Business Rules: BR-5 (filename format)

## 3. Preconditions
- Run R (acme, May 2026) with 3 payslips generated (TC-PAY-004-01); HR Maya authenticated with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Single download | GET /api/v1/payroll/runs/{R}/slips/{EMP-001}/pdf | FR-6 single |
| Bulk download | POST /api/v1/payroll/runs/{R}/slips/download-all | FR-6 ZIP |
| ZIP entry name | {EmployeeNo}_5_2026.pdf | BR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Click "View/Download" on EMP-001's row -> single-download endpoint. | 200 OK; `Content-Type: application/pdf`; body is EMP-001's PDF (matches the stored blob at `{acmeTenantId}/payroll/{R}/{EMP-001}.pdf`). |
| 2 | Click "Download All" on the run detail. | A ZIP-generation job is enqueued (UI shows estimated ZIP size + async indicator, per UI/UX notes); accepted response with a tracking handle. |
| 3 | Wait for ZIP completion; obtain the download link. | ZIP available; a download link is delivered to HR (delivery via Notification System CONDITIONAL -- enqueue/availability asserted). |
| 4 | Download and open the ZIP. | ZIP contains exactly 3 entries -- one per generated payslip; each entry name follows BR-5 `{EmployeeNo}_5_2026.pdf`; each extracted file is a valid PDF matching the stored blob. |
| 5 | Request single download for an employee whose PDF is NOT yet generated (pdf_status=Pending/null). | 404/409 with a clear "payslip not generated" message; no empty/partial file returned. |
| 6 | Verify Download All on a run with zero generated PDFs. | Returns a clear "no payslips generated yet" response; no empty ZIP silently downloaded. |

## 6. Postconditions
- Individual and bulk download paths both serve only generated, tenant-scoped PDFs; ZIP entries are BR-5-named.
