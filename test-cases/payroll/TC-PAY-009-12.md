# TC-PAY-009-12: Accessibility + responsive -- reports sidebar, filter panel, charts, bank-advice preview, export toolbar WCAG 2.1 AA; 360-1920

## 1. Test Objective
Verify NFR + S8 UI/UX: the Payroll Reports experience -- the Notion-style report-type sidebar, the filter/configuration panel, the analytics charts (monthly trend line, department pie, statutory stacked bar, department bar), the bank-advice preview table, and the export toolbar (CSV/Excel/PDF icon buttons) -- conforms to WCAG 2.1 AA (keyboard operability, screen-reader semantics, colour contrast, non-colour-only encoding) and renders responsively from 360px to 1920px, with detailed tables deferring to desktop and charts remaining viewable on mobile.

## 2. Related Requirements
- User Story: US-PAY-009
- Acceptance Criteria: AC-1, AC-2, AC-4
- Functional Requirements: FR-1, FR-2, FR-5
- Non-Functional Requirements: NFR-6
- Business Rules: BR-2

## 3. Preconditions
- Tenant "acme"; a generated Payroll Summary Report + analytics dashboard + bank-advice preview available.
- Keyboard-only and screen-reader (NVDA/VoiceOver) test setup; axe-core available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360, 768, 1280, 1920 px | responsive range |
| WCAG | 2.1 AA | target |
| Tools | keyboard-only, screen reader, axe-core | a11y checks |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate the report-type sidebar by keyboard (Tab/arrow/Enter). | All report types are reachable + selectable by keyboard; focus order is logical; focus is visible; selected item has an accessible state (WCAG 2.1.1, 2.4.7). |
| 2 | Operate the filter/configuration panel (period, department, etc.) by keyboard + screen reader. | Each control has a programmatic label; values + validation errors are announced; the panel is fully keyboard-operable (WCAG 1.3.1, 4.1.2, 3.3.1). |
| 3 | Inspect the charts (trend line, pie, stacked bar, department bar). | Charts expose an accessible text alternative / data table; information is not conveyed by colour alone (legends + labels/patterns); tooltips reachable (WCAG 1.1.1, 1.4.1, NFR-6). |
| 4 | Inspect the bank-advice preview table. | Table has proper header associations; masked account values are announced as masked; export/download controls are labelled (WCAG 1.3.1; BR-2 masking preserved). |
| 5 | Operate the export toolbar (CSV/Excel/PDF icon buttons) by keyboard. | Each icon button has an accessible name; activatable by keyboard; not colour/icon-only without a label (WCAG 4.1.2, 1.1.1). |
| 6 | Render at 360 / 768 / 1280 / 1920 px; run axe-core. | Layout adapts without loss of content/functionality; charts viewable on mobile; detailed tables horizontally scroll/defer to desktop; no critical axe violations; contrast >= 4.5:1 (WCAG 1.4.3, 1.4.10). |

## 6. Postconditions
- The reports sidebar, filter panel, charts, bank-advice preview, and export toolbar meet WCAG 2.1 AA and are responsive 360-1920px.
