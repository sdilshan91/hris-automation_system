# TC-PAY-005-01: My Payslips list shows only Finalized-run payslips, sorted most-recent-first, with Pay Period / Gross / Deductions / Net (happy path)

## 1. Test Objective
Verify AC-1 / FR-1 / FR-2 / BR-1: an authenticated Employee with `Payroll.Read.Self` opens the "My Payslips" page from the self-service portal; the list shows ALL of the employee's payslips that belong to Finalized payroll runs only, sorted by pay period descending (most recent first), each row showing Pay Period (month/year), Gross Earnings, Total Deductions, and Net Salary, plus paid/LOP days and a PDF-available indicator. The query is scoped to the authenticated employee within the active tenant (FR-8, application-level `employee_id` + EF tenant filter).

## 2. Related Requirements
- User Story: US-PAY-005
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-2, FR-8
- Business Rules: BR-1
- Data Requirements: S7 (payroll_slip), API Response - Payslip List (items[]: payslipId, payMonth, payYear, grossEarnings, totalDeductions, netSalary, paidDays, lopDays, pdfAvailable; totalCount, page, pageSize)

## 3. Preconditions
- Tenant "acme" Active, subdomain `acme.yourhrm.com`, Payroll module enabled.
- Employee "Nadia Perera" (EMP-001) authenticated in acme with `Payroll.Read.Self` and active tenant membership.
- EMP-001 has payslips across several months: at least 3 from Finalized runs (e.g. Mar/Apr/May 2026) and at least 1 from a ReviewPending or Approved run (e.g. Jun 2026) which must NOT appear.
- Payslip PDFs generated for the Finalized runs (US-PAY-004).

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Log in as EMP-001; click "My Payslips" in the self-service sidebar. | The My Payslips page loads (FR-1); a loading skeleton shows then resolves to the payslip list. |
| 2 | Inspect the returned list. | Exactly the Finalized-run payslips for EMP-001 are listed (Mar, Apr, May 2026); the Jun 2026 ReviewPending slip is absent (BR-1, FR-2). |
| 3 | Verify sort order. | Rows ordered by pay period descending: May, Apr, Mar (most recent first, AC-1). |
| 4 | Verify each row's columns. | Each row shows Pay Period, Gross Earnings, Total Deductions, Net Salary (right-aligned numerics); the May row shows 50000.00 / 8500.00 / 41500.00; paid days 22, LOP 0; PDF-available indicator set. |
| 5 | Verify the API payload (GET my-payslips). | Response matches the Payslip List contract: items[] with payslipId/payMonth/payYear/grossEarnings/totalDeductions/netSalary/paidDays/lopDays/pdfAvailable; totalCount = count of Finalized slips; page=1, pageSize=12. |
| 6 | Verify scope. | Every returned payslipId belongs to EMP-001 in acme; no other employee's slip and no other tenant's slip is present (FR-8). |

## 6. Postconditions
- No state change (read-only). The employee sees only their own Finalized-run payslips, newest first.
