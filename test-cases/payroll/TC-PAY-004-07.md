# TC-PAY-004-07: Blob path traversal blocked (NFR-6) and generated PDFs contain NO executable content / JavaScript (NFR-5)

## 1. Test Objective
Verify NFR-5 and NFR-6: (a) the blob storage path is constructed server-side from the tenant_id + run_id + employee_id and is VALIDATED so that no request input (employeeId, runId, filename) can inject path-traversal sequences (`../`, absolute paths, URL-encoded `%2e%2e`, null bytes, alternate separators) to read or write outside the tenant's `{tenantId}/payroll/` prefix; (b) the rendered PDF contains no JavaScript / executable actions (no `/JavaScript`, `/JS`, `/OpenAction`, `/AA`, `/Launch`, embedded files) -- QuestPDF output is static content only.

## 2. Related Requirements
- User Story: US-PAY-004
- Acceptance Criteria: AC-4 (tenant-scoped paths)
- Non-Functional Requirements: NFR-5 (no JS in PDF), NFR-6 (path traversal prevented)
- Functional Requirements: FR-5 (storage path)

## 3. Preconditions
- Tenant "acme"; run R with generated payslips; HR Maya with `Payroll.*.All`.
- A sample of generated PDFs available for inspection.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Traversal employeeId | `../../globex/payroll/X` | must be rejected |
| Encoded traversal | `..%2f..%2fetc%2fpasswd` | must be rejected |
| Absolute path | `/etc/passwd`, `C:\Windows\win.ini` | must be rejected |
| Null byte | `EMP-001%00.pdf` | must be rejected |
| PDF scan tokens | /JavaScript /JS /OpenAction /AA /Launch /EmbeddedFile | must be absent |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Call the single-download endpoint with `employeeId = ../../globex/payroll/X`. | 400/404 rejected; no file outside `{acmeTenantId}/payroll/` is read; the resolved path is canonicalized and confirmed to stay within the tenant prefix (NFR-6). |
| 2 | Call download with URL-encoded traversal `..%2f..%2f...`. | Decoded then validated; rejected; no traversal. |
| 3 | Call download with an absolute path / drive path / UNC path as the id. | Rejected; server ignores client-supplied absolute paths and builds the path itself. |
| 4 | Call download with a null-byte-truncated id (`EMP-001%00.pdf`). | Rejected; no truncation bypass. |
| 5 | Force a generation with a manipulated runId/employeeId containing separators. | The blob writer rejects/sanitizes; nothing is written outside `{acmeTenantId}/payroll/{R}/`. |
| 6 | Scan a generated PDF's raw bytes for executable tokens (NFR-5). | None of `/JavaScript`, `/JS`, `/OpenAction`, `/AA`, `/Launch`, `/EmbeddedFile` present; PDF opens as static content with no script execution prompt. |
| 7 | Open a generated PDF in a viewer with script-execution enabled. | No JS runs; no auto-action fires. |

## 6. Postconditions
- Path construction is traversal-proof and tenant-confined; PDFs are static and script-free.
