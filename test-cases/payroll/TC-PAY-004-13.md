# TC-PAY-004-13: Payslip branding builder resolves tenant name/address/colour + logo with fallbacks (ISSUE-158)

## 1. Test Objective
Verify the ISSUE-158 `PayslipBranding.From(Tenant, logoBytes, fallbackName)` pure mapping: the company name prefers the tenant name, degrades to the supplied fallback, then to `"Company"`; blank/whitespace address and primary colour degrade to `null`; logo bytes are passed through verbatim. Keeps branding resolution unit-testable without rendering a PDF.

## 2. Related Requirements
- User Story: US-PAY-004
- Functional Requirement: FR-2 / BR-3 (company header branding)
- Defect: ISSUE-158

## 3. Preconditions
- None (pure domain function; no DB, no tenant context).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Tenant.Name | "  Acme Corp  " | Trimmed, preferred |
| fallbackName | "acme" | Used only when name blank |
| Tenant.Address | "  " / " 1 Industrial Way " | Blank → null; else trimmed |
| Tenant.PrimaryColor | "  " / " #1d4ed8 " | Blank → null; else trimmed |
| logoBytes | PNG magic bytes | Passed through verbatim |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | `From` with a present name | CompanyName == trimmed tenant name |
| 2 | `From` with a blank name + fallback | CompanyName == fallback |
| 3 | `From` with both blank | CompanyName == "Company" |
| 4 | `From` with blank / present address | CompanyAddress null / trimmed |
| 5 | `From` with blank / present colour | PrimaryColor null / trimmed |
| 6 | `From` with / without logoBytes | LogoBytes same reference / null |

## 6. Postconditions
- None (pure function).

## 7. Notes / Deferred
- `PayslipPdfRenderer.ParseColor` is private; its only public seam renders a real PDF (out of scope here). Blank/invalid hex fallback default is `Colors.Blue.Darken2` — the render seam's non-throw is covered by `PayslipPdfRendererTests.Render_WithTenantBrandColor_DoesNotThrow`.
