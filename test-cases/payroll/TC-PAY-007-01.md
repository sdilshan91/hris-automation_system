# TC-PAY-007-01: Create a Bonus adjustment for a period -> included as a payslip line item in that period's run; reimbursement-with-document stored at {tenantId}/payroll/adjustments/{id}/ (happy path)

## 1. Test Objective
Verify AC-1 / AC-3 / FR-1 / FR-3 / NFR-5: an HR Officer on the Payroll Adjustments page creates a Bonus adjustment for Employee X (amount 10,000, applicable June 2026), the record is saved Pending and linked to the employee with tenant_id stamped (AC-1, FR-1); when the June 2026 payroll run executes the engine auto-picks up the pending adjustment and includes it as an earning line item on Employee X's payslip (FR-3). Also create a Reimbursement adjustment with a supporting PDF: the document is stored in blob storage at `{tenantId}/payroll/adjustments/{adjustmentId}/` and `supporting_document_path` is linked to the record (AC-3, NFR-5).

## 2. Related Requirements
- User Story: US-PAY-007
- Acceptance Criteria: AC-1, AC-3
- Functional Requirements: FR-1, FR-3
- Non-Functional Requirements: NFR-5
- Business Rules: BR-1 (active salary structure), BR-2 (bonus is an earning)
- Data Requirements: S7 (payroll_adjustment table)

## 3. Preconditions
- Tenant "acme" Active, subdomain `acme.yourhrm.com`, Payroll module enabled.
- User authenticated in acme with `Payroll.*.All`.
- Employee X has an active salary structure assignment (US-PAY-002); June 2026 has NO Finalized payroll run yet (BR-7) and no run in Processing for that period (BR-8).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Bonus | employee=X, type=Bonus, amount=10000.00, period=2026-06, is_taxable=true | AC-1, FR-1 |
| Reimbursement | employee=X, type=Reimbursement, amount=3500.00, period=2026-06, is_taxable=false | AC-3, BR-4 |
| Document | receipt.pdf, 1.2MB, application/pdf | NFR-5 valid |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open Payroll Adjustments; click "New Adjustment"; select Employee X (typeahead), type=Bonus, amount=10000, period=June 2026, is_taxable=true, description "Q2 performance bonus"; Save. | A `payroll_adjustment` row persists with tenant_id=acme, employee_id=X, adjustment_type=Bonus, amount=10000.00, applicable_pay_month=6, applicable_pay_year=2026, status=Pending, created_by/created_at set (AC-1, FR-1). |
| 2 | In the same slide-over create a Reimbursement for Employee X amount=3500, is_taxable=false; attach `receipt.pdf` (1.2MB); Save. | A second `payroll_adjustment` (type=Reimbursement, Pending) persists; the file is stored at `acme/payroll/adjustments/{adjustmentId}/receipt.pdf` and `supporting_document_path` points to it (AC-3, NFR-5). |
| 3 | Confirm both rows appear in the Adjustments table for acme with status badge "Pending". | Both adjustments listed under acme only; status=Pending; bonus marked taxable, reimbursement non-taxable (BR-4). |
| 4 | Execute the June 2026 payroll run (US-PAY-003) for acme. | The run engine picks up both pending June-2026 adjustments for Employee X and adds them as line items on the payslip: Bonus as an earning increasing gross (BR-2), Reimbursement as a non-taxable line (BR-4) (FR-3). |
| 5 | Open Employee X's June 2026 payslip detail. | The payslip shows a "Bonus" earning line of 10,000 (taxable, included in gross) and a "Reimbursement" line of 3,500 (non-taxable); net reflects both (FR-3). |
| 6 | Re-check the two adjustment records after the run is finalized. | Both move to status=Applied with `applied_in_payroll_run_id` set to the June run (FR-4 -- verified in detail in TC-PAY-007-11). |

## 6. Postconditions
- Two adjustments exist for acme (Bonus + Reimbursement), included on Employee X's June payslip; reimbursement document persisted under the tenant-scoped blob path.
