# TC-PAY-001-03: Duplicate component code within the same tenant is rejected; same code allowed in a different tenant (negative)

## 1. Test Objective
Verify BR-2 / FR-1: a salary component `code` must be unique within a tenant. Creating a second component with code `BASIC` in tenant acme is rejected (409 Conflict), while a different tenant (globex) may freely use code `BASIC` — confirming the uniqueness constraint is scoped to `tenant_id`, not global.

## 2. Related Requirements
- User Story: US-PAY-001
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1
- Business Rules: BR-2
- Data Requirements: S7 (code UNIQUE per tenant)

## 3. Preconditions
- Tenant "acme" already has a component with code `BASIC`.
- Tenant "globex" has NO component with code `BASIC`.
- HR Officers authenticated separately in acme and globex, both with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Existing code (acme) | BASIC | Already exists |
| Duplicate attempt (acme) | BASIC | Should be rejected |
| Same code (globex) | BASIC | Should be allowed |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As acme HR, `POST /api/v1/payroll/components` with code `BASIC` (any name/type) | Response 409 Conflict (or 422) with a clear "component code already exists in this tenant" message. No second row is created. |
| 2 | Verify the DB | Exactly one `salary_component` row with code `BASIC` and `tenant_id` = acme; the unique index on (tenant_id, code) prevented the duplicate. |
| 3 | Attempt with a code differing only by case (`basic`) | System treats codes case-insensitively (or as specified) and rejects the duplicate; document the normalization rule applied. |
| 4 | Switch to globex context; `POST /api/v1/payroll/components` with code `BASIC` | Response 201 Created — the same code is permitted in a different tenant because uniqueness is scoped per tenant (BR-2). |
| 5 | Verify the DB | One acme `BASIC` row and one globex `BASIC` row coexist; no constraint violation. |

## 6. Postconditions
- acme retains a single `BASIC` component; globex now has its own `BASIC`; no cross-tenant collision.
