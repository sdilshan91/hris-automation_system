# TC-PAY-002-11: CTC breakdown preview <= 500ms (NFR-2) and bulk assign 500 employees <= 30s (NFR-1)

## 1. Test Objective
Verify NFR-2 and NFR-1: the CTC breakdown preview responds in <= 500ms for preview rendering, and bulk assignment of one salary structure to up to 500 employees completes within 30 seconds, all results tenant-scoped and correct.

## 2. Related Requirements
- User Story: US-PAY-002
- Acceptance Criteria: AC-1, AC-4
- Non-Functional: NFR-1, NFR-2
- Functional Requirements: FR-3, FR-5

## 3. Preconditions
- Tenant "acme" Active with 500 Active employees and no current assignments.
- FT-IN active structure with a realistic component count (>= 6 components).
- HR authenticated with `Payroll.*.All`. Performance environment representative of production.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Employees | 500 Active | bulk batch |
| Structure | FT-IN (>= 6 components) | applied to all |
| CTCs | distinct per employee | individual values |
| Preview iterations | 100 | for P95 measurement |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Call `POST .../salary/preview` for a single CTC 100 times under nominal load; record latency. | P95 <= 500ms (NFR-2); breakdown values correct each time. |
| 2 | Submit a 500-employee bulk assign `POST .../salary/bulk`; measure end-to-end wall time. | Completes <= 30s (NFR-1); progress indicator reaches 100%. |
| 3 | Verify created records. | 500 * (#components) `employee_salary_component` rows created, all `tenant_id`=acme, correct per-employee CTC. |
| 4 | Re-run bulk at 500 employees twice more; record p50/p95 wall time. | Consistently <= 30s; no timeouts; no partial-corruption (each employee fully assigned or cleanly failed). |
| 5 | Verify preview latency is unaffected while a bulk job runs concurrently. | Preview P95 stays <= 500ms (no head-of-line blocking that breaks the SLA). |

## 6. Postconditions
- Preview meets the 500ms P95 SLA; 500-employee bulk assign completes under 30s with correct tenant-scoped data.
