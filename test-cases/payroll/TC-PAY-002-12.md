# TC-PAY-002-12: Compensation tab, CTC breakdown table, revision timeline, and bulk-assign spreadsheet meet WCAG 2.1 AA

## 1. Test Objective
Verify the salary-assignment UI surfaces are accessible to WCAG 2.1 AA: the Compensation tab, the CTC breakdown preview table, the salary revision timeline, and the desktop bulk-assign spreadsheet are fully keyboard operable, screen-reader friendly, and color-contrast compliant. Override fields' "non-standard" indication is not conveyed by color alone.

## 2. Related Requirements
- User Story: US-PAY-002
- Acceptance Criteria: AC-1, AC-2, AC-3, AC-4
- UI/UX: S8 (Compensation tab, breakdown table, timeline, spreadsheet, override highlight)

## 3. Preconditions
- Ravi Kumar has an assignment with at least one override and a revision history.
- Test tools: keyboard-only, NVDA/VoiceOver, axe-core, contrast analyzer.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360px, 768px, 1280px, 1920px | responsive; bulk-assign desktop-only |
| Browsers | Chrome, Edge, Firefox, Safari | cross-browser |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate the Compensation tab using only the keyboard (Tab/Shift+Tab/Enter/Esc). | All controls reachable in a logical order; visible focus indicator; tab itself exposed via ARIA tab role. |
| 2 | Open the assign panel and the CTC breakdown preview; inspect the table. | Breakdown rendered as a semantic table with header cells (Component | Monthly Amount) and a labeled total row; screen reader announces row/column headers and the total. |
| 3 | Inspect override fields. | Override status conveyed by an icon/text label + ARIA, not color alone; highlighted border meets 3:1 non-text contrast. |
| 4 | Navigate the revision timeline; expand/collapse an entry by keyboard. | Expandable entries are buttons with `aria-expanded`; before/after comparison readable by screen reader. |
| 5 | Open the bulk-assign spreadsheet (desktop); navigate cells by keyboard; paste CTCs. | Grid keyboard-navigable (arrow keys), cells labeled; validation errors announced via `aria-live`. On mobile (360px) bulk assign hidden with a clear, screen-reader-announced "desktop only" message. |
| 6 | Run axe-core on each surface; check text contrast. | Zero critical/serious violations; text contrast >= 4.5:1 (>= 3:1 large); amounts not color-only encoded. |
| 7 | Verify across Chrome, Edge, Firefox, Safari at 360-1920px. | Consistent operability; no layout breakage; breakdown card stacks vertically on mobile. |

## 6. Postconditions
- All salary-assignment UI surfaces pass WCAG 2.1 AA across supported browsers and viewports.
