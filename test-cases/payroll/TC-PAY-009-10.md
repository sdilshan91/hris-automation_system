# TC-PAY-009-10: Performance -- 5,000-employee report <=2min (NFR-1); dashboard charts <=3s on pre-aggregated data (NFR-6); export files auto-deleted after 24h (NFR-4)

## 1. Test Objective
Verify NFR-1 / NFR-6 / NFR-4 / NFR-2 / NFR-3: a standard payroll report (e.g. Employee Payroll Register) for up to 5,000 employees completes within 2 minutes; analytics dashboard charts render within 3 seconds by reading pre-aggregated data (not recomputing from raw payslips); year-end tax statement generation for 5,000 employees runs asynchronously via Hangfire within 15 minutes; and temporarily-stored export files are auto-deleted 24 hours after creation.

## 2. Related Requirements
- User Story: US-PAY-009
- Acceptance Criteria: AC-1, AC-3, AC-4
- Functional Requirements: FR-2, FR-4, FR-5
- Non-Functional Requirements: NFR-1, NFR-2, NFR-3, NFR-4, NFR-6
- Data Requirements: S7 (pre-aggregated dashboard table)

## 3. Preconditions
- Tenant "acme" seeded with a 5,000-employee Finalized run + a populated pre-aggregated dashboard table.
- Hangfire available; export temp storage configured with a 24h retention job.
- NOTE: requires a seeded performance environment; CONDITIONAL where 5,000-employee seed data / the pre-aggregation table / the retention sweep job are not yet wired -- the SLA assertions then run against available data with the targets documented.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Register size | 5,000 employees | NFR-1 |
| Report SLA | <= 2 min standard report | NFR-1 |
| Chart SLA | <= 3 s (pre-aggregated) | NFR-6 |
| Tax statements | 5,000 PDFs <= 15 min async | NFR-2 |
| Export retention | auto-delete @ 24h | NFR-4 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Generate the Employee Payroll Register for 5,000 employees. | Completes within 2 minutes (NFR-1); served from read-optimized/cached aggregations where possible (NFR-3). |
| 2 | Load the analytics dashboard (monthly trend line, department pie, statutory stacked bar). | All charts render within 3 seconds, reading the pre-aggregated table -- not recomputing from raw payslips (NFR-6, FR-5). |
| 3 | Trigger Year-End Tax Statements for 5,000 employees. | Runs asynchronously via Hangfire; the user is shown "we'll notify you" and completion is within 15 minutes (NFR-2, FR-4). |
| 4 | Generate an export file; note its creation timestamp; advance/inspect at 24h. | The export file is auto-deleted by the retention job at/after 24 hours; the download link expires (NFR-4). |
| 5 | Re-run the register after a payroll finalization refreshes the pre-aggregation. | The pre-aggregated data reflects the new run; chart SLA still met (NFR-6). |
| 6 | Confirm large async reports do not block the request thread. | The synchronous request returns promptly with a job handle; heavy work is offloaded to Hangfire (FR-4). |

## 6. Postconditions
- 5,000-employee report <=2min; dashboard charts <=3s from pre-aggregated data; 5,000 tax PDFs <=15min async; export files auto-deleted at 24h.
