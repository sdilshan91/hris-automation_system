# TC-PAY-010-11: Authz on integration/reconciliation surface + internal-service (non-HTTP) cross-module access; attendance/leave fetch for 5,000 emps <=2min; reconciliation report <=30s (NFR-1, NFR-4, NFR-5)

## 1. Test Objective
Verify the security and performance non-functionals: (a) only users with `Payroll.Run` / `Payroll.*.All` may trigger the reconciliation report, payroll run, or encashment processing -- others get 403, unauthenticated 401; (b) cross-module attendance/leave access uses internal service interfaces, not outbound HTTP calls (NFR-4); (c) the attendance+leave data fetch for 5,000 employees completes within 2 minutes as part of the overall run (NFR-1); (d) the pre-payroll reconciliation report generates within 30 seconds for 5,000 employees (NFR-5).

## 2. Related Requirements
- User Story: US-PAY-010
- Acceptance Criteria: AC-4, AC-5
- Functional Requirements: FR-1, FR-2, FR-7
- Non-Functional Requirements: NFR-1, NFR-4, NFR-5

## 3. Preconditions
- Seeded performance environment: tenant "acme" with ~5,000 active employees, finalized attendance + approved leave for the period.
- Roles available: Payroll.Run holder, a non-payroll role (e.g. Employee), and an unauthenticated client.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Employee count | 5,000 | perf scale |
| Attendance+leave fetch SLA | <= 2 min | NFR-1 |
| Reconciliation report SLA | <= 30 s | NFR-5 |
| Cross-module access | internal service interface | NFR-4 (not HTTP) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As a non-payroll user, call the reconciliation/run/encashment endpoints. | 403 Forbidden on each (authz enforced). |
| 2 | As an unauthenticated client, call the same endpoints. | 401 Unauthorized. |
| 3 | As a Payroll.Run user, trigger the run; inspect how attendance/leave are obtained. | Data is read via internal service interfaces in-process; no outbound HTTP call to another module (NFR-4). |
| 4 | Run the attendance+leave fetch phase for 5,000 employees. | Completes within 2 minutes (NFR-1). |
| 5 | Generate the pre-payroll reconciliation report for 5,000 employees. | Generates within 30 seconds (NFR-5). |
| 6 | Confirm the fetch is tenant-scoped under load. | Only acme's records are fetched; SLA holds without cross-tenant scan (links to TC-PAY-ISO-037). |

## 6. Postconditions
- Integration/reconciliation surface is authz-gated; cross-module access is internal; fetch <=2min and reconciliation <=30s at 5,000 employees.
