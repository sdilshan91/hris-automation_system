# TC-PAY-008-05: Finalized status is terminal and irreversible; payslip records locked/immutable on finalize (BR-6, FR-8)

## 1. Test Objective
Verify BR-6 / FR-8 / AC-5: once a run is Finalized, no further status change is possible (terminal + irreversible) and ALL payslip records for the run are locked and immutable. No actor -- including a Tenant Admin -- can re-open, re-approve, reject, re-run, edit a slip, or delete the run.

## 2. Related Requirements
- User Story: US-PAY-008
- Acceptance Criteria: AC-5
- Functional Requirements: FR-8
- Business Rules: BR-6
- Data Requirements: S7

## 3. Preconditions
- A June 2026 run is Finalized for acme (via TC-PAY-008-01 path) with slips generated.
- Users: hr1 (Payroll.Run), fin1 (Payroll.Approve), admin1 (Tenant Admin).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Run | June 2026, status=Finalized | terminal |
| Attempted transitions | -> Approved, -> AwaitingApproval, -> ReviewPending, -> Rejected, -> Cancelled | all rejected |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As admin1, attempt to set the Finalized run back to Approved / ReviewPending / AwaitingApproval (force via API). | All rejected (409/400) -- Finalized is terminal and irreversible; status stays Finalized (BR-6). |
| 2 | As hr1, attempt to Reject or Cancel the Finalized run. | Rejected -- no status change permitted from Finalized (BR-6). |
| 3 | Attempt to edit any `payroll_slip` field (amount, net, status) for the Finalized run. | Rejected -- slip records are locked/immutable (FR-8). |
| 4 | Attempt to re-run / re-generate slips / delete the run for the Finalized period. | Rejected -- the run is immutable; corrections must flow through a payroll adjustment (US-PAY-007), not by reopening (BR-6, cross-ref BR-7 US-PAY-007). |
| 5 | Confirm the approval workflow instance for the run is closed. | The workflow instance is in a terminal/closed state; no new approval action can be taken on it (BR-6). |
| 6 | Confirm read access is unaffected. | The Finalized run + slips remain fully readable/downloadable; only mutation is blocked (FR-8, AC-5). |

## 6. Postconditions
- The Finalized run and its slips are immutable and read-only; no reversal path exists outside an adjustment in a later period.
