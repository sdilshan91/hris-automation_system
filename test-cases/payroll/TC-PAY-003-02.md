# TC-PAY-003-02: Duplicate run for a Finalized period rejected with 409 Conflict; one non-cancelled run per period enforced (BR-1)

## 1. Test Objective
Verify AC-4 and BR-1: when a payroll_run for May 2026 already exists with status=Finalized, an attempt to create another run for the same tenant + pay period is rejected with 409 Conflict indicating the period is already finalized; and more generally, only ONE payroll run per tenant per pay period may exist in a non-cancelled state at any time (a second run is blocked while one is in Queued/Processing/ReviewPending/Approved/Finalized). A run IS permitted for a period whose only prior run is Cancelled (FR-7 boundary, covered in TC-PAY-003-08).

## 2. Related Requirements
- User Story: US-PAY-003
- Acceptance Criteria: AC-4
- Functional Requirements: FR-1
- Business Rules: BR-1
- Data Requirements: S7 (payroll_run.status; one-non-cancelled-per-period invariant)

## 3. Preconditions
- Tenant "acme"; an existing payroll_run for May 2026 with status=Finalized.
- HR Officer authenticated in acme with `Payroll.Run`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Existing run | May 2026, status=Finalized | Period already finalized |
| New request | May 2026 | Same tenant + period |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | `POST /api/v1/payroll/runs` for May 2026 (acme). | 409 Conflict; error message indicates the period is already finalized; NO new payroll_run row created; NO Hangfire job enqueued. |
| 2 | Set the existing May 2026 run to ReviewPending (precondition variant); POST again for May 2026. | 409 Conflict -- a non-cancelled run already exists for the period (BR-1); no duplicate run created. (Note: re-running an in-ReviewPending/Cancelled period is FR-7 and is exercised in TC-PAY-003-08, not via a second initiate.) |
| 3 | Cancel the May 2026 run (status=Cancelled); POST again for May 2026. | 201/202 accepted -- a Cancelled run does not block a new run for the period (BR-1 / FR-7). |
| 4 | Verify June 2026 (a different period) is unaffected. | A run for June 2026 is accepted even while May 2026 is Finalized (per-period scope). |

## 6. Postconditions
- No duplicate non-cancelled run exists for acme/May-2026; the period invariant holds.
