# TC-PAY-012-12: Accessibility + responsive -- Payroll History table, run-detail audit timeline, diff view, filter bar, and export toolbar meet WCAG 2.1 AA across 360-1920px

## 1. Test Objective
Verify the UI accessibility + responsive requirements (S8): the Payroll History database-style table, the run-detail vertical audit timeline, the before/after diff view, the audit filter bar (date-range picker, action dropdown, actor search, resource filter), and the export toolbar are keyboard-operable, screen-reader-friendly, and meet WCAG 2.1 AA contrast, across the 360-1920px range. Status is never conveyed by colour alone.

## 2. Related Requirements
- User Story: US-PAY-012
- Acceptance Criteria: AC-1, AC-2, AC-4
- Functional Requirements: FR-1, FR-4, FR-5, FR-6, FR-8
- UI/UX: S8 (Notion-like), mobile notes

## 3. Preconditions
- Tenant "acme" Active with payroll history + audit entries; axe-core / screen reader (NVDA/VoiceOver) + keyboard available.
- HR Officer authenticated with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360, 768, 1280, 1920 px | responsive |
| Components | history table, timeline, diff view, filter bar, export toolbar | S8 |
| Tool | axe-core (0 serious/critical) | WCAG 2.1 AA |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Keyboard-navigate the history table (sort headers, filter controls, row activation). | All columns/sorts/filters reachable + operable by keyboard; visible focus indicators; sortable headers expose sort state to AT (aria-sort). |
| 2 | Open run detail; tab through Summary/Payslips/Audit Trail tabs + the timeline cards. | Tabs follow the ARIA tab pattern; timeline cards + expandable diff are keyboard-operable and announced; expand/collapse state exposed. |
| 3 | Open a diff view; verify changed fields. | Changed fields are distinguished by text/icon + colour (not colour alone); contrast >= 4.5:1; SR announces added/removed/modified semantically. |
| 4 | Operate the filter bar (date-range picker, action dropdown, actor search, resource filter) by keyboard + SR. | Each control is labelled, reachable, and operable; date picker keyboard-accessible; results update announced via live region. |
| 5 | Operate the export toolbar (CSV/Excel). | Buttons labelled + keyboard-activatable; download initiation announced. |
| 6 | Run axe-core at 360, 768, 1280, 1920px; verify layout. | 0 serious/critical violations; no horizontal-scroll trap; history table + timeline reflow/scroll readably (diff view may defer to desktop per mobile notes); status badges have text labels. |

## 6. Postconditions
- History table, audit timeline, diff view, filter bar, and export toolbar meet WCAG 2.1 AA and remain usable across 360-1920px.
