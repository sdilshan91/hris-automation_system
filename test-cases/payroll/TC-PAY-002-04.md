# TC-PAY-002-04: Sum of components != CTC beyond +/-1 tolerance is rejected (within tolerance accepted)

## 1. Test Objective
Verify FR-6: the system validates that the sum of all component values equals the declared annual CTC within a configurable tolerance (+/- 1 currency unit). Assignments whose component sum deviates beyond the tolerance are rejected (400); assignments within tolerance are accepted (rounding-residue case).

## 2. Related Requirements
- User Story: US-PAY-002
- Functional Requirements: FR-6, FR-2, FR-3
- Data Requirements: S7 (numeric(18,2))

## 3. Preconditions
- Tenant "acme" Active; FT-IN active structure available.
- Ravi Kumar Active; HR authenticated with `Payroll.*.All`.
- Tolerance configured at +/- 1.00.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| annual_ctc (case A reject) | 600000.00 | Overrides summing to 605000.00 (over by 5000) |
| annual_ctc (case B reject) | 600000.00 | Overrides summing to 599998.00 (under by 2) |
| annual_ctc (case C accept) | 600000.00 | Sum 600000.50 (within +/-1 rounding residue) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Case A: assign FT-IN with overrides whose component sum = 605000.00 against CTC 600000.00; submit `POST .../salary`. | 400 Bad Request; message states component sum (605000.00) does not match declared CTC (600000.00) beyond tolerance. No rows created. |
| 2 | Case B: overrides sum to 599998.00 against CTC 600000.00; submit. | 400 Bad Request; under-by-2 exceeds +/-1 tolerance. No rows created. |
| 3 | Case C: a rule rounding leaves the sum at 600000.50 against CTC 600000.00; submit. | 201 Created; within +/-1 tolerance, accepted (FR-6 boundary). |
| 4 | Preview the rejected cases (Case A/B). | Preview surfaces a visible mismatch warning and a blocked "Confirm" button. |

## 6. Postconditions
- Only the within-tolerance assignment (Case C) persists; out-of-tolerance attempts create no rows.
