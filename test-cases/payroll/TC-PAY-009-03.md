# TC-PAY-009-03: Export any payroll report to Excel via ClosedXML -- valid .xlsx opens correctly with all rows/columns

## 1. Test Objective
Verify AC-4 / FR-2: clicking "Export" on a payroll report generates an Excel (.xlsx) file using ClosedXML (technical doc S33.4) and downloads it; the produced workbook is a valid OOXML file that opens in spreadsheet applications, contains all displayed rows + columns with correct headers and numeric formatting, and matches the on-screen report data exactly. CSV and PDF export paths are exercised in TC-PAY-009-11.

## 2. Related Requirements
- User Story: US-PAY-009
- Acceptance Criteria: AC-4
- Functional Requirements: FR-1a, FR-2
- Business Rules: BR-1
- Data Requirements: S7 (Payroll Summary Report Columns)

## 3. Preconditions
- Tenant "acme"; a generated Payroll Summary Report for May 2026 displayed on screen.
- HR user `hr1` with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Report | Payroll Summary Report May 2026 | source for export |
| Format | Excel (.xlsx) | ClosedXML, S33.4 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As hr1, on the displayed report, click "Export" -> Excel. | An .xlsx file is generated server-side via ClosedXML and downloaded (AC-4, FR-2). |
| 2 | Validate the downloaded file as OOXML. | The file is a valid .xlsx (correct ZIP/OOXML signature); it opens without repair prompts in spreadsheet applications (ClosedXML output validation). |
| 3 | Inspect the worksheet header + data. | Header row matches the report columns (S7); one row per department + a totals row; values match the on-screen figures exactly. |
| 4 | Inspect numeric cells. | Monetary columns are numeric (not text), numeric(18,2) precision preserved; employee-count cells are integers. |
| 5 | Export an empty-result report (period with no Finalized run). | A valid .xlsx with header + an empty/"no data" indicator is produced; no error/corrupt file (BR-1). |
| 6 | Confirm the export reflects only acme's tenant-filtered data. | No cross-tenant rows in the exported workbook (isolation reinforced by TC-PAY-ISO-033). |

## 6. Postconditions
- A valid ClosedXML .xlsx export of the report exists, openable in spreadsheet apps, matching on-screen data with correct types/precision.
