# TC-PAY-005-05: Employee A requests Employee B's payslip by id (URL/id manipulation) -> 403 Forbidden; Self scope blocks list, detail, and download (negative / security)

## 1. Test Objective
Verify AC-4 / FR-5 / BR-5: the `Payroll.Read.Self` permission restricts every payslip surface to the authenticated employee's own slips. When Employee A manipulates the payslip id in the detail or PDF URL to target Employee B's slip (same tenant), the system returns 403 Forbidden (or 404 with no existence/data leak) and never returns B's payslip data, salary figures, PDF bytes, or any identifying detail in the response or error message.

## 2. Related Requirements
- User Story: US-PAY-005
- Acceptance Criteria: AC-4
- Functional Requirements: FR-5, FR-8
- Business Rules: BR-5
- Non-Functional Requirements: NFR-4 (zero cross-employee leak)

## 3. Preconditions
- Tenant "acme". Employee A = EMP-001 (`Payroll.Read.Self`), Employee B = EMP-002 (a different employee in the same tenant).
- EMP-002 has a Finalized May 2026 payslip with id `payslipB`.
- EMP-001 is authenticated; EMP-001 has obtained or guessed `payslipB`'s id.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Attacker | EMP-001 (Employee A) | self scope |
| Target | EMP-002's payslip `payslipB` | another employee |
| Endpoints | GET my-payslips/{payslipB}; GET my-payslips/{payslipB}/pdf | FR-4/FR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As EMP-001, GET my-payslips/{payslipB} (detail). | 403 Forbidden (Self scope, AC-4) or 404 with no data; no salary/component data for EMP-002 returned. |
| 2 | As EMP-001, GET my-payslips/{payslipB}/pdf (download). | 403 / 404; no PDF bytes for EMP-002 served. |
| 3 | Inspect the error response body + headers. | Generic error only; no employee name, employee number, amounts, department, or storage path for EMP-002 leaked (BR-5, NFR-4). |
| 4 | Confirm `payslipB` never appears in EMP-001's list. | The my-payslips list for EMP-001 contains only EMP-001's slips; `payslipB` is absent regardless of pagination/filter. |
| 5 | As EMP-001, GET my-payslips/{payslipB}'s detail again with a forged/elevated header (e.g. injected employee id param). | Server resolves employee from the authenticated principal, not from client input; still 403/404. |
| 6 | Verify EMP-001's own slips remain fully accessible. | EMP-001 can read and download their own payslips normally -- Self scope blocks only cross-employee access. |

## 6. Postconditions
- Employee A cannot read, download, or infer Employee B's payslip by any id manipulation; no cross-employee data leaks.
