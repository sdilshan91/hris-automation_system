# TC-PAY-004-03: Regenerate Payslips on a non-finalized run overwrites existing PDFs with the updated template + bumps timestamp (AC-5)

## 1. Test Objective
Verify AC-5: when HR clicks "Regenerate Payslips" on a NON-finalized run (ReviewPending/Approved) after a payslip template/branding change, the system re-renders each employee's PDF, OVERWRITES the existing blob at the same path `{tenantId}/payroll/{runId}/{employeeId}.pdf`, updates `pdf_generated_at` to the new time, and applies the updated template (new logo/footer/colors/custom fields). The slip content snapshot (BR-2 denormalized component names + amounts) is unchanged -- only the rendering/template changes.

## 2. Related Requirements
- User Story: US-PAY-004
- Acceptance Criteria: AC-5
- Functional Requirements: FR-3 (per-tenant template), FR-1, FR-5, FR-7
- Business Rules: BR-1 (run must be in an allowed status), BR-2 (content snapshot unchanged)

## 3. Preconditions
- Run R (acme, May 2026, ReviewPending) with 3 payslips already Generated (TC-PAY-004-01).
- Tenant template updated: new footer text + new header color + new logo.
- HR Maya authenticated with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Template change | footer text, header color, logo | FR-3 |
| Run status | ReviewPending | non-finalized -> regenerate allowed |
| Path | unchanged (overwrite) | FR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Record current `pdf_generated_at` + a byte hash of EMP-001's existing PDF. | Baseline captured. |
| 2 | Update the tenant payslip template (footer/color/logo). | Template change persisted (US-PAY-003-independent config). |
| 3 | On run R, click "Regenerate Payslips"; let the Hangfire job complete. | Job re-renders all 3 PDFs; same blob paths overwritten in place (no new {runId} folder, no orphaned old files). |
| 4 | Re-open EMP-001's PDF. | New footer text + header color + logo present; content sections (earnings/deductions/net) identical to before (BR-2 snapshot unchanged). |
| 5 | Verify slip status fields. | `pdf_generated_at` is NEWER than the baseline; `pdf_status=Generated`; `pdf_storage_path` unchanged; `pdf_file_size_bytes` re-recorded. |
| 6 | Attempt "Regenerate Payslips" on a FINALIZED run. | Rejected per BR-1/immutability (regenerate is offered only on non-finalized runs); finalized PDFs unchanged. (Covered together with TC-PAY-004-04 for the status-gate.) |

## 6. Postconditions
- The 3 PDFs are overwritten in place with the new template; timestamps bumped; underlying slip data unchanged.
