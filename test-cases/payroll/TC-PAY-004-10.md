# TC-PAY-004-10: Payslip list table, generation status bar, inline PDF preview modal, and Download All meet WCAG 2.1 AA

## 1. Test Objective
Verify the US-PAY-004 UI surfaces meet WCAG 2.1 AA and are fully keyboard + screen-reader operable: (1) the searchable/filterable payslip list table (Employee Name | Employee No | Department | Net Salary | PDF Status | Actions); (2) the generation status bar / progress indicator ("4,850 / 5,000 generated"); (3) the inline PDF preview modal (embedded viewer); (4) the "Download All" control showing estimated ZIP size + async state. Includes responsive behavior 360px-1920px (mobile = individual view/download only, no bulk).

## 2. Related Requirements
- User Story: US-PAY-004
- Acceptance Criteria: AC-1, AC-3
- UI/UX Notes: status bar, inline preview modal, searchable table, Download All, mobile constraints
- Standard: WCAG 2.1 AA

## 3. Preconditions
- Run R (acme) with payslips generated; HR Maya with `Payroll.*.All`.
- Tools: keyboard only, NVDA/VoiceOver, axe-core, browser zoom.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360px, 768px, 1280px, 1920px | responsive |
| Contrast target | >= 4.5:1 text, >= 3:1 UI/large | WCAG 1.4.3/1.4.11 |
| Status bar role | progressbar with aria-valuenow/min/max | live progress |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Tab through the payslip list table + search/filter. | All interactive cells/controls reachable in logical order; visible focus indicators; table uses proper `<th>`/scope; search + filter operable by keyboard; sortable headers announce sort state. |
| 2 | Inspect the generation status bar with a screen reader. | Exposed as `role=progressbar` with `aria-valuenow/min/max` (or an `aria-live` region announcing "4,850 of 5,000 generated"); progress updates are announced without stealing focus. |
| 3 | Open the inline PDF preview modal via keyboard (Enter on "View"). | Focus moves into the modal; focus is trapped; `Esc` closes and returns focus to the triggering row; modal has an accessible name; embedded viewer is reachable; a text alternative / download fallback is offered for AT users. |
| 4 | Operate "Download All" by keyboard. | Button has an accessible name; estimated ZIP size + async/generating state announced (aria-live); disabled/busy state programmatically conveyed. |
| 5 | Run axe-core on the run detail + modal. | Zero critical/serious violations; PDF-status badges convey status by text/icon, not color alone (1.4.1). |
| 6 | Check color contrast on table, status badges, status bar, buttons. | All >= WCAG 2.1 AA thresholds; tenant-branding colors do not drop below contrast. |
| 7 | Resize 360px -> 1920px. | Layout reflows with no horizontal scroll/loss at 320px-equivalent; on mobile the bulk "Download All" is hidden while individual view/download remains (per UI/UX mobile note). |

## 6. Postconditions
- The payslip list, status bar, preview modal, and Download All are WCAG 2.1 AA conformant and responsive across the supported range.
