# TC-PAY-005-03: Download PDF returns the employee's own tenant-branded payslip PDF generated in US-PAY-004 (happy path)

## 1. Test Objective
Verify AC-3 / FR-4: when the Employee clicks "Download PDF" for one of their own Finalized payslips, the endpoint `GET /api/v1/payroll/my-payslips/{payslipId}/pdf` returns the pre-generated, tenant-branded PDF (the exact file produced by US-PAY-004), with the correct content-type and a download disposition; no on-demand regeneration occurs. The PDF served is the one stored at the tenant-scoped blob path for EMP-001's slip.

## 2. Related Requirements
- User Story: US-PAY-005
- Acceptance Criteria: AC-3
- Functional Requirements: FR-4, FR-5 (self scope), FR-8
- Dependencies: US-PAY-004 (pre-generated PDF), US-TENANT-xxx (branding)

## 3. Preconditions
- Tenant "acme"; Employee EMP-001 authenticated with `Payroll.Read.Self`.
- EMP-001's May 2026 payslip belongs to a Finalized run and has `pdf_status=Generated` with a stored `pdf_storage_path` (US-PAY-004).
- Tenant branding (logo, company name, address) configured; PDF filename per US-PAY-004 BR-5 (`{EmployeeNo}_{PayMonth}_{PayYear}.pdf`).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Endpoint | GET /api/v1/payroll/my-payslips/{payslipId}/pdf | FR-4 |
| Payslip | May 2026 (EMP-001), pdf_status=Generated | downloadable |
| Expected content-type | application/pdf | download |
| Expected filename | EMP-001_05_2026.pdf | US-PAY-004 BR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As EMP-001, click "Download PDF" on the May 2026 detail card. | The download initiates; browser receives the file (AC-3). |
| 2 | Inspect the HTTP response. | 200 OK, `Content-Type: application/pdf`, `Content-Disposition: attachment; filename="EMP-001_05_2026.pdf"`. |
| 3 | Open the downloaded PDF. | It is the pre-generated US-PAY-004 PDF: tenant logo + company name + address, EMP-001's pay details, earnings/deductions, gross/deductions/net. No new render was triggered (served from blob). |
| 4 | Confirm no on-demand generation. | Server logs show the file was served from the stored `pdf_storage_path`; no QuestPDF render call for this request (assumption: pre-generated only). |
| 5 | Request the PDF for a payslip whose run is NOT yet generated (`pdf_status != Generated`). | Endpoint responds gracefully (404/409 "PDF not available"), not a 500; the list's `pdfAvailable=false` matches. |
| 6 | Verify scope. | The endpoint resolves the slip via EMP-001 + active tenant; the returned bytes belong only to EMP-001 (FR-5/FR-8). |

## 6. Postconditions
- The employee obtains their own branded PDF; no payslip data is modified.
