# TC-PAY-012-01: Payroll History chronological list -- all runs with Pay Period/Status/Employee Count/Total Net/Initiated By/Approved By/Finalized Date, sortable + filterable by period/status/year (happy path)

## 1. Test Objective
Verify the primary success flow across AC-1 and FR-1: an HR Officer with `Payroll.*.All` navigates to Payroll History and is shown a chronological list of every payroll run for the tenant via `GET /api/v1/payroll/runs`, with each row exposing Pay Period, Status, Employee Count, Total Net, Initiated By, Approved By, and Finalized Date; the list is sortable (by period/net) and filterable by period, status, and year, with pagination.

## 2. Related Requirements
- User Story: US-PAY-012
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1
- Business Rules: BR-3 (history never deleted)
- Data Requirements: payroll_run (US-PAY-003), approval history (US-PAY-008)

## 3. Preconditions
- Tenant "acme" Active, subdomain `acme.yourhrm.com`, Payroll module enabled.
- At least 4 payroll runs exist spanning two years (e.g. Mar 2025 Finalized, Apr 2025 Finalized, Apr 2026 ReviewPending, May 2026 Finalized) with known employee counts, total net, initiator, approver, and finalized date.
- HR Officer "Maya Singh" authenticated in acme with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Subdomain | acme.yourhrm.com | Active tenant |
| Runs | Mar 2025 / Apr 2025 / Apr 2026 / May 2026 | mixed statuses + years |
| Columns | Pay Period, Status, Employee Count, Total Net, Initiated By, Approved By, Finalized Date | AC-1 |
| Sort | period desc (default), Total Net | AC-1, FR-1 |
| Filters | year=2025, status=Finalized | AC-1, FR-1 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate to Payroll > History. | `GET /api/v1/payroll/runs` returns 200 with a paginated, chronological (most-recent first) list of all 4 runs for acme only. |
| 2 | Inspect a row's columns. | Each row shows Pay Period, Status badge, Employee Count, Total Net (numeric(18,2)), Initiated By, Approved By (or "--" if none), and Finalized Date (or "--" if not finalized). |
| 3 | Click the "Total Net" column header to sort. | List re-sorts by Total Net; toggling reverses direction; ordering is correct. |
| 4 | Apply filter year=2025 + status=Finalized. | Only Mar 2025 + Apr 2025 (Finalized) rows are returned; the 2026 runs are excluded; request carries the filter to the API (server-side filter, not client-only). |
| 5 | Clear filters and page through results. | Pagination metadata (page/size/total) is correct; no run is duplicated or dropped across pages. |
| 6 | Confirm the ReviewPending (Apr 2026) run appears with empty Approved By / Finalized Date. | Non-finalized runs are still listed (history is complete, BR-3); finalize-only fields are blank, not fabricated. |

## 6. Postconditions
- No data mutated; the history view reflects the current set of runs for acme accurately.
