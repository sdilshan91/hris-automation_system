# TC-PAY-010-01: LOP from absence -- 3 unapproved absent days -> 3 LOP days + LOP deduction = (basic/working_days)*3 (golden 22,000/22/3 -> 3,000) (happy path)

## 1. Test Objective
Verify AC-1 / FR-1 / FR-3: when the payroll engine runs for a period with finalized attendance, it fetches the monthly attendance summary per employee (working days, present, absent, half-days, lates, OT hours) and computes Loss-of-Pay for days that are absent AND have no approved paid leave. With the golden data (monthly basic 22,000, total working days 22, 3 unapproved absent days), the payslip shows `lop_days = 3` and an LOP deduction of `(22,000 / 22) * 3 = 3,000`, and net salary is reduced by exactly 3,000. Daily rate uses working_days from the shift calendar (BR-8), not a flat 30.

## 2. Related Requirements
- User Story: US-PAY-010
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-2, FR-3
- Business Rules: BR-1, BR-8
- Data Requirements: S7 (Attendance Summary -> payroll_slip.lop_days), payroll_slip.lop deduction line

## 3. Preconditions
- Tenant "acme" Active, subdomain `acme.yourhrm.com`, Payroll module enabled.
- Employee X has an active salary structure (US-PAY-002) with monthly_basic = 22,000.
- Attendance for May 2026 is FINALIZED (`is_finalized = true`); X's summary: total_working_days = 22, present_days = 19, absent_days = 3, half_days = 0, late_count = 0, overtime_hours = 0.
- No approved leave for X covering those 3 absent days (so they are unpaid absence per BR-1).
- HR user `hr1` authenticated in acme with `Payroll.Run`.

| Field | Value | Notes |
|-------|-------|-------|
| Period | May 2026 | finalized attendance |
| monthly_basic | 22,000 | from salary structure |
| total_working_days | 22 | shift calendar (BR-8) |
| absent_days (unapproved) | 3 | drives LOP |
| daily_rate | 22,000 / 22 = 1,000 | FR-3 |
| Expected lop_days | 3 | payslip |
| Expected LOP deduction | 1,000 * 3 = 3,000 | golden |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As hr1, initiate the May 2026 payroll run for acme (attendance finalized). | Run is accepted (not blocked); the engine fetches X's attendance summary via the internal attendance service (FR-1, NFR-4). |
| 2 | Inspect the attendance summary consumed for X. | total_working_days=22, present=19, absent=3, half=0, lates=0, OT=0, is_finalized=true (FR-1). |
| 3 | Inspect the leave summary consumed for X. | No approved paid leave covers the 3 absent days, so all 3 are eligible for LOP (FR-2, BR-1). |
| 4 | Inspect X's generated payslip. | `lop_days = 3`; an LOP deduction line of exactly 3,000 is present (FR-3). |
| 5 | Verify the daily rate derivation. | daily_rate = monthly_basic / total_working_days = 22,000 / 22 = 1,000; LOP = 1,000 * 3 = 3,000; working_days came from the shift calendar, not 30 (BR-8). |
| 6 | Verify net salary impact. | Net salary is reduced by exactly 3,000 versus a no-LOP baseline; payslip totals reconcile (gross - deductions incl. LOP = net) (AC-1). |

## 6. Postconditions
- X's May 2026 payslip carries lop_days=3 and a 3,000 LOP deduction sourced from finalized attendance; net reduced accordingly.
