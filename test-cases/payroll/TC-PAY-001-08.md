# TC-PAY-001-08: Authorization — only Payroll.*.All / Tenant Admin may configure components and structures; others 403 (security)

## 1. Test Objective
Verify the precondition and AC-1/AC-3 authorization model: salary component and structure CRUD requires `Payroll.*.All` (HR Officer) or the Tenant Admin role. Authenticated users without payroll configuration permission (e.g. a plain Employee, or a user with only read permission) receive 403 Forbidden on write operations; unauthenticated requests receive 401.

## 2. Related Requirements
- User Story: US-PAY-001
- Acceptance Criteria: AC-1, AC-2, AC-3, AC-4, AC-5
- Functional Requirements: FR-1, FR-2, FR-3
- Preconditions: requires `Payroll.*.All` or Tenant Admin

## 3. Preconditions
- Tenant "acme" with: HR Officer Maya (Payroll.*.All), Tenant Admin Alex, and Employee Sam (no payroll permission), all authenticated separately.
- A salary component and structure exist in acme.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Maya | Payroll.*.All | allowed |
| Alex | Tenant Admin | allowed |
| Sam | Employee (no payroll) | denied |
| Anon | no token | 401 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Maya, POST/PUT/DELETE on components and structures | All authorized: 2xx responses. |
| 2 | As Alex (Tenant Admin), same write operations | All authorized: 2xx responses. |
| 3 | As Sam (Employee), `POST /api/v1/payroll/components` (and structure create, link, delete, reorder, activate) | Each returns 403 Forbidden; no rows created or modified. |
| 4 | As Sam, `GET /api/v1/payroll/components` | Returns 403 if read also requires payroll permission, OR 200 limited per the read policy — assert against the documented read scope; never expose write actions in the UI for Sam. |
| 5 | With no bearer token, call any write endpoint | 401 Unauthorized (authentication required before authorization). |
| 6 | As Sam, attempt to tamper a structure activation by calling the API directly (bypassing hidden UI) | Still 403 — authorization is enforced server-side, not just by hiding UI controls. |

## 6. Postconditions
- Only Payroll.*.All / Tenant Admin can mutate payroll configuration; no privilege escalation via direct API calls.
