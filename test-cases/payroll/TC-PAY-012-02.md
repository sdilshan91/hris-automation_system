# TC-PAY-012-02: Run detail page -- Summary tab (totals/metrics) + Payslips tab (searchable employee list) + Audit Trail tab (chronological run timeline: initiated/status changes/approved/rejected + comments) (happy path)

## 1. Test Objective
Verify AC-2 and FR-6: selecting a payroll run from history opens a run detail page with the complete run summary, all employee payslips (searchable), and the run's audit timeline -- a per-run, chronologically ordered view showing who initiated the run, when each status change occurred, who approved/rejected, and the associated comments.

## 2. Related Requirements
- User Story: US-PAY-012
- Acceptance Criteria: AC-2
- Functional Requirements: FR-6, FR-1
- Business Rules: BR-4 (audit sufficient to reconstruct the run's event sequence)
- Data Requirements: payroll_run / payroll_slip (US-PAY-003), payroll_approval_history (US-PAY-008), audit_log (S19.9/S24)

## 3. Preconditions
- Tenant "acme" Active; a Finalized May 2026 run R with 3 employee payslips, a known initiator, an approver, and a recorded status path Queued -> ReviewPending -> AwaitingApproval -> Approved -> Finalized.
- The run has audit_log + approval-history entries for each transition with comments.
- HR Officer "Maya Singh" authenticated in acme with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Run | R (May 2026), Finalized | AC-2 |
| Tabs | Summary / Payslips / Audit Trail | S8 UI |
| Status path | Queued->ReviewPending->AwaitingApproval->Approved->Finalized | FR-6 |
| Search | EMP-002 | payslip search |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | From history, click run R. | Run detail page opens with three tabs: Summary, Payslips, Audit Trail. |
| 2 | View the Summary tab. | Shows run totals/metrics: pay period, status, employee count, total gross/deductions/statutory/net, initiated-by, approved-by, finalized date -- reconciling with the history row (AC-1) values. |
| 3 | Open the Payslips tab; search "EMP-002". | All 3 employee payslips are listed; the search filters to EMP-002 only; each row drills to the individual payslip (US-PAY-004/005 surface). |
| 4 | Open the Audit Trail tab. | A chronological timeline of all actions for THIS run: PayrollRun.Initiated (actor + timestamp), each status change, PayrollRun.Approved (approver + comment), PayrollRun.Finalized -- ordered oldest-to-newest (or newest-first per UI), each card showing timestamp, actor, action description, and comment. |
| 5 | Verify the timeline contains only this run's events. | Events are scoped to run R (filtered by resource_type=PayrollRun + resource_id=R); no other run's events bleed in. |
| 6 | Cross-check against the approval history (US-PAY-008). | Approve/Reject entries match `payroll_approval_history` (actor, decision, comment, timestamp); a financial auditor could reconstruct the full sequence (BR-4). |

## 6. Postconditions
- No data mutated; run detail accurately presents summary + payslips + the run's complete chronological audit timeline.
