# TC-PAY-010-04: Attendance NOT finalized -> payroll run blocked with warning "Attendance data for May 2026 is not yet finalized" (negative)

## 1. Test Objective
Verify AC-4: when attendance for the payroll period is NOT finalized, the system blocks the payroll run with the exact warning "Attendance data for {period} is not yet finalized" and does NOT compute any LOP/overtime/encashment or persist slips. A link to the attendance finalization page is surfaced. Once attendance is finalized, the same run proceeds.

## 2. Related Requirements
- User Story: US-PAY-010
- Acceptance Criteria: AC-4
- Functional Requirements: FR-1 (depends on finalized summary), FR-7
- Data Requirements: Attendance Summary.is_finalized
- UI/UX: warning banner on payroll initiation page with link to attendance finalization

## 3. Preconditions
- Tenant "acme" Active; Payroll module enabled.
- Attendance for May 2026 is NOT finalized (`is_finalized = false`) for at least one in-scope employee.
- HR user `hr1` authenticated in acme with `Payroll.Run`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Period | May 2026 | attendance NOT finalized |
| is_finalized | false | blocks run (AC-4) |
| Expected message | "Attendance data for May 2026 is not yet finalized" | exact text |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As hr1, attempt to initiate the May 2026 payroll run. | Run is BLOCKED before compute; response carries the warning "Attendance data for May 2026 is not yet finalized" (AC-4). |
| 2 | Inspect side effects. | No payroll_run advances to compute; no slips, no LOP/OT/encashment values persisted (fail-closed). |
| 3 | Inspect the payroll initiation page. | A warning banner is shown at the top with a link to the attendance finalization page (UI/UX). |
| 4 | Boundary: finalize attendance for May 2026, then retry the run. | The block clears; the run proceeds and computes LOP/OT from the now-finalized summary (AC-4 -> AC-1/AC-2). |
| 5 | Boundary: only a subset of employees finalized (mixed state). | The run remains blocked with the same warning until the period is fully finalized (no partial silent compute). |

## 6. Postconditions
- Payroll for an unfinalized attendance period is blocked with the exact warning + finalization link; it proceeds only once finalized.
