# TC-PAY-003-03: Payroll run blocked when attendance for the period is not locked/finalized (BR-3)

## 1. Test Objective
Verify BR-3 and the FR-4 precondition: a payroll run cannot be initiated (or, if a guard is deferred to the worker, cannot proceed) when attendance for the pay period has not yet been locked/finalized. The system surfaces a clear, period-specific error and does NOT create a ReviewPending run with computed slips from un-finalized attendance.

## 2. Related Requirements
- User Story: US-PAY-003
- Acceptance Criteria: AC-1 (precondition), AC-2 (lock dependency)
- Functional Requirements: FR-4
- Business Rules: BR-3
- Dependencies: US-ATT-* finalized attendance; US-LEAVE-* approved leave

## 3. Preconditions
- Tenant "acme"; active employees with salary structures.
- Attendance for May 2026 is NOT yet locked/finalized (still open/editable).
- HR Officer authenticated in acme with `Payroll.Run`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| pay_month / pay_year | 5 / 2026 | Attendance not locked |
| Attendance state | open (not finalized) | Violates BR-3 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | "New Payroll Run" -> select May 2026; observe the pre-run validation summary. | Validation flags attendance not finalized for the period; the "Run" action is disabled OR a blocking warning is shown. |
| 2 | `POST /api/v1/payroll/runs` for May 2026. | Request rejected (422/409) with a message indicating attendance for the period must be locked/finalized first; NO payroll_run advances to Processing; NO slips computed. |
| 3 | Lock/finalize attendance for May 2026, then POST again. | Run is accepted (202 + Queued) and proceeds normally (cross-checks the happy path of TC-PAY-003-01). |
| 4 | (Worker-guard variant) If the lock check runs in the worker, verify the run terminates with status=Cancelled/Failed + a log entry rather than persisting slips from open attendance. | No partial slips persisted from un-finalized attendance; run does not reach ReviewPending; failure logged (NFR-4). |

## 6. Postconditions
- No payroll slips are computed from un-finalized attendance; the run only proceeds after attendance is locked.
