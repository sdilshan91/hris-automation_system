# TC-PAY-002-03: Assigning an inactive/deactivated salary structure is rejected with 400

## 1. Test Objective
Verify FR-7: the system prevents assigning an inactive or deactivated salary structure to an employee. Attempting to assign a structure whose `is_active`=false returns 400 Bad Request with a clear message, and no `employee_salary_component` rows are created.

## 2. Related Requirements
- User Story: US-PAY-002
- Functional Requirements: FR-7, FR-1
- Data Requirements: S7

## 3. Preconditions
- Tenant "acme" Active; Payroll enabled.
- A salary structure "Legacy 2024" (LEG-24) exists with `is_active`=false (deactivated).
- An active structure "Full-Time India" (FT-IN) also exists (control).
- Employee Ravi Kumar Active with no current assignment; HR authenticated with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Inactive structure | Legacy 2024 (LEG-24), is_active=false | Negative case |
| Active structure | FT-IN, is_active=true | Control |
| annual_ctc | 600000.00 | |
| effective_from | 2026-07-01 | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | In the assign panel, attempt to select LEG-24. | Inactive structures are not selectable / are filtered out of the dropdown (UI guard). |
| 2 | Bypass the UI: `POST /api/v1/payroll/employees/{id}/salary` with `salary_structure_id`=LEG-24, CTC 600000, effective_from 2026-07-01. | Response 400 Bad Request; error indicates the structure is inactive/deactivated and cannot be assigned (FR-7). No rows created. |
| 3 | Verify persistence. | Zero `employee_salary_component` rows for Ravi; employee remains "Payroll Incomplete". |
| 4 | Repeat the same request with active FT-IN (control). | Response 201 Created; assignment succeeds. |
| 5 | Deactivate FT-IN after assigning, then attempt to assign FT-IN to a different employee. | 400 Bad Request; existing assignments unaffected by the later deactivation. |

## 6. Postconditions
- No assignment created from the inactive structure; the active-structure control assignment succeeds.
