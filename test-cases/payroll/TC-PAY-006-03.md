# TC-PAY-006-03: Golden EPF calculation with wage ceiling -- basic 20,000, ceiling 15,000, rate 12% yields EPF 1,800 (not 2,400)

## 1. Test Objective
Verify AC-2 / BR-8 / FR-2: EPF (social-security) deduction is computed on the **lesser of the applicable base and the wage ceiling**: employee EPF = min(basic, ceiling) * employee_rate, employer EPF = min(basic, ceiling) * employer_rate. For basic 20,000, monthly wage ceiling 15,000, rate 12%, the result is min(20000,15000)*12% = 15,000*12% = 1,800 -- NOT 20,000*12% = 2,400. Both employee and employer sides are computed on the capped base. Canonical golden test from the Test Hints.

## 2. Related Requirements
- User Story: US-PAY-006
- Acceptance Criteria: AC-2
- Functional Requirements: FR-2, FR-5
- Business Rules: BR-8 (wage ceiling per pay period)
- Data Requirements: S7 (social_security_rule: employee_rate, employer_rate, wage_ceiling_annual, applicable_on)

## 3. Preconditions
- Tenant "acme" with an EPF rule: employee_rate 12, employer_rate 12, wage_ceiling_annual 180000 (monthly 15,000), applicable_on=Basic, active.
- User authenticated as Tenant Admin / `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Basic salary (month) | 20,000 | above ceiling |
| Monthly wage ceiling | 15,000 | annual 180,000 / 12 (BR-8) |
| Rate | 12% | employee & employer |
| Expected employee EPF | 1,800 | min(20000,15000)*12% |
| Expected employer EPF | 1,800 | same capped base |
| Wrong (uncapped) value | 2,400 | must NOT be produced |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Invoke the EPF calculation (or Test Calculation panel, FR-5) for a basic of 20,000. | Employee EPF = 1,800 (15,000 * 12%, ceiling applied) -- NOT 2,400 (AC-2, BR-8). |
| 2 | Inspect the employer contribution. | Employer EPF = 1,800, also computed on the capped 15,000 base (AC-2). |
| 3 | Compute for a basic BELOW the ceiling (e.g. 12,000). | Employee EPF = 12,000 * 12% = 1,440; no ceiling applied because basic < ceiling. |
| 4 | Compute for a basic exactly AT the ceiling (15,000). | Employee EPF = 1,800 (15,000 * 12%); boundary handled without off-by-one. |
| 5 | Set applicable_on=Gross and recompute with gross > ceiling. | The ceiling caps the Gross base identically (min(gross, ceiling) * rate). |
| 6 | Verify wage-ceiling derivation. | Monthly ceiling = annual 180,000 / 12 = 15,000 per pay period (BR-8); calculation does not use the full annual ceiling for a single month. |

## 6. Postconditions
- No state change (calculation only); ceiling-capped EPF verified at, below, and above the ceiling.
