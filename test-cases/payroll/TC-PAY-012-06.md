# TC-PAY-012-06: System actor for Hangfire-job actions (not null) + IP/user-agent captured for approval/finalize (non-repudiation)

## 1. Test Objective
Verify BR-7 and BR-5: system-initiated payroll actions (Hangfire job processing -- run compute completion, payslip PDF generation, email distribution) are logged with a SYSTEM actor identifier, never a null actor; and sensitive interactive actions (PayrollRun.Approved, PayrollRun.Finalized) capture the actor's IP address and user agent for non-repudiation.

## 2. Related Requirements
- User Story: US-PAY-012
- Acceptance Criteria: AC-3
- Functional Requirements: FR-2, FR-3
- Business Rules: BR-7 (system actor, not null), BR-5 (IP/user-agent for approval/finalize)
- Non-Functional Requirements: NFR-4 (immutable)

## 3. Preconditions
- Tenant "acme" Active; a payroll run progresses through compute (Hangfire), payslip generation (Hangfire), interactive approval, finalize, and email distribution (Hangfire).
- HR Officer + Approver authenticated with known client IP/user-agent; Hangfire worker operational.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| System actor | a stable system identifier (e.g. system user id / "SYSTEM") | BR-7 |
| Job actions | PayrollRun.Completed, PayslipPDF.Generated, PayslipEmail.Sent | BR-7 |
| Interactive actions | PayrollRun.Approved, PayrollRun.Finalized | BR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Trigger a run compute via Hangfire; inspect the PayrollRun.Completed audit entry. | actor_user_id is the SYSTEM actor identifier, NOT null (BR-7); the entry is clearly attributable to system/job processing. |
| 2 | Trigger payslip PDF generation; inspect the PayslipPDF.Generated entry. | Logged with the system actor (BR-7); resource_type/resource_id correct; not null actor. |
| 3 | Trigger email distribution; inspect the PayslipEmail.Sent entry. | Logged with the system actor (BR-7); the job ran under its tenant job-arg context. |
| 4 | Have the approver Approve the run from a browser. | PayrollRun.Approved entry captures actor_user_id (the human approver) + ip_address + user_agent from the request -- server-derived, not client body (BR-5). |
| 5 | Finalize the run interactively. | PayrollRun.Finalized entry captures actor + ip_address + user_agent (BR-5); sufficient for non-repudiation. |
| 6 | Confirm no audit entry across the sequence has a null actor. | Every entry (system or human) has a non-null actor_user_id (BR-1/BR-7). |

## 6. Postconditions
- Job-driven entries carry the system actor; approval/finalize entries carry IP + user-agent; no null actor exists.
