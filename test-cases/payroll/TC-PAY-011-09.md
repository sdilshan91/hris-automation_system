# TC-PAY-011-09: No salary amounts in the email body + attachment size guard + authz -- the email body discloses no net/gross/deduction figures (amounts only in the PDF), the attached PDF is <=200KB, and only Payroll.*.All may trigger/re-send (security / NFR-4 / NFR-5 / FR-1)

## 1. Test Objective
Verify NFR-5, NFR-4 and the authorization contract: the payslip email BODY must not include any salary amounts (net/gross/deductions) -- the template variable {NetSalary} notwithstanding, the rendered body must not expose amounts in plaintext per the security requirement; amounts live only in the attached PDF. The attached payslip PDF must be <=200KB (NFR-4). Only an HR user with `Payroll.*.All` may trigger Send Payslips / Re-send; other roles get 403 and unauthenticated requests get 401.

## 2. Related Requirements
- User Story: US-PAY-011
- Acceptance Criteria: AC-2, AC-5
- Functional Requirements: FR-1, FR-2, FR-3, FR-4
- Non-Functional Requirements: NFR-4 (attachment <=200KB), NFR-5 (no amounts in body)

## 3. Preconditions
- Tenant "acme" Finalized run R with employees having generated PDFs; one PDF deliberately near the size boundary.
- Roles available: HR Officer (`Payroll.*.All`), a plain Employee, a Recruiter (no payroll perms), and an unauthenticated client.
- SMTP sink captures emails incl. attachment bytes.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Email body | no net/gross/deduction figures | NFR-5 |
| Attachment size | <= 200KB | NFR-4 |
| Allowed role | Payroll.*.All | FR-1 |
| Denied roles | Employee, Recruiter -> 403; none -> 401 | authz |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Send Payslips on run R; inspect each email body (NFR-5). | The body contains the employee name, pay month/year, company name, and a notice that the payslip is attached -- but NO salary amounts (no net/gross/deduction numbers) rendered in plaintext. |
| 2 | Inspect the attached PDF size (NFR-4). | Each attached payslip PDF is <= 200KB; if a generated PDF exceeds 200KB the send is flagged/handled per the size guard (oversize was flagged at generation per US-PAY-004), never silently delivering an oversized attachment. |
| 3 | Confirm amounts ARE present in the attached PDF, not the body. | The PDF (not the email text) carries earnings/deductions/net -- separation of disclosure is preserved (NFR-5). |
| 4 | As a plain Employee, attempt to trigger Send Payslips / Re-send via the API. | 403 Forbidden; no job enqueued (authz, FR-1). |
| 5 | As a Recruiter (no payroll perms), attempt the send. | 403 Forbidden; no job enqueued. |
| 6 | Unauthenticated, call the send endpoint. | 401 Unauthorized; no job enqueued. |

## 6. Postconditions
- Email bodies disclose no salary amounts; attachments stay <=200KB; only Payroll.*.All can send/re-send (others 403, unauth 401).
