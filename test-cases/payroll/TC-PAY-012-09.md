# TC-PAY-012-09: Authz -- Payroll history + audit-trail view/export require Payroll/audit-view permission; others 403, unauthenticated 401; audit-view-only cannot reach payroll mutations

## 1. Test Objective
Verify the access-control matrix for US-PAY-012's read surface: viewing Payroll History, run detail, the audit trail, and exporting the audit trail require `Payroll.*.All` or the audit-viewing permission; users lacking it get 403; unauthenticated requests get 401; and an audit-view-only role cannot perform payroll write operations.

## 2. Related Requirements
- User Story: US-PAY-012
- Acceptance Criteria: AC-1, AC-2, AC-4
- Functional Requirements: FR-1, FR-4, FR-5, FR-6
- Non-Functional Requirements: NFR-4
- Preconditions: `Payroll.*.All` or audit-viewing permission

## 3. Preconditions
- Tenant "acme" Active; users: HR Officer (Payroll.*.All), Auditor (audit-view only), plain Employee (no payroll/audit perm).
- Payroll history + audit entries exist.

## 4. Test Data
| Role | Expected on history/audit read+export | Notes |
|------|----------------------------------------|-------|
| Payroll.*.All | 200 | full access |
| Auditor (audit-view) | 200 read + export | AC-4 viewer |
| Employee (no perm) | 403 | AC-1/2/4 |
| Unauthenticated | 401 | -- |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As HR Officer, GET history, run detail, audit trail, and POST audit export. | All return 200; data scoped to acme. |
| 2 | As Auditor (audit-view only), GET audit trail + export. | 200 -- the auditor can view and export the trail (AC-4). |
| 3 | As Auditor, attempt a payroll mutation (e.g. update a component). | 403 -- audit-view does not grant write; the auditor surface is read-only. |
| 4 | As plain Employee, GET history / audit trail / run detail. | 403 Forbidden on each; no payroll history or audit data returned. |
| 5 | Unauthenticated (no/expired token), GET any of the endpoints. | 401 Unauthorized. |
| 6 | Confirm 403/401 bodies leak no audit data. | Error responses contain no audit rows, actor names, or run figures. |

## 6. Postconditions
- Only permitted roles read/export history + audit; auditor is read-only; others 403/401; no data leak in error paths.
