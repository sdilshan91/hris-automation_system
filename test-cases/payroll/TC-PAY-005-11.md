# TC-PAY-005-11: My Payslips list and expandable detail card meet WCAG 2.1 AA (accessibility)

## 1. Test Objective
Verify NFR-3 / AC-2: the My Payslips list table and the inline expandable detail card are WCAG 2.1 AA compliant -- keyboard operable, screen-reader friendly, with sufficient color contrast (including the green-tinted earnings / red-tinted deduction rows not relying on color alone), proper roles/labels, focus management on expand/collapse, and an accessible Download PDF action.

## 2. Related Requirements
- User Story: US-PAY-005
- Acceptance Criteria: AC-2
- Non-Functional Requirements: NFR-3
- Reference: technical doc section 32 (accessibility)

## 3. Preconditions
- Tenant "acme"; Employee EMP-001 with several Finalized payslips and one open detail card.
- axe-core / screen reader (NVDA or VoiceOver) available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Surfaces | My Payslips list + expandable detail card + Download PDF button | NFR-3 |
| Standard | WCAG 2.1 AA | section 32 |
| Contrast min | 4.5:1 text / 3:1 large | AA |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run axe-core on the My Payslips list view. | No WCAG 2.1 AA violations; list table has proper table semantics / row roles, column headers associated with cells. |
| 2 | Navigate the list with keyboard only (Tab / Arrow / Enter). | Every row, year filter, search, pagination control, and Download button is reachable and operable; visible focus indicator throughout. |
| 3 | Expand a payslip row with Enter/Space. | The inline detail card opens; focus moves into / is announced for the expanded region; aria-expanded state reflects open/closed. |
| 4 | Run axe-core on the expanded detail card. | No AA violations; earnings/deductions tables have headers; YTD column labeled. |
| 5 | Verify earnings (green) vs deductions (red) rows. | Distinction is conveyed by text/label, not color alone; contrast of tinted rows meets >= 4.5:1 for text. |
| 6 | Screen-reader pass over list + detail. | Amounts, component names, and the Download PDF button are announced with meaningful labels; right-aligned monospace numerics read correctly. |
| 7 | Collapse the card with keyboard. | Focus returns to the originating row; no focus trap. |

## 6. Postconditions
- No state change. List and detail views pass WCAG 2.1 AA via automated + manual checks.
