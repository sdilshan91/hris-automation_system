# TC-PAY-007-10: Bulk CSV of 1,000 adjustments completes <=30s (NFR-2); adjustment processing adds <=10% run overhead (NFR-1)

## 1. Test Objective
Verify FR-2 / NFR-2 / NFR-1: a bulk CSV upload of 1,000 adjustment records (employee_no, adjustment_type, amount, description, is_taxable) is validated and committed within 30 seconds with a validation preview before commit; and including adjustments in a payroll run adds no more than 10% overhead to the total run time versus a baseline run without adjustments.

## 2. Related Requirements
- User Story: US-PAY-007
- Functional Requirements: FR-2, FR-3
- Non-Functional Requirements: NFR-1 (<=10% run overhead), NFR-2 (1,000 records <=30s)
- Business Rules: BR-1

## 3. Preconditions
- Tenant "acme" seeded with >= 1,000 active employees (valid employee_no values); user with `Payroll.*.All`.
- A baseline payroll-run timing for the period WITHOUT adjustments is recorded for the NFR-1 comparison.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| CSV | 1,000 rows: employee_no, adjustment_type, amount, description, is_taxable (header row) | NFR-2 |
| CSV with errors | 50 rows referencing unknown employee_no / bad type | preview must flag |
| Baseline run | same period, no adjustments | NFR-1 reference |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Drag-drop a 1,000-row valid CSV; observe the validation preview. | Preview parses all rows, shows a per-row valid/invalid summary, no commit yet (FR-2). |
| 2 | Commit the 1,000-row upload; measure wall time end-to-end. | All 1,000 `payroll_adjustment` rows created (Pending) within <= 30s (P95 over repeated runs) (NFR-2). |
| 3 | Upload a CSV containing 50 invalid rows (unknown employee_no, bad type). | Preview flags the 50 invalid rows; HR can commit only valid rows or abort; no partial silent corruption (FR-2). |
| 4 | Record a baseline payroll-run time for a period with zero adjustments. | Baseline T0 captured. |
| 5 | Run the same period with the 1,000 pending adjustments present; measure run time T1. | (T1 - T0) / T0 <= 10% -- adjustment processing overhead within budget (NFR-1). |
| 6 | Confirm all imported rows carry tenant_id=acme (no cross-tenant employee_no resolution). | Bulk resolution is tenant-scoped (ties to TC-PAY-ISO-027). |

## 6. Postconditions
- 1,000-row import within SLA; run overhead within 10%; invalid rows surfaced pre-commit.
