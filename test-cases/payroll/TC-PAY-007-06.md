# TC-PAY-007-06: Adjustment created after the target period's run enters Processing is deferred to the next period (BR-8 timing boundary)

## 1. Test Objective
Verify BR-8 / FR-3: an adjustment created after the payroll run for its target period has entered Processing status is NOT included in that in-flight run; it is deferred to the next available period. Covers the timing boundary against the Pending-pickup window of FR-3.

## 2. Related Requirements
- User Story: US-PAY-007
- Functional Requirements: FR-3
- Business Rules: BR-8 (created-after-Processing -> deferred to next period), BR-7 (Finalized -> next period)
- Data Requirements: S7 (status, applicable_pay_month/year)

## 3. Preconditions
- Tenant "acme"; user with `Payroll.*.All`; Employee X active structure.
- June 2026 payroll run exists and is in Processing status (US-PAY-003); July 2026 has no run yet.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Late adjustment | type=Bonus, amount=2500.00, intended period=2026-06 | created while June run = Processing |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | With the June 2026 run in Processing, create a Bonus adjustment for Employee X targeting June 2026. | The system detects the June run is Processing (BR-8); the adjustment is NOT picked up by the in-flight June run. |
| 2 | Inspect the persisted record's effective period. | applicable_pay_month/year is set to July 2026 (deferred to the next available period), status=Pending (BR-8). |
| 3 | Let the June run finish; open the June payslips. | The late Bonus does NOT appear on any June payslip (FR-3 pickup window closed at Processing). |
| 4 | Execute the July 2026 run. | The deferred Bonus appears on Employee X's July payslip (FR-3). |
| 5 | Boundary contrast: create an adjustment for July 2026 while June is Processing but July has no run. | Included normally in the eventual July run (only the in-Processing/Finalized target triggers deferral). |

## 6. Postconditions
- The late adjustment is deferred to and applied in July, not the in-flight June run.
