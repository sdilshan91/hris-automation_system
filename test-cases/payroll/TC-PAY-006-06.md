# TC-PAY-006-06: Taxable income = gross - exempt components - declared exemptions; below-threshold / tax-exempt employee skips tax deduction

## 1. Test Objective
Verify BR-2 / BR-6 / FR-7: income tax is computed on **taxable income = gross earnings - exempt components - declared exemptions** (e.g. provident-fund contributions, investment declarations / standard deduction), not on raw gross. And per BR-6, an employee whose taxable income falls below the lowest taxable threshold (or who has a tax-exempt status) has tax skipped entirely (tax = 0), not computed as a negative or error.

## 2. Related Requirements
- User Story: US-PAY-006
- Acceptance Criteria: AC-1
- Functional Requirements: FR-5, FR-7 (exemptions/rebates)
- Business Rules: BR-2 (taxable income), BR-6 (below-threshold skip)
- Data Requirements: S7 (tax_slab, statutory_rule)

## 3. Preconditions
- Tenant "acme" with slabs [0-250K@0%, 250K-500K@5%, 500K-1M@20%, 1M+@30%] and a standard-deduction / Section-80C-equivalent exemption configured (FR-7).
- User authenticated as Tenant Admin / `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Gross earnings | 800,000 | annualised |
| Exempt components | 50,000 | e.g. travel allowance exempt |
| Declared exemptions | 100,000 | PF + investments (FR-7) |
| Taxable income | 650,000 | 800K - 50K - 100K (BR-2) |
| Below-threshold income | 240,000 | < 250K (BR-6) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Compute tax for gross 800,000 with 50,000 exempt + 100,000 declared exemptions. | Taxable income = 650,000 (BR-2); tax computed progressively on 650,000 = 0 + 12,500 + 150,000*20% (=30,000) = 42,500. |
| 2 | Inspect that tax is NOT computed on raw gross 800,000. | Tax base is the reduced 650,000, not 800,000 (BR-2). |
| 3 | Compute tax for an employee whose taxable income = 240,000 (below the 250K threshold). | Tax = 0; the deduction is skipped entirely (BR-6); no negative tax, no error. |
| 4 | Flag an employee as tax-exempt status and compute. | Tax skipped (tax = 0) regardless of income (BR-6). |
| 5 | Boundary: taxable income exactly at the threshold 250,000. | Tax = 0 (entirely within the 0% slab); just above (250,001) yields a tiny positive tax. |
| 6 | Verify exemptions cannot drive taxable income negative. | If exemptions exceed gross, taxable income floors at 0 and tax = 0 (no negative base). |

## 6. Postconditions
- No state change (calculation only); taxable-income reduction and below-threshold skip verified.
