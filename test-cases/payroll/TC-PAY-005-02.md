# TC-PAY-005-02: Selecting a payslip expands the inline detail card with full earnings + deductions breakdown (and YTD if enabled), with a Download PDF action (happy path)

## 1. Test Objective
Verify AC-2 / FR-3 / FR-7: when the Employee clicks a payslip row, the detail opens inline as an expandable (Notion-style) card without navigating away, showing employee header (name, employee number, department, designation), a full Earnings breakdown and a full Deductions breakdown (each row: component name + amount, and YTD amount when the tenant has YTD display enabled), gross earnings, total deductions, net salary, and working/paid/LOP days, plus a "Download PDF" button. The detail payload matches the Payslip Detail contract.

## 2. Related Requirements
- User Story: US-PAY-005
- Acceptance Criteria: AC-2
- Functional Requirements: FR-3, FR-7
- Business Rules: BR-2 (denormalised point-in-time component names)
- Data Requirements: API Response - Payslip Detail (employee{}, earnings[], deductions[], grossEarnings, totalDeductions, netSalary, workingDays, paidDays, lopDays, ytdAmount per component)

## 3. Preconditions
- Tenant "acme"; Employee EMP-001 authenticated with `Payroll.Read.Self`.
- EMP-001 has a Finalized May 2026 payslip with multiple earning components (e.g. Basic, HRA, Allowances) and deduction components (e.g. EPF Employee, Tax) plus statutory items.
- Tenant has YTD display enabled (FR-7); prior-month Finalized slips exist for the same fiscal year so YTD sums are computable.

| Field | Value | Notes |
|-------|-------|-------|
| Payslip | May 2026 (EMP-001) | Finalized |
| Earning sample | Basic Salary 25000.00, ytd 125000.00 | green-tinted row |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | From the list, click the May 2026 payslip row. | The detail expands inline as an animated card / slide-over (no new page, AC-2). |
| 2 | Verify the employee header. | Shows employee name, employee number, department, designation (component names denormalised/point-in-time per BR-2). |
| 3 | Verify the Earnings section. | Each earning component listed with name + amount; YTD column populated when enabled (Basic 25000.00 / ytd 125000.00); rows visually distinct (green tint). |
| 4 | Verify the Deductions section. | Each deduction component listed with name + amount + YTD (EPF 3000.00 / ytd 15000.00); rows visually distinct (red tint); statutory items itemised. |
| 5 | Verify the totals + days. | Gross 50000.00, total deductions 8500.00, net 41500.00; working 22 / paid 22 / LOP 0; sum(earnings) = gross, sum(deductions) = totalDeductions, gross - deductions = net. |
| 6 | Verify the Download PDF action. | A "Download PDF" secondary button with a download icon is present and enabled. |
| 7 | Verify the detail API payload. | GET my-payslips/{payslipId} returns the Payslip Detail contract for EMP-001 only. |

## 6. Postconditions
- No state change. The expanded detail accurately reflects the persisted payroll_slip_detail rows.
