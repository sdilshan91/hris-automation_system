# TC-PAY-010-05: Half-day absence counts as 0.5 LOP days (boundary, BR-2)

## 1. Test Objective
Verify BR-2 / FR-3: a half-day absence (without covering approved paid leave) contributes 0.5 LOP days, not a full day and not zero. With a daily rate of 1,000, one half-day absence yields a 500 LOP deduction; combined full-and-half-day cases sum correctly (e.g. 2 full + 1 half = 2.5 LOP -> 2,500).

## 2. Related Requirements
- User Story: US-PAY-010
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-3
- Business Rules: BR-1, BR-2
- Data Requirements: Attendance Summary.half_days (numeric(5,2))

## 3. Preconditions
- Tenant "acme" Active; Payroll module enabled.
- Employee has an active salary structure; daily_rate = 1,000 (monthly_basic 22,000 / 22 working days).
- Attendance for the period FINALIZED with half_days = 1 (a recorded half-day absence) and no approved paid leave covering it.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| half_days (uncovered) | 1 | -> 0.5 LOP (BR-2) |
| daily_rate | 1,000 | |
| Expected LOP for half-day | 0.5 * 1,000 = 500 | boundary |
| Combined case | 2 full + 1 half | -> 2.5 LOP -> 2,500 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run payroll for a period where the employee has 1 uncovered half-day absence. | `lop_days = 0.5`; LOP deduction = 0.5 * 1,000 = 500 (BR-2). |
| 2 | Verify it is neither rounded up to 1 nor dropped to 0. | The half-day is exactly 0.5 LOP -- numeric(5,2) precision preserved. |
| 3 | Combine 2 full absent days + 1 half-day absence (all uncovered). | lop_days = 2.5; LOP = 2.5 * 1,000 = 2,500. |
| 4 | Add an approved paid half-day leave covering the half-day absence. | That half-day is excluded from LOP (BR-1) -> lop_days drops accordingly. |
| 5 | Verify net impact and reconciliation. | Net reduced by exactly the half-day-inclusive LOP; payslip totals reconcile. |

## 6. Postconditions
- Half-day absences are counted as 0.5 LOP and combine correctly with full-day absences; covered half-days excluded.
