# TC-PAY-009-08: Bank advice account-number masking -- last-4 only in UI preview, FULL number in the downloaded file (BR-2)

## 1. Test Objective
Verify BR-2: the bank advice preview rendered in the UI must mask account numbers partially, showing only the last 4 digits (e.g. ****1234), while the actual downloaded file contains the FULL, unmasked account numbers required for disbursement. This prevents shoulder-surfing/PII exposure on screen while preserving file correctness, and the masked value must never be what is written into the downloadable file.

## 2. Related Requirements
- User Story: US-PAY-009
- Acceptance Criteria: AC-2
- Functional Requirements: FR-1e
- Non-Functional Requirements: NFR-4
- Business Rules: BR-2
- Data Requirements: S7 (Bank Advice File Columns)

## 3. Preconditions
- Tenant "acme"; Finalized May 2026 run; employees with known full account numbers (e.g. 9876543211234).
- HR user `hr1` with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Full account | 9876543211234 | stored value |
| UI preview | ****1234 (last 4) | BR-2 masked |
| File value | 9876543211234 (full) | BR-2 download |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As hr1, open the Bank Advice preview table in the UI. | Account numbers are masked to last-4 only (e.g. ****1234); the full number is NOT present in the rendered DOM/markup (BR-2, NFR-4). |
| 2 | Inspect the API response that populates the preview. | The preview API returns masked account values only; full numbers are not sent to the browser for the preview (BR-2). |
| 3 | Click "Download Full File"; open the downloaded bank advice file. | The file contains the FULL unmasked account numbers (e.g. 9876543211234) needed for disbursement (BR-2, AC-2). |
| 4 | Diff the masked preview value vs the file value. | They differ -- masking applies ONLY to the preview; the file never contains the masked form. |
| 5 | Confirm the full-file download is permission-gated. | Only an authorized Payroll/Reports user can download the full file (see TC-PAY-009-09); preview-vs-file distinction does not leak full numbers to unauthorized roles. |
| 6 | Check logs/audit for the full account number. | Full account numbers are not written to application logs; PII not leaked (NFR-4). |

## 6. Postconditions
- UI preview shows masked (last-4) account numbers; only the authorized downloaded file carries full numbers; no full-number leak to the browser preview or logs.
