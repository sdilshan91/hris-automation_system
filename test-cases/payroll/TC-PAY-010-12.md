# TC-PAY-010-12: Reconciliation table (color-coded cells) + not-finalized warning banner + encashment UI WCAG 2.1 AA; 360-1920 responsive (NFR-3)

## 1. Test Objective
Verify the attendance/leave integration UI meets WCAG 2.1 AA and is responsive 360px-1920px: the pre-payroll reconciliation table with color-coded cells (red absences, amber late, green full attendance) must not convey status by color alone; the daily-attendance drill-down, the not-finalized warning banner, the overtime-breakdown tooltip, and the encashment trigger UI are all keyboard-operable and screen-reader friendly.

## 2. Related Requirements
- User Story: US-PAY-010
- Acceptance Criteria: AC-1, AC-3, AC-4
- Functional Requirements: FR-5, FR-7
- Non-Functional Requirements: NFR-3 (implied WCAG/responsive)
- UI/UX: reconciliation table, color-coded cells, drill-down calendar, warning banner, OT tooltip, encashment UI

## 3. Preconditions
- Tenant "acme"; reconciliation page, payroll initiation page, and encashment UI reachable with seeded data (absences, lates, full attendance, OT hours, an unfinalized-attendance state).
- Axe (or equivalent) + keyboard-only + screen-reader (NVDA/VoiceOver) available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Color cells | red=absent, amber=late, green=full | not color-only |
| Surfaces | reconciliation table, drill-down, warning banner, OT tooltip, encashment UI | WCAG AA |
| Viewports | 360, 768, 1280, 1920 px | responsive |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run axe on the reconciliation page, drill-down, payroll-initiation, and encashment UI. | Zero critical/serious WCAG 2.1 AA violations. |
| 2 | Inspect the color-coded reconciliation cells. | Status is also conveyed by text/icon/label (e.g. "Absent", "Late") -- not color alone; contrast >= 4.5:1 (1.4.1, 1.4.3). |
| 3 | Keyboard-only: navigate the table, open an employee's daily drill-down, hover/focus the OT tooltip, trigger encashment. | All reachable/operable via keyboard; visible focus throughout; OT breakdown tooltip exposed on focus, not hover-only (2.1.1, 2.4.7). |
| 4 | Screen-reader: read the reconciliation table + the not-finalized warning banner. | Table headers/cells announced with associations; the warning ("Attendance not yet finalized") announced as an alert with its finalization link (1.3.1, 4.1.3). |
| 5 | Resize 360 -> 1920 px. | Reconciliation summary usable at 360px (detailed daily drill-down may be desktop-only per UI notes); no horizontal scroll trap or clipped content. |
| 6 | Cross-browser smoke (Chrome, Edge, Firefox, Safari). | Reconciliation table + banner + encashment UI render and operate consistently. |

## 6. Postconditions
- Integration UI passes WCAG 2.1 AA, conveys status beyond color, is keyboard/SR operable, and responsive 360-1920.
