# TC-PAY-005-12: Payslip list and detail are fully responsive and readable at 360px, with horizontally scrollable breakdown table (responsive / AC-5)

## 1. Test Objective
Verify AC-5: on a mobile device down to 360px width, the My Payslips list and detail render as a fully responsive, readable layout -- the list becomes a full-width stacked card layout, the Download PDF button is prominently placed, and the component breakdown table is horizontally scrollable if it overflows, with no content clipped or overlapping. Verified across the 360px-to-1920px responsive range.

## 2. Related Requirements
- User Story: US-PAY-005
- Acceptance Criteria: AC-5
- Non-Functional Requirements: NFR-3 (a11y carries into mobile)
- UI/UX Notes: S8 (full-width card layout, stacked rows, horizontal scroll for breakdown)

## 3. Preconditions
- Tenant "acme"; Employee EMP-001 with Finalized payslips and a multi-component breakdown.
- Test harness/emulator supporting 360px, 768px, 1024px, 1920px viewports (Playwright device emulation).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Min viewport | 360px | AC-5 |
| Breakpoints | 360 / 768 / 1024 / 1920 | responsive range |
| Mobile layout | full-width stacked cards | S8 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Render My Payslips at 360px width. | List shows as full-width stacked cards; Pay Period / Gross / Deductions / Net all readable; no horizontal page scroll, no clipped text (AC-5). |
| 2 | Open a payslip detail at 360px. | Detail renders as a full-width card; earnings/deductions visible; Download PDF button prominent and tappable (>= 44px target). |
| 3 | Inspect the component breakdown table at 360px. | If the table overflows, it is horizontally scrollable within its container (page does not scroll horizontally); all columns reachable via scroll. |
| 4 | Rotate / widen to 768px and 1024px. | Layout reflows progressively (cards -> table / slide-over on desktop); no overlap. |
| 5 | Render at 1920px. | Desktop table / slide-over layout; content centered/constrained, readable. |
| 6 | Verify touch interactions at 360px. | Row tap expands detail; Download PDF tap initiates download; no hover-only affordances. |

## 6. Postconditions
- No state change. The payslip views are usable and readable across 360px-1920px.
