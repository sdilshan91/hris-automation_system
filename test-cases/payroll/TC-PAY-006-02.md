# TC-PAY-006-02: Golden progressive income-tax calculation -- income 750,000 over [0-250K@0%, 250K-500K@5%, 500K-1M@20%] yields tax of exactly 62,500

## 1. Test Objective
Verify BR-3 / FR-5 / AC-1: the statutory calculation service computes income tax **progressively** -- each slab's rate applies only to the income within that slab's range, not to the total income. For a taxable income of 750,000 over slabs [0-250K@0%, 250K-500K@5%, 500K-1M@20%, 1M+@30%], the result is exactly 62,500 (250,000*0% + 250,000*5% + 250,000*20% = 0 + 12,500 + 50,000 = 62,500), NOT a flat 750,000*20% = 150,000. This is the canonical golden test from US-PAY-006 Test Hints.

- User Story: US-PAY-006

- Functional Requirements: FR-5 (Test Calculation), FR-6

## 3. Preconditions
- Tenant "acme" with the FY slabs [0-250K@0%, 250K-500K@5%, 500K-1M@20%, 1M+@30%] configured and active.
- User authenticated as Tenant Admin / `Payroll.*.All`.

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Invoke the statutory tax calculation (or the Test Calculation panel, FR-5) with taxable income 750,000. | The computed income tax is exactly 62,500 (BR-3). |
| 2 | Inspect the per-slab breakdown. | Slab 0-250K contributes 0; 250K-500K contributes 12,500; 500K-1M contributes 50,000 on the 250,000 that falls in that band; total 62,500. |
| 3 | Assert the result is NOT flat-rate. | The result is NOT 150,000 (750,000 * 20% top-band rate); progressive evaluation is confirmed. |
| 4 | Boundary: compute for taxable income exactly 250,000 (top of the 0% band). | Tax = 0 (entire amount in the 0% slab). |
| 5 | Boundary: compute for taxable income exactly 500,000. | Tax = 12,500 (0 + 250,000*5%); no double-counting at the slab edge. |
| 6 | Boundary: compute for taxable income 1,200,000 (into the 30% band). | Tax = 0 + 12,500 + 100,000 (500K-1M@20%) + 200,000*30% = 172,500; 1M+ band applies only to the 200,000 above 1M. |
