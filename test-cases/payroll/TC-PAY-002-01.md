# TC-PAY-002-01: Assign active structure with CTC -> employee_salary_component rows created from rules, with CTC breakdown preview before confirm (happy path)

## 1. Test Objective
Verify the primary success flow across AC-1 and FR-1/FR-2/FR-3: an authenticated HR Officer with `Payroll.*.All` assigns an active salary structure to an Active employee with an annual CTC of 600,000 and an effective date; the system auto-calculates each component value from the CTC and the component rules, renders a CTC breakdown preview (two-column Component / Monthly Amount table with a total) BEFORE confirmation (FR-3), and on confirm persists one `employee_salary_component` row per structure component (annual + monthly numeric(18,2), `is_override`=false, `effective_from`, `tenant_id`).

## 2. Related Requirements
- User Story: US-PAY-002
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-2, FR-3
- Business Rules: BR-1
- Data Requirements: S7 (employee_salary_component; numeric(18,2); tenant_id FK; effective_from/to)

## 3. Preconditions
- Tenant "acme" Active, subdomain `acme.yourhrm.com`, Payroll module enabled.
- An active salary structure "Full-Time India" (FT-IN) exists with components: Basic (40% of CTC), HRA (20% of Basic), Conveyance (fixed 24,000/yr).
- Employee "Ravi Kumar" exists in Core HR with status Active and no current salary assignment.
- HR Officer "Maya Singh" authenticated in acme with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Subdomain | acme.yourhrm.com | Active tenant |
| Employee | Ravi Kumar (Active) | No current assignment |
| Salary structure | Full-Time India (FT-IN), active | Basic 40%, HRA 20% of Basic, Conveyance fixed 24,000 |
| annual_ctc | 600000.00 | numeric(18,2) |
| effective_from | 2026-07-01 | Required |
| Expected Basic | 240000.00 / yr (20000.00/mo) | 40% of CTC |
| Expected HRA | 48000.00 / yr (4000.00/mo) | 20% of Basic |
| Expected Conveyance | 24000.00 / yr (2000.00/mo) | Fixed |
| Remainder/Special Allowance | 288000.00 / yr | CTC balancer so sum == CTC (FR-6) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate to Ravi Kumar's profile -> "Compensation" tab -> "Assign Salary Structure". | Assignment panel opens with fields: salary_structure (select), effective_from, annual_ctc, optional per-component overrides. |
| 2 | Select FT-IN, enter annual_ctc 600000.00, effective_from 2026-07-01; click "Preview"; observe `POST /api/v1/payroll/employees/{id}/salary/preview`. | Response <= 500ms (NFR-2 covered separately); body returns calculated per-component annual+monthly values; breakdown table renders Basic 20000/mo, HRA 4000/mo, Conveyance 2000/mo, Special Allowance 24000/mo, total monthly 50000.00. Preview does NOT persist. |
| 3 | Verify the sum of components equals the declared CTC. | Sum of annual components = 600000.00 == annual_ctc (within +/-1, FR-6). |
| 4 | Click "Confirm"; observe `POST /api/v1/payroll/employees/{id}/salary`. | Request carries `X-Tenant-Subdomain: acme` + bearer; response 201 Created; body lists created component rows with `tenant_id`=acme, `is_override`=false, `effective_from`=2026-07-01, `effective_to`=null. |
| 5 | Verify persisted rows. | One `employee_salary_component` row per structure component (Basic, HRA, Conveyance, Special Allowance) for Ravi, all `tenant_id`=acme; `annual_amount`/`monthly_amount` stored as numeric(18,2); monthly = annual/12. |
| 6 | Reload the Compensation tab. | Shows current structure FT-IN, CTC 600,000, and the component breakdown card; employee no longer flagged "Payroll Incomplete" (BR-5). |

## 6. Postconditions
- Ravi Kumar has an active salary assignment (FT-IN, CTC 600,000, effective 2026-07-01) with one employee_salary_component row per component, all tenant-scoped.
