# TC-PAY-003-08: Status transition matrix enforced; re-run allowed in ReviewPending/Cancelled; Finalized is immutable (BR-6 / BR-7 / FR-7)

## 1. Test Objective
Verify BR-6, BR-7, and FR-7: the payroll_run status machine permits ONLY the legal transitions Queued -> Processing -> ReviewPending -> Approved -> Finalized, plus any pre-Finalized status -> Cancelled; illegal transitions are rejected. A run in ReviewPending or Cancelled may be RE-RUN (previous slip data is replaced, FR-7). Once Finalized, the run is IMMUTABLE -- no status change, no slip mutation, no re-run; corrections must go through a payroll adjustment (US-PAY-007, out of scope here).

## 2. Related Requirements
- User Story: US-PAY-003
- Acceptance Criteria: AC-3 (ReviewPending), AC-4 (Finalized conflict)
- Functional Requirements: FR-1, FR-7
- Business Rules: BR-6, BR-7
- Data Requirements: S7 (payroll_run.status; payroll_slip replacement on re-run)

## 3. Preconditions
- Tenant "acme"; a payroll_run for May 2026 reachable through each status for the matrix checks.
- HR with `Payroll.Run` (+ approve permission for the Approved transition).

## 4. Test Data
| From -> To | Legal? | Notes |
|-----------|--------|-------|
| Queued -> Processing | yes | worker start |
| Processing -> ReviewPending | yes | compute done |
| ReviewPending -> Approved | yes | reviewer approves |
| Approved -> Finalized | yes | finalize |
| any pre-Finalized -> Cancelled | yes | BR-6 |
| ReviewPending -> Queued | no | backward |
| Finalized -> * | no | immutable (BR-7) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Drive a run through Queued -> Processing -> ReviewPending -> Approved -> Finalized. | Each legal transition succeeds and is timestamped/audited (approved_by/at, finalized_at). |
| 2 | Attempt an illegal backward transition (e.g. ReviewPending -> Queued, Approved -> Processing). | Rejected (409/422); status unchanged. |
| 3 | Cancel a run in Processing (pre-Finalized -> Cancelled). | Succeeds; status=Cancelled. |
| 4 | Re-run a period whose run is ReviewPending (FR-7). | New computation REPLACES the prior slips for that period (no duplicate slips); run returns to Processing then ReviewPending. |
| 5 | Re-run a period whose run is Cancelled (FR-7). | Allowed; fresh slips produced (cross-ref TC-PAY-003-02 step 3). |
| 6 | Attempt ANY change on a Finalized run: status change, edit a slip, re-run, re-initiate the period. | All rejected (BR-7 immutability; re-initiate -> 409 per AC-4); Finalized slips unchanged; message points to payroll adjustment (US-PAY-007). |

## 6. Postconditions
- Only legal transitions occur; ReviewPending/Cancelled runs are re-runnable with slip replacement; Finalized runs are immutable.
