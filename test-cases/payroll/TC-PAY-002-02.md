# TC-PAY-002-02: Component override saved while other components retain calculated values

## 1. Test Objective
Verify AC-3 / FR-1: when HR overrides the calculated value of a specific component (sets HRA to a custom fixed amount) during assignment, the override is persisted for that employee-component combination with `is_override`=true while all other components retain their rule-calculated values (`is_override`=false). The CTC balancer adjusts so the component sum still equals the declared CTC (FR-6).

## 2. Related Requirements
- User Story: US-PAY-002
- Acceptance Criteria: AC-3
- Functional Requirements: FR-1, FR-2, FR-3, FR-6
- Data Requirements: S7 (employee_salary_component.is_override)

## 3. Preconditions
- As TC-PAY-002-01 preconditions; FT-IN structure available; Ravi Kumar Active with no current assignment.
- HR authenticated in acme with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| annual_ctc | 600000.00 | numeric(18,2) |
| HRA override (annual) | 60000.00 | Custom fixed; calculated would be 48000.00 |
| effective_from | 2026-07-01 | Required |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open assign panel for Ravi, select FT-IN, CTC 600000.00; in the breakdown override field for HRA enter 60000.00 (annual). | HRA field is visually distinct (highlighted) to indicate a non-standard value; preview recalculates. |
| 2 | Click "Preview"; observe `POST .../salary/preview`. | HRA shows 60000.00/yr (5000/mo) flagged as override; Basic still 240000.00 (calculated); CTC balancer (Special Allowance) reduces by 12000.00 so total annual = 600000.00 (FR-6). |
| 3 | Confirm; observe `POST .../salary`. | 201 Created; HRA row persisted with `is_override`=true and `annual_amount`=60000.00; Basic/Conveyance/Special rows `is_override`=false. |
| 4 | Verify persisted rows. | Only HRA carries `is_override`=true; other components retain calculated values; sum == CTC within +/-1. |
| 5 | Edit the assignment, change HRA override to a value that breaks the CTC sum beyond tolerance with no balancer room. | Save rejected 400 with sum-mismatch message (cross-ref TC-PAY-002-05). |

## 6. Postconditions
- Ravi has an assignment where HRA is an override and all other components are calculated; component sum == declared CTC.
