# TC-PAY-010-06: Late-arrival-to-LOP conversion -- 6 lates under policy "3 lates = 0.5 LOP" -> 1.0 LOP day (boundary, BR-3)

## 1. Test Objective
Verify BR-3 / FR-3: late arrivals beyond the tenant-configured threshold are converted to LOP per the tenant's late-deduction policy. With the policy "3 lates = 0.5 LOP day" and 6 late arrivals in the period, the conversion yields exactly 1.0 LOP day; boundary counts at/below the threshold and partial blocks are handled correctly.

## 2. Related Requirements
- User Story: US-PAY-010
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-3
- Business Rules: BR-3
- Data Requirements: Attendance Summary.late_count (int); tenant late-deduction policy

## 3. Preconditions
- Tenant "acme" Active; Payroll module enabled.
- Tenant late-deduction policy configured: every 3 lates = 0.5 LOP day.
- Employee has an active salary structure; daily_rate = 1,000.
- Attendance for the period FINALIZED with late_count = 6.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Policy | 3 lates = 0.5 LOP | tenant config (BR-3) |
| late_count | 6 | -> 1.0 LOP |
| daily_rate | 1,000 | |
| Expected LOP from lates | 1.0 * 1,000 = 1,000 | golden |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run payroll for the employee with late_count = 6 under the "3 lates = 0.5 LOP" policy. | Late-to-LOP conversion = (6 / 3) * 0.5 = 1.0 LOP day; LOP deduction from lates = 1,000 (BR-3). |
| 2 | Boundary: late_count = 2 (below threshold). | No LOP from lates (0 conversion) -- below the first 3-late block. |
| 3 | Boundary: late_count = 3 (exact threshold). | Exactly 0.5 LOP day from lates. |
| 4 | Boundary: late_count = 5 (one full block + partial). | Conversion uses complete blocks per tenant policy -> 0.5 LOP (the 2 trailing lates do not form a new block) unless policy specifies otherwise; the configured rule is applied consistently. |
| 5 | Combine late-LOP with absence-LOP. | Total lop_days = absence LOP + late-conversion LOP; deduction reconciles; no double counting. |

## 6. Postconditions
- Late arrivals convert to LOP per the tenant policy; 6 lates @ "3=0.5" yields 1.0 LOP; threshold boundaries handled.
