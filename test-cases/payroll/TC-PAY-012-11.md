# TC-PAY-012-11: Audit-trail export to CSV and Excel -- filtered set exported with all required columns + correct values; diff view renders before/after side-by-side

## 1. Test Objective
Verify FR-5 and FR-8: the filtered payroll audit trail can be exported to CSV and Excel (.xlsx via ClosedXML); the export contains the same rows/columns as the on-screen filtered set with accurate values (timestamp, actor, action, resource_type, resource_id, before/after, IP, user-agent); and the configuration-change diff view renders before/after side-by-side with changed fields highlighted.

## 2. Related Requirements
- User Story: US-PAY-012
- Acceptance Criteria: AC-4
- Functional Requirements: FR-5 (CSV/Excel export), FR-8 (before/after diff view)
- Business Rules: BR-4 (auditor reconstruction)
- Data Requirements: ClosedXML (Excel)

## 3. Preconditions
- Tenant "acme" Active; a filtered payroll audit set (e.g. last 30 days, action=SalaryComponent.Updated) with several entries that have non-trivial before/after JSON.
- Auditor authenticated with audit-view permission.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Filter | last 30 days, SalaryComponent.Updated | FR-4 |
| Export formats | CSV, .xlsx | FR-5 |
| Diff entry | HRA value 20 -> 25 | FR-8 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Apply the filter; click Export > CSV. | A CSV downloads containing exactly the filtered rows; columns include timestamp, actor, action, resource_type, resource_id, before, after, ip_address, user_agent; values match the on-screen data. |
| 2 | Click Export > Excel. | A valid OOXML .xlsx (ClosedXML) downloads, opens in a spreadsheet app, headers + rows + values match the filtered set; timestamps/text not corrupted. |
| 3 | Compare export row count to the on-screen filtered count. | Equal -- the export reflects the active filter, not the full unfiltered table. |
| 4 | Open a config-change entry's diff view in the UI. | before/after JSON rendered side-by-side; the changed field (value 20 -> 25) highlighted (amber=modified); unchanged fields not flagged; additions/removals coloured per S8. |
| 5 | Verify the export contains no other tenant's rows. | Export is tenant-scoped to acme (see TC-PAY-ISO-045/047). |

## 6. Postconditions
- CSV + Excel exports produced for the filtered set with correct columns/values; diff view renders before/after correctly; tenant-scoped.
