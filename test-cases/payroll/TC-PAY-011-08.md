# TC-PAY-011-08: Per-recipient payslip isolation + sender domain -- each email carries ONLY its own recipient's payslip (no cross-employee attachment mix-up), the "From" address uses the tenant's configured sender domain, and no other employee's data appears in the body (security / AC-5 / FR-8 / BR-4)

## 1. Test Objective
Verify AC-5, FR-8 and BR-4: every payslip email contains ONLY the recipient employee's own payslip PDF -- there is no cross-employee data leakage (an employee never receives or sees another employee's attachment, name, or amounts), even under concurrent/rate-limited sending. The email "From"/sender address uses the tenant's configured sender domain (e.g. `payroll@acme.yourhrm.com`) when available, else the system default. (Cross-TENANT isolation is covered by TC-PAY-ISO-041..044; this case focuses on cross-EMPLOYEE attachment/body isolation within a tenant + the sender domain.)

## 2. Related Requirements
- User Story: US-PAY-011
- Acceptance Criteria: AC-5
- Functional Requirements: FR-2, FR-3, FR-8
- Business Rules: BR-4 (tenant sender domain)
- Non-Functional Requirements: NFR-5 (no other-employee data in body)

## 3. Preconditions
- Tenant "acme" Finalized run R with 3 employees (EMP-001, EMP-002, EMP-003), distinct names + distinct PDFs.
- Tenant has a configured sender address `payroll@acme.yourhrm.com` (BR-4); a second tenant "globex" has its own sender `payroll@globex.yourhrm.com` for the default-fallback comparison.
- HR Officer authenticated in acme with `Payroll.*.All`; SMTP sink captures all messages incl. headers + attachments.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Run | R (acme), Finalized, 3 employees | distinct payslips |
| Expected per-email attachment | recipient's own {employeeId}.pdf only | AC-5 |
| Expected From | payroll@acme.yourhrm.com | BR-4 tenant sender |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Send Payslips on run R; capture all 3 emails at the sink. | 3 emails, one per employee, each addressed only to that employee (no shared To/CC/BCC). |
| 2 | Open each email's attachment and confirm ownership (AC-5). | EMP-001's email contains ONLY EMP-001's PDF; likewise EMP-002 and EMP-003 -- no employee receives another's attachment; no attachment swap under sequential/rate-limited sends. |
| 3 | Inspect each email body for foreign data (NFR-5, AC-5). | The body references only the recipient ({EmployeeName} = the recipient); no other employee's name/number/amounts appear; no payslip list/IDs of others leak. |
| 4 | Inspect the From / sender header (BR-4). | From = the tenant's configured `payroll@acme.yourhrm.com`; reply/envelope sender are tenant-scoped, not a generic shared address. |
| 5 | On a tenant without a configured sender, send and inspect From. | From falls back to the system default sender (BR-4) -- still a valid, tenant-appropriate address, never another tenant's domain. |

## 6. Postconditions
- Each recipient received only their own payslip with no cross-employee data in attachment or body; the From address is the tenant's configured (or default) sender.
