# TC-PAY-008-08: Approval review summary content + variance-vs-previous-month thresholds + exceptions list + drill-down to individual payslips (FR-4, FR-5)

## 1. Test Objective
Verify FR-4 / FR-5 / AC-2: the approval review page presents a comprehensive, correct summary (total employees, total gross, total deductions, total statutory, total net, previous-month comparison + variance %, and an exceptions/warnings list), applies the documented variance colour thresholds (green for decrease, amber for increase > 5%, red for increase > 15%), and lets the approver drill down into an individual employee's payslip.

## 2. Related Requirements
- User Story: US-PAY-008
- Acceptance Criteria: AC-2
- Functional Requirements: FR-4, FR-5
- Data Requirements: Payroll Run Summary fields (S7)

## 3. Preconditions
- A June 2026 run in AwaitingApproval for acme with 120 employees; a Finalized May 2026 run exists for variance comparison.
- Some exceptions exist: 1 employee with a negative-net warning, 1 missing salary structure (skipped, US-PAY-003 AC-6).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| May total_net | 5,000,000 | baseline |
| Variance cases | -3% (green), +8% (amber), +20% (red) | threshold boundaries FR-4 |
| Exceptions | negative-net warning, missing-structure skip | FR-4 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the approval review page for the June run. | The left summary panel shows total_employees=120, total_gross, total_deductions, total_statutory, total_net, previous_month_total_net (May), and variance_percentage -- all matching the underlying slip aggregates (FR-4). |
| 2 | Verify the variance figure + colour for total_net = -3% vs May. | Variance shown as a decrease and highlighted GREEN (FR-4). |
| 3 | Set up / verify a run whose total_net is +8% vs previous month. | Variance highlighted AMBER (increase > 5% and <= 15%) (FR-4 boundary). |
| 4 | Set up / verify a run whose total_net is +20% vs previous month. | Variance highlighted RED (increase > 15%) (FR-4 boundary). |
| 5 | Review the exceptions/warnings list. | The negative-net warning and the missing-structure skip are listed as exceptions on the review page (FR-4). |
| 6 | From the right-panel employee list, search for an employee and click to drill down. | The individual employee's payslip detail opens from the approval page (earnings/deductions/statutory/net), enabling the approver to verify before approving (FR-5, AC-2). |

## 6. Postconditions
- The approver sees a correct, complete summary with threshold-coloured variance and can drill into any employee payslip; no figure is fabricated.
