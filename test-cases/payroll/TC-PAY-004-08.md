# TC-PAY-004-08: Authorization -- only `Payroll.*.All` holders may generate/regenerate/retry/download payslips; others 403; unauthenticated 401

## 1. Test Objective
Verify the authorization surface of every payslip endpoint (generate, regenerate, individual retry, single download, Download All): all require the `Payroll.*.All` permission. An authenticated user WITHOUT it (plain Employee, Recruiter) receives 403 Forbidden; an unauthenticated request receives 401. Authorization is enforced server-side regardless of UI affordances. (Self-service employee download of one's OWN payslip, if/when offered, is a separate permission and out of scope here -- this verifies the HR/admin generation+management surface.)

## 2. Related Requirements
- User Story: US-PAY-004
- Acceptance Criteria: AC-1, AC-3, AC-4, AC-5
- Preconditions: "HR Officer has Payroll.*.All permission"
- Security: authentication + role-based authorization

## 3. Preconditions
- Tenant "acme"; run R with payslips; users: Maya (`Payroll.*.All`), Dev (Employee, no payroll perms), Recruiter (Recruitment.* only).

## 4. Test Data
| User | Permission | Expected |
|------|-----------|----------|
| Maya | Payroll.*.All | allowed |
| Dev | Employee (none) | 403 |
| Recruiter | Recruitment.* only | 403 |
| (none) | unauthenticated | 401 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Maya, POST generate, POST regenerate, POST retry, GET single-download, POST download-all. | All authorized (202/200); side effects occur. |
| 2 | As Dev (no payroll perms), call each of the 5 endpoints. | 403 Forbidden on every one; no job enqueued; no PDF served. |
| 3 | As Recruiter, call each endpoint. | 403 Forbidden -- a different-module permission does not grant `Payroll.*.All`. |
| 4 | Unauthenticated (no bearer), call each endpoint. | 401 Unauthorized on every one. |
| 5 | Verify UI for Dev/Recruiter. | Generate/Regenerate/Download buttons hidden (defense in depth); but server still enforces (steps 2-3 are authoritative). |
| 6 | As Dev, attempt a direct single-download by guessing a valid {R}/{EMP} path. | 403 (authz) -- and additionally tenant-blocked if cross-tenant (see TC-PAY-ISO-013/014). |

## 6. Postconditions
- Only `Payroll.*.All` holders can generate/regenerate/retry/download; unauthorized attempts blocked server-side with no side effects.
