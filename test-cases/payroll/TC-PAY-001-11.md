# TC-PAY-001-11: Performance — fetch all components <= 200ms P95 (NFR-2) and pagination scales (NFR-3)

## 1. Test Objective
Verify NFR-2: the API for fetching all salary components for a tenant responds within <= 200ms (P95). Verify NFR-3: paginated reads (default 25, max 100) return consistently and the Redis-cached list (NFR-1) is served quickly with cache invalidation on writes not degrading P95.

## 2. Related Requirements
- User Story: US-PAY-001
- Non-Functional Requirements: NFR-1, NFR-2, NFR-3
- Acceptance Criteria: AC-1

## 3. Preconditions
- Tenant "acme" seeded with 200 salary components (per Test Hints) and several structures.
- Representative network conditions; warm and cold cache states both measured.
- HR Officer authenticated in acme with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Component count | 200 | per Test Hint |
| Concurrency | 50 virtual users | sustained read load |
| SLA | P95 <= 200ms | NFR-2 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Warm the cache, then drive `GET /api/v1/payroll/components` at 50 concurrent users for 2 min | Server-side P95 latency <= 200ms (NFR-2); P99 reported. Zero errors; all responses tenant-scoped to acme. |
| 2 | Measure a cold-cache run (Redis flushed) | First-hit latency recorded; subsequent hits served from the 15-min TTL cache (NFR-1) and meet the 200ms SLA. |
| 3 | `GET .../components?page=1&page_size=25` and page through to the end | Each page returns within SLA; pagination metadata (total, page count) accurate (NFR-3). |
| 4 | Issue a write (create/update a component) during the read load, then re-read | Cache invalidated on write; the next read reflects the change and still meets the SLA (no stale-cache violation, no latency spike beyond SLA). |
| 5 | Request `page_size=100` under load | Returns 100 items within SLA; `page_size=101` capped to 100. |

## 6. Postconditions
- Component fetch meets the 200ms P95 SLA across cached/uncached and paginated reads.
