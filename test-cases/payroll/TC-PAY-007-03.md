# TC-PAY-007-03: Deduction that would drive net salary negative -> system warns HR and blocks/caps (negative-net guard)

## 1. Test Objective
Verify BR-3 / AC-2 / FR-3: when total deductions including the adjustment would result in a negative net salary, the system warns HR and does not silently produce a negative net. Covers the warning surface at create time (best-effort projection) and the hard guard at run time.

## 2. Related Requirements
- User Story: US-PAY-007
- Acceptance Criteria: AC-2
- Functional Requirements: FR-3
- Business Rules: BR-3 (total deductions cannot result in negative net; warn HR)

## 3. Preconditions
- Tenant "acme"; user with `Payroll.*.All`; Employee Y active structure with a small net (e.g. projected net 6,000 for the period after standard deductions).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Employee Y projected net | 6,000 | period 2026-06 |
| Over-deduction | type=Deduction, amount=9000.00, period=2026-06 | would yield -3,000 |
| At-zero deduction | type=Deduction, amount=6000.00 | exact-zero boundary |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Create a Deduction of 9,000 for Employee Y for June 2026 (period with a known projected net of 6,000). | The UI surfaces a warning that this deduction would drive net salary negative (-3,000); HR must acknowledge / cannot finalize a negative net (BR-3). |
| 2 | Proceed to run payroll for June 2026 with the 9,000 deduction still pending. | The run engine enforces BR-3: net is not produced as a negative value -- the run either flags the slip for HR review (deduction-exceeds-net warning on the slip) or caps recovery, per the engine's documented rule; no payslip is finalized with net < 0. |
| 3 | Replace with an exact 6,000 deduction (drives net to exactly 0). | Net = 0.00 is permitted (boundary at zero is valid; negative is not) (BR-3). |
| 4 | Replace with 5,999.99 deduction. | Net = 0.01 produced normally (just-below boundary). |
| 5 | Confirm the warning text never leaks another employee's figures and references only Employee Y's projected net. | Warning is scoped to Employee Y only. |

## 6. Postconditions
- No payslip with negative net exists; HR was warned for the over-deduction case; zero-net boundary accepted.
