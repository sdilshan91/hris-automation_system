# TC-PAY-004-01: Generate Payslips on a ReviewPending/Finalized run -> Hangfire job renders one PDF per employee at {tenantId}/payroll/{runId}/{employeeId}.pdf, each PDF containing all required sections (happy path)

## 1. Test Objective
Verify the primary success flow across AC-1, AC-2 and FR-1/FR-2/FR-4/FR-5/FR-7: an HR Officer with `Payroll.*.All` clicks "Generate Payslips" on a payroll run in ReviewPending (or Finalized) status; the API synchronously enqueues a single Hangfire job (`GeneratePayslipsJob`) carrying tenant_id + run_id and returns an accepted response; the worker (with `ITenantContext` restored from job args) renders one QuestPDF PDF per employee in the run, stores each at the tenant-scoped blob path `{tenantId}/payroll/{runId}/{employeeId}.pdf`, and stamps each `payroll_slip` row with `pdf_generated_at`, `pdf_storage_path`, `pdf_status=Generated`, `pdf_file_size_bytes`. Each PDF contains every required section: company logo + name + address, employee name/number/department/designation/DOJ/masked bank account, pay period, earnings breakdown, deductions breakdown, itemized statutory items, gross earnings, total deductions, net salary, and working/paid/LOP days.

## 2. Related Requirements
- User Story: US-PAY-004
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-1, FR-2, FR-4, FR-5, FR-7
- Business Rules: BR-1 (run must be ReviewPending/Approved/Finalized)
- Data Requirements: S7 (payroll_slip pdf_generated_at / pdf_storage_path / pdf_status / pdf_file_size_bytes)

## 3. Preconditions
- Tenant "acme" Active, subdomain `acme.yourhrm.com`, Payroll module enabled, tenant branding (logo, company name, address) configured (US-TENANT-xxx).
- A completed payroll run R for May 2026 in status ReviewPending (US-PAY-003) with 3 `payroll_slip` rows (+ `payroll_slip_detail` per component: Earning/Deduction/Statutory).
- Tenant has a configured payslip template (or uses the system default).
- HR Officer "Maya Singh" authenticated in acme with `Payroll.*.All`.
- Blob storage (local filesystem in dev) available; Hangfire worker operational.
