# TC-PAY-005-09: Authorization matrix -- only the authenticated employee with Payroll.Read.Self sees their own payslips; cross-employee 403 and cross-tenant zero-leak (security)

## 1. Test Objective
Verify AC-4 / FR-5 / FR-8 / NFR-4: enforce the access matrix on the employee payslip endpoints (list, detail, PDF). An unauthenticated request -> 401; an authenticated user without `Payroll.Read.Self` -> 403; an employee accessing another employee's slip in the same tenant -> 403/404; and a user authenticated in Tenant B sees NONE of Tenant A's payslips. This complements the dedicated isolation TCs (TC-PAY-ISO-017..020) at the API-authorization layer.

## 2. Related Requirements
- User Story: US-PAY-005
- Acceptance Criteria: AC-4
- Functional Requirements: FR-5, FR-8
- Non-Functional Requirements: NFR-4, NFR-5

## 3. Preconditions
- Tenant A "acme": EMP-001 (`Payroll.Read.Self`) with Finalized payslips; user "NoPay" with no payroll permission.
- Tenant B "globex": EMP-B01 (`Payroll.Read.Self`) with its own Finalized payslips.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Endpoints | GET my-payslips, my-payslips/{id}, my-payslips/{id}/pdf | FR-1/FR-4 |
| acme employee | EMP-001 (Self) | allowed (own only) |
| acme no-perm user | NoPay | 403 |
| globex employee | EMP-B01 (Self) | sees only globex slips |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Call the 3 endpoints with no/invalid bearer token. | 401 Unauthorized for each. |
| 2 | As acme user "NoPay" (no `Payroll.Read.Self`), call the endpoints. | 403 Forbidden; no payslip data returned. |
| 3 | As EMP-001, call the endpoints for EMP-001's own slips. | 200 OK; only EMP-001's own slips/detail/PDF returned. |
| 4 | As EMP-001, target EMP-002's slip id (same tenant). | 403/404; no EMP-002 data (cross-employee block, AC-4). |
| 5 | As globex EMP-B01, list payslips and try an acme payslip id. | List returns only globex slips; the acme id -> 404 (filtered out of globex scope); zero acme data leaks (FR-8, NFR-4). |
| 6 | As EMP-001 (acme), try a globex payslip id. | 404; no globex data; isolation holds both directions. |

## 6. Postconditions
- The endpoints enforce 401 (unauth), 403 (no perm / cross-employee), and tenant isolation (cross-tenant 404, zero leak).
