# TC-PAY-007-07: Adjustments marked "Applied" after a finalized run prevent double application; cancellation only allowed while Pending (FR-4 status lifecycle)

## 1. Test Objective
Verify FR-4 / FR-6 / FR-3: after an adjustment is included in a finalized payroll run it is marked status=Applied with `applied_in_payroll_run_id` set, and is never picked up by a subsequent run (no double application); cancellation is allowed only for Pending adjustments, never for Applied ones.

## 2. Related Requirements
- User Story: US-PAY-007
- Functional Requirements: FR-3, FR-4, FR-6
- Business Rules: BR-6 (cancel only remaining/pending)
- Data Requirements: S7 (status Pending/Applied/Cancelled, applied_in_payroll_run_id)

## 3. Preconditions
- Tenant "acme"; user with `Payroll.*.All`; Employee X active structure.
- A Bonus adjustment for June 2026 exists, status=Pending.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Bonus | type=Bonus, amount=10000.00, period=2026-06, status=Pending | to be applied |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Finalize the June 2026 payroll run that includes the Bonus. | The adjustment moves to status=Applied; `applied_in_payroll_run_id` = June run id (FR-4). |
| 2 | Re-run / re-trigger payroll for an adjacent period (e.g. a corrective July run) and let the engine scan pending adjustments. | The Applied June bonus is NOT picked up again -- only Pending adjustments matching the run period are selected; no double application (FR-3, FR-4). |
| 3 | Attempt to cancel the now-Applied bonus. | Rejected -- cancellation is only permitted for Pending adjustments; Applied is terminal (FR-6). |
| 4 | Create a fresh Pending adjustment and cancel it before any run. | Cancellation succeeds -> status=Cancelled; a Cancelled adjustment is never picked up by any run (FR-6, FR-3). |
| 5 | Attempt to edit the amount of an Applied adjustment. | Rejected -- Applied adjustments are immutable (consistency with FR-4 no-double-application). |
| 6 | Verify the status state machine: Pending->Applied and Pending->Cancelled are the only transitions; Applied/Cancelled are terminal. | No transition out of Applied or Cancelled is allowed. |

## 6. Postconditions
- Applied adjustments are immutable and never re-applied; only Pending adjustments are cancellable.
