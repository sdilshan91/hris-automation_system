# TC-PAY-006-11: Test Calculation panel previews statutory deductions before saving; versioned rules are immutable for finalized periods (corrections via adjustments)

## 1. Test Objective
Verify FR-5 / FR-4 / BR-7: the Test Calculation panel lets the admin enter a sample monthly gross and see computed tax, EPF, ETF, and net deductions in real time BEFORE saving the rule (it does not mutate stored rules). And per BR-7, statutory rules cannot be modified retroactively for periods that already have finalized payroll runs -- such retroactive edits are blocked and the admin is directed to payroll adjustments (US-PAY-007); a NEW effective-dated version is the supported path going forward (FR-4).

## 2. Related Requirements
- User Story: US-PAY-006
- Acceptance Criteria: AC-1, AC-2, AC-3
- Functional Requirements: FR-4 (versioning), FR-5 (test calculation), FR-7
- Business Rules: BR-7 (no retroactive change to finalized periods)
- Data Requirements: S7

## 3. Preconditions
- Tenant "acme" with FY 2025-2026 statutory rules; at least one FINALIZED payroll run exists in that FY.
- User authenticated as Tenant Admin / `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Sample gross | 100,000 | test-calc input |
| Expected preview | tax + EPF + ETF + net deductions | FR-5 |
| Finalized period | May 2025 (FY 2025-2026) | BR-7 |
| New version FY | 2026-2027 | FR-4 path |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the Test Calculation panel; enter sample monthly gross 100,000 (before saving any change). | Computed tax, EPF, ETF, and net deductions are shown in real time (FR-5); no statutory_rule/tax_slab record is created or modified by the preview. |
| 2 | Edit a slab in the editor (unsaved) and re-run the preview. | The preview reflects the unsaved edit; stored rules remain unchanged until Save. |
| 3 | Attempt to retroactively edit the FY 2025-2026 rule that governs the already-FINALIZED May 2025 run. | Blocked; an error indicates rules cannot be changed for finalized periods; the admin is directed to payroll adjustments (US-PAY-007) (BR-7). |
| 4 | Create a NEW effective-dated version (FY 2026-2027) instead. | Accepted; the historical FY 2025-2026 rule is retained unchanged; future periods use the new version (FR-4). |
| 5 | Confirm the version timeline shows both versions with their effective ranges. | Both versions retained and distinguishable (FR-4, AC-3). |
| 6 | Verify the test-calc preview is read-only with respect to audit. | Preview generates no audit "change" record; only actual saves are audit-logged (NFR-4). |

## 6. Postconditions
- A new fiscal-year version may be added; finalized-period rules remain immutable; previews never mutate stored rules.
