# TC-PAY-011-03: Send Payslips from a non-Finalized run is rejected; the action is only available on Finalized runs (negative / BR-1 guard)

## 1. Test Objective
Verify BR-1 and FR-1: payslip emails can only be sent for a Finalized payroll run. Attempting to trigger the send from a run in any non-Finalized status (Draft/Processing/ReviewPending/Approved/AwaitingApproval/Cancelled) is rejected by the API with a 4xx and a clear message; no Hangfire job is enqueued and no emails are sent. The "Send Payslips" button is disabled/hidden in the UI for those statuses, and a forged direct API call (bypassing the disabled button) is still rejected server-side.

## 2. Related Requirements
- User Story: US-PAY-011
- Acceptance Criteria: AC-1 (Finalized precondition)
- Functional Requirements: FR-1
- Business Rules: BR-1 (Finalized-only send)

## 3. Preconditions
- Tenant "acme" with payroll runs in each status: R-rev (ReviewPending), R-app (Approved), R-proc (Processing), R-cancel (Cancelled), and R-fin (Finalized, control).
- HR Officer authenticated with `Payroll.*.All`; SMTP sink capturing mail.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| R-rev | ReviewPending | send must be rejected |
| R-app | Approved | send must be rejected |
| R-proc | Processing | send must be rejected |
| R-cancel | Cancelled | send must be rejected |
| R-fin | Finalized | send allowed (control) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open each non-Finalized run detail page. | "Send Payslips" button is disabled or hidden (enabled only for Finalized runs with generated PDFs). |
| 2 | Forge a direct POST send-payslips request for R-rev (ReviewPending), bypassing the UI. | 400/409 with a message like "Payslips can only be sent for Finalized runs"; NO `SendPayslipEmailsJob` enqueued; no email sent (BR-1). |
| 3 | Repeat the forged send for R-app, R-proc, R-cancel. | Each rejected with the same Finalized-only error; no jobs enqueued, no emails sent. |
| 4 | As a control, send for R-fin (Finalized). | 202 Accepted; job enqueued; emails sent normally (confirms the guard rejects only non-Finalized statuses). |
| 5 | Verify the SMTP sink and `payslip_email_log` for the rejected runs. | Zero emails and zero log rows for R-rev/R-app/R-proc/R-cancel. |

## 6. Postconditions
- Only the Finalized run produced a job + emails; non-Finalized send attempts rejected server-side with no side effects.
