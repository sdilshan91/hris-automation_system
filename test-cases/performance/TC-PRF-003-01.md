# TC-PRF-003-01: Manager rates all goals of a direct report with valid comments + summary, submits -> weighted manager score + FINAL combined score computed, "Manager Review Submitted", employee notified, review locked (happy path)

## 1. Test Objective
Verify the primary success flow across AC-1, AC-2 and FR-1/2/3/4/5: an authenticated Manager with `Performance.Review.Team` opens Performance > Team Reviews during an open manager-review window and selects a direct report who has submitted their self-assessment. The form shows each goal with the employee's self-rating and self-comments on the left alongside empty manager-rating + manager-comment fields on the right (AC-1, FR-1). The manager enters a valid rating (within the tenant scale, FR-2) and a >=20-char comment (FR-3) for every goal, adds an overall summary comment (<=5000 chars, FR-5), and clicks "Submit Manager Review". The system computes the weighted manager score, computes the FINAL combined score using the tenant self:manager ratio (FR-4, BR-4), sets status to "Manager Review Submitted", notifies the employee (AC-2), and locks the review read-only.

## 2. Related Requirements
- User Story: US-PRF-003
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-1, FR-2, FR-3, FR-4, FR-5
- Business Rules: BR-1, BR-2, BR-4
- Data Requirements: S7 (review record: id, tenant_id, employee_id, manager_id, goal_id, cycle_id, manager_rating, manager_comment, summary_comment, manager_score, final_score, status, submitted_at, audit fields)

## 3. Preconditions
- Tenant "acme" exists, status Active, subdomain `acme.yourhrm.com`, Performance module enabled.
- An active appraisal cycle "FY26-H1" (US-PRF-004) exists with the manager-review window OPEN (start <= today <= end).
- Manager "Ravi Shah" is authenticated in acme (valid JWT carrying acme `tenant_id`) and holds `Performance.Review.Team`.
- Employee "Asha Patel" is Ravi's DIRECT REPORT in the org tree (Core HR) and has SUBMITTED her self-assessment for FY26-H1 (US-PRF-002) with 3 goals weighted 40/35/25 and self-ratings 5/4/3.
- Tenant rating scale is 1-5 numeric; self:manager weight ratio is 30:70 (BR-4).
- No manager review exists yet for Asha in FY26-H1.
