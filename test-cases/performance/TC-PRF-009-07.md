# TC-PRF-009-07: Weighted overall completion -> 3 goals with different weights + progress -> verify weighted-average calculation (FR-4)

## 1. Test Objective
Verify FR-4: the system computes an employee's overall goal completion percentage as the WEIGHTED average of individual goal progress percentages (weight x progress, summed, divided by total weight), not a simple arithmetic mean. The calculation is server-authoritative and matches a data-driven expected value. The same weighted figure drives the manager team-summary "overall completion %" column (AC-4).

## 2. Related Requirements
- User Story: US-PRF-009
- Functional Requirements: FR-4
- Acceptance Criteria: AC-4 (overall completion % in the team table)

## 3. Preconditions
- Tenant "acme"; employee "Sam Lee" authenticated with `Performance.Read.Self`.
- Sam has exactly 3 goals in the active cycle with the weights below (weights sum to 100% per US-PRF-001 FR-3).

## 4. Test Data
| Goal | Weight | Progress | Weight x Progress |
|------|--------|----------|-------------------|
| G1 | 50% | 80% | 40.0 |
| G2 | 30% | 50% | 15.0 |
| G3 | 20% | 10% | 2.0 |
| **Overall** | 100% | -- | **57.0%** (40+15+2) |

Note: a simple (unweighted) mean would be (80+50+10)/3 = 46.7% -- the test asserts the WEIGHTED 57.0%, distinguishing the two.

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Sam, set G1=80%, G2=50%, G3=10% via progress updates | Each per-goal progress persists. |
| 2 | View the overall completion widget on My Goals | Overall completion reads 57.0% (weighted), NOT 46.7% (the unweighted mean) (FR-4). |
| 3 | Confirm server-authoritative | `GET .../performance/my-goals/summary` returns overallCompletion = 57.0 computed server-side; a tampered client value does not alter the persisted/returned figure. |
| 4 | View Sam's row in Dana's Team Goals table | The overall completion % column shows the same 57.0% (AC-4 consistency). |
| 5 | Change G3 to 60% and re-check | Overall recomputes to 50+15+12 = 67.0%; the figure updates deterministically. |
| 6 | Edge: a goal with weight 0 (if permitted) | Contributes 0 to the weighted sum and total-weight denominator per the documented rule; no divide-by-zero. |

## 6. Postconditions
- Overall completion is the weighted average (57.0% for the seeded set), server-authoritative and consistent between the employee view and the manager table. No data corrupted.
