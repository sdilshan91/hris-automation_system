# TC-PRF-002-02: Submit with one goal unrated is rejected; partial set saved as draft only (BR-2)

## 1. Test Objective
Verify BR-2 and AC-2: a self-assessment cannot be submitted while any assigned goal is unrated. The "Submit" action is gated client-side and the server independently rejects a submit payload missing a rating/comment for any goal; an incomplete set may only be persisted as a draft (AC-3), never as submitted.

## 2. Related Requirements
- User Story: US-PRF-002
- Acceptance Criteria: AC-2, AC-3
- Functional Requirements: FR-3
- Business Rules: BR-2

## 3. Preconditions
- acme cycle FY26-H1 self-assessment window OPEN; Asha authenticated with `Performance.Read.Self`.
- Asha has 3 acknowledged goals; no submitted self-assessment exists.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Goal 1 | rated (rating 4, comment 25 chars) | complete |
| Goal 2 | rated (rating 3, comment 22 chars) | complete |
| Goal 3 | UNRATED (no rating / no comment) | the missing one |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Rate Goal 1 and Goal 2; leave Goal 3 unrated | Progress shows 2/3; "Submit Self-Assessment" remains disabled. |
| 2 | Force-submit by bypassing the UI: POST submit with only 2 of 3 goals rated | Server rejects with 400/422 and an "all goals must be rated before submission" error (BR-2); no submitted record is created. |
| 3 | Inspect persisted state | No self-assessment with status submitted exists for Asha/FY26-H1. |
| 4 | Click "Save as Draft" with the 2-of-3 set | Accepted; a self-assessment row persists with status `draft` and the 2 rated goals (AC-3). The unrated goal remains blank. |
| 5 | Re-open My Review | The draft loads with Goal 1/2 prefilled and Goal 3 still unrated; "Submit" still disabled until all 3 are rated. |

## 6. Postconditions
- No submitted self-assessment exists with an unrated goal; a valid draft holds the partial set.
