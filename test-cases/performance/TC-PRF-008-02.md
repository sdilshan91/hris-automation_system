# TC-PRF-008-02: Manager or HR records a checkpoint (progress assessment OnTrack/AtRisk/NotMet, evidence notes, file attachment) -> employee notified of the outcome (AC-3, FR-4)

## 1. Test Objective
Verify AC-3 / FR-4: when a PIP checkpoint date arrives, the manager OR HR navigates to the PIP and clicks "Record Checkpoint", and the system displays a checkpoint form where the reviewer records a progress assessment, evidence of improvement (notes), an updated status (On Track / At Risk / Not Met), comments, and an optional file attachment. On save the checkpoint outcome is persisted (immutably, see TC-PRF-008-10), appended to the PIP's checkpoint history, and the employee is notified of the checkpoint outcome.

## 2. Related Requirements
- User Story: US-PRF-008
- Acceptance Criteria: AC-3
- Functional Requirements: FR-4, FR-5 (history)
- Business Rules: BR-1 (manager MAY record checkpoints)
- Data Requirements: S7 (pip_checkpoints; tenant_id scoped; attachment tenant-scoped storage)

## 3. Preconditions
- An Active PIP for Sam Lee exists in acme (TC-PRF-008-01) with a checkpoint due 2026-07-31.
- Manager "Dana Cole" and HR "Nadia Khan" are authenticated in acme; both can record checkpoints (BR-1).
