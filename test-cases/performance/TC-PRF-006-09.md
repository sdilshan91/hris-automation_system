# TC-PRF-006-09: PDF export of the complete signed review (goals, ratings, notes, signatures) with tenant branding <=3s (AC-4, FR-6, NFR-4)

## 1. Test Objective
Verify AC-4, FR-6 and NFR-4: a completed (Signed Off) review is exportable as a PDF containing the full record -- goals, ratings, meeting notes, sign-off timestamps and digital signatures (name + timestamp) -- rendered with tenant branding (logo), and the export completes within 3 seconds for a single review document. Assert the export ENDPOINT/SEAM, the report data model (all sections present), authz (only authorized viewers), and tenant scoping. If the PDF rendering library is not yet wired, assert the export seam returns the correct content type / report model and note full visual rendering as a CONDITIONAL extension point.

## 2. Related Requirements
- User Story: US-PRF-006
- Acceptance Criteria: AC-4 (export as PDF)
- Functional Requirements: FR-6 (PDF of complete review with tenant branding)
- Non-Functional Requirements: NFR-4 (export <=3s)
- Data Requirements: S7

## 3. Preconditions
- Tenant "acme", Performance module enabled; acme has a configured logo/branding.
- Liam Carter's review is "Signed Off" with goals, ratings, notes, and both signatures.
- HR Officer "Nadia Khan" (`Performance.Review.All`) authenticated in acme.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Review | Liam Carter, Signed Off | FR-6 |
| Branding | acme logo | FR-6 |
| SLA | <=3s | NFR-4 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Nadia, open Liam's signed review and click "Export PDF"; observe `GET .../performance/reviews/{reviewId}/export` | The request carries `X-Tenant-Subdomain: acme` + bearer; the endpoint returns `application/pdf` (HttpResponse<Blob>) with a Content-Disposition filename (or the report model if rendering is deferred). |
| 2 | Inspect the exported document content | It contains: the employee + cycle header, all goals + ratings, the full meeting notes (four sections), both sign-off names + timestamps, and the acme logo/branding (FR-6). If anonymity/PII rules apply they are honored. |
| 3 | Measure export latency over repeated runs | P95 <= 3 seconds for the single-review document (NFR-4). |
| 4 | Attempt export as an unauthorized user (an unrelated employee / no `Performance.Review` permission) | 403 -- export is gated to authorized viewers (manager of record / HR); the document is not returned. |
| 5 | Attempt export with another tenant's reviewId | 404 -- tenant-scoped (cross-tenant covered in TC-PRF-ISO-021/024). |
| 6 | If PDF rendering library is not wired | The export seam still returns the structured report model + correct content negotiation; full PDF fidelity is documented as a CONDITIONAL extension point (consistent with US-PRF-005 FR-7 PDF deferral). |

## 6. Postconditions
- The signed review is exportable as a branded PDF (or via the documented seam) within the 3s SLA, gated by authz and tenant scope.
