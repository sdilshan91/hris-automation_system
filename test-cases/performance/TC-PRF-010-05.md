# TC-PRF-010-05: Budget tracking -> budget $100k, recommendations total $110k -> SOFT warning (not a hard block); HR can proceed with justification

## 1. Test Objective
Verify FR-8 / BR-4: HR can set a bonus/increment budget for the cycle and the system tracks consumed vs. remaining as recommendations are made. When the allocated budget is exceeded, the system shows a WARNING (not a hard block) -- HR may proceed beyond budget with a justification. The budget tracker reflects consumed/remaining accurately as recommendations are added/removed, with color thresholds (green/amber/red).

## 2. Related Requirements
- User Story: US-PRF-010
- Functional Requirements: FR-8 (budget tracking: consumed vs. remaining)
- Business Rules: BR-4 (budget exceed = warning, NOT a hard block; proceed with justification)
- Data Requirements: S7 (budget_id FK; recommendation amounts)
- Constraints: budget tracking is optional/tenant-disableable.

## 3. Preconditions
- Tenant "acme"; HR Officer Pat Ng (`Performance.Publish.All`); FY25 cycle.
- Budget tracking is ENABLED with a bonus/increment budget of $100,000 for FY25.
- Existing bonus/increment recommendations total $90,000 (consumed), leaving $10,000.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Budget | $100,000 | FY25 bonus/increment |
| Already consumed | $90,000 | remaining $10,000 |
| New bonus | $20,000 | would bring total to $110,000 |
| Over-budget justification | "Retention-critical; approved verbally by VP." | required to proceed over budget |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Pat, open the FY25 workspace; observe the budget tracker widget | Shows $90,000 consumed / $10,000 remaining of $100,000; bar color amber (near limit), not red yet. |
| 2 | Add a new $20,000 bonus recommendation (total -> $110,000) | The tracker recomputes to $110,000 consumed / -$10,000 (over by $10,000); a WARNING is displayed ("Budget exceeded by $10,000"); the bar turns red. The save is NOT hard-blocked (BR-4). |
| 3 | Attempt to proceed/submit the over-budget recommendation | The system requires a justification to proceed beyond budget; with the justification supplied, the recommendation saves/submits successfully (BR-4 = soft warning). |
| 4 | Try to proceed over budget WITHOUT a justification | Proceeding over budget without a justification is refused (the justification is the gate, not a hard cap); supplying it allows proceeding. |
| 5 | Remove the $20,000 recommendation | The tracker returns to $90,000 consumed / $10,000 remaining; the over-budget warning clears; bar returns to amber. |
| 6 | (Disabled branch) On a cycle with budget tracking disabled | No budget widget/warning is enforced; recommendations save freely (budget tracking is optional). |

## 6. Postconditions
- The budget tracker accurately reflects consumed/remaining; exceeding the budget produces a warning, never a hard block; proceeding over budget is allowed only with a justification. Tenant-scoped to acme.
