# TC-PRF-010-01: HR opens the recommendation workspace for a completed cycle -> employees with final score/grade/tenure/comp/manager flags -> create + submit a recommendation -> routed through the approval workflow (happy path)

## 1. Test Objective
Verify the primary success flow for AC-1 and AC-3 (FR-1/FR-4): an authenticated HR Officer with `Performance.Read.All` + `Performance.Publish.All` navigates to Performance > Recommendations for a completed cycle whose final ratings are published, and sees a workspace listing every in-tenant employee with their final performance score, current grade/band, tenure, compensation data, the manager recommendation flag from US-PRF-003, and empty recommendation fields. HR creates a recommendation for an employee (type + details + justification), clicks "Submit Recommendation"; the system persists it tenant-scoped, links it to the employee's performance record, and routes it through the tenant's configured approval workflow (status -> Pending Approval). All data is acme-only.

## 2. Related Requirements
- User Story: US-PRF-010
- Acceptance Criteria: AC-1, AC-3
- Functional Requirements: FR-1 (recommendation types), FR-4 (approval workflow)
- Business Rules: BR-1 (ratings published, satisfied here), BR-5 (promotion needs target grade + effective date, asserted in TC-PRF-010-08)
- Data Requirements: S7 (recommendations table; type, details JSONB, status, approver chain, tenant_id)

## 3. Preconditions
- Tenant "acme" exists, status Active, subdomain `acme.yourhrm.com`, Performance module enabled.
- HR Officer "Pat Ng" is authenticated in acme (valid JWT carrying acme `tenant_id`) and holds `Performance.Read.All` + `Performance.Publish.All`.
- An appraisal cycle "FY25 Annual" (US-PRF-004) is Completed with final ratings PUBLISHED (BR-1); calibration is disabled OR completed (BR-2).
- Employees in acme have final scores, current grade/band, tenure, compensation, and (some) manager recommendation flags from US-PRF-003.
- The tenant approval workflow engine is configured for recommendations; the Notification System (S25) is available (enqueue asserted, delivery conditional).
