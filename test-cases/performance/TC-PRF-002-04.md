# TC-PRF-002-04: Boundary values accepted -- comment exactly 20 chars, achievement 0 and 100, rating at scale min/max (FR-2, FR-3)

## 1. Test Objective
Verify the inclusive boundaries of the self-assessment validation: a comment of exactly 20 characters is accepted (FR-3 minimum is inclusive), achievement percentages of exactly 0 and exactly 100 are accepted (S7 range 0-100 inclusive), and self-ratings at the scale minimum (1) and maximum (5) are accepted (FR-2). One value past each boundary in the open direction is rejected.

## 2. Related Requirements
- User Story: US-PRF-002
- Acceptance Criteria: AC-2
- Functional Requirements: FR-2, FR-3
- Data Requirements: S7 (achievement 0-100 inclusive; comment >= 20)

## 3. Preconditions
- acme cycle FY26-H1 self-assessment window OPEN; Asha authenticated with `Performance.Read.Self`; 3 acknowledged goals; rating scale 1-5.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Goal 1 | comment exactly 20 chars, rating 1, achievement 0 | lower boundaries |
| Goal 2 | comment 20 chars, rating 5, achievement 100 | upper boundaries |
| Goal 3 | comment exactly 20 chars, rating 3, achievement 50 | mid |
| Just-below comment | 19 chars | must be rejected |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Enter a 19-char comment on Goal 1 | Rejected ("at least 20 characters"); submit blocked. |
| 2 | Change to exactly 20 chars; set rating 1, achievement 0 | Accepted; no error. |
| 3 | Goal 2: rating 5 (scale max), achievement 100, 20-char comment | Accepted; no error. |
| 4 | Goal 3: rating 3, achievement 50, 20-char comment; submit | Submission succeeds (all goals rated, all values within inclusive bounds); persisted self_assessment shows rating 1/5/3, achievement 0/100/50, all comments length 20. |
| 5 | Inspect persisted values | Stored exactly as entered; no truncation or coercion at the boundaries. |

## 6. Postconditions
- Inclusive boundary values are accepted and persisted; the value just past each boundary is rejected.
