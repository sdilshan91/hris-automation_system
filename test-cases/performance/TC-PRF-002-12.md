# TC-PRF-002-12: Weighted self-assessment score computed from goal ratings and weights (FR-4)

## 1. Test Objective
Verify FR-4: on submission the system computes a weighted self-assessment score from the individual goal self-ratings and their goal weights. The computed score matches the expected weighted average for a known input set, and the self vs. manager weight ratio (BR-4) is applied only at final-score time (not double-applied here).

## 2. Related Requirements
- User Story: US-PRF-002
- Functional Requirements: FR-4
- Business Rules: BR-4 (self:manager ratio applied at final score)
- Data Requirements: S7 (weighted_self_score output)

## 3. Preconditions
- acme cycle FY26-H1 self-assessment window open; Asha authenticated with `Performance.Read.Self`.
- Asha has 3 goals weighted 40/35/25 (sum 100, per US-PRF-001); rating scale 1-5.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Goal 1 | weight 40, rating 5 | |
| Goal 2 | weight 35, rating 4 | |
| Goal 3 | weight 25, rating 3 | |
| Expected weighted self-score | (5*40 + 4*35 + 3*25)/100 = 4.15 (on the 1-5 scale) | weighted average |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Rate all goals (5/4/3) with valid comments and submit | Submission succeeds; the response/record includes `weighted_self_score`. |
| 2 | Verify the computed score | `weighted_self_score` = 4.15 on the 1-5 scale (matches the weighted average of rating*weight / total weight); rounding follows the defined convention. |
| 3 | Change one rating in a fresh draft (e.g. Goal 1 -> 4) and re-compute | The score recomputes deterministically ((4*40+4*35+3*25)/100 = 3.75); no stale value. |
| 4 | Confirm the self:manager ratio is not applied yet | The stored `weighted_self_score` is the raw weighted self score; the BR-4 self:manager ratio (e.g. 30:70) is applied later at final-score calculation, not baked into this value. |

## 6. Postconditions
- The weighted self-score is correctly derived from goal ratings and weights, deterministic, and excludes the final-score ratio.
