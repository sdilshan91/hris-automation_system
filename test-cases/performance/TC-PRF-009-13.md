# TC-PRF-009-13: Authz -> employee posts/views updates only for their OWN goals (Performance.Read.Self); cross-employee IDOR blocked; manager limited to direct reports; unauth 401

## 1. Test Objective
Verify authorization for goal progress tracking: an employee with `Performance.Read.Self` can post/view updates only on their OWN goals; Employee A cannot post or read updates on Employee B's goals, including by passing B's goalId/updateId directly (IDOR). A manager can drill into direct reports only (non-report blocked, complementing TC-PRF-009-03). Unauthenticated requests are rejected 401.

## 2. Related Requirements
- User Story: US-PRF-009
- Non-Functional Requirements: NFR-2 (tenant isolation / authz)
- Business Rules: BR-5 (visibility), AC-4 (manager scope = direct reports)
- Preconditions: `Performance.Read.Self`

## 3. Preconditions
- Tenant "acme"; Employee A "Sam Lee" and Employee B "Mia Tan" both have goals + updates.
- Manager "Dana Cole" has Sam as a direct report but NOT Owen Park.
- B's goalId / updateId are known for the IDOR probe.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Employee A | Sam Lee | acting user |
| Employee B | Mia Tan | victim of IDOR probe |
| B's goalId/updateId | known | direct-id probe |
| Manager | Dana Cole | report scope |
| Non-report | Owen Park | blocked for Dana |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Sam, view + add updates on Sam's own goals | Allowed (Performance.Read.Self). |
| 2 | As Sam, `GET .../performance/goals/{B_goalId}/updates` and `POST .../updates` for Mia's goal | Blocked (403 / not found) -- Sam cannot read or write Mia's goal updates even with the direct id (IDOR blocked). |
| 3 | As Sam, attempt to comment on Mia's update id | Blocked -- not Sam's goal, not Sam's manager/HR scope. |
| 4 | As Dana (manager), drill into Sam's updates | Allowed (direct report). |
| 5 | As Dana, attempt to drill into Owen Park's updates by id/URL | Blocked (403) -- Owen is not Dana's report; scope derived from the org tree, not client input. |
| 6 | Send the my-goals / team-goals / updates requests with NO auth token | 401 Unauthorized on every endpoint. |
| 7 | Verify server-side enforcement | All checks hold when bypassing the client and calling the API directly. |

## 6. Postconditions
- Employees act only on their own goals; managers only on direct reports; cross-employee IDOR and unauth are blocked. No unauthorized read/write.
