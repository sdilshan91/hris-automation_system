# TC-PRF-005-14: Boundary — minimum reviewers per category enforced; radar renders with 3/5/10 competencies (FR-3, AC-4)

## 1. Test Objective
Verify FR-3 and AC-4 at the boundaries: the configurable minimum number of reviewers per category is enforced (e.g. at least 2 peers — exactly the minimum is accepted, one below is flagged), and the aggregated results radar/per-competency view renders correctly across varying competency counts (3, 5, 10) without breaking the chart or aggregation.

## 2. Related Requirements
- User Story: US-PRF-005
- Acceptance Criteria: AC-4
- Functional Requirements: FR-3, FR-4

## 3. Preconditions
- 360-enabled cycle "FY26 Annual Review" active for acme; minimum peer reviewers configured = 2.
- Seeded employees with feedback sets that hit each boundary (1 peer vs 2 peers; competency sets of 3, 5, 10).
- HR Officer "Nadia Khan" (`Performance.Review.All`) authenticated.

| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Configure 2 as the peer minimum; submit feedback with exactly 2 peers | Results release is permitted at exactly the minimum (cross-ref TC-PRF-005-04); per-category averages compute over 2 peers. |
