# TC-PRF-007-08: Server rejects a manager attempting to pull org-wide aggregates (scope cannot be escalated via request params)

## 1. Test Objective
Verify AC-5 + BR-1 + BR-3 + NFR-2 server-side scope enforcement: a Manager with only `Performance.Read.Team` cannot escalate to org-wide analytics by manipulating the request -- removing/altering a scope param, passing `scope=org`, requesting another team's department, or hitting the top/bottom-performers endpoint. The server derives scope from the authenticated user's role + org-tree position, NOT from client input, and rejects or down-scopes every escalation attempt.

## 2. Related Requirements
- User Story: US-PRF-007
- Acceptance Criteria: AC-5
- Business Rules: BR-1, BR-3
- Non-Functional Requirements: NFR-2

## 3. Preconditions
- Tenant "acme" / cycle "FY26"; Manager "Maya Shah" authenticated with `Performance.Read.Team` only; other teams/departments exist.
- An HR endpoint set exists for org-wide overview / top-bottom / department drill-down.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Manager | Maya Shah | Performance.Read.Team |
| Escalation attempts | scope=org, foreign deptId, top/bottom endpoint, no-scope param | all must fail/down-scope |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Maya, `GET .../performance/dashboard/overview?scope=org` (force org-wide) | The server IGNORES the client `scope` and returns team-scoped data only -- or 403; never org-wide aggregates (BR-1, NFR-2). |
| 2 | `GET .../performance/dashboard/overview` with NO scope param | Server derives team scope from Maya's identity; returns team-only data, not a permissive org-wide default. |
| 3 | `GET .../performance/dashboard/top-performers?n=10` (org-wide top/bottom) | 403 -- the org-wide top/bottom endpoint requires `Performance.Read.All`; managers get only the team-ranking endpoint (BR-3). |
| 4 | `GET .../performance/dashboard/departments/{otherDeptId}/employees` (a department Maya doesn't manage) | 403 -- Maya cannot read a roster outside her reporting line. |
| 5 | `GET .../performance/dashboard/export?scope=org` | 403 / down-scoped to team; never an org-wide export. |
| 6 | Inspect every above response body/headers | No org-wide average, completion rate, distribution, or other-team employee leaks through any field, even partially. |

## 6. Postconditions
- All manager-driven scope-escalation attempts are rejected or silently down-scoped to the team; org-wide analytics remain exclusive to `Performance.Read.All`.
