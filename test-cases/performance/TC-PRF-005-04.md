# TC-PRF-005-04: Releasing 360 results below the minimum peer threshold warns/blocks HR (BR-4, FR-3)

## 1. Test Objective
Verify BR-4 / FR-3: the configurable minimum number of peer reviewers must be met before 360 results are released; otherwise HR is warned (and release is blocked / requires an explicit override per the implementation contract). Protects anonymity and statistical validity by not exposing results derived from too few peers.

## 2. Related Requirements
- User Story: US-PRF-005
- Acceptance Criteria: AC-4
- Functional Requirements: FR-3
- Business Rules: BR-4

## 3. Preconditions
- 360-enabled cycle "FY26 Annual Review" active for acme; Liam Carter under review.
- Tenant-configured minimum peer reviewers = 2 (FR-3).
- Only ONE peer (Ava Reyes) has submitted; the second peer (Ben Cho) has NOT submitted.
- HR Officer "Nadia Khan" authenticated with `Performance.Review.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Min peers required | 2 | FR-3 tenant config |
| Peers submitted | 1 (Ava) | below threshold |
| Action | Release 360 results | BR-4 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As HR, attempt to release Liam's 360 results with only 1 of 2 required peers submitted | The system warns that the minimum peer threshold is not met (e.g. "At least 2 peer reviews are required before releasing results") and does NOT release results to the employee/manager (BR-4). |
| 2 | Bypass the UI: `POST .../performance/360/{liamId}/release` | Server rejects with 422 (or 409) and the threshold message; results remain unreleased; no results-available notification is sent. |
| 3 | Have Ben Cho submit so 2 peers are now complete; retry release | Release now succeeds (200); results become viewable; per the implementation contract any documented HR override path is exercised and the override is audited. |
| 4 | Confirm anonymity safety | With the threshold met, individual peer comments are shown only in aggregate/anonymized form per the anonymity setting (cross-ref TC-PRF-005-06). |

## 6. Postconditions
- Results are not released below the peer threshold; once met, release succeeds and notifies the reviewee/manager.
