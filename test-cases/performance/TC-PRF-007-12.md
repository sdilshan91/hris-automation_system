# TC-PRF-007-12: Dashboard charts responsive 360px->4K + WCAG 2.1 AA + loading skeletons

## 1. Test Objective
Verify NFR-4 (+ S8 UI notes): all dashboard charts (histogram, department bar, trend line, completion donut) render responsively from 360px to 4K, the dashboard meets WCAG 2.1 AA (keyboard operability, screen-reader labels for charts/widgets, color contrast, non-color-only encodings), and loading skeletons display in the chart areas during data fetch.

## 2. Related Requirements
- User Story: US-PRF-007
- Non-Functional Requirements: NFR-4 (chart.js responsive sizing), NFR-1 (perceived load via skeletons)
- UI/UX: S8 (responsive grid 3/2/1 column; loading skeletons; breadcrumb)
- Standard: WCAG 2.1 AA

## 3. Preconditions
- Tenant "acme" / cycle "FY26" dashboard available.
- HR Officer "Nadia Khan" authenticated in acme with `Performance.Read.All`.
- An automated a11y checker (axe) + screen reader (NVDA/VoiceOver) + viewport emulation are available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360px, 768px, 1440px, 4K (2160p) | NFR-4 / S8 |
| Grid | 1-col / 2-col / 3-col | S8 responsive grid |
| Standard | WCAG 2.1 AA | a11y |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the dashboard at 1440px; run axe | No WCAG 2.1 AA violations; charts have accessible names / text alternatives (e.g. an accessible data table or aria-label summarizing each chart). |
| 2 | Resize to 360px, 768px, 4K | The widget grid reflows (3-col desktop -> 2-col tablet -> 1-col mobile per S8); charts resize responsively (chart.js) without clipping or horizontal scroll; the filter sidebar collapses on mobile. |
| 3 | Navigate the entire dashboard + filter panel + drill-down using only the keyboard | All interactive elements (filter dropdowns, export menu, department bars/links, breadcrumb, trend cycle selector) are reachable and operable; visible focus indicators; logical tab order. |
| 4 | Inspect chart color encodings | Information is not conveyed by color alone (e.g. trend up/down also has an icon/label; distribution bands labeled); contrast ratios meet AA. |
| 5 | Throttle the network / re-fetch on filter change | Loading skeletons render in the chart card areas during fetch, then resolve to charts (S8, NFR-1 perceived load); no layout shift jank. |
| 6 | Screen-reader pass over a chart widget | The SR announces the widget title + a meaningful summary (e.g. average score, top department) rather than an empty canvas. |

## 6. Postconditions
- The dashboard is responsive 360px->4K, passes WCAG 2.1 AA, and shows loading skeletons during data fetch.
