# TC-PRF-004-13: Cycle creation with 5,000 participants <=5s; dashboard loads <=2s P95 (NFR-1 / NFR-4)

## 1. Test Objective
Verify NFR-1 and NFR-4: creating a cycle scoped to up to 5,000 participants (materializing cycle_participants + scheduling Hangfire jobs) completes within 5 seconds, and the cycle dashboard — including aggregate per-phase completion statistics — loads within 2 seconds at P95.

## 2. Related Requirements
- User Story: US-PRF-004
- Acceptance Criteria: AC-2, AC-3
- Non-Functional Requirements: NFR-1, NFR-4

## 3. Preconditions
- Tenant "acme" seeded with >= 5,000 active employees across departments.
- A configured rating scale; HR Officer Maya authenticated.
- A representative perf environment (warm DB, indexes present) — measurements require a seeded perf env.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Participant count | 5,000 | all-employees scope |
| Creation SLA | <= 5s | NFR-1 |
| Dashboard SLA | <= 2s P95 | NFR-4 |
| Dashboard sample | >= 100 requests | for a meaningful P95 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Create a cycle scoped to all 5,000 active employees; measure end-to-end create time | Creation (cycle + 5,000 cycle_participants + Hangfire job registration) completes within 5 seconds (NFR-1). |
| 2 | Verify correctness | Exactly 5,000 participant rows persisted, all tenant_id=acme; Hangfire jobs registered once (no per-participant job explosion). |
| 3 | With seeded progress, request the cycle dashboard >= 100 times and record latency | Dashboard P95 <= 2 seconds including per-phase completion % + overdue aggregates (NFR-4). |
| 4 | Inspect the aggregate query | Stats are computed with set-based aggregates (no N+1 per participant); the participant-count denominator is correct. |
| 5 | Note environment dependency | If no seeded perf env exists, this TC is the documented SLA target to run against a perf build (same convention as other modules). |

## 6. Postconditions
- Cycle creation and dashboard load meet their SLAs at the 5,000-participant scale.
