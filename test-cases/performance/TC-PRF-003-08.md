# TC-PRF-003-08: HR Officer with Performance.Review.All can review ANY employee in their tenant AND reopen a submitted manager review (unlocking it for editing)

## 1. Test Objective
Verify BR-3 and AC-5: an HR Officer holding `Performance.Review.All` can rate ANY employee in their tenant (not limited to direct reports) and can REOPEN a manager review that has already been submitted. Reopening flips the review out of the locked "Manager Review Submitted" state so the manager (or HR) can edit it; a manager WITHOUT `.All` cannot reopen their own submitted review. The reopen action is itself tenant-scoped (HR cannot reopen another tenant's review -- see TC-PRF-ISO-009).

## 2. Related Requirements
- User Story: US-PRF-003
- Acceptance Criteria: AC-5
- Business Rules: BR-2, BR-3
- Functional Requirements: FR-7 (reopen audited)

## 3. Preconditions
- acme tenant; HR Officer "Nadia" holds `Performance.Review.All`.
- A submitted, locked manager review exists for Asha in FY26-H1 (from TC-PRF-003-01).
- Manager Ravi holds only `Performance.Review.Team`.
- Bonus: an employee "Kiran" who is NOT anyone's direct report exists.

## 4. Test Data
| Actor | Action | Expected |
|-------|--------|----------|
| Nadia (.All) | review Kiran (no manager link) | allowed |
| Nadia (.All) | reopen Asha's submitted review | allowed -> editable |
| Ravi (.Team) | reopen own submitted review | 403 forbidden |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Nadia, open and rate Kiran (who has no managing manager) | Allowed -- `.All` is not restricted to direct reports (BR-3). |
| 2 | As Ravi, attempt to reopen his own submitted review for Asha | 403 Forbidden; review stays locked (only `.All` may reopen, BR-3 / AC-5). |
| 3 | As Nadia, reopen Asha's submitted review | Status flips from "Manager Review Submitted" to a reopened/editable state; the review becomes editable again. |
| 4 | As Ravi, re-open Asha's review after the HR reopen | The form is now editable; Ravi can amend ratings and re-submit. |
| 5 | Inspect the audit log for the reopen | A reopen entry is logged with Nadia's user id + timestamp (FR-7). |

## 6. Postconditions
- HR `.All` can review anyone and reopen submitted reviews; a `.Team`-only manager cannot reopen; reopen is audited.
