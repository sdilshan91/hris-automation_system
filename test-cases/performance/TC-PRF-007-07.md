# TC-PRF-007-07: An employee (no manager/HR scope) navigating to the dashboard is redirected to their own review page

## 1. Test Objective
Verify BR-1: a plain Employee who has neither `Performance.Read.Team` nor `Performance.Read.All` cannot view the analytics dashboard; navigating to Performance > Dashboard redirects them to their own review/self-service page (their own data only), and any direct dashboard API call from an employee context returns no org/team aggregate.

## 2. Related Requirements
- User Story: US-PRF-007
- Business Rules: BR-1 (employees see only their own data, redirected to their review page)
- Acceptance Criteria: AC-5 (scope enforcement)
- Non-Functional Requirements: NFR-2 (scope isolation)

## 3. Preconditions
- Tenant "acme" / cycle "FY26".
- Employee "Liam Carter" authenticated in acme with only `Performance.Read.Self` (no Team/All scope).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Employee | Liam Carter | Performance.Read.Self only |
| Dashboard route | /performance (dashboard) | BR-1 redirect source |
| Redirect target | Liam's own review / my-review | BR-1 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Liam, navigate to `https://acme.yourhrm.com/performance` (Dashboard) | The UI redirects Liam to his own review page (e.g. /my-review); the analytics dashboard is NOT rendered (BR-1). |
| 2 | Directly call `GET .../performance/dashboard/overview` with Liam's token | 403 Forbidden (or a scoped self-only response that contains NO org/team aggregate); never org-wide averages/top-bottom (BR-1, NFR-2). |
| 3 | Attempt `GET .../performance/dashboard/departments/{id}/employees` as Liam | 403 -- an employee cannot drill into a department roster. |
| 4 | Attempt the export endpoint as Liam | 403 -- an employee cannot export dashboard analytics. |
| 5 | Verify Liam's own review page loads | Liam sees only his own performance data (own scores/review), consistent with his self scope. |

## 6. Postconditions
- Employees are confined to their own review data; the dashboard, drill-down, and export endpoints reject employee-scope callers.
