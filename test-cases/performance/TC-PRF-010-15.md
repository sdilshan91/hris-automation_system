# TC-PRF-010-15: Performance (auto-gen 5,000 employees <=10s; workspace <=2.5s P95 paginated) + accessibility (WCAG 2.1 AA, responsive 360px-4K)

## 1. Test Objective
Verify NFR-1, NFR-4, and accessibility: (NFR-1) auto-generation of recommendations across up to 5,000 employees completes within 10 seconds; (NFR-4) the recommendation workspace loads within 2.5 seconds (P95) with a paginated employee list and no per-employee N+1; and the workspace, auto-generation wizard, budget tracker, comparison cards, and summary charts are WCAG 2.1 AA accessible and responsive from 360px to 4K. Both NFRs require a seeded performance environment.

## 2. Related Requirements
- User Story: US-PRF-010
- Non-Functional Requirements: NFR-1 (auto-gen 5,000 <=10s), NFR-4 (workspace <=2.5s P95 paginated)
- UI/UX: data table, auto-generation wizard, budget tracker, comparison cards, Chart.js charts, mobile condensed table + bottom-sheet (S8)

## 3. Preconditions
- Tenant "acme" seeded with a completed cycle of 5,000 employees with published final ratings.
- A performance test harness (load generator + timing capture) and an accessibility audit tool (axe / screen reader) are available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Employees | 5,000 | seeded |
| Auto-gen SLA | <=10s | NFR-1 |
| Workspace SLA | <=2.5s P95 | NFR-4, paginated |
| Viewports | 360px, 768px, 1920px, 4K | responsive |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run auto-generate (rating thresholds) across the 5,000-employee cycle; measure end-to-end | Completes within 10 seconds (NFR-1) using set-based evaluation (no per-employee round trips). |
| 2 | Load the recommendation workspace (first page) and measure P95 over repeated loads | P95 <=2.5s with a paginated employee list; the query is tenant-filtered + paginated, no N+1 on score/grade/comp/flag joins (NFR-4). |
| 3 | Paginate / sort / filter the workspace | Subsequent pages stay within the latency budget; sorting/filtering is server-side over the paginated set. |
| 4 | Run an accessibility audit on the workspace, wizard, budget tracker, comparison cards, and summary charts | WCAG 2.1 AA: keyboard-operable inline editing + wizard steps, screen-reader labels on table cells + budget progress bar (aria), chart summaries available to SR, status not conveyed by color alone, sufficient contrast. |
| 5 | Resize 360px -> 4K | Layout adapts: condensed table with swipeable row actions + bottom-sheet editing at 360px (S8); comparison cards stack; no horizontal scroll trap or clipped controls. |
| 6 | Keyboard-only pass | All actions (open editor, select type, set amount, submit, approve, export, open summary) are reachable and operable via keyboard with a visible focus order. |

## 6. Postconditions
- Auto-gen meets the 10s budget at 5,000 employees; the workspace meets the 2.5s P95 paginated budget; the UI is WCAG 2.1 AA accessible and responsive 360px-4K. No data mutated beyond seeded test recommendations. Tenant-scoped to acme.
