# TC-PRF-001-12: Goal-setting UI accessibility (WCAG 2.1 AA) and responsiveness 360px–4K (NFR-3)

## 1. Test Objective
Verify NFR-3 and the UI/UX notes: the goal-setting form, weight-distribution stacked bar, goal cards, and team dashboard are fully responsive from 360px to 4K and meet WCAG 2.1 AA — keyboard operable (including drag-and-drop reorder), screen-reader labelled, and sufficient colour contrast.

## 2. Related Requirements
- User Story: US-PRF-001
- Non-Functional Requirements: NFR-3
- Acceptance Criteria: AC-1, AC-4
- UI/UX Notes: S8 (Notion-like cards, stacked bar chart, drag-reorder, mobile bottom-sheet)

## 3. Preconditions
- Manager "Ravi Kumar" authenticated in acme; goal-setting form and team dashboard reachable; axe-core/Lighthouse available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Breakpoints | 360px, 768px, 1280px, 1920px, 4K (3840px) | NFR-3 range |
| Standard | WCAG 2.1 AA | contrast >= 4.5:1 text |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the goal-setting form at 360px, 768px, 1920px and 4K | Layout reflows without horizontal scroll or clipping; on mobile (360px) goal editing uses the bottom-sheet; no overlap. |
| 2 | Tab through the form (title, description, category, weight, target, unit, due date, Save) | All fields reachable in a logical order with a visible focus ring; the weight stepper and category select are keyboard operable. |
| 3 | Reorder goals using the keyboard (not just mouse drag) | Drag-and-drop reorder has a keyboard-accessible equivalent; order changes announced to assistive tech. |
| 4 | Run axe-core/Lighthouse on the form and the team dashboard | Zero critical/serious violations; the weight stacked-bar chart conveys allocation via text/labels, not colour alone; form fields have associated labels and aria error messaging. |
| 5 | Verify the validation error "Goal weights must total 100%" with a screen reader | The error is announced (aria-live / role=alert) and programmatically associated with the weight control. |

## 6. Postconditions
- The goal-setting UI passes WCAG 2.1 AA checks and is responsive across 360px–4K.
