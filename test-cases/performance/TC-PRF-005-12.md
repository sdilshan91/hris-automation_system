# TC-PRF-005-12: Feedback form is mobile single-column + WCAG 2.1 AA; results dashboard accessible (NFR-5)

## 1. Test Objective
Verify NFR-5 and the UI/UX notes: the 360 feedback form is fully mobile-responsive (single-column layout with collapsible competency sections at 360px) so reviewers can submit from any device, and both the feedback form and the results dashboard meet WCAG 2.1 AA (keyboard operable rating inputs, screen-reader labels, sufficient color contrast, chart content not conveyed by color alone).

## 2. Related Requirements
- User Story: US-PRF-005
- Acceptance Criteria: AC-2, AC-3, AC-4
- Non-Functional Requirements: NFR-5

## 3. Preconditions
- A reviewer with an assigned 360 feedback form for Liam in acme.
- An aggregated results dashboard available (radar + per-competency bars).
- Test devices/emulation from 360px to 1920px; axe-core + screen reader (NVDA/VoiceOver).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360, 768, 1280, 1920 px | responsive range |
| Rating input | star/slider per competency | must be keyboard + touch operable |
| Standard | WCAG 2.1 AA | NFR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the feedback form at 360px | Single-column layout; competency sections collapse/expand; no horizontal scroll; rating inputs + comment areas usable by touch (NFR-5, §8 mobile). |
| 2 | Operate the entire form by keyboard only | Every rating control + comment field + Submit is reachable and operable via keyboard; visible focus order is logical; rating value changeable without a mouse. |
| 3 | Run axe-core on the form + results dashboard | Zero WCAG 2.1 AA violations (labels, roles, contrast). |
| 4 | Screen-reader pass on the form | Each competency question, its rating control, and current value are announced with accessible names; required fields announced. |
| 5 | Inspect the radar/bar charts | Self/Manager/Peer/Report series are distinguishable beyond color (labels/patterns/legend); a text/table equivalent of the chart data is available to screen readers. |
| 6 | Verify across 768/1280/1920 | Layout reflows correctly; charts and completion tracker remain legible and accessible. |

## 6. Postconditions
- Feedback form and results dashboard are WCAG 2.1 AA compliant and usable from 360px upward.
