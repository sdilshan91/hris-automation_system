# TC-PRF-001-08: Closed goal-setting window renders read-only and prevents modification (AC-5, BR-1)

## 1. Test Objective
Verify AC-5 and BR-1: when the goal-setting window has closed for the cycle, the manager sees a read-only view with the message "The goal-setting window for this cycle has closed" and cannot add or edit goals. The block is enforced server-side (window check), and attempts before the window opens are likewise blocked.

## 2. Related Requirements
- User Story: US-PRF-001
- Acceptance Criteria: AC-5
- Functional Requirements: FR-1
- Business Rules: BR-1

## 3. Preconditions
- acme cycle "FY25-H2" exists with the goal-setting window CLOSED (end date in the past).
- acme cycle "FY27-H1" exists with the window NOT YET OPEN (start date in the future).
- Manager "Ravi Kumar" authenticated in acme with `Performance.SetGoal.Team`; Asha is his direct report; Asha has existing goals in FY25-H2.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Cycle FY25-H2 | window closed (past) | after-window case |
| Cycle FY27-H1 | window future | before-window case |
| Message | "The goal-setting window for this cycle has closed" | AC-5 exact text |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate to FY25-H2 goals for Asha | The view is read-only; existing goals display but inputs/Save are disabled; banner shows "The goal-setting window for this cycle has closed" (AC-5). |
| 2 | Bypass the UI: `POST .../goals` (create) and `PUT .../goals/{id}` (edit) for FY25-H2 | Both 403/409 with a window-closed error (BR-1); no create/modify occurs; existing goals unchanged. |
| 3 | Attempt `DELETE .../goals/{id}` for FY25-H2 | Rejected (window closed); goal not deleted. |
| 4 | Navigate to FY27-H1 (window not yet open) and attempt to add a goal | Blocked with a window-not-open message; `POST .../goals` returns 403/409 (BR-1: goals only during the goal-setting phase). |
| 5 | Verify persistence | FY25-H2 goals are byte-for-byte unchanged; no goal exists for FY27-H1. |

## 6. Postconditions
- Goal creation/edit/delete is impossible outside the open goal-setting window; the read-only view and message are shown.
