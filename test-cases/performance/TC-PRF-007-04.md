# TC-PRF-007-04: Drill-down -> click a department bar -> navigate to that department's employee list with individual scores + breadcrumb trail

## 1. Test Objective
Verify FR-5: clicking a department's bar in the department-wise comparison chart navigates the HR Officer to a drill-down view listing that department's employees with their individual performance scores for the active filter context, and renders the breadcrumb trail (Dashboard > Department > [Employee]) so the user can navigate back up.

## 2. Related Requirements
- User Story: US-PRF-007
- Functional Requirements: FR-5
- Acceptance Criteria: AC-1 (department bar originates here), AC-2 (drill-down respects active filters)
- UI/UX: S8 (breadcrumb trail)

## 3. Preconditions
- Tenant "acme" / cycle "FY26" dashboard rendered (TC-PRF-007-01), with Engineering having a known roster and known per-employee scores.
- HR Officer "Nadia Khan" authenticated in acme with `Performance.Read.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Department bar clicked | Engineering | FR-5 |
| Expected roster | seeded Engineering employees | with individual scores |
| Breadcrumb | Dashboard > Engineering | S8 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | On the dashboard, click the Engineering bar in the department-wise chart; observe `GET .../performance/dashboard/departments/eng/employees?cycleId=FY26` | 200; the view navigates to the Engineering drill-down; a breadcrumb "Dashboard > Engineering" renders (FR-5, S8). |
| 2 | Verify the employee list | Lists Engineering employees for FY26 with name, job title, and individual performance score; only acme/Engineering employees appear (NFR-2). |
| 3 | Verify the active filter context carries through | If a grade/location/employment-type filter was active on the dashboard, the drill-down list is scoped to the same slice (AC-2 consistency). |
| 4 | Click an individual employee in the list | The breadcrumb extends to "Dashboard > Engineering > [Employee]" and (where permitted) the employee's review detail / score breakdown is shown. |
| 5 | Click "Dashboard" in the breadcrumb | Navigates back to the overview with the prior filter state intact. |
| 6 | Confirm scope + tenant | An HR `.All` user sees all Engineering employees; the department id cannot be swapped for another tenant's department id (cross-tenant IDOR covered by TC-PRF-ISO-026; manager scope covered by TC-PRF-007-06). |

## 6. Postconditions
- The Engineering drill-down list with individual scores + breadcrumb is displayed; navigation back to the overview preserves filters; no cross-tenant data exposed.
