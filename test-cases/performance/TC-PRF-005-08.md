# TC-PRF-005-08: Weighted 360 composite score is computed per category weights and feeds the final performance score (FR-6/BR-6)

## 1. Test Objective
Verify FR-6 / BR-6: 360 feedback is aggregated into a composite score using configurable per-category weights (e.g. self 10% / manager 40% / peers 30% / reports 20%), the per-category inputs are correctly averaged before weighting, and the resulting 360 composite is incorporated into the employee's final performance score alongside self and manager ratings. Server is authoritative; the calculation is data-driven across weight configurations.

## 2. Related Requirements
- User Story: US-PRF-005
- Acceptance Criteria: AC-4
- Functional Requirements: FR-6
- Business Rules: BR-6

## 3. Preconditions
- 360-enabled cycle "FY26 Annual Review" active for acme; Liam Carter under review.
- All categories submitted: Self, Manager, 2 Peers, 2 Reports, on a 1-5 scale.
- Category weights configured: self 10% / manager 40% / peers 30% / reports 20% (sum = 100%).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Self avg | 4.0 | one self rating |
| Manager avg | 5.0 | one manager rating |
| Peers avg | (4 + 3) / 2 = 3.5 | Ava 4, Ben 3 |
| Reports avg | (4 + 4) / 2 = 4.0 | Sara 4, Tom 4 |
| Weights | 10 / 40 / 30 / 20 | self/mgr/peers/reports |
| Expected composite | 0.10*4.0 + 0.40*5.0 + 0.30*3.5 + 0.20*4.0 = **4.25** | weighted |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Ensure all six feedback records exist with the ratings above | Per-category averages: self 4.0, manager 5.0, peers 3.5, reports 4.0. |
| 2 | `GET .../performance/360/{liamId}/results` and read the composite score | Composite = 4.25 (0.10*4.0 + 0.40*5.0 + 0.30*3.5 + 0.20*4.0); peers/reports are averaged WITHIN category before the category weight is applied (FR-6). |
| 3 | Reconfigure weights to self 25 / mgr 25 / peers 25 / reports 25 and recompute (or use a second seeded employee) | Composite = 0.25*(4.0+5.0+3.5+4.0) = 4.125 — calculation is data-driven on the configured weights, server authoritative. |
| 4 | Inspect Liam's FINAL performance score | The 360 composite feeds into the final performance score per the tenant's blending rule (BR-6); changing the 360 composite changes the final score; the final score is server-computed, not client-computed. |
| 5 | Edge: a category with zero submissions (e.g. no reports) | The composite either redistributes/renormalizes the remaining weights or excludes the empty category per the documented rule, consistently — no divide-by-zero, no silent inclusion of a 0 average. |

## 6. Postconditions
- Liam's 360 composite = 4.25 for the seeded data; the final performance score reflects the 360 composite per BR-6.
