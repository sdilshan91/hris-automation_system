# TC-PRF-002-08: Hangfire deadline-approaching reminder (in-app + email) fires for non-submitters (AC-5, FR-7)

## 1. Test Objective
Verify AC-5 and FR-7: as the self-assessment deadline approaches (reminder threshold, e.g. 3 days before), a Hangfire scheduled job sends an automated reminder (in-app + email) to every employee who has NOT submitted, and does NOT remind employees who have already submitted. The reminder is tenant-scoped.

## 2. Related Requirements
- User Story: US-PRF-002
- Acceptance Criteria: AC-5
- Functional Requirements: FR-7
- Assumptions: reminder thresholds configurable by HR (default 7/3/1 days before deadline)

## 3. Preconditions
- acme cycle FY26-H1 with a self-assessment deadline; Hangfire is running.
- Asha has NOT submitted (draft or empty); Bala has already submitted.
- A reminder threshold (e.g. 3 days before deadline) is configured.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Reminder threshold | 3 days before deadline | AC-5 example |
| Non-submitter | Asha | should be reminded |
| Submitter | Bala | should NOT be reminded |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Advance time (or trigger the job) to the 3-days-before-deadline threshold | The Hangfire reminder job executes for acme's FY26-H1 cycle, scoped to the acme tenant context (job arg carries tenant_id). |
| 2 | Inspect Asha's in-app notifications | An in-app reminder "Your self-assessment for FY26-H1 is due in 3 days" is delivered to Asha (AC-5). |
| 3 | Inspect the email enqueue | A reminder email to Asha is ENQUEUED (delivery CONDITIONAL on the Notification System S25 -- the enqueue is asserted here). |
| 4 | Inspect Bala (already submitted) | No reminder (in-app or email) is generated for Bala -- the job filters to non-submitters only. |
| 5 | Confirm tenant scoping | Only acme non-submitters are reminded; no employee of another tenant receives a reminder from acme's job run. |

## 6. Postconditions
- Non-submitters receive a deadline reminder (in-app delivered + email enqueued); submitters are excluded; reminders are tenant-scoped.
