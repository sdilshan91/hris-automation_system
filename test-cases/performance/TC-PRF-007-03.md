# TC-PRF-007-03: Multi-cycle Trend view -> select 3 cycles -> line chart shows correct average-score series, with per-department overlay

## 1. Test Objective
Verify AC-3 and FR-7: the HR Officer switches to the "Trend" view and selects multiple cycles; the system renders a chart.js line chart plotting the org-wide average performance score for each selected cycle in chronological order, and supports overlaying department-specific trend lines so departmental trajectories can be compared over time.

## 2. Related Requirements
- User Story: US-PRF-007
- Acceptance Criteria: AC-3
- Functional Requirements: FR-7
- Non-Functional Requirements: NFR-4 (chart.js)

## 3. Preconditions
- Tenant "acme" has >=3 completed cycles with submitted reviews: FY24, FY25, FY26, each with a KNOWN org-wide average score and known per-department averages.
- HR Officer "Nadia Khan" authenticated in acme with `Performance.Read.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Cycles selected | FY24, FY25, FY26 | 3 points on the line |
| Expected org averages | e.g. 3.6, 3.8, 3.9 | seeded series |
| Department overlay | Engineering, Sales | per-dept trend lines |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Switch to the "Trend" view; select cycles FY24, FY25, FY26; observe `GET .../performance/dashboard/trend?cycleIds=FY24,FY25,FY26` | 200; payload returns an ordered series of {cycle, averageScore} for acme only; a chart.js line chart renders 3 points in chronological order (AC-3, FR-7). |
| 2 | Verify the org-wide average series | Each point equals the seeded org-wide average for that cycle; the x-axis is ordered by cycle start date, not selection order. |
| 3 | Enable the per-department overlay for Engineering and Sales | Additional line series render for each selected department, each plotting that department's average per cycle (FR-7 overlay). |
| 4 | Hover a data point | The tooltip shows the cycle name + exact average score (and department when on an overlay line). |
| 5 | Deselect FY24, leaving FY25 + FY26 | The line chart recomputes to 2 points; overlays adjust accordingly. |
| 6 | Select a single cycle | The trend renders a single point / degenerate line without error (boundary). |
| 7 | Confirm tenant scoping | Only acme cycles are selectable; a cycle id from another tenant cannot be plotted (cross-tenant covered by TC-PRF-ISO-026). |

## 6. Postconditions
- A multi-cycle trend line chart with optional department overlays is displayed for the selected acme cycles; no cross-tenant cycle data is shown.
