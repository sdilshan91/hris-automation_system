# TC-PRF-002-15: Self-assessment UI is WCAG 2.1 AA + responsive 360px, rating inputs usable via touch and keyboard (NFR-5)

## 1. Test Objective
Verify NFR-5: the self-assessment UI (goal accordion cards, star/slider rating inputs, achievement % field, rich-text comment, file upload area, sticky submit button, progress indicator) is fully operable on a 360px mobile viewport with touch, fully operable via keyboard, and meets WCAG 2.1 AA for screen readers and color contrast.

## 2. Related Requirements
- User Story: US-PRF-002
- Non-Functional Requirements: NFR-5
- Acceptance Criteria: AC-1, AC-3
- UI/UX: S8 (accordion, star/slider, progress indicator, sticky submit)

## 3. Preconditions
- acme cycle FY26-H1 self-assessment window open; Asha authenticated with `Performance.Read.Self`; multiple goals exist.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360px, 768px, 1280px | mobile -> desktop |
| Tools | keyboard only, axe/Lighthouse, screen reader (NVDA/VoiceOver) | a11y audit |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load My Review at 360px | Goals render as a collapsible accordion; no horizontal scroll; the submit button is reachable (sticky bottom); all rating inputs are visible and tappable with touch targets >= 44x44px (NFR-5). |
| 2 | Set a star/slider rating using touch on mobile | The rating updates correctly via tap/drag; achievement % and comment are editable on touch. |
| 3 | Operate the whole form with the keyboard only (Tab/Shift+Tab/Arrow/Enter/Space) | Every goal card, rating control, achievement field, comment editor, file upload, and submit button is reachable and operable; focus order is logical; focus is visible; the rating control is settable via arrow keys. |
| 4 | Run axe/Lighthouse and a screen-reader pass | No WCAG 2.1 AA violations; rating inputs and progress indicator have accessible names/roles/values (e.g. "Goal 1 rating, 4 of 5"); error messages are announced; the closed-window banner is announced. |
| 5 | Check color contrast on ratings, progress bar, errors, and the sticky submit | All text and meaningful UI meet >= 4.5:1 (normal) / 3:1 (large/UI) contrast. |

## 6. Postconditions
- The self-assessment UI passes WCAG 2.1 AA and is fully touch- and keyboard-operable down to 360px.
