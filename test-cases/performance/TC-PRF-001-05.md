# TC-PRF-001-05: Boundary — exactly 100% weights, exactly 1 and exactly 10 goals, title/description at max length

## 1. Test Objective
Verify the accepting edges of the validation rules in FR-2/3 and BR-2: a single goal at exactly 100% saves; exactly 10 goals whose weights sum to exactly 100% save; and a goal with title at the 200-char limit and description at the 2000-char limit saves, while one character over either limit is rejected.

## 2. Related Requirements
- User Story: US-PRF-001
- Functional Requirements: FR-2, FR-3
- Business Rules: BR-2, BR-3

## 3. Preconditions
- Manager "Ravi Kumar" authenticated in acme with `Performance.SetGoal.Team`; window OPEN; direct reports available (Asha and others).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Single goal | weight 100% | exactly the max single allocation; lower edge of BR-2 count (1) |
| Ten goals | weights 10×10% = 100% | upper edge of BR-2 count (10), total exactly 100 |
| Title | 200 chars | FR-2 max; 201 chars = over |
| Description | 2000 chars | FR-2 max; 2001 chars = over |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Create exactly 1 goal at weight 100% for Asha and Save | 201 Created; the single-goal-100% set is accepted (lower BR-2 edge + exact 100% total). |
| 2 | For a second employee, create exactly 10 goals at 10% each (total 100%) and Save | 201 Created; 10 goals persisted (upper BR-2 edge). |
| 3 | Set a goal title to exactly 200 chars and description to exactly 2000 chars; Save | Accepted; values stored untruncated. |
| 4 | Set the title to 201 chars; Save | Rejected 400/422 (FR-2 max 200); not persisted. |
| 5 | Set the description to 2001 chars; Save | Rejected 400/422 (FR-2 max 2000); not persisted. |

## 6. Postconditions
- The accepting boundaries (1 goal, 10 goals, exact 100%, max-length title/description) all persist; the just-over edges are rejected.
