# TC-PRF-010-13: Export -> PDF/Excel aggregate recommendation report matches the dashboard stats (export seam; tenant-scoped + authz)

## 1. Test Objective
Verify FR-6: the system generates a recommendation summary report (PDF/Excel) with aggregate statistics for leadership review, and the exported figures MATCH the on-screen recommendation summary (AC-4). The export is tenant-scoped and authz-restricted (HR `Performance.Read.All`/`Publish.All`); PDF/XLSX rendering is asserted at the export SEAM with tenant branding inputs (consistent with US-PRF-005 FR-7 / US-PRF-007 FR-8).

## 2. Related Requirements
- User Story: US-PRF-010
- Functional Requirements: FR-6 (PDF/Excel summary report)
- Acceptance Criteria: AC-4 (aggregate statistics the report reflects)

## 3. Preconditions
- Tenant "acme"; HR Officer Pat Ng (`Performance.Read.All`).
- The FY25 summary (TC-PRF-010-07) shows 6 promotions, $48,000 bonus pool, increments Eng 4 / Sales 3 / Support 2.
- The reporting library (XLSX writer; QuestPDF or similar for PDF) is available OR asserted at the seam.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Formats | PDF, Excel (XLSX) | FR-6 |
| Expected promotions | 6 | matches dashboard |
| Expected bonus pool | $48,000 | matches dashboard |
| Branding | acme primary color + logo | PDF |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Pat, from the FY25 summary click Export -> Excel | `GET .../recommendations/summary/export?format=xlsx` returns an XLSX file download (no ApiResponse envelope) with the aggregate stats. |
| 2 | Compare the XLSX values to the on-screen summary | Total promotions = 6, bonus pool = $48,000, increment distribution Eng 4 / Sales 3 / Support 2 -- identical to the dashboard (AC-4); only acme data. |
| 3 | Export -> PDF | A PDF is produced with the same aggregates + acme tenant branding (primary color/logo); PDF rendering asserted at the export seam (conditional on the PDF library; full visual fidelity is the extension point). |
| 4 | Request an unsupported format (e.g. `format=docx`) | 400 invalid_format -- only the supported formats are accepted. |
| 5 | Authz + tenant scoping | A manager (team scope) exports only their team's figures; an employee/unauthorized caller is rejected (403); a caller in another tenant never receives acme's export (NFR-2). |

## 6. Postconditions
- The PDF/Excel recommendation report matches the dashboard aggregates, is tenant-scoped + authz-restricted, and carries tenant branding on PDF. No data mutated. Tenant-scoped to acme.
