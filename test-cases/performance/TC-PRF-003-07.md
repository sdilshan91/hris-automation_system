# TC-PRF-003-07: Scope authz -- a manager can ONLY review their DIRECT REPORTS; reviewing a non-report (or another team's employee) is forbidden; unauthenticated blocked

## 1. Test Objective
Verify BR-2 and NFR-2 scope isolation: a manager with `Performance.Review.Team` may open and submit reviews only for employees who are their direct reports in the org tree. Attempting to view or rate a non-report -- a peer's report, an employee in another team/department, or any employee not directly reporting to them -- is forbidden (403), including direct API access by employeeId (IDOR). The org tree is the single source of truth for the manager-report relationship. Unauthenticated access is rejected (401).

## 2. Related Requirements
- User Story: US-PRF-003
- Business Rules: BR-2
- Non-Functional Requirements: NFR-2
- Functional Requirements: FR-1

## 3. Preconditions
- acme tenant; Ravi (Performance.Review.Team) has direct report Asha.
- Maya is a DIRECT REPORT of a different manager (Priya), NOT of Ravi.
- An unauthenticated client is available.

## 4. Test Data
| Actor | Target | Expected |
|-------|--------|----------|
| Ravi | Asha (own report) | allowed |
| Ravi | Maya (Priya's report) | 403 forbidden |
| Ravi via API by employeeId=Maya | review GET/POST | 403 (IDOR blocked) |
| Unauthenticated | any review | 401 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Ravi, open the Team Reviews dashboard | Only Ravi's direct reports are listed; Maya does NOT appear (BR-2). |
| 2 | As Ravi, request Maya's review by direct URL / employeeId | 403 Forbidden; no review data for Maya is returned (IDOR blocked, NFR-2). |
| 3 | As Ravi, POST a manager rating for Maya's goals via the API | 403 Forbidden; nothing persisted. |
| 4 | As Ravi, open and rate Asha (own report) | Allowed (control case). |
| 5 | Call the review API with no/expired token | 401 Unauthorized. |
| 6 | Re-parent Maya under Ravi in the org tree, then retry step 2 | Now allowed -- confirms the org tree is the authoritative source for scope. |

## 6. Postconditions
- A manager can only access reviews for current direct reports; non-report access is forbidden at UI + API; unauth is 401; the org tree drives scope.
