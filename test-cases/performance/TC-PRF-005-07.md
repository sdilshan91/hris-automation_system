# TC-PRF-005-07: Anonymity cannot be retroactively disabled after feedback has been submitted (BR-5)

## 1. Test Objective
Verify BR-5: once anonymous feedback has been submitted for a 360 review, anonymity cannot be retroactively turned OFF. This prevents a reviewer who answered under a promise of anonymity from being de-anonymized after the fact, which would be a trust/compliance violation.

## 2. Related Requirements
- User Story: US-PRF-005
- Functional Requirements: FR-5
- Business Rules: BR-5

## 3. Preconditions
- 360-enabled cycle "FY26 Annual Review" active for acme with anonymity ENABLED.
- At least one anonymous feedback record has already been submitted for Liam Carter.
- HR Officer "Nadia Khan" (`Performance.Review.All`) authenticated; an admin able to toggle cycle anonymity settings.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Anonymity | ON | feedback already submitted under it |
| Attempted change | ON -> OFF | invalid after submission (BR-5) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | In the cycle/360 settings, attempt to toggle anonymity from ON to OFF after feedback exists | The toggle is disabled/locked with an explanatory message (e.g. "Anonymity cannot be disabled after feedback has been submitted") (BR-5). |
| 2 | Bypass the UI: `PUT .../performance/360/{cycleOrReviewId}/settings` with `{ anonymous: false }` | Server rejects with 409/422; the anonymity flag stays ON; no `feedback_360.anonymity` flags are flipped. |
| 3 | Re-query the results API as employee/manager | Reviewer identifiers remain absent — the previously-submitted anonymous feedback stays anonymous (cross-ref TC-PRF-005-06). |
| 4 | Confirm the reverse direction (OFF -> ON before any submission) is allowed | If no feedback has been submitted yet, anonymity may still be changed freely — BR-5 only locks the ON->OFF direction once feedback exists. |

## 6. Postconditions
- Anonymity remains ON; no submitted feedback is de-anonymized; the setting is locked for the lifetime of the review.
