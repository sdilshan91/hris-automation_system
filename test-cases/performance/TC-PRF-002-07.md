# TC-PRF-002-07: Closed self-assessment window renders read-only and blocks submit/edit (AC-4, BR-1)

## 1. Test Objective
Verify AC-4 and BR-1: when the self-assessment window has closed for the cycle, the employee sees a read-only view with the exact message "The self-assessment period for this cycle has ended" and cannot submit or edit. The block is enforced server-side (window check), independent of the UI, and a window that has not yet opened is likewise blocked.

## 2. Related Requirements
- User Story: US-PRF-002
- Acceptance Criteria: AC-4
- Functional Requirements: FR-1
- Business Rules: BR-1

## 3. Preconditions
- acme cycle "FY25-H2" exists with the self-assessment window CLOSED (end date in the past); Asha has goals (and possibly a draft) in FY25-H2.
- acme cycle "FY27-H1" exists with the window NOT YET OPEN (start date in the future).
- Asha authenticated in acme with `Performance.Read.Self`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Cycle FY25-H2 | window closed (past) | after-window case |
| Cycle FY27-H1 | window future | before-window case |
| Message | "The self-assessment period for this cycle has ended" | AC-4 exact text |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open My Review for FY25-H2 | The view is read-only; any existing draft/values display but inputs and "Submit"/"Save as Draft" are disabled; banner shows the exact text "The self-assessment period for this cycle has ended" (AC-4). |
| 2 | Bypass the UI: POST submit and PUT edit for FY25-H2 | Both rejected 403/409 with a window-closed error (BR-1); no submission or edit occurs; existing data unchanged. |
| 3 | Open My Review for FY27-H1 (window not yet open) and attempt to enter/submit ratings | Blocked with a window-not-open message; bypass submit returns 403/409 (BR-1: self-assessment only during the self-assessment phase). |
| 4 | Verify persistence | FY25-H2 data is byte-for-byte unchanged; no self-assessment record is created for FY27-H1. |

## 6. Postconditions
- Submission/edit is impossible outside the open self-assessment window; the read-only view and exact closed message are shown.
