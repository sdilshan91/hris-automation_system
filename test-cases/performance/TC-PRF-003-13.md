# TC-PRF-003-13: Manager-review UI conforms to WCAG 2.1 AA -- keyboard navigation for all rating inputs; mobile 360px stacked layout replaces side-by-side

## 1. Test Objective
Verify NFR-4 / §8 UI notes: the manager-review form and Team Reviews dashboard conform to WCAG 2.1 AA. Every rating input (rating selector, comment field, summary, submit) is reachable and operable by keyboard alone with a visible focus order and labels; status chips and rating badges meet color-contrast and are not color-only (have text/icon). At 360px the side-by-side self-vs-manager layout collapses to a stacked layout with swipeable/expandable goal cards, with no loss of function.

## 2. Related Requirements
- User Story: US-PRF-003
- Non-Functional Requirements: NFR-4
- Acceptance Criteria: AC-1, AC-4

## 3. Preconditions
- acme review form + Team Reviews dashboard rendered with data.
- Axe/Lighthouse + screen reader (NVDA/VoiceOver) + a 360px viewport available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewport | 360px, 768px, 1280px | stacked vs side-by-side |
| Standard | WCAG 2.1 AA | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run axe-core on the review form and dashboard | Zero WCAG 2.1 AA violations (contrast, names/roles/values, labels). |
| 2 | Navigate the review form with keyboard only (Tab/Shift+Tab/arrow/Enter/Space) | Every rating input, comment field, summary, and Submit is reachable and operable; focus order is logical; focus is visible; rating selectors are operable via keyboard (NFR-4). |
| 3 | Verify status chips + rating badges | Status/rating are conveyed by text/icon plus color (not color-only); contrast >= 4.5:1. |
| 4 | Drive a screen reader through a goal card | Self-rating vs manager-rating regions are announced with clear labels; the unrated-goals error (TC-PRF-003-02) is announced via an aria-live region. |
| 5 | Resize to 360px | Side-by-side collapses to a stacked/swipeable card layout; all fields remain usable via touch + keyboard; no horizontal scroll or clipped controls. |

## 6. Postconditions
- The manager-review experience is WCAG 2.1 AA compliant, fully keyboard-operable, and usable on a 360px stacked layout.
