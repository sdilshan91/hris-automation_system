# TC-PRF-003-06: Team Reviews dashboard shows each direct report's review status (pending self-assessment / self-assessment submitted / manager review pending / completed) with color-coded indicators

## 1. Test Objective
Verify AC-4: the Team Reviews dashboard displays a summary table of the manager's direct reports, each with its current review status across the workflow -- pending self-assessment -> self-assessment submitted -> manager review pending -> completed -- rendered with color-coded status chips. The dashboard reflects state transitions correctly (an employee who has submitted self-assessment shows "manager review pending"; after the manager submits, shows "completed") and is filterable/sortable.

## 2. Related Requirements
- User Story: US-PRF-003
- Acceptance Criteria: AC-4
- Functional Requirements: FR-1
- Business Rules: BR-2 (only direct reports listed)

## 3. Preconditions
- Ravi has 4 direct reports in acme FY26-H1, each at a different stage:
  - Emp1: not yet self-assessed -> "pending self-assessment"
  - Emp2: self-assessment submitted, no manager review -> "self-assessment submitted" / "manager review pending"
  - Emp3: manager review in draft -> "manager review pending"
  - Emp4: manager review submitted -> "completed"

## 4. Test Data
| Employee | Stage | Expected chip / color |
|----------|-------|------------------------|
| Emp1 | pending self-assessment | grey/neutral |
| Emp2 | self-assessment submitted | blue/info (action: manager review) |
| Emp3 | manager review pending | amber/in-progress |
| Emp4 | completed | green |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate to Performance > Team Reviews as Ravi | A table lists exactly Ravi's 4 direct reports (no non-reports, BR-2), each row showing name, job title, and a color-coded status chip matching the table above (AC-4). |
| 2 | Verify the status semantics | Emp1 grey "pending self-assessment"; Emp2 blue "self-assessment submitted" (selectable to start the manager review); Emp3 amber "manager review pending"; Emp4 green "completed". |
| 3 | Submit Emp2's manager review, then return to the dashboard | Emp2's chip transitions to green "completed"; the count of completed increments. |
| 4 | Sort/filter by status | The table sorts/filters by status correctly; counts per status are accurate. |

## 6. Postconditions
- The dashboard accurately reflects each direct report's review stage with correct color coding and updates on transition.
