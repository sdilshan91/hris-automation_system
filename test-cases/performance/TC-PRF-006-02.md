# TC-PRF-006-02: Meeting notes / sign-off request rejected before the manager review is submitted (BR-1)

## 1. Test Objective
Verify BR-1 and the FR-3 sign-off ordering: meeting notes can only be added (and an employee sign-off requested) AFTER the manager review for that employee has been submitted. Attempting to add notes or request sign-off while the manager review is still in progress (Pending Self-Assessment / Self-Assessment Submitted / Manager Review in Draft, i.e. not submitted) is rejected on the client AND re-enforced server-side. This prevents an out-of-order sign-off on an incomplete assessment.

## 2. Related Requirements
- User Story: US-PRF-006
- Acceptance Criteria: AC-2 (sign-off request)
- Functional Requirements: FR-3 (manager signs first; ordered workflow)
- Business Rules: BR-1 (notes only after manager review submitted)

## 3. Preconditions
- Tenant "acme", Performance module enabled, active cycle in the review/sign-off phase.
- Employee "Liam Carter" has a manager review that is NOT yet submitted (status Manager Review in Draft / not submitted).
- Manager "Maya Shah" authenticated in acme with `Performance.Review.Team` over Liam.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Employee | Liam Carter | manager review NOT submitted |
| Review status | ManagerReviewSubmitted = false | BR-1 precondition not met |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Maya, open Liam's review while the manager review is still in Draft | The "Add Meeting Notes" / "Request Employee Sign-Off" actions are disabled or hidden; a hint indicates the manager review must be submitted first (BR-1). |
| 2 | Bypass the UI: `POST .../performance/reviews/{reviewId}/meeting-notes` directly | Server rejects with 409/422 (review not in a sign-off-eligible state); no review_meeting_notes row created (BR-1). |
| 3 | Bypass the UI: `POST .../performance/reviews/{reviewId}/request-signoff` directly | Server rejects with 409/422; status unchanged; no signoff request created; employee NOT notified (FR-3 ordering enforced server-side). |
| 4 | Submit the manager review (US-PRF-003), then retry steps 2-3 | After submission the notes endpoint and request-signoff succeed (the BR-1 gate is satisfied), confirming the rejection was state-driven, not a blanket block. |

## 6. Postconditions
- No meeting notes or sign-off request exist for Liam's review until the manager review is submitted.
