# TC-PRF-003-03: Manager comment <20 chars rejected; manager rating outside the configured scale rejected; summary comment > max rejected (client + server)

## 1. Test Objective
Verify the per-goal input rules for manager rating: a manager comment shorter than 20 characters is rejected (FR-3); a manager rating below the scale minimum or above the scale maximum (or non-integer/blank) is rejected and must use the same tenant-configured scale as the self-assessment (FR-2); an overall summary comment exceeding the 5000-character cap is rejected (FR-5). Each rule is enforced client-side and re-validated server-side.

## 2. Related Requirements
- User Story: US-PRF-003
- Acceptance Criteria: AC-2 (valid-submission gate)
- Functional Requirements: FR-2, FR-3, FR-5

## 3. Preconditions
- Same as TC-PRF-003-01. Tenant rating scale 1-5 numeric.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Short comment | 19 chars | FR-3 reject |
| Rating low | 0 | below scale min (1) -> reject (FR-2) |
| Rating high | 6 | above scale max (5) -> reject (FR-2) |
| Rating non-numeric | "good" | reject (FR-2) |
| Summary | 5001 chars | over FR-5 cap -> reject |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Enter a 19-char comment on Goal 1 and try to submit | Inline error "Comment must be at least 20 characters"; submit blocked (FR-3). A bypass POST returns 400. |
| 2 | Set Goal 1 rating to 0, then to 6, then to "good" | Each is rejected with a scale error (e.g. "Rating must be between 1 and 5"); submit blocked (FR-2). Bypass POSTs return 400. |
| 3 | Enter a 5001-char summary comment and submit | Rejected "Summary comment must be 5000 characters or fewer" (FR-5); bypass POST returns 400. |
| 4 | Correct all fields to valid values (>=20-char comment, rating 1-5, summary <=5000) and submit | Submission succeeds. |

## 6. Postconditions
- Sub-20-char comments, out-of-scale ratings, and over-cap summaries are rejected at both layers; only valid input is persisted.
