# TC-PRF-001-07: Authorization — only the direct reporting manager or HR with Performance.SetGoal.All can set goals (BR-4)

## 1. Test Objective
Verify BR-4 and the preconditions/authorization model: only the employee's direct reporting manager (with `Performance.SetGoal.Team`) or an HR user with `Performance.SetGoal.All` can create/edit goals for that employee. A manager who is not the employee's manager, an employee, and an unauthenticated request are all blocked.

## 2. Related Requirements
- User Story: US-PRF-001
- Functional Requirements: FR-1
- Business Rules: BR-4
- NFR: NFR-2 (tenant scope), authz model

## 3. Preconditions
- acme has: Manager Ravi (manages Asha), Manager Sara (manages Devin, NOT Asha), HR user Hana with `Performance.SetGoal.All`, and Employee Asha (no SetGoal permission). All in cycle FY26-H1, window OPEN.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Ravi | Performance.SetGoal.Team, manages Asha | should succeed |
| Sara | Performance.SetGoal.Team, does NOT manage Asha | should be 403 |
| Hana | Performance.SetGoal.All (HR) | should succeed for any employee |
| Asha | no SetGoal permission | should be 403 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Ravi, `POST .../goals` setting goals for Asha | 201 — Ravi is Asha's direct manager (BR-4). |
| 2 | As Sara, `POST .../goals` setting goals for Asha | 403 Forbidden — Sara is not Asha's reporting manager and lacks `.All`. No goals persisted. |
| 3 | As Hana (HR, `.All`), `POST .../goals` setting goals for Asha (and for Devin) | 201 for both — `.All` allows setting goals for any employee in the tenant (BR-4). |
| 4 | As Asha (employee, no SetGoal perm), `POST .../goals` for herself | 403 Forbidden — employees cannot self-assign goals. |
| 5 | Unauthenticated `POST .../goals` | 401 Unauthorized. |

## 6. Postconditions
- Goal mutation is restricted to the direct reporting manager or HR `.All`; all other actors are rejected with no data leakage in the error.
