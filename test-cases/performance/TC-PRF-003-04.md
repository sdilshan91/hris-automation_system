# TC-PRF-003-04: FINAL combined score = (self_score * self_w) + (manager_score * manager_w) computed correctly across ratios 50:50, 30:70, 0:100 (data-driven)

## 1. Test Objective
Verify FR-4 and BR-4: the final combined score is computed as `(self_score * self_weight) + (manager_score * manager_weight)` using the tenant-configured self vs. manager weight ratio. Validate the formula data-driven across three configured ratios -- 50:50, 30:70, and 0:100 (manager-only) -- confirming the manager score is the weighted average of per-goal manager ratings (by goal weight) and the final score blends self and manager scores per the ratio. The 0:100 case proves a manager-only configuration ignores the self score entirely.

## 2. Related Requirements
- User Story: US-PRF-003
- Acceptance Criteria: AC-2
- Functional Requirements: FR-4
- Business Rules: BR-4

## 3. Preconditions
- acme cycle FY26-H1, manager-review window open; Asha is Ravi's direct report with submitted self-assessment.
- 3 goals weighted 40/35/25. Self-ratings 5/4/3 -> self_score = (5*40+4*35+3*25)/100 = 4.15. Manager ratings 4/4/3 -> manager_score = (4*40+4*35+3*25)/100 = 3.75.
- The tenant self:manager ratio is reconfigured between runs (50:50, 30:70, 0:100). (Per BR-4 weights are tenant-configurable; assume an HR/admin config seam sets the ratio for the cycle.)

## 4. Test Data (data-driven)
| Case | self:manager ratio | self_score | manager_score | Expected final_score |
|------|--------------------|------------|---------------|----------------------|
| A | 50:50 | 4.15 | 3.75 | (4.15*0.50)+(3.75*0.50) = 3.95 |
| B | 30:70 | 4.15 | 3.75 | (4.15*0.30)+(3.75*0.70) = 3.87 |
| C | 0:100 | 4.15 | 3.75 | (4.15*0.00)+(3.75*1.00) = 3.75 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Configure ratio 50:50; submit the manager review with the data above; read the persisted final_score | manager_score = 3.75; final_score = 3.95 (Case A), within rounding tolerance. |
| 2 | Reset, configure 30:70, resubmit; read final_score | final_score = 3.87 (Case B). manager_score unchanged at 3.75. |
| 3 | Reset, configure 0:100, resubmit; read final_score | final_score = 3.75 (Case C) -- equal to manager_score; the self_score contributes 0. |
| 4 | Confirm the server (not the client) computed each score | The final_score in the API response/persisted row matches the server computation; a tampered client-sent final_score is ignored/overwritten by the server. |

## 6. Postconditions
- The final combined score follows `(self*self_w)+(manager*manager_w)` for every configured ratio; manager_score is the goal-weighted manager average; server is authoritative.
