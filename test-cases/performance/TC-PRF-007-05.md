# TC-PRF-007-05: Export dashboard as CSV, Excel (XLSX), and PDF -> data accuracy + tenant branding on PDF + completes <=5s for 5,000 employees

## 1. Test Objective
Verify AC-4, FR-8, and NFR-5: the HR Officer clicks "Export" and selects each format (CSV, Excel/XLSX, PDF); the system generates and downloads a report that reflects all visible charts and data tables for the current filter/cycle context, with accurate data, tenant branding (primary color/logo from tenant settings) on the PDF, and completes within 5 seconds for a tenant with up to 5,000 employees. The PDF/XLSX rendering is asserted at the export SEAM where rendering is deferred to the reporting library.

## 2. Related Requirements
- User Story: US-PRF-007
- Acceptance Criteria: AC-4
- Functional Requirements: FR-8
- Non-Functional Requirements: NFR-5 (export <=5s for 5,000 employees)

## 3. Preconditions
- Tenant "acme" with cycle "FY26" and ~5,000 participants seeded for the performance-timing run; tenant branding (primary color + logo) configured.
- HR Officer "Nadia Khan" authenticated in acme with `Performance.Read.All` + `Reports.View.All`.
- The reporting/PDF library (e.g. QuestPDF) and the XLSX writer are wired, OR the export route exposes a seam that asserts the data model + branding inputs when rendering is deferred.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Formats | CSV, XLSX, PDF | FR-8 |
| Population | ~5,000 employees | NFR-5 timing |
| Branding | acme primary color + logo | PDF only (FR-8) |
| SLA | <=5s | NFR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | With the org-wide FY26 view open, click Export > CSV; observe `GET .../performance/dashboard/export?cycleId=FY26&format=csv` | 200 with `Content-Type: text/csv` + `Content-Disposition` filename; the CSV rows match the visible data tables (completion, averages, per-department, top/bottom) for acme/FY26. |
| 2 | Click Export > Excel (XLSX) | 200 with the XLSX content type + filename; the workbook contains the dashboard tables; numeric cells match the on-screen aggregates (data accuracy). |
| 3 | Click Export > PDF | 200 with `application/pdf` + filename; the PDF embeds the charts + tables AND applies acme's tenant branding (primary color, logo) -- NOT a generic theme (FR-8). |
| 4 | Apply a department filter, then export each format again | The exports reflect the FILTERED slice, not the org-wide set (AC-4 "all visible charts and data"). |
| 5 | Measure export generation time for the 5,000-employee tenant (P95 over repeated runs) | Each format completes within 5 seconds (NFR-5). If rendering is deferred, the data-assembly seam completes within budget and the test documents the rendering library as the extension point. |
| 6 | Verify authz + tenant scoping of export | The export contains only acme data; a manager/employee cannot export org-wide (covered by TC-PRF-007-06/-08); cross-tenant export blocked (TC-PRF-ISO-026). |

## 6. Postconditions
- CSV/XLSX/PDF reports for the current acme view are generated accurately, PDF carries tenant branding, and generation meets the <=5s SLA at 5,000 employees.
