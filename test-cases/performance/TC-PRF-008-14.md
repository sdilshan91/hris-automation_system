# TC-PRF-008-14: PIP summary report (PDF) -- objectives, checkpoints, outcomes, signatures -- asserted at the export seam/endpoint (FR-7)

## 1. Test Objective
Verify FR-7: the system generates a PIP summary report (PDF) including all objectives, all checkpoints, the final outcome, and signatures. Because PDF rendering depends on a reporting library that may be an extension point, the test asserts the export ENDPOINT/SEAM, the report data model (all sections present), tenant branding inputs, and authz + tenant scoping; full visual fidelity is documented as conditional.

> Note: PDF rendering is CONDITIONAL on the reporting library (QuestPDF or similar) being wired -- consistent with US-PRF-005 FR-7 / US-PRF-006 FR-6 / US-PRF-007 FR-8 in this module. This TC asserts the export seam + data model + authz/tenant-scoping + branding inputs and documents full PDF fidelity as the extension point. The data-completeness + authorization assertions hold regardless of the renderer.

## 2. Related Requirements
- User Story: US-PRF-008
- Functional Requirements: FR-7 (PIP summary PDF)
- Business Rules: BR-1 (HR), FR-8 (visibility restriction carries to the report)
- Non-Functional Requirements: NFR-2 (tenant-scoped artifact)
