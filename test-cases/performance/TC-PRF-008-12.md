# TC-PRF-008-12: PIP creation and checkpoint recording complete within 800ms (P95) (NFR-1)

## 1. Test Objective
Verify NFR-1: PIP creation (create + initiate, including persisting objectives + checkpoints + scheduling Hangfire jobs) and checkpoint recording each complete within 800ms at P95 under representative load, with no N+1 query patterns. This sits within the platform write SLA (P95 <= 800ms write).

## 2. Related Requirements
- User Story: US-PRF-008
- Non-Functional Requirements: NFR-1 (PIP create + checkpoint <= 800ms P95)
- Acceptance Criteria: AC-2 (create/initiate), AC-3 (checkpoint)

- A seeded acme performance environment (representative employees, mentors, an existing cycle).
- HR "Nadia Khan" and manager "Dana Cole" authenticated in acme.
