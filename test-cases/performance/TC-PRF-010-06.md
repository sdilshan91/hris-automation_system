# TC-PRF-010-06: Comparison view -> current vs. recommended grade / title / compensation per employee

## 1. Test Objective
Verify FR-5: for each employee with a recommendation, the system provides a comparison view showing CURRENT vs. RECOMMENDED state side-by-side -- grade/band, job title, and compensation. The current values come from Core HR; the recommended values come from the recommendation details. The comparison is read-only and accurate for promotion (grade/title change), increment (compensation change), and bonus (one-off, no permanent comp change) recommendation types.

## 2. Related Requirements
- User Story: US-PRF-010
- Functional Requirements: FR-5 (comparison view current vs. recommended)
- Data Requirements: Core HR employee grade/band/title/compensation; recommendation details (target grade, increment %, bonus amount)
- UI/UX: comparison cards (S8)

## 3. Preconditions
- Tenant "acme"; HR Officer Pat Ng (`Performance.Read.All`) with compensation visibility (note: compensation access is additionally role-restricted -- see TC-PRF-010-09).
- Jordan has a Promotion recommendation (current G5 "Senior Engineer" $120k -> recommended G6 "Staff Engineer").
- Emp C has an Increment 5% recommendation (current $90k -> recommended $94.5k).
- Emp E has a Bonus $5k recommendation (no permanent grade/comp change).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Jordan current | G5 / Senior Engineer / $120,000 | from Core HR |
| Jordan recommended | G6 / Staff Engineer / (band midpoint) | promotion |
| Emp C current | G3 / $90,000 | increment base |
| Emp C recommended | +5% -> $94,500 | increment |
| Emp E | Bonus $5,000 | no permanent comp change |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Pat, open Jordan's comparison card | Side-by-side: current G5 / Senior Engineer / $120,000 vs. recommended G6 / Staff Engineer / recommended compensation; the delta is shown clearly (FR-5). |
| 2 | Open Emp C's comparison card (Increment 5%) | Current $90,000 vs. recommended $94,500 (computed from +5%); grade/title unchanged. |
| 3 | Open Emp E's comparison card (Bonus) | Compensation row shows the one-off bonus $5,000; current grade/title/base unchanged (a bonus is not a permanent comp change). |
| 4 | Verify the current side is authoritative from Core HR | The "current" values match the live Core HR grade/title/compensation for each employee (not a stale snapshot); recommended values come from the recommendation details. |
| 5 | Verify read-only | The comparison view does not allow editing current values; only the recommendation side is editable (via the workspace editor). |

## 6. Postconditions
- Comparison cards accurately render current vs. recommended grade/title/compensation per employee for promotion, increment, and bonus types. No data mutated. Tenant-scoped to acme.
