# TC-PRF-006-05: Auto-close -- employee does not sign within the configurable window -> Hangfire closes to "No Response" + notifies HR (BR-3)

## 1. Test Objective
Verify BR-3: if the employee does not sign off (neither Acknowledge nor Dispute) within a tenant-configurable period (default 7 days), a Hangfire job auto-closes the review with a "No Response" status and notifies HR. Verify the window is read from tenant Performance settings, the job runs in tenant context, is idempotent (does not double-close or re-notify), retries with backoff on transient failure, and that a review which IS signed or disputed before the deadline is NOT auto-closed.

## 2. Related Requirements
- User Story: US-PRF-006
- Acceptance Criteria: AC-3 (sign-off lifecycle)
- Business Rules: BR-3 (auto-close to "No Response" + notify HR)
- Assumptions/Constraints: S10 (auto-close timeout tenant-configurable)

## 3. Preconditions
- Tenant "acme", Performance module enabled; the sign-off auto-close window is configured (set to a SHORT period, e.g. 1 minute, for the test).
- Liam Carter's review is in "Pending Employee Sign-Off" (manager signed, employee notified) and the employee has NOT signed or disputed.
- An HR Officer "Nadia Khan" exists in acme.
- Hangfire is running.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Auto-close window | short (test value) | tenant-configurable (S10) |
| No-response status | "No Response" | BR-3 |
| Notify | Nadia Khan (HR) | BR-3 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Leave Liam's review unsigned/undisputed past the configured window; let the Hangfire auto-close job run | The job picks up the overdue pending-sign-off review (scoped to acme), transitions its status to "No Response" (BR-3); manager sign-off remains recorded but no employee signature exists. |
| 2 | Observe HR notification | Nadia (HR) receives an in-app + email notification that the review auto-closed with "No Response" (BR-3; delivery CONDITIONAL on Notification System S25 -- assert in-app push + email enqueue). |
| 3 | Re-run / re-trigger the same job | The job is IDEMPOTENT -- the already-closed review is not re-closed and HR is not re-notified (no duplicate). |
| 4 | Set up a second review signed by the employee BEFORE the window; run the job | A review already "Signed Off" (or "Disputed") is NOT auto-closed -- only pending-sign-off reviews past their deadline are affected. |
| 5 | Confirm the audit trail | The auto-close action is audit-logged (system actor + timestamp; FR-7) and tenant-scoped. |

## 6. Postconditions
- The unsigned review is "No Response"; HR was notified once; signed/disputed reviews are untouched; the action is audit-logged.
