# TC-PRF-004-03: Phase dates outside the cycle's overall window rejected (negative / BR-3)

## 1. Test Objective
Verify BR-3: every phase's start and end date must fall within the cycle's overall start and end dates. A phase starting before the cycle start, or ending after the cycle end, is rejected on both create and edit.

## 2. Related Requirements
- User Story: US-PRF-004
- Acceptance Criteria: AC-2, AC-5
- Functional Requirements: FR-2
- Business Rules: BR-3

## 3. Preconditions
- Tenant "acme" active; rating scale configured; HR Officer Maya authenticated with cycle permissions.
- Cycle period 2026-07-01 .. 2026-12-31.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Case A early start | goal-setting 2026-06-15..2026-07-31 | start before cycle start 2026-07-01 |
| Case B late end | publish 2026-12-15..2027-01-10 | end after cycle end 2026-12-31 |
| Case C both inside | goal-setting 2026-07-01..2026-07-31 | control — should pass |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Enter Case A (goal-setting starts 2026-06-15, before the cycle window) and attempt "Create Cycle" | Client + server reject: "Phase dates must be within the cycle period"; 400 Bad Request; nothing persisted (BR-3). |
| 2 | Enter Case B (publish ends 2027-01-10, after the cycle window) and attempt create | Rejected client + server with the same boundary error; 400. |
| 3 | Enter Case C (phase fully inside the window) | Accepted by validation (no boundary error) — confirms the rule does not over-reject. |
| 4 | On an existing Draft cycle, edit a phase to push its end past the cycle end (AC-5 path) — `PUT .../cycles/{id}/phases` | Edit rejected with the boundary error; existing dates unchanged; 400. |
| 5 | Edit the cycle's overall end date EARLIER than an existing phase's end date | Rejected: shrinking the window cannot orphan an existing phase outside it; 400 (or the UI blocks with the same message). |

## 6. Postconditions
- No phase exists outside its cycle's window; existing data unchanged.
