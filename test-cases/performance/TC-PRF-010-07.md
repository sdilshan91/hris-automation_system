# TC-PRF-010-07: Recommendation summary -> aggregate statistics: total promotions, bonus pool, increment distribution by department, comparison vs. previous cycle

## 1. Test Objective
Verify AC-4: once recommendations have been submitted/approved, HR navigates to the recommendation summary and sees aggregate statistics for the cycle -- total promotions recommended, total bonus pool allocated, increment distribution by department, and a comparison against the previous cycle's recommendations. Aggregates are tenant-scoped, derived from the actual recommendation set, and update as recommendations change status.

## 2. Related Requirements
- User Story: US-PRF-010
- Acceptance Criteria: AC-4
- Functional Requirements: FR-7 (history across cycles, used for the previous-cycle comparison)
- UI/UX: Chart.js bar charts for aggregate statistics (S8)

## 3. Preconditions
- Tenant "acme"; HR Officer Pat Ng (`Performance.Read.All`).
- FY25 has a known recommendation set: 6 promotions, bonus pool $48,000, increments across Engineering / Sales / Support.
- FY24 (previous cycle) recommendation history exists: 4 promotions, bonus pool $30,000 (for the comparison).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| FY25 promotions | 6 | total count |
| FY25 bonus pool | $48,000 | sum of bonus amounts |
| Increment by dept | Eng 4 / Sales 3 / Support 2 | distribution |
| FY24 promotions | 4 | previous cycle |
| FY24 bonus pool | $30,000 | previous cycle |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Pat, open the FY25 recommendation summary | Aggregate stats render: total promotions = 6, total bonus pool = $48,000, increment distribution by department (Eng 4 / Sales 3 / Support 2) as a bar chart (AC-4). All acme-scoped. |
| 2 | Verify the aggregates against the underlying set | Each aggregate equals the server-side computation over the actual FY25 recommendations (no client recompute drift); only acme recommendations are counted. |
| 3 | View the previous-cycle comparison | The summary shows FY25 vs. FY24: promotions 6 vs. 4 (+2), bonus pool $48,000 vs. $30,000 (+$18,000), with the deltas displayed (AC-4 + FR-7). |
| 4 | Reject/withdraw one promotion recommendation, refresh | The promotions count updates (e.g. 6 -> 5) per the documented counting rule (e.g. approved-only vs. submitted); the bonus pool/increment distribution recompute consistently. |
| 5 | Confirm scope/authz | The summary endpoint is restricted to `Performance.Read.All` (HR); a manager sees only their team scope (TC-PRF-010-09); no cross-tenant aggregates. |

## 6. Postconditions
- The recommendation summary shows accurate, tenant-scoped aggregate statistics and a previous-cycle comparison. No data mutated beyond the test's reject/withdraw. Tenant-scoped to acme.
