# TC-PRF-004-07: Hangfire deadline-approaching reminders fire to non-completers; jobs tenant-scoped + retry/backoff (AC-4 / FR-5 / NFR-3)

## 1. Test Objective
Verify AC-4, FR-5 and NFR-3: when a phase deadline approaches, the Hangfire reminder job triggers at the configured interval and sends automated reminders (in-app + email) only to participants who have NOT completed the current phase. The job runs in the correct tenant context and is resilient to transient failures via retry with exponential backoff (Polly).

## 2. Related Requirements
- User Story: US-PRF-004
- Acceptance Criteria: AC-4
- Functional Requirements: FR-5
- Non-Functional Requirements: NFR-3

## 3. Preconditions
- Active cycle "FY26 Annual Review" in acme; self-assessment phase end 2026-08-31; reminder interval configured (e.g. 3 days before end).
- 40 of 100 participants have NOT submitted self-assessment; 60 have.
- Hangfire is running with the reminder job registered for this cycle/phase.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Phase | self-assessment | end 2026-08-31 |
| Reminder trigger | 2026-08-28 (3 days before) | configured interval |
| Non-completers | 40 | should receive reminder |
| Completers | 60 | should NOT receive reminder |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Advance time / trigger the reminder job at the configured interval (2026-08-28) | The job executes within the acme tenant context (tenant resolved from job arguments, not request) (NFR-3). |
| 2 | Inspect who is notified | Exactly the 40 non-completers receive an in-app reminder; the 60 who submitted receive none (AC-4). Email enqueue is asserted; delivery CONDITIONAL on the Notification System (S25). |
| 3 | Inject a transient failure (e.g. notification service 503) on the first attempt | The job fails the attempt and is retried with exponential backoff per the Polly policy; it eventually succeeds without duplicating reminders to already-notified participants (NFR-3). |
| 4 | Confirm tenant scoping of the job | The job only reads/writes acme participants; it never enumerates or notifies participants of other tenants' cycles. |
| 5 | Verify idempotency across the interval window | Re-running the same scheduled occurrence does not double-send to the same non-completer for the same deadline. |

## 6. Postconditions
- Only current-phase non-completers in acme were reminded; the job is resilient and tenant-isolated.
