# TC-PRF-004-11: Participant scoping — department scope rejects out-of-scope employee; employee not in two active cycles of same type (FR-3 / BR-4)

## 1. Test Objective
Verify FR-3 and BR-4: a cycle scoped to a department includes only that department's employees, and adding an employee from another department is rejected; and an employee cannot be a participant in two active cycles of the same type simultaneously.

## 2. Related Requirements
- User Story: US-PRF-004
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-3, FR-4
- Business Rules: BR-4

## 3. Preconditions
- Tenant "acme" active; departments Engineering and Sales set up in Core HR.
- Employee "Asha" is in Engineering; employee "Ben" is in Sales.
- HR Officer Maya authenticated with cycle permissions.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Scope | Engineering department | FR-3 department scope |
| In-scope employee | Asha (Engineering) | should be a participant |
| Out-of-scope employee | Ben (Sales) | manual add should be rejected |
| Type | annual | for BR-4 concurrent-cycle check |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Create a cycle scoped to the Engineering department | Participant list resolves to exactly the active Engineering employees (incl. Asha); Ben (Sales) is NOT included (FR-3). |
| 2 | Manually add Ben (Sales) to the Engineering-scoped cycle's participant list | Rejected: employee is outside the cycle scope; Ben is not added (FR-3). |
| 3 | Create a SECOND active cycle of type `annual` and attempt to add Asha (already a participant in the first active annual cycle) | Rejected (BR-4): an employee cannot be in two active cycles of the same type simultaneously; the conflict identifies the existing cycle. |
| 4 | Create a cycle of a DIFFERENT type (`quarterly`) and add Asha | Accepted — BR-4 only blocks the SAME type concurrently; Asha may be in an annual + a quarterly cycle (FR-4). |
| 5 | Scope a cycle to "all active employees" | Participant count equals the tenant's active headcount; terminated/inactive employees are excluded. |

## 6. Postconditions
- Participants respect department scope; no employee is in two active same-type cycles.
