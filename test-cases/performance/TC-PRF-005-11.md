# TC-PRF-005-11: Feedback form loads <=400ms P95; results view + radar render <=2s for 20 reviewers (NFR-1/NFR-4)

## 1. Test Objective
Verify NFR-1 and NFR-4: the 360 feedback form loads within 400ms (P95), and the aggregated results view with the radar chart renders within 2 seconds for up to 20 reviewers per employee, with no N+1 query explosion as the reviewer count grows.

## 2. Related Requirements
- User Story: US-PRF-005
- Acceptance Criteria: AC-3, AC-4
- Non-Functional Requirements: NFR-1, NFR-4

## 3. Preconditions
- Seeded performance environment for acme: an employee with 20 assigned reviewers across categories, all submitted, on a 5-competency scale.
- Representative production-like data volume; warm cache excluded from the cold-path measurement where relevant.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Reviewers | 20 | NFR-4 ceiling |
| Competencies | 5 | typical |
| SLA form load | <=400ms P95 | NFR-1 |
| SLA results+radar | <=2s | NFR-4 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the 360 feedback form (`GET .../performance/360/feedback/{assignmentId}`) under representative load | Server response P95 <=400ms (NFR-1). |
| 2 | Load the aggregated results view with radar for the 20-reviewer employee (`GET .../performance/360/{revieweeId}/results`) | End-to-end render (data + radar chart) completes within 2s (NFR-4). |
| 3 | Inspect query execution for the results aggregation | Per-category averages computed with set-based aggregates; no N+1 (one query per reviewer) as reviewer count scales from 5 -> 20. |
| 4 | Measure across 3, 5, 10, 20 reviewers | Render time stays within SLA and scales sub-linearly; radar handles 3, 5, 10 competencies without breaching 2s. |

## 6. Postconditions
- Form and results meet their SLAs at the NFR ceiling; aggregation is set-based, not N+1.
