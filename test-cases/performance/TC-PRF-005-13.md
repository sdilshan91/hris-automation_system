# TC-PRF-005-13: 360 summary report is exportable as PDF (branding + charts + anonymized comments) (FR-7)

## 1. Test Objective
Verify FR-7: the system generates a per-employee 360 feedback summary report that is exportable as PDF, including tenant branding, the radar/per-competency charts, the composite score, and anonymized comments when anonymity is on. The primary assertion is the export SEAM/endpoint and tenant-scoping; full PDF visual rendering fidelity is CONDITIONAL on the PDF library being wired.

## 2. Related Requirements
- User Story: US-PRF-005
- Acceptance Criteria: AC-4
- Functional Requirements: FR-7, FR-5 (anonymized comments)

## 3. Preconditions
- 360-enabled cycle "FY26 Annual Review" active for acme with anonymity ON; Liam fully reviewed with composite computed.
- HR Officer "Nadia Khan" (`Performance.Review.All`) authenticated in acme.
- Tenant branding (logo) configured for acme.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Reviewee | Liam Carter | results released |
| Format | PDF | FR-7 (QuestPDF or similar) |
| Anonymity | ON | comments anonymized in PDF |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As HR, request the 360 summary export: `GET .../performance/360/{liamId}/report?format=pdf` (or `POST .../export`) | The export endpoint exists and returns 200 with `Content-Type: application/pdf` (or enqueues a generation job and returns a download handle); the request is tenant-scoped (acme). |
| 2 | Inspect the generated PDF (or its data model if rendering is deferred) | Contains the acme branding/logo, per-competency averages, the radar/perspective comparison, the composite score, and comments. (If the PDF rendering library is not yet wired, assert the report DATA MODEL + the export seam, and note rendering as an extension point.) |
| 3 | Verify anonymity in the PDF | With anonymity ON, comments in the PDF carry NO reviewer identifiers — consistent with the results API (cross-ref TC-PRF-005-06); de-anonymization via the PDF path is not possible. |
| 4 | Attempt the export as an unauthorized user / for another tenant's employee | 403/404 — export honors the same authz + tenant isolation as the results API (cross-ref TC-PRF-005-05, TC-PRF-ISO-017). |

## 6. Postconditions
- A tenant-branded, anonymized 360 summary PDF (or its seam + data model) is produced for authorized HR only.
