# TC-PRF-008-01: HR creates a PIP (reason, duration, objectives w/ success criteria, checkpoints, mentor, escalation) -> Initiate -> employee+manager+mentor notified + Hangfire checkpoint reminders scheduled (happy path)

## 1. Test Objective
Verify the primary success flow for AC-1 and AC-2 (FR-1/FR-2/FR-3): an authenticated HR Officer with `Performance.Review.All` navigates to Performance > PIP > "Create PIP" for an employee flagged for improvement, and the system displays a PIP creation form with all required fields (employee name pre-filled, PIP reason, duration start/end dates, improvement objectives with title/description/success criteria/due date, review checkpoint dates, assigned mentor/coach, escalation action). On "Initiate PIP" the system: creates the PIP tenant-scoped in status Active (Draft persisted first per FR-2), persists its objectives and checkpoint schedule, notifies the employee, their manager, and the assigned mentor via in-app + email, and schedules Hangfire jobs for the PIP start notification, checkpoint reminders (3 days before each checkpoint), the PIP end-date reminder, and overdue-checkpoint alerts (FR-3).

## 2. Related Requirements
- User Story: US-PRF-008
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-1, FR-2, FR-3
- Business Rules: BR-3 (duration >=30 days, valid here), BR-4 (acknowledgement requested)
- Non-Functional Requirements: NFR-1 (<=800ms create), NFR-4 (sensitive fields encrypted at rest)
- Data Requirements: S7 (pip, pip_objectives, pip_checkpoints tables; tenant_id scoped; sensitive fields encrypted via pgcrypto)

## 3. Preconditions
- Tenant "acme" exists, status Active, subdomain `acme.yourhrm.com`, Performance module enabled.
- HR Officer "Nadia Khan" is authenticated in acme (valid JWT carrying acme `tenant_id`) and holds `Performance.Review.All`.
- Employee "Sam Lee" exists in acme, has a completed review with a rating below the tenant PIP threshold, has been flagged for improvement (US-PRF-003 FR-6), and has NO active PIP (BR-2).
- "Sam Lee" reports to manager "Dana Cole"; mentor "Priya Raman" exists in acme.
- The Notification System (S25) and Hangfire are available (in dev, the enqueue is asserted; DELIVERY is conditional).

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Nadia, navigate to `https://acme.yourhrm.com/performance` > PIP and click "Create PIP" for Sam Lee | The PIP creation form renders with employee name PRE-FILLED (Sam Lee) and empty fields: PIP reason, start/end dates, objectives (title/description/success criteria/due date), checkpoint dates, mentor/coach, escalation action (AC-1). |
| 2 | Fill reason, duration 2026-07-01..2026-09-29, one objective w/ success criteria + due date, two checkpoint dates, mentor Priya Raman, escalation = Termination recommendation; observe Save as Draft | PIP persists in status Draft tenant-scoped (FR-2); objectives + checkpoint rows written to pip_objectives / pip_checkpoints with the same tenant_id. |
| 3 | Click "Initiate PIP"; observe `POST .../performance/pips/{id}/initiate` (or create+initiate) | Request carries `X-Tenant-Subdomain: acme` + bearer; 200/201; status transitions Draft -> Active (FR-2); response is acme-scoped only (NFR-2). |
| 4 | Inspect the persisted PIP | PIP has tenant_id = acme, employee_id = Sam, manager + mentor recorded, status Active, escalation action stored; reason + escalation notes encrypted at rest (NFR-4, asserted in TC-PRF-008-11). |
| 5 | Check notifications | In-app + email notifications enqueued to Sam (employee), Dana (manager), and Priya (mentor) announcing PIP initiation (AC-2, FR-3); enqueue asserted, delivery conditional on S25. |
| 6 | Inspect scheduled Hangfire jobs | Jobs scheduled for: PIP start notification; checkpoint reminders 3 days before 2026-07-31 and 2026-08-31; PIP end-date reminder (2026-09-29); overdue-checkpoint alerts (FR-3). Each job carries acme tenant context. |
| 7 | Confirm acknowledgement requested | Sam is prompted to acknowledge PIP initiation; the 5-business-day non-acknowledgement timer is armed (BR-4, exercised in TC-PRF-008-08). |

## 6. Postconditions
