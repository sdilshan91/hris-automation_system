# TC-PRF-009-03: Manager Team Goals -> summary table (overall completion %, # at-risk, last update) per direct report + drill-down to employee goals/updates; scope = direct reports

## 1. Test Objective
Verify AC-4: a manager navigating to Performance > Team Goals sees a summary table with one row per DIRECT REPORT showing the team member, their overall goal completion percentage, the number of goals at risk, and the last update date; the manager can drill down into an individual employee's goals and update history. The table is scoped to the manager's direct reports only (org tree authoritative) -- non-reports never appear.

## 2. Related Requirements
- User Story: US-PRF-009
- Acceptance Criteria: AC-4
- Functional Requirements: FR-3 (drill-down to updates), FR-4 (overall completion %)
- Non-Functional Requirements: NFR-2 (tenant isolation), NFR-1 (list latency, asserted in TC-PRF-009-14)
- Data Requirements: S7

## 3. Preconditions
- Tenant "acme"; manager "Dana Cole" authenticated with `Performance.Review.Team` (and/or `Performance.View.Team`).
- Dana has 4 direct reports (incl. Sam Lee) in the active cycle, each with goals + recent progress updates; one report has 2 goals flagged At Risk.
- "Owen Park" is an acme employee who is NOT Dana's report (reports to a different manager).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Manager | Dana Cole | 4 direct reports |
| Report w/ at-risk | "Mia Tan" | 2 goals At Risk |
| Non-report | Owen Park | must NOT appear |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Dana, navigate to `https://acme.yourhrm.com/performance` > Team Goals | A summary table renders with one row per direct report (4 rows), columns: team member, overall completion %, # of goals at risk, last update date (AC-4). |
| 2 | Inspect Mia Tan's row | Overall completion % reflects her weighted goal progress (FR-4), the at-risk count shows 2, and the last update date shows her most recent update. |
| 3 | Confirm scope | Owen Park (a non-report) does NOT appear in the table; only Dana's 4 direct reports are listed (org tree authoritative). |
| 4 | Click a team member row to drill down | The system shows that employee's individual goals (cards with progress/status) and their update history/timeline (AC-4, FR-3), all acme-scoped. |
| 5 | Attempt to drill into Owen Park by direct id/URL | Blocked -- Dana cannot view a non-report's goals/updates (403 / not found); scope is derived from the org tree, not client input (cross-report IDOR covered in TC-PRF-009-13). |
| 6 | Verify request scoping | `GET .../performance/team-goals` returns only acme + Dana's-reports data; no other-manager or cross-tenant rows. |

## 6. Postconditions
- The manager sees an accurate team summary table limited to direct reports and can drill into each report's goals/updates. No non-report or cross-tenant data exposed.
