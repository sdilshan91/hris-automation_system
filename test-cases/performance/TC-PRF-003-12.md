# TC-PRF-003-12: Review form for a single employee loads within 400ms (P95), including the employee's self-assessment data

## 1. Test Objective
Verify NFR-1: the manager-review form for one employee -- which fetches the goals, the manager-rating fields, AND the employee's self-assessment ratings/comments for the side-by-side view -- loads within 400ms at P95. The combined self+manager payload must not blow the SLA (no N+1 per-goal self-assessment fetch).

## 2. Related Requirements
- User Story: US-PRF-003
- Non-Functional Requirements: NFR-1
- Acceptance Criteria: AC-1

## 3. Preconditions
- A seeded performance environment: acme tenant, FY26-H1, an employee with the maximum realistic goal count (10 goals, US-PRF-001 BR-2) each carrying self-rating + self-comments.
- A load/perf tool able to sample P95 over >=100 requests against the review-form endpoint.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Goals per employee | 10 | upper bound (BR-2) |
| Sample size | >=100 requests | for P95 |
| SLA | <=400ms P95 | NFR-1 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Warm caches; fire >=100 GETs against the single-employee review-form endpoint | Server-side P95 latency <=400ms (NFR-1), including the self-assessment data in the same payload/round-trip. |
| 2 | Inspect the query plan / request count | No N+1: self-assessment + goals + manager fields are fetched in a bounded number of tenant-filtered queries, not one-per-goal. |
| 3 | Confirm tenant filtering does not regress latency | The tenant query filter is index-backed; P95 holds under concurrent load from multiple tenants. |

## 6. Postconditions
- The review form (with self-assessment data) meets the 400ms P95 SLA without N+1 fetches.

> Note: NFR-1 requires a seeded performance environment; this TC is a perf gate, asserted against that environment.
