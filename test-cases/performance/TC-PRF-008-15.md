# TC-PRF-008-15: Hangfire jobs -- PIP start notification, checkpoint reminders (3 days before each checkpoint), PIP end-date reminder, overdue-checkpoint alerts -- fire at the configured times, tenant-scoped, idempotent, retried (FR-3)

## 1. Test Objective
Verify FR-3: on PIP initiation the system schedules Hangfire jobs for (a) the PIP start notification, (b) checkpoint reminders 3 days before each checkpoint date, (c) the PIP end-date reminder, and (d) overdue-checkpoint alerts. Each job fires at the correct time, runs in the correct tenant context, targets the correct recipients (employee/manager/HR/mentor as appropriate), is idempotent (no duplicate notifications on retry), and is retried with Polly backoff on transient failure. Rescheduling on extension is verified.

## 2. Related Requirements
- User Story: US-PRF-008
- Functional Requirements: FR-3 (Hangfire jobs)
- Acceptance Criteria: AC-2 (jobs scheduled on initiate), AC-3 (checkpoint reminders), AC-4/FR-6 (reschedule on extend)
- Non-Functional Requirements: NFR-2 (jobs run in tenant context)

## 3. Preconditions
- An Active PIP for Sam Lee exists in acme with checkpoints 2026-07-31 and 2026-08-31 and end date 2026-09-29 (TC-PRF-008-01).
- Hangfire is available; a time-travel/clock control is available to the harness.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Start notification | at initiation | FR-3 |
| Checkpoint reminders | 2026-07-28, 2026-08-28 | 3 days before each checkpoint |
| End reminder | ~2026-09-29 | FR-3 |
| Overdue alert | checkpoint date passes with no record | FR-3 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Immediately after initiation, inspect scheduled Hangfire jobs | Start-notification, two checkpoint-reminder jobs (2026-07-28, 2026-08-28), end-date-reminder, and overdue-alert jobs exist, each carrying acme tenant context (FR-3, NFR-2). |
| 2 | Advance the clock to 2026-07-28 | The first checkpoint reminder fires; employee + manager (+ HR) notified 3 days before the 2026-07-31 checkpoint (FR-3). |
| 3 | Let the 2026-07-31 checkpoint date pass WITHOUT a recorded checkpoint | The overdue-checkpoint alert fires to manager/HR (FR-3). |
| 4 | Re-run/retry a job (simulate transient failure) | The job is idempotent -- no duplicate notification is sent; Polly retry/backoff applies on transient failure (NFR-2 resilience). |
| 5 | Extend the PIP (new end date / checkpoints, per TC-PRF-008-03) | The reminder + end-date jobs are RESCHEDULED to the new dates; stale jobs for superseded dates do not fire (FR-6/FR-3). |
| 6 | Confirm tenant scoping of every job | Each job touches only acme PIPs/recipients; never another tenant's (NFR-2, see TC-PRF-ISO-032). |

## 6. Postconditions
- All PIP Hangfire jobs are scheduled, fire at the right times to the right recipients, are tenant-scoped + idempotent + retried, and reschedule on extension. No Tenant B data touched.
