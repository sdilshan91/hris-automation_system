# TC-PRF-002-03: Invalid field values rejected -- comment < 20 chars, rating outside scale, achievement % outside 0-100 (FR-2, FR-3)

## 1. Test Objective
Verify input validation per FR-3 (comment minimum 20 characters per goal) and FR-2 / S7 (self-rating must be within the tenant-configured scale; achievement percentage must be 0-100). Each invalid value is rejected client-side and independently by the server; a submit/save carrying any invalid value does not persist that value.

## 2. Related Requirements
- User Story: US-PRF-002
- Acceptance Criteria: AC-2
- Functional Requirements: FR-2, FR-3
- Data Requirements: S7 (self_rating per scale; achievement_pct 0-100; comment >= 20 chars)

## 3. Preconditions
- acme cycle FY26-H1 self-assessment window OPEN; Asha authenticated with `Performance.Read.Self`.
- Tenant rating scale is 1-5 numeric.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Comment too short | "Did well." (9 chars) | < 20 (FR-3 violation) |
| Rating below scale | 0 | scale min is 1 |
| Rating above scale | 6 | scale max is 5 |
| Achievement negative | -5 | < 0 |
| Achievement over 100 | 130 | > 100 |
| Non-numeric achievement | "abc" | type violation |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Enter a 9-char comment on Goal 1 and try to submit | Field-level error "Comment must be at least 20 characters" (FR-3); submit blocked. A bypass submit returns 400/422 and is not persisted. |
| 2 | Set Goal 1 rating to 0, then to 6 | Both rejected as outside the 1-5 scale (FR-2); a bypass save/submit with rating 0 or 6 returns 400/422; value not persisted. |
| 3 | Set Goal 1 achievement to -5, then 130 | Both rejected (must be 0-100); bypass save/submit returns 400/422; value not persisted. |
| 4 | Set achievement to a non-numeric "abc" | Rejected as invalid type; not persisted. |
| 5 | Inspect persisted state | No self_assessment row holds a sub-20-char comment, an out-of-scale rating, or an out-of-range achievement %. |

## 6. Postconditions
- No invalid self-rating, achievement %, or short comment is accepted by client or server.
