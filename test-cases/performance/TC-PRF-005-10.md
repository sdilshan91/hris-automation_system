# TC-PRF-005-10: Assigned reviewer receives an in-app + email notification with a link to the feedback form (AC-2)

## 1. Test Objective
Verify AC-2: when an employee enters the 360-feedback phase and reviewers are assigned, each assigned reviewer receives a notification (in-app + email) containing a link to a feedback form that presents the rating scale and competency-based questions. This is the assignment notification (distinct from the deadline reminder in TC-PRF-005-09).

## 2. Related Requirements
- User Story: US-PRF-005
- Acceptance Criteria: AC-2
- Functional Requirements: FR-1, FR-4

## 3. Preconditions
- 360-enabled cycle "FY26 Annual Review" active for acme; Liam under review.
- HR Officer "Nadia Khan" (`Performance.Review.All`) authenticated, about to assign reviewers.
- Notification System (S25) available (or its enqueue seam assertable).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Reviewers assigned | Maya, Ava, Ben, Sara, Tom | manager + peers + reports |
| Channels | in-app + email | AC-2 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As HR, finalize reviewer assignment + "Start 360 Feedback" | The system enters the 360-feedback phase for Liam. |
| 2 | Inspect notifications generated | Each assigned reviewer (Maya, Ava, Ben, Sara, Tom) gets one in-app notification AND one email enqueued (AC-2; delivery CONDITIONAL on S25 — assert the enqueue + in-app push). |
| 3 | Inspect a notification payload | It contains a link to that reviewer's feedback form; opening it loads the competency-based questions + the tenant rating scale + optional per-competency comment (FR-4). |
| 4 | Confirm self-assignment behavior | The reviewee's own Self assessment task is surfaced to Liam (as a self-review task), consistent with FR-1's Self category. |
| 5 | Confirm a reviewer NOT assigned to Liam receives nothing | An unrelated employee gets no 360 notification for Liam. |

## 6. Postconditions
- All assigned reviewers are notified in-app + email with a working form link; non-assignees receive nothing.
