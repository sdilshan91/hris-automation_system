# TC-PRF-003-05: Boundary -- manager rating at scale min(1) and max(5), comment exactly 20 chars, summary exactly 5000 chars accepted; one past each boundary rejected

## 1. Test Objective
Verify boundary/equivalence handling for manager-rating inputs: ratings exactly at the scale minimum (1) and maximum (5) are accepted while 0 and 6 are rejected (FR-2); a manager comment of exactly 20 characters is accepted while 19 is rejected (FR-3); a summary comment of exactly 5000 characters is accepted while 5001 is rejected (FR-5). This pins the inclusive/exclusive edges of every numeric and length boundary on the manager-review form.

## 2. Related Requirements
- User Story: US-PRF-003
- Functional Requirements: FR-2, FR-3, FR-5

## 3. Preconditions
- Same as TC-PRF-003-01. Scale 1-5; comment min 20; summary max 5000.

## 4. Test Data
| Field | Boundary value | Expected |
|-------|----------------|----------|
| Rating | 1 (min) | accept |
| Rating | 5 (max) | accept |
| Rating | 0 / 6 | reject |
| Comment | exactly 20 chars | accept |
| Comment | 19 chars | reject |
| Summary | exactly 5000 chars | accept |
| Summary | 5001 chars | reject |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Submit all goals with rating 1 and 20-char comments | Accepted; review submits; manager_score reflects the minimum ratings. |
| 2 | Resubmit (new cycle/employee) with rating 5 and 20-char comments | Accepted; manager_score reflects the maximum ratings. |
| 3 | Try rating 0 and 6 | Both rejected at client + server (FR-2). |
| 4 | Try a 19-char comment | Rejected (FR-3); a 20-char comment is accepted. |
| 5 | Enter a 5000-char summary, then 5001 | 5000 accepted; 5001 rejected (FR-5). |

## 6. Postconditions
- Inclusive boundaries (rating 1/5, comment 20, summary 5000) pass; one step past each fails.
