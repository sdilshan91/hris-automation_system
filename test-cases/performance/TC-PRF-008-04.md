# TC-PRF-008-04: PIP lifecycle (negative) checkpoints Not Met -> outcome "Not Met" -> HR confirms escalation (reassignment/demotion/non-renewal/termination recommendation) -> stakeholders notified + immutable audit record (AC-4/AC-5, FR-5, BR-6)

## 1. Test Objective
Verify the negative PIP lifecycle for AC-4 + AC-5 (FR-5, BR-6): checkpoints record "Not Met"; at the end HR sets the final outcome to "Not Met", which surfaces the configured escalation action; HR confirms the escalation decision (one of reassignment, demotion, contract non-renewal, or termination recommendation -- per the tenant's configured options, BR-6); the system records the escalation decision, notifies relevant stakeholders, and creates an immutable audit record (FR-5).

## 2. Related Requirements
- User Story: US-PRF-008
- Acceptance Criteria: AC-4, AC-5
- Functional Requirements: FR-2 (Not Met status), FR-5 (immutable audit record)
- Business Rules: BR-6 (configurable escalation options)
- Data Requirements: S7 (pip; escalation notes encrypted at rest, NFR-4)

## 3. Preconditions
- An Active PIP for employee "Joel Park" exists in acme (initiated as in TC-PRF-008-01) with escalation configured (e.g. Termination recommendation) and at least one checkpoint.
- The tenant's escalation options (BR-6) are configured: reassignment, demotion, contract non-renewal, termination recommendation.
- HR Officer "Nadia Khan" is authenticated in acme with `Performance.Review.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| PIP | Joel Park's Active PIP | escalation = Termination recommendation |
| Checkpoint outcomes | Not Met (both checkpoints) | AtRisk -> NotMet trajectory |
| Final outcome | Not Met | AC-4 -> triggers escalation |
| Confirmed escalation | Termination recommendation | BR-6 option |
| Stakeholders | employee, manager, HR, mentor | AC-5 notified |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Manager/HR records both checkpoints with status "Not Met" + evidence (per TC-PRF-008-02) | Checkpoints recorded Not Met; employee notified each time; PIP remains Active until outcome set. |
| 2 | As Nadia, at PIP end open the outcome review | Summary of all checkpoints (Not Met) shown; outcomes offered: Successfully Completed / Extended / Not Met (AC-4). |
| 3 | Select outcome "Not Met"; `POST .../performance/pips/{id}/outcome` body `{outcome:"NotMet"}` | 200; status -> Not Met (FR-2); the system surfaces the configured escalation action for HR confirmation (AC-4 -> AC-5). |
| 4 | HR confirms the escalation = Termination recommendation; `POST .../performance/pips/{id}/escalation/confirm` | 200; the escalation decision is recorded; escalation notes persisted ENCRYPTED at rest (NFR-4). |
| 5 | Verify stakeholder notification | Relevant stakeholders (employee, manager, HR, mentor) notified of the escalation decision (AC-5); enqueue asserted, delivery conditional on S25. |
| 6 | Verify audit record | An IMMUTABLE audit record of the Not Met outcome + escalation decision is created (FR-5): it cannot be edited or deleted by anyone incl. HR; carries actor id + server timestamp + tenant_id. |
| 7 | Attempt an alternative escalation (e.g. Demotion) on another PIP | Each BR-6 option (reassignment / demotion / contract non-renewal / termination recommendation) is selectable per the tenant config and recorded identically. |
