# TC-PRF-010-08: Gates -> recommendations only after final ratings published (BR-1); only after calibration complete if enabled (BR-2); promotion requires target grade + effective date (BR-5)

## 1. Test Objective
Verify the eligibility/validation gates: (BR-1) recommendations can only be generated/submitted after the appraisal cycle's final ratings are PUBLISHED; (BR-2) if calibration is enabled for the cycle, recommendations can only proceed after calibration is COMPLETED; (BR-5) a Promotion recommendation MUST include both the target grade/band and the effective date. Each gate is enforced server-side, not just in the UI.

## 2. Related Requirements
- User Story: US-PRF-010
- Business Rules: BR-1 (ratings published), BR-2 (calibration complete if enabled), BR-5 (promotion needs target grade + effective date)
- Functional Requirements: FR-1 (recommendation details), FR-2 (auto-generation gated)

## 3. Preconditions
- Tenant "acme"; HR Officer Pat Ng (`Performance.Publish.All`).
- Cycle FY26-A: final ratings NOT yet published (for BR-1).
- Cycle FY26-B: calibration ENABLED but NOT yet completed (for BR-2).
- Cycle FY25: ratings published + calibration complete/disabled (the valid baseline, for BR-5).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| FY26-A | ratings unpublished | BR-1 reject |
| FY26-B | calibration enabled, incomplete | BR-2 reject |
| FY25 | ready | BR-5 promotion validation |
| Promotion missing grade | no target grade | reject |
| Promotion missing date | no effective date | reject |
| Promotion valid | G6 + 2026-07-01 | accept |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | On FY26-A (ratings unpublished), attempt auto-generate or create a recommendation | Blocked: the workspace shows recommendations are unavailable until final ratings are published; a direct `POST .../recommendations?cycleId=FY26-A` returns 409/422 (BR-1). No recommendation persists. |
| 2 | Publish FY26-A's final ratings, retry | Recommendations are now permitted (BR-1 gate satisfied). |
| 3 | On FY26-B (calibration enabled, incomplete), attempt to create/submit a recommendation | Blocked server-side until calibration is COMPLETED; direct API call returns 409/422 (BR-2). After marking calibration complete, the action is permitted. |
| 4 | On FY25, create a Promotion recommendation but OMIT the target grade | Rejected client + server (400): a promotion requires the target grade/band (BR-5). |
| 5 | Create a Promotion but OMIT the effective date | Rejected client + server (400): a promotion requires the effective date (BR-5). |
| 6 | Create a Promotion with BOTH target grade (G6) + effective date (2026-07-01) | Accepted -- the recommendation persists with both fields (BR-5). Non-promotion types (bonus/increment) do not require these fields. |

## 6. Postconditions
- Recommendations are blocked before ratings are published and (when calibration is enabled) before calibration completes; promotions without a target grade or effective date are rejected; a fully-specified promotion is accepted. All gates enforced server-side. Tenant-scoped to acme.
