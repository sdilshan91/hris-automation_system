# TC-REC-001-02: Publishing a vacancy exposes it on the public careers page with a unique SEO slug (public toggle enabled)

## 1. Test Objective
Verify that when the tenant has the public careers page enabled (tenant module configuration S35.2.9), publishing a vacancy to `Open` also makes it appear on the tenant's public careers page, and a unique, SEO-friendly URL slug is generated for it.

## 2. Related Requirements
- User Story: US-REC-001
- Acceptance Criteria: AC-2
- Functional Requirements: FR-4, FR-5
- Business Rules: BR-5
- Dependencies: Tenant module configuration for public careers page toggle (S35.2.9)

## 3. Preconditions
- Tenant "acme" has the public careers page **enabled** at the tenant level.
- Recruiter "Riley Park" (Recruitment.Create.All) is authenticated in acme.
- A Draft vacancy "Senior Backend Engineer" exists in acme with the per-vacancy public toggle inheriting the enabled tenant setting (not individually excluded).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Tenant public careers page | Enabled | Tenant-level config (S35.2.9) |
| Vacancy | Senior Backend Engineer (Draft) | Public toggle inherited = on |
| Public URL base | https://acme.yourhrm.com/careers | Tenant-branded public listing |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Authenticate as Riley Park; open the Draft vacancy and click "Publish" | Status changes to `Open` (200 OK). |
| 2 | Inspect the published vacancy record | A non-null `slug` is generated, SEO-friendly (lowercase, hyphenated, e.g. `senior-backend-engineer-vac-2026-0001`), unique within the tenant. |
| 3 | As an authenticated recruiter, open the internal listing | The vacancy appears with status `Open`. |
| 4 | Navigate to the public careers page `https://acme.yourhrm.com/careers` (the public listing) | The `Open` vacancy appears in the public listing with title, department, location, and employment type. |
| 5 | Open the vacancy detail at `https://acme.yourhrm.com/careers/{slug}` | The detail page loads and renders the (sanitized) description and qualifications. |
| 6 | Verify the slug uniqueness rule | Publishing a second vacancy with the same title yields a distinct slug (e.g., suffixed with the reference number), not a collision. |

## 6. Postconditions
- The `Open` vacancy is visible on both the internal listing and the public careers page.
- A unique SEO slug is persisted for the vacancy.
