# TC-REC-002-08: Boundary validation -- cover letter 2000 / 2001 chars and resume exactly 25 MB

## 1. Test Objective
Verify the FR-1 field boundaries: a cover letter of exactly 2000 characters is accepted while 2001 is rejected, and a resume of exactly 25 MB is accepted while just over the limit is rejected (the > 25 MB rejection itself is exercised in TC-REC-002-03). Also confirm required-field validation (first name, last name, email, resume) and email-format validation.

## 2. Related Requirements
- User Story: US-REC-002
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-1
- Non-Functional Requirements: NFR-1 (25 MB accept boundary)

## 3. Preconditions
- Tenant "acme" exists; vacancy "Senior Backend Engineer" is `Open` and publicly listed.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Cover letter (max) | exactly 2000 chars | Accept boundary |
| Cover letter (over) | exactly 2001 chars | Reject boundary |
| Resume (max) | resume-25mb.pdf, exactly 25 MB (26,214,400 bytes), application/pdf | Accept boundary |
| Required fields | first name, last name, email, resume | Mandatory |
| Invalid email | "not-an-email" | Reject |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Submit with a cover letter of exactly 2000 characters (valid resume) | Accepted (201 Created); cover letter persisted in full. |
| 2 | Submit with a cover letter of exactly 2001 characters | Rejected (4xx) with a "max 2000 characters" validation message; no record created. |
| 3 | Submit with a resume of exactly 25 MB (PDF) | Accepted; the 25 MB file is stored at the tenant-scoped path (upper inclusive bound). |
| 4 | Submit omitting a required field (e.g. no last name, or no resume) | Rejected with a clear required-field error; no record created. |
| 5 | Submit with `email = "not-an-email"` | Rejected with an email-format validation error; no record created. |
| 6 | Verify the DB reflects only the accepted submissions | Rows exist only for the 2000-char and 25 MB accepted cases. |

## 6. Postconditions
- Field boundaries enforced exactly: 2000-char cover letter and 25 MB resume accepted; 2001-char and invalid/missing fields rejected.
