# TC-REC-002-05: Applications to a non-Open vacancy or past the application deadline are rejected (negative)

## 1. Test Objective
Verify BR-6: applications can only be submitted to vacancies with status `Open` and before the application deadline (if set). Submissions to a `Draft`/`On Hold`/`Closed`/`Cancelled` vacancy, or after a set deadline, are rejected with a clear message and no record is created.

## 2. Related Requirements
- User Story: US-REC-002
- Acceptance Criteria: AC-1 (implies vacancy must be Open)
- Business Rules: BR-6
- Functional Requirements: FR-6
- Dependencies: US-REC-001 (vacancy status lifecycle)

## 3. Preconditions
- Tenant "acme" exists with these vacancies: "Closed Role" (`Closed`), "Hold Role" (`On Hold`), "Draft Role" (`Draft`), and "Deadline Role" (`Open` with `application_deadline` set to a past date, e.g. 2026-06-01).
- An `Open` vacancy "Live Role" with no past deadline exists as the positive control.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Closed vacancy | Closed Role (Closed) | Reject |
| On-hold vacancy | Hold Role (On Hold) | Reject |
| Draft vacancy | Draft Role (Draft) | Reject (not publicly applyable) |
| Past-deadline vacancy | Deadline Role (Open, deadline 2026-06-01) | Reject (deadline passed; today 2026-06-15) |
| Control | Live Role (Open, no deadline / future deadline) | Accept |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Attempt `POST .../vacancies/{closedRoleId}/applications` with a valid resume | Rejected (4xx) with a "no longer accepting applications" message; no `applicant` row created. |
| 2 | Repeat against the `On Hold` and `Draft` vacancies | Each is rejected; non-Open vacancies do not accept applications. |
| 3 | Attempt to apply to "Deadline Role" (Open but deadline 2026-06-01 < today) | Rejected with a "deadline passed" message; no record created. |
| 4 | Attempt to apply to "Live Role" (Open, no/future deadline) | Accepted (201 Created) -- confirms the rejection is specific to status/deadline, not a blanket failure. |
| 5 | Verify the DB after the rejected attempts | No `applicant` rows exist for the closed/hold/draft/past-deadline vacancies; one row exists for "Live Role". |

## 6. Postconditions
- Applications exist only for the `Open`, within-deadline vacancy; all other attempts were rejected with no side effects.
