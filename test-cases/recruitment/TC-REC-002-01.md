# TC-REC-002-01: External applicant submits an application with a resume from the public careers page (happy path)

## 1. Test Objective
Verify the primary success flow (AC-1): an anonymous external applicant browses an `Open` vacancy on the tenant's public careers page, fills the application form (first name, last name, email, phone, cover letter) and uploads a valid resume; the application is saved with pipeline stage `Applied`, the resume is stored in blob storage under the tenant-scoped path `{tenantId}/recruitment/{vacancyId}/{applicantId}/{filename}`, an application reference number and `applied_at` timestamp are generated, and the applicant receives the tenant's "Application Received" confirmation email.

## 2. Related Requirements
- User Story: US-REC-002
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-2, FR-5, FR-6
- Data Requirements: S7 (UUID PK, tenant_id FK, vacancy_id FK, stage `Applied`, resume storage key, reference number, applied_at, source)

## 3. Preconditions
- Tenant "acme" exists with status `active`, subdomain `acme.yourhrm.com`, and the public careers page toggle **enabled** (tenant module config S35.2.9).
- Vacancy "Senior Backend Engineer" exists in acme with status `Open`, publicly listed, no application deadline passed.
- The tenant's "Application Received" notification template is configured.
- Blob storage and the (FR-3) virus-scan path are available (see TC-REC-002-10 for scan assertions).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Subdomain | acme.yourhrm.com | Active tenant, public careers enabled |
| Vacancy | Senior Backend Engineer (Open) | Publicly listed |
| First name | Jordan | Required |
| Last name | Rivera | Required |
| Email | jordan.rivera@example.com | Required, validated |
| Phone | +1 555 0100 | Optional |
| Cover letter | "I am excited to apply..." (under 2000 chars) | Optional |
| Resume | jordan-resume.pdf, 1.2 MB, application/pdf | Required, allowed MIME, under 25 MB |
| Source | public | Anonymous submission |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Anonymously navigate to `https://acme.yourhrm.com/careers` | The public careers page loads (tenant-branded) and lists the `Open` "Senior Backend Engineer" vacancy. |
| 2 | Open the vacancy detail and click "Apply" | The application form opens with required fields marked and the upload zone showing accepted formats (PDF/DOCX/DOC) and max size (25 MB). No authentication is required. |
| 3 | Fill first name, last name, email, phone, cover letter; drag-and-drop `jordan-resume.pdf` | Inline validation passes; the upload zone shows progress then the selected filename. |
| 4 | Submit and observe `POST /api/v1/recruitment/vacancies/{vacancyId}/applications` (multipart) | Request carries `X-Tenant-Subdomain: acme` (no bearer token). Response is 201 Created. |
| 5 | Inspect the response body | Body contains `id` (UUID applicant), `tenant_id` = acme, `vacancy_id` matching, `stage: "Applied"`, a non-null `reference_number`, `applied_at` timestamp, `source: "public"`, `is_internal: false`, and a `resume` storage key. |
| 6 | Verify the resume storage key/path | The stored object path matches `{acme_tenantId}/recruitment/{vacancyId}/{applicantId}/{filename}` (FR-2); the file is retrievable and byte-identical to the upload. |
| 7 | Verify the persisted `applicant` row | One row exists with the returned `id`, `tenant_id` = acme, `vacancy_id` matching, `stage = Applied`, resume storage key set, `applied_at` set. |
| 8 | Verify the confirmation email | An "Application Received" email is sent to jordan.rivera@example.com using the acme template and contains the correct application reference number (FR-5). |
| 9 | Observe the confirmation screen | The UI shows a success screen with the application reference number and next-steps text. |

## 6. Postconditions
- One `applicant` row exists in acme at stage `Applied`, linked to the vacancy, with a tenant-scoped resume blob and a unique reference number.
- A confirmation email has been dispatched to the applicant.
