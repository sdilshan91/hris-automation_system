# TC-REC-003-04: Filter bar by stage / source / date range / search updates board and counts; clear restores all (happy path + alternative)

## 1. Test Objective
Verify AC-4 / FR-6: the filter bar filters the pipeline by pipeline stage, application source, applied-date range, and free-text search on name/email; the Kanban board updates to show only matching applicants with per-column counts recomputed; clearing filters restores the full board.

## 2. Related Requirements
- User Story: US-REC-003
- Acceptance Criteria: AC-4
- Functional Requirements: FR-6, FR-5 (counts)

## 3. Preconditions
- Tenant "acme" is active; a recruiter with `Recruitment.Read.All` is authenticated.
- Vacancy "Senior Backend Engineer" has 14 applicants of mixed source (public/internal/referral) and a range of applied dates, with at least one named "Jordan Rivera".

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Filter: source | referral | Subset of applicants |
| Filter: stage | Screening | Single stage |
| Filter: date range | 2026-06-01 .. 2026-06-10 | Applied-date window |
| Search text | "jordan" | Matches name/email |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Apply source = "referral"; observe the pipeline request carries the filter params | Board shows only referral applicants; each column count badge recomputes to the filtered subset; total reflects the filtered set (FR-6, FR-5). |
| 2 | Add a date-range filter (2026-06-01..2026-06-10) combined with source | Filters AND-combine: only referral applicants applied within the window remain; counts update again. |
| 3 | Clear the date and source filters, then type "jordan" in search | Board shows only applicants whose name/email matches "jordan"; counts reflect matches across their stage columns. |
| 4 | Apply a stage filter = "Screening" | Only the Screening column (or only Screening-stage cards) is shown / non-matching columns show zero; counts consistent. |
| 5 | Click "Clear filters" | All filters and active filter chips are removed; the board returns to the full 14-applicant view with original per-column counts (AC-4). |
| 6 | Apply a filter that matches nothing (e.g. search "zzzznomatch") | Board shows an empty/zero state across columns with all counts at 0; no error; clearing restores. |

## 6. Postconditions
- No applicant data modified. Filtering is a read-only view operation; clearing fully restores the unfiltered board.
