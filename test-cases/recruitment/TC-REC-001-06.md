# TC-REC-001-06: Invalid vacancy status transitions are rejected; valid transitions are accepted (negative + state machine)

## 1. Test Objective
Verify FR-2's status set (`Draft`, `Open`, `On Hold`, `Closed`, `Cancelled`) and that the system enforces a valid state machine: legal transitions (e.g., Draft -> Open -> On Hold -> Open -> Closed) succeed while illegal transitions (e.g., Closed -> Open, Draft -> Closed without publishing per workflow rules, Closed -> On Hold) are rejected.

## 2. Related Requirements
- User Story: US-REC-001
- Acceptance Criteria: AC-2, AC-5
- Functional Requirements: FR-2
- Test Hint: Draft -> Open -> On Hold -> Open -> Closed; verify invalid transitions are rejected

## 3. Preconditions
- Tenant "acme" with Recruitment enabled.
- Recruiter "Riley Park" (Recruitment.Create.All) is authenticated in acme.
- A Draft vacancy with all required fields populated exists.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Valid path | Draft -> Open -> On Hold -> Open -> Closed | Expected to succeed |
| Invalid: Closed -> Open | reopen a closed vacancy | Expected to be rejected |
| Invalid: Closed -> On Hold | from terminal-ish Closed | Expected to be rejected |
| Invalid: Cancelled -> Open | from Cancelled | Expected to be rejected |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Transition Draft -> Open (publish) | 200 OK; status `Open`. |
| 2 | Transition Open -> On Hold | 200 OK; status `On Hold`; vacancy hidden from public/active listing while On Hold. |
| 3 | Transition On Hold -> Open | 200 OK; status `Open` again; re-appears on listings. |
| 4 | Transition Open -> Closed | 200 OK; status `Closed`. |
| 5 | Attempt Closed -> Open | Rejected with a 409/422 invalid-transition error; status remains `Closed`. |
| 6 | Attempt Closed -> On Hold | Rejected with an invalid-transition error; status remains `Closed`. |
| 7 | On a separate Cancelled vacancy, attempt Cancelled -> Open | Rejected with an invalid-transition error; status remains `Cancelled`. |
| 8 | Verify each rejected attempt at the DB | No status change persisted for any illegal transition; valid transitions persisted with audit entries. |

## 6. Postconditions
- Only valid status transitions are persisted; the vacancy state machine is enforced.
