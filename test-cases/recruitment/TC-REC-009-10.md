# TC-REC-009-10: Export dashboard data — CSV and Excel (.xlsx) match the filtered view; PDF + async generation deferrals handled (FR-8, NFR-5)

## 1. Test Objective
Verify FR-8 / NFR-5: the dashboard exports tabular data as CSV and Excel (.xlsx via ClosedXML) and the full dashboard view as PDF (via QuestPDF). The exported file content matches the CURRENTLY APPLIED filters (date range + department/vacancy drill-down), with correct headers and values. For large datasets, generation is asynchronous (queued via Hangfire) with a download notification on completion (NFR-5). The PDF path and the async/Hangfire path are written CONDITIONAL on the Reports & Analytics (S33) export libraries and Hangfire wiring being present in this increment — if a path is not yet wired, assert the seam (export request accepted, job/outbox entry created) rather than weakening the case.

## 2. Related Requirements
- User Story: US-REC-009
- Functional Requirements: FR-8 (CSV/Excel/PDF export)
- Non-Functional Requirements: NFR-5 (large exports async via Hangfire + download notification)
- Acceptance Criteria: AC-2 (export reflects the selected period)
- Dependencies: Reports & Analytics module S33 (ClosedXML, QuestPDF); Hangfire S28

## 3. Preconditions
- Tenant "acme" dashboard loaded with a known filtered view (e.g. Department = Engineering, last 30 days). User has dashboard view + export permission.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Applied filter | Engineering, last 30 days | export must match |
| CSV | tabular KPI/funnel/source rows | header + values |
| Excel | .xlsx via ClosedXML | same data, formatted |
| PDF | full dashboard via QuestPDF | CONDITIONAL on S33 |
| Large export | > async threshold | queued via Hangfire (NFR-5) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | With the Engineering/last-30-days filter applied, click Export -> CSV | A CSV downloads; rows/headers match the on-screen filtered KPIs, funnel, and source data (FR-8, AC-2). |
| 2 | Click Export -> Excel | An .xlsx (ClosedXML) downloads with the same filtered data; opens without corruption. |
| 3 | Click Export -> PDF | A PDF (QuestPDF) of the full dashboard view downloads. CONDITIONAL: if QuestPDF/S33 not wired, the export request is accepted and the generation seam is asserted (must NOT be skipped or weakened to "no export"). |
| 4 | Trigger an export over the async threshold (large dataset) | Generation is queued via Hangfire (non-blocking response) and a download notification is delivered on completion (NFR-5). CONDITIONAL: if Hangfire async export not wired, assert the job/outbox enqueue seam. |
| 5 | Compare exported values to the screen | Exact match for the applied period + drill-down (no full-tenant leakage into a department-scoped export). |

## 6. Postconditions
- No source data mutated; exports reflect the applied filters; PDF/async paths asserted or seam-asserted per wiring.
