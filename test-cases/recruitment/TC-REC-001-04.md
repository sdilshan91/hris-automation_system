# TC-REC-001-04: Closing an Open vacancy stops new applications and retains existing applicants in their stage

## 1. Test Objective
Verify that closing an `Open` vacancy that has received applicants transitions its status to `Closed`, prevents new applications, and leaves existing applicants in their current pipeline stage (neither deleted nor rejected).

## 2. Related Requirements
- User Story: US-REC-001
- Acceptance Criteria: AC-5
- Functional Requirements: FR-2, FR-7
- Business Rules: BR-3

## 3. Preconditions
- Tenant "acme" has an `Open` vacancy "Senior Backend Engineer".
- Two applicants exist on the vacancy: "Alex" in stage `Screening` and "Jamie" in stage `Interview`.
- Recruiter "Riley Park" (Recruitment.Create.All) is authenticated in acme.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Vacancy | Senior Backend Engineer (Open) | Has 2 applicants |
| Applicant 1 | Alex -> Screening | Existing stage |
| Applicant 2 | Jamie -> Interview | Existing stage |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Riley Park, open the vacancy and click "Close" (or change status via the inline dropdown) | A confirmation appears; on confirm, `POST /api/v1/recruitment/vacancies/{id}/close` (or status PATCH) returns 200 OK. |
| 2 | Verify the persisted row | `status = Closed`; an audit-log entry records the close action (FR-7). |
| 3 | Reload the internal listing | The vacancy shows a red "Closed" badge and is excluded from the active/public listings. |
| 4 | Attempt to submit a new application to the closed vacancy (public careers page or API) | The application is rejected (no new applications accepted); appropriate message/HTTP error returned. |
| 5 | Verify the existing applicants | Alex remains in `Screening` and Jamie remains in `Interview`; neither is deleted nor moved to `Rejected`. |

## 6. Postconditions
- The vacancy is `Closed`; no new applications can be submitted.
- Existing applicants remain in their prior pipeline stages.
