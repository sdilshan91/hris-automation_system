# TC-REC-010-07: Conversion of a non-Hired applicant OR a Hired applicant with NO accepted offer is rejected; action unavailable (FR-1, AC-1, preconditions)

## 1. Test Objective
Verify the eligibility precondition for conversion (FR-1, AC-1, story preconditions): the "Convert to Employee" action is available ONLY when the applicant is in the "Hired" stage WITH an offer in `Accepted` status. Both the UI (action hidden/disabled) and the API (hard 409/422 reject) must enforce this for the negative cases: (a) applicant in a non-Hired stage (e.g. Interview/Offer), and (b) applicant in Hired but with no offer, or an offer that is Sent/Declined/Expired/Withdrawn (not Accepted). No employee is created in any rejected case.

## 2. Related Requirements
- User Story: US-REC-010
- Acceptance Criteria: AC-1 (only for Hired + Accepted)
- Functional Requirements: FR-1 (action available only when Hired + accepted offer)
- Preconditions: story S2 (applicant Hired with Accepted offer)

## 3. Preconditions
- Tenant "acme"; HR Officer with `Recruitment.Manage.All` + `Employee.Create.All`.
- Applicant A1: stage "Interview" (not Hired).
- Applicant A2: stage "Hired" but offer status = `Sent` (not Accepted).
- Applicant A3: stage "Hired" with no offer at all.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| A1 | Interview stage | non-Hired |
| A2 | Hired, offer Sent | offer not Accepted |
| A3 | Hired, no offer | missing accepted offer |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | View A1 (Interview) | "Convert to Employee" action is NOT offered (hidden/disabled) (FR-1). |
| 2 | Call the convert API for A1 directly | Rejected 409/422 ("applicant must be Hired with an accepted offer"); no employee created (AC-1). |
| 3 | View A2 (Hired, offer Sent) | Action NOT offered; converting requires an Accepted offer (FR-1). |
| 4 | Call the convert API for A2 directly | Rejected 409/422; no employee created. |
| 5 | Call the convert API for A3 (Hired, no offer) | Rejected 409/422 ("no accepted offer to map from"); no employee created. |
| 6 | Verify state unchanged | A1/A2/A3 pipeline stages, offers, and vacancy filled_counts are unchanged after every rejection. |

## 6. Postconditions
- No employee created for any ineligible applicant; pipeline + vacancy state unchanged.
