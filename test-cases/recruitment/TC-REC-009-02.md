# TC-REC-009-02: Date range filter (preset + custom) updates ALL dashboard metrics and charts to the selected period

## 1. Test Objective
Verify AC-2 / FR-6: selecting a date range — preset (last 7 days, last 30 days, last quarter, last year) or a custom range — re-queries and updates every dashboard widget (all KPI cards, funnel, source effectiveness, time-to-hire trend, vacancy status summary, recent activity) so each reflects only data within the selected period. Confirms the filter is applied GLOBALLY (one filter drives all widgets), the previous-period comparison shifts accordingly, and switching back restores the prior values.

## 2. Related Requirements
- User Story: US-REC-009
- Acceptance Criteria: AC-2
- Functional Requirements: FR-6 (global date range filter), FR-1/FR-2/FR-3/FR-4/FR-5/FR-9 (widgets it drives)
- Business Rules: BR-1 (time-to-hire by applied_at), BR-2 (acceptance rate per period), BR-4 (refresh on load, no streaming)

## 3. Preconditions
- Tenant "acme" with applicant/offer/hire data spread across multiple periods: a known subset in the last 7 days, a larger superset in the last 30 days, and additional data in the last quarter (so the three presets yield distinct, predictable values).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Last 7 days | 12 applicants, 1 hire | small recent subset |
| Last 30 days | 100 applicants, 5 hires | default superset |
| Last quarter | 300 applicants, 18 hires | larger superset |
| Custom range | 2026-04-01 .. 2026-04-30 | bounded month, distinct values |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the dashboard at the default period; note all KPI + chart values | Baseline rendered (FR-6 default applied). |
| 2 | Click the "7d" preset pill | All widgets re-query; Total Applicants = 12, Hires = 1; funnel/source/trend/status/activity all reflect only the last 7 days. |
| 3 | Click the "90d" (last quarter) preset | All widgets update to 300 applicants / 18 hires; funnel counts and source counts scale to the quarter; trend chart spans the quarter. |
| 4 | Open the custom range picker and select 2026-04-01 to 2026-04-30 | All widgets reflect ONLY April data; previous-period comparison uses March (equal-length prior window). |
| 5 | Select an inverted custom range (end before start) | Rejected with a validation message; no malformed query issued; prior valid view retained. |
| 6 | Re-select "30d" | Dashboard restores the default-period values from Step 1 (consistent, idempotent). |

## 6. Postconditions
- No data mutated; the single global date filter consistently drove every widget; out-of-range/inverted input rejected.
