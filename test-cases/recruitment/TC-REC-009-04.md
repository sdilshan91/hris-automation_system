# TC-REC-009-04: Source effectiveness chart shows applicants per source and hire-conversion rate per source (BR-6)

## 1. Test Objective
Verify AC-4 / FR-3 / BR-6: the source effectiveness chart displays applicant counts grouped by source category and the hire-conversion rate per source. Source categories per BR-6 are Public Careers Page, Internal Application, Referral, Manual Entry (plus any tenant custom sources). Per-source hire conversion = `hires from source / applicants from source * 100`, asserted against a seeded dataset with distinct per-source counts. Confirms the chart honours the global date filter and that an unrepresented source either shows 0 or is omitted consistently.

## 2. Related Requirements
- User Story: US-REC-009
- Acceptance Criteria: AC-4
- Functional Requirements: FR-3 (source effectiveness + per-source conversion)
- Business Rules: BR-6 (source categories; tenants may add custom sources)

## 3. Preconditions
- Tenant "acme" seeded for the period with applicants and hires by source: Public Careers Page 50 applicants / 2 hires, Referral 30 / 3, Internal 15 / 1, Manual Entry 5 / 0, plus a tenant custom source "LinkedIn" 10 / 1.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Public Careers Page | 50 applicants / 2 hires | conversion 4% |
| Referral | 30 / 3 | conversion 10% |
| Internal Application | 15 / 1 | conversion 6.7% |
| Manual Entry | 5 / 0 | conversion 0% |
| LinkedIn (custom) | 10 / 1 | conversion 10%; custom source surfaces |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | View the source effectiveness chart | Bars/segments per source with applicant counts 50/30/15/5/10 (FR-3, BR-6). |
| 2 | Inspect Public Careers Page conversion | Shows 4% = 2/50*100. |
| 3 | Inspect Referral conversion | Shows 10% = 3/30*100. |
| 4 | Inspect Manual Entry conversion | Shows 0% (0 hires); rendered, not omitted/errored. |
| 5 | Verify the custom source "LinkedIn" appears | Custom tenant source surfaces with 10 applicants / 10% conversion (BR-6 custom sources). |
| 6 | Apply a date filter excluding all source data | Chart shows empty state "No data for the selected period"; no divide-by-zero. |

## 6. Postconditions
- No data mutated; per-source counts and conversion rates match BR-6 categories incl. custom sources.
