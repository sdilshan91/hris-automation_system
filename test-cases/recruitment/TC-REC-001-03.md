# TC-REC-001-03: Editing an Open vacancy updates it, writes an audit log entry, and reflects on both listings

## 1. Test Objective
Verify that a recruiter editing any field of an `Open` vacancy (e.g., description, headcount) and saving updates the record, creates an audit-trail entry, and that the updated information is reflected immediately on both the internal listing and the public careers page.

## 2. Related Requirements
- User Story: US-REC-001
- Acceptance Criteria: AC-3
- Functional Requirements: FR-7
- Non-Functional Requirements: NFR-4 (sanitization on edit)
- Dependencies: Audit logging module

## 3. Preconditions
- Tenant "acme" has the public careers page enabled.
- An `Open`, publicly-listed vacancy "Senior Backend Engineer" (headcount 2) exists in acme.
- Recruiter "Riley Park" (Recruitment.Create.All) is authenticated in acme.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Vacancy | Senior Backend Engineer (Open) | Publicly listed |
| New headcount | 3 | Changed from 2 |
| New description | "<p>Updated: build backend + on-call.</p>" | Rich text edit |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Riley Park, open the `Open` vacancy and change headcount 2 -> 3 and edit the description | Form accepts edits without errors. |
| 2 | Save and observe `PUT /api/v1/recruitment/vacancies/{id}` | Response is 200 OK; body reflects headcount 3 and the new description; `updated_at` advanced. |
| 3 | Verify the persisted row | `headcount = 3`; description updated and HTML-sanitized; status remains `Open`. |
| 4 | Verify the tenant audit trail | A new audit-log entry exists for the update action, scoped to acme, referencing the vacancy `id`, the actor (Riley Park), and the changed fields/timestamp. |
| 5 | Reload the internal listing and vacancy detail | The updated headcount and description appear immediately. |
| 6 | Reload the public careers detail page `https://acme.yourhrm.com/careers/{slug}` | The updated information is reflected on the public page. |

## 6. Postconditions
- The vacancy reflects the edited values everywhere it is shown.
- An audit-log entry recording the update exists in acme's audit trail.
