# TC-REC-009-11: Empty-state and boundary behaviour — no recruitment data, single record, and divide-by-zero metrics

## 1. Test Objective
Verify boundary and empty-state handling across the dashboard: a tenant/department with NO recruitment data shows friendly "No data for the selected period" placeholders on every widget (not blank/errored charts), and rate metrics that would divide by zero (offer acceptance rate with 0 sent offers; funnel/source conversions with 0 at the prior stage; time-to-hire with 0 hires) render as 0% or "--" without throwing. Also verifies a minimal single-record dataset renders correctly (one applicant, one vacancy).

## 2. Related Requirements
- User Story: US-REC-009
- Functional Requirements: FR-1, FR-2, FR-3, FR-4, FR-5, FR-9 (all widgets)
- Business Rules: BR-1, BR-2, BR-3 (rate formulas; divide-by-zero guards)
- UI/UX S8 (empty-state messaging)

## 3. Preconditions
- Tenant "emptyco" with zero recruitment data. Separately, tenant "acme" with exactly one vacancy and one applicant (not yet hired, no offers).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| emptyco | 0 vacancies / 0 applicants / 0 offers | full empty state |
| acme single | 1 vacancy, 1 applicant (Applied) | minimal dataset |
| Offers sent | 0 | acceptance rate divide-by-zero guard |
| Hires | 0 | time-to-hire = "--"/0, not NaN |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the dashboard as an emptyco user | Every KPI shows 0; every chart shows "No data for the selected period"; no console/server error. |
| 2 | Inspect the Offer Acceptance Rate KPI (0 offers sent) | Shows 0% or "--", NOT NaN/Infinity (BR-2 divide-by-zero guard). |
| 3 | Inspect the funnel/source conversions (0 at prior stage) | Conversions shown as 0%/"--"; no error (BR-3). |
| 4 | Inspect Average Time-to-Hire (0 hires) | Shows 0/"--" days, not NaN (BR-1). |
| 5 | Open the dashboard for acme's single-record dataset | KPIs reflect 1 vacancy / 1 applicant; funnel shows Applied=1 and downstream 0; charts render without error. |

## 6. Postconditions
- No data mutated; empty and minimal datasets render gracefully with guarded rate math.
