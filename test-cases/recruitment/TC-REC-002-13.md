# TC-REC-002-13: Public application form is WCAG 2.1 AA accessible and responsive down to 360px

## 1. Test Objective
Verify NFR-2 (accessible, WCAG 2.1 AA) and NFR-5 (mobile-responsive, 360px minimum): the public careers page and application form -- including the drag-and-drop file upload zone -- are keyboard operable, screen-reader friendly, meet color-contrast requirements, and remain usable at 360px width with large touch targets.

## 2. Related Requirements
- User Story: US-REC-002
- Acceptance Criteria: AC-1
- Non-Functional Requirements: NFR-2 (WCAG 2.1 AA), NFR-5 (responsive 360px)
- UI/UX Notes: S8 (full-width fields, large touch targets, drag-and-drop zone with progress)

## 3. Preconditions
- Tenant "acme" has the public careers page enabled with an `Open` vacancy and a reachable application form.
- An automated a11y scanner (e.g. axe) and a screen reader (NVDA/VoiceOver) plus a 360px viewport / device emulator are available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewport (mobile) | 360 x 640 | NFR-5 minimum width |
| Viewport (desktop) | 1920 x 1080 | Upper end |
| Standard | WCAG 2.1 AA | NFR-2 |
| File upload | drag-and-drop zone + fallback file input | Must be keyboard reachable |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run an automated a11y scan (axe) on the careers page and the application form | Zero WCAG 2.1 AA violations (or only documented, justified exceptions). |
| 2 | Navigate the entire form using only the keyboard (Tab/Shift+Tab/Enter/Space) | All fields, the file upload control, and the submit button are reachable and operable; focus order is logical; focus is visible. |
| 3 | Operate the file upload via keyboard (not just drag-and-drop) | A keyboard-accessible file input fallback exists; the drag-and-drop zone is not the only way to attach a resume. |
| 4 | Inspect with a screen reader | All inputs have programmatic labels; the upload zone announces accepted formats and the 25 MB max; validation errors are announced (aria-live) and associated with their fields. |
| 5 | Check color contrast on text, labels, error states, and buttons | All meet WCAG 2.1 AA contrast (>= 4.5:1 normal text, 3:1 large text/UI). |
| 6 | Resize to 360px width | The form is full-width and usable with no horizontal scroll; touch targets are large; the vacancy description is collapsible; submission works. |
| 7 | Confirm submission success screen is accessible | The confirmation (with reference number) is announced and reachable; focus moves to it on success. |

## 6. Postconditions
- The public form meets WCAG 2.1 AA and is fully usable at 360px via keyboard and screen reader.
