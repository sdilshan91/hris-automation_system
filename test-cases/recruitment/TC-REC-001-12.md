# TC-REC-001-12: Vacancy creation form and public careers page meet WCAG 2.1 AA and are responsive (360px-4K)

## 1. Test Objective
Verify NFR-5 and NFR-3: the vacancy creation form (authenticated) and the public careers page (anonymous) comply with WCAG 2.1 AA -- keyboard operability, screen-reader compatibility, and color contrast -- and the form is fully responsive from 360px to 4K.

## 2. Related Requirements
- User Story: US-REC-001
- Non-Functional Requirements: NFR-3 (responsive 360px-4K), NFR-5 (public careers page WCAG 2.1 AA)
- Acceptance Criteria: AC-1 (form), AC-2 (public page)
- Test Hint: test responsive layout at 360px, 768px, 1024px, 1920px breakpoints

## 3. Preconditions
- Tenant "acme" with the public careers page enabled and at least one Open public vacancy.
- Recruiter "Riley Park" (Recruitment.Create.All) is authenticated in acme.
- An automated a11y scanner (e.g., axe) plus manual keyboard and screen-reader (NVDA/VoiceOver) checks are available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Breakpoints | 360, 768, 1024, 1920 px (+ 4K) | Responsive checks |
| Targets | Vacancy creation form; public careers list + detail | Authed + anonymous |
| Standard | WCAG 2.1 AA | Contrast >= 4.5:1 text |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the vacancy creation form and run the automated a11y scan | Zero critical/serious WCAG 2.1 AA violations; every field has an associated label; the rich text editor exposes accessible controls. |
| 2 | Operate the entire form with the keyboard only (Tab/Shift+Tab/Enter/Space; rich-text toolbar reachable) | All controls reachable in a logical order; visible focus indicators; no keyboard traps; dropdowns (department/job title/hiring manager) operable and announce options. |
| 3 | Navigate the form with a screen reader | Labels, required-field state, and validation errors are announced (errors programmatically associated to inputs). |
| 4 | Verify color contrast for text, status badges (Draft/Open/On Hold/Closed), and buttons | All meet >= 4.5:1 (>= 3:1 for large text/UI components); status is not conveyed by color alone (badge text/icon present). |
| 5 | Resize/emulate the form at 360, 768, 1024, 1920px and 4K | Layout reflows without horizontal scrolling or overlap; fields stack vertically on mobile; toolbar collapses gracefully. |
| 6 | Load the public careers page + a vacancy detail anonymously and run the a11y scan + keyboard + screen-reader checks | Public pages meet WCAG 2.1 AA; landmarks/headings present; "Apply" actions are keyboard-operable and labeled. |

## 6. Postconditions
- The vacancy form and public careers page pass WCAG 2.1 AA and are usable across the responsive range.
