# TC-REC-002-02: Internal employee applies to an open vacancy with pre-filled profile data and a linked employee record (internal application)

## 1. Test Objective
Verify AC-4 / FR-8 / BR-5: an authenticated employee navigating to an open internal vacancy and clicking "Apply" gets a form pre-filled from their employee profile (name, email, phone), and on submission the application is linked to their employee record and flagged as internal (`is_internal = true`, `source: "internal"`).

## 2. Related Requirements
- User Story: US-REC-002
- Acceptance Criteria: AC-4
- Functional Requirements: FR-8, FR-6
- Business Rules: BR-5
- Dependencies: Core HR module (employee profile data)

## 3. Preconditions
- Tenant "acme" exists and is active.
- Employee "Sam Carter" has an active employee record in acme (profile: first name Sam, last name Carter, email sam.carter@acme.com, phone +1 555 0142) and is authenticated (valid JWT with acme `tenant_id`).
- Vacancy "Engineering Team Lead" exists in acme with status `Open`, available to internal applicants.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Auth context | acme | Authenticated employee |
| Employee | Sam Carter (active record) | Source of pre-fill + linkage |
| Profile email | sam.carter@acme.com | Pre-filled, identifies applicant |
| Vacancy | Engineering Team Lead (Open) | Internal vacancy |
| Resume | sam-resume.docx, application/vnd.openxmlformats-officedocument.wordprocessingml.document | Allowed MIME |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Authenticate as Sam Carter in acme; open the internal listing and the "Engineering Team Lead" vacancy; click "Apply" | An internal application modal/slide-over opens with first name, last name, email, phone **pre-filled** from Sam's employee profile (FR-8); fields remain editable before submit. |
| 2 | Upload `sam-resume.docx`, optionally edit the cover letter, and submit | `POST .../applications` carries the acme bearer token + `X-Tenant-Subdomain: acme`. Response is 201 Created. |
| 3 | Inspect the response body | `tenant_id` = acme, `stage: "Applied"`, `source: "internal"`, `is_internal: true`, and an `employee_id` linking to Sam Carter's employee record (FR-8, BR-5). |
| 4 | Verify the persisted `applicant` row | Row has `is_internal = true`, `source = internal`, `employee_id` = Sam Carter's record, resume stored at the tenant-scoped path. |
| 5 | Verify pre-fill integrity | The persisted applicant name/email/phone match Sam's profile values (unless edited in Step 1); no other employee's data is used. |
| 6 | Confirm the application appears for recruiters with an internal indicator | Recruiters in acme see the application flagged as internal in the applicant list. |

## 6. Postconditions
- One internal `applicant` row exists in acme, flagged `is_internal = true` and linked to Sam Carter's employee record.
