# TC-REC-002-03: Oversized resume (> 25 MB) is rejected and not persisted (negative)

## 1. Test Objective
Verify AC-2 / FR-1: a resume file exceeding the 25 MB limit is rejected with a clear error message, no `applicant` record is created, and nothing is written to blob storage.

## 2. Related Requirements
- User Story: US-REC-002
- Acceptance Criteria: AC-2
- Functional Requirements: FR-1
- Non-Functional Requirements: NFR-1 (limit boundary; happy-path size in TC-REC-002-08)

## 3. Preconditions
- Tenant "acme" exists; vacancy "Senior Backend Engineer" is `Open` and publicly listed.
- The public application form is reachable anonymously.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Vacancy | Senior Backend Engineer (Open) | Target |
| Oversized resume | bigresume.pdf, 26 MB, application/pdf | Exceeds 25 MB limit |
| Boundary reference | 25 MB exactly = accept | Verified in TC-REC-002-08 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the application form for the vacancy and select `bigresume.pdf` (26 MB) | Client-side validation flags the file as too large before upload begins (clear inline error stating the 25 MB max), OR upload is allowed to start but the server rejects it. |
| 2 | Force the multipart `POST .../applications` with the 26 MB file (bypassing client validation, e.g. via API) | Response is 4xx (413 Payload Too Large or 400) with a clear error message; no application is created. |
| 3 | Verify the database | No new `applicant` row exists for this email/vacancy. |
| 4 | Verify blob storage | No resume object was persisted at `{tenantId}/recruitment/{vacancyId}/.../bigresume.pdf` (the file was rejected before persistence). |
| 5 | Verify no confirmation email | No "Application Received" email is sent. |

## 6. Postconditions
- No applicant record and no resume blob were created from the rejected oversized upload.
