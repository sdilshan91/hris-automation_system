# TC-REC-007-01: Generate offer letter from template -> PDF with variable substitution, stored at tenant-scoped path, displayed for preview (happy path)

## 1. Test Objective
Verify the primary generation flow (AC-1, FR-1/FR-2/FR-3/FR-4): a recruiter with `Recruitment.Offer.All`, for an applicant in the "Offer" stage, selects a tenant-configured offer template, fills the offer form (position, department, reporting manager, salary amount+currency+frequency, benefits summary, start date, expiry date, probation period, optional custom clauses), and clicks "Generate". On generate the system (a) renders the template to a PDF substituting placeholders (`{{applicant_name}}`, `{{position}}`, `{{salary}}`, `{{start_date}}`, `{{company_name}}`, `{{expiry_date}}`, etc.) with the form/applicant/tenant values, (b) persists ONE `offer` row (status `Draft`, version 1, offer reference number, tenant_id from session, pdf_storage_key) WITHOUT sending, (c) stores the PDF in blob storage at the tenant-scoped path `{tenantId}/recruitment/{vacancyId}/{applicantId}/offers/{filename}` (FR-3), and (d) returns the PDF for inline preview (FR-4). This is REC-007's generation walk; sending is TC-REC-007-02.

## 2. Related Requirements
- User Story: US-REC-007

- Business Rules: BR-4 (placeholders), BR-6 (expiry mandatory; default +7d)

## 3. Preconditions
- Tenant "acme" active; recruiter `recruiter@acme` authenticated with `Recruitment.Offer.All`.
- Applicant {acme_applicantId} on vacancy {acme_vacancyId} is in the "Offer" pipeline stage (REC-004 advancement).
- The tenant has at least one offer letter template configured (S35.2.9) with the BR-4 placeholders + tenant branding (logo/colors).
- PDF generation library (QuestPDF or equivalent) + File & Document Management (S26) wired, OR a blob/log stub is in place (see Conditional note).
