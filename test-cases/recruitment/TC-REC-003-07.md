# TC-REC-003-07: Moving an applicant to "Rejected" without a reason is rejected; with a reason it succeeds and is recorded (negative + happy)

## 1. Test Objective
Verify BR-3: moving an applicant to the "Rejected" stage requires a rejection reason (dropdown + optional free text). A move to Rejected without a reason is rejected server-side with no stage change; a move with a valid reason succeeds and the reason is persisted in the stage-history record.

## 2. Related Requirements
- User Story: US-REC-003
- Acceptance Criteria: AC-2
- Business Rules: BR-3, BR-5
- Functional Requirements: FR-3

## 3. Preconditions
- Tenant "acme" is active; a recruiter with `Recruitment.Manage.All` is authenticated.
- Applicant "Casey Lee" exists at stage "Screening".

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Applicant | Casey Lee | At "Screening" |
| To stage | Rejected | Requires reason (BR-3) |
| Missing reason | (none) | Must be rejected |
| Valid reason | "Not enough experience" (dropdown) + optional note | Must succeed |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Drag Casey Lee to "Rejected" and confirm without selecting a reason (or send `PATCH .../stage` to Rejected with no reason) | The UI requires a reason before submit; the API rejects (4xx, validation error) "rejection reason required". The optimistic move reverts; the applicant stays at "Screening". |
| 2 | Verify the applicant row after the failed attempt | `pipeline_stage_id` unchanged (still Screening); no `applicant_stage_history` row created (BR-3). |
| 3 | Retry the move to "Rejected" selecting reason "Not enough experience" and an optional free-text note | 200/204; applicant moves to "Rejected". |
| 4 | Verify the persisted row + history | `applicant.pipeline_stage_id` = Rejected; a new `applicant_stage_history` row records from-stage "Screening", to-stage "Rejected", the actor, timestamp, and the rejection reason/notes (BR-5). |
| 5 | Verify board counts | Screening count decremented, Rejected count incremented; total unchanged. |

## 6. Postconditions
- Casey Lee is at "Rejected" with a recorded reason; the reason-less attempt left no side effects.
