# TC-REC-010-05: After conversion the applicant shows a "Converted" badge + link to the new employee; vacancy shows updated filled/headcount ratio; onboarding trigger seam (AC-4, FR-6, FR-7, FR-8)

## 1. Test Objective
Verify the post-conversion UI/state (AC-4, FR-6, FR-7): viewing the converted applicant record shows a "Converted" badge and a working deep link to the newly created employee profile (traceability via `converted_to_employee_id`); and the vacancy view shows the updated filled/headcount ratio (e.g. 1/3). Also asserts the onboarding-workflow TRIGGER seam (FR-8) at the boundary only — checklist generation is owned by the Onboarding module.

NOTE: Onboarding checklist generation (FR-8) is owned by the Onboarding module; this case asserts only that conversion FIRES the onboarding trigger (and does NOT block conversion if the Onboarding module is disabled — story assumptions). The vacancy filled/headcount ratio also surfaces on the REC-009 dashboard (verified there).

## 2. Related Requirements
- User Story: US-REC-010
- Acceptance Criteria: AC-4
- Functional Requirements: FR-6 (applicant link fields drive the badge/link), FR-7 (filled/headcount ratio), FR-8 (onboarding trigger seam)
- Cross-story: US-REC-009 (vacancy fill ratio on dashboard)

## 3. Preconditions
- TC-REC-010-01 executed: applicant {acme_applicantId} converted to employee {newEmployeeId}; vacancy {acme_vacancyId} headcount 3, filled_count 1.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Applicant | {acme_applicantId} | converted |
| Employee | {newEmployeeId} | link target |
| Vacancy ratio | 1/3 | filled/headcount (FR-7) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | View the converted applicant {acme_applicantId} | A "Converted" badge is displayed on the applicant record (AC-4). |
| 2 | Click the employee link on the applicant | Navigates to employee {newEmployeeId}'s profile (deep link resolves via `converted_to_employee_id`) (AC-4, FR-6). |
| 3 | View vacancy {acme_vacancyId} | Shows the updated filled/headcount ratio 1/3 (FR-7). |
| 4 | Verify the "Convert to Employee" action is gone | The action is no longer offered for {acme_applicantId} (already converted) — see TC-REC-010-06 for the hard reject. |
| 5 | Verify onboarding trigger seam | Conversion fired the onboarding-workflow trigger for {newEmployeeId} (FR-8); if the Onboarding module is disabled, the trigger is a no-op and the conversion still succeeded (assumptions). |

## 6. Postconditions
- Applicant shows Converted badge + employee link; vacancy ratio reflects the fill; onboarding trigger fired (seam).
