# TC-REC-001-11: Vacancy list page loads within 400 ms (P95) for up to 500 active vacancies per tenant

## 1. Test Objective
Verify NFR-1: the vacancy list page/endpoint returns within 400 ms at the 95th percentile when the tenant has up to 500 active vacancies, while remaining tenant-scoped.

## 2. Related Requirements
- User Story: US-REC-001
- Non-Functional Requirements: NFR-1 (list <= 400 ms P95 @ 500 vacancies)
- Data Requirements: S7 (indexes on (tenant_id, status) and (tenant_id, department_id))
- Test Hint: load-test vacancy list with 500 vacancies and verify P95 < 400 ms

## 3. Preconditions
- Tenant "acme" seeded with 500 active vacancies across multiple departments and statuses.
- A second tenant "globex" seeded with its own vacancies (to confirm the query stays tenant-scoped under load).
- Recruiter "Riley Park" (Recruitment.Read.All) is authenticated in acme.
- Test runs on representative hardware with a warmed connection pool.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Active vacancies (acme) | 500 | NFR-1 ceiling |
| Page size | 25 (default) | Paginated list |
| Sample size | >= 200 requests | For a stable P95 |
| Filters | status=Open, department filter | Exercise indexed paths |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Issue >= 200 `GET /api/v1/recruitment/vacancies?status=Open&page=1` requests against acme and record latencies | P95 response time <= 400 ms; no errors. |
| 2 | Repeat with a department filter applied | P95 remains <= 400 ms (indexed `(tenant_id, department_id)` path). |
| 3 | Measure the SPA list page end-to-end render | Page load stays within the platform page-load budget (<= 2.5s) with the 500-vacancy dataset. |
| 4 | Inspect the DB query plan | Queries use the `(tenant_id, status)` / `(tenant_id, department_id)` indexes; no full table scan; the tenant filter is always applied. |
| 5 | Confirm result correctness under load | Every returned vacancy belongs to acme (no globex rows leak in under concurrency). |

## 6. Postconditions
- The vacancy list meets the NFR-1 P95 budget at 500 vacancies and remains tenant-scoped.
