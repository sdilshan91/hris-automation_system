# TC-REC-008-13: Candidate portal is WCAG 2.1 AA accessible and fully responsive from 360px (step indicator, interview card, offer buttons, timeline)

## 1. Test Objective
Verify NFR-2: the candidate portal meets WCAG 2.1 AA and is fully responsive from 360px up. The step indicator, interview card, offer Accept/Decline buttons (and confirmation modal), and the vertical timeline are usable on a 360px viewport with large touch targets, are keyboard-operable, are announced correctly by screen readers, and meet color-contrast requirements (including the green/blue/gray step states, which must not rely on color alone).

## 2. Related Requirements
- User Story: US-REC-008
- Non-Functional Requirements: NFR-2 (responsive 360px-4K + WCAG 2.1 AA)
- Functional Requirements: FR-2 (step indicator), FR-3 (interview card), FR-5 (offer buttons + modal), FR-6 (timeline)

## 3. Preconditions
- Applicant {acme_applicantId} with an application, upcoming interview, and active offer. Valid magic link available.
- Automated a11y tool (axe) + manual keyboard/screen-reader pass available; responsive testing at 360px and up.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360px, 768px, 1280px, 1920px | responsive range |
| A11y standard | WCAG 2.1 AA | target |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the portal at 360px width | Cards are full-width with large touch targets; the step indicator is usable (swipeable/wrapped, not clipped); the offer buttons are reachable; no horizontal overflow (NFR-2). |
| 2 | Run automated axe checks on dashboard, interview, offer, and timeline views | No WCAG 2.1 AA violations (contrast, names/roles/values, landmarks, headings). |
| 3 | Navigate the entire portal by keyboard only (Tab/Shift+Tab/Enter/Esc) | All interactive elements (download buttons, Accept/Decline, modal, request-new-link form) are reachable + operable with a visible focus indicator; the confirmation modal traps focus and closes on Esc. |
| 4 | Exercise with a screen reader | Step indicator stage states (completed/current/future) and offer status are conveyed by text/ARIA, not color alone; interview details and timeline events are announced in a sensible order. |
| 5 | Verify color contrast of step states + status badges | Green/blue/gray states + status badges meet AA contrast; state is also indicated textually/iconographically (not color-only). |

## 6. Postconditions
- Portal passes WCAG 2.1 AA automated + manual checks and is usable from 360px; no data mutated.
