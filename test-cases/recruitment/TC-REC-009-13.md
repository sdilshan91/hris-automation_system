# TC-REC-009-13: Dashboard is WCAG 2.1 AA accessible and fully responsive (charts reflow to single column at 360px) (NFR-4)

## 1. Test Objective
Verify NFR-4 and the UI/UX notes: the recruitment dashboard meets WCAG 2.1 AA and is fully responsive from 360px to 4K. Charts (funnel, source, trend, status) resize and reflow to a single column on mobile; KPI cards stack; wide charts offer horizontal scroll where needed. Accessibility coverage: keyboard navigation through KPI cards, filters, chart controls, and the activity feed; screen-reader exposure of chart data (accessible names / data tables / aria-labels, since canvas charts are not inherently readable); visible focus indicators; and color-contrast (chart segments + trend arrows + status colors) meeting AA, with non-color-only encoding of status.

## 2. Related Requirements
- User Story: US-REC-009
- Non-Functional Requirements: NFR-4 (responsive 360px-4K; charts reflow)
- Acceptance Criteria: AC-1, AC-2, AC-3, AC-4 (all rendered widgets)
- UI/UX S8 (mobile stacking; empty state; chart library a11y)

## 3. Preconditions
- Tenant "acme" dashboard with representative data so all charts render. An axe-core (or equivalent) scanner, a keyboard, and a screen reader (NVDA/VoiceOver) are available; viewports 360px / 768px / 1920px / 4K testable.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360, 768, 1920, 3840px | reflow checkpoints |
| Contrast target | >= 4.5:1 text / >= 3:1 UI+graphics | WCAG 2.1 AA |
| SR target | NVDA / VoiceOver | chart data exposed |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the dashboard at 1920px and run an automated a11y scan (axe-core) | No WCAG 2.1 AA violations (contrast, names/roles, landmarks). |
| 2 | Resize to 360px | KPI cards stack vertically; charts reflow to a single column / full width; wide charts scroll horizontally; no content clipped or overlapping (NFR-4). |
| 3 | Navigate the dashboard with the keyboard only | Filters, date pills, chart controls, export menu, and activity-feed links are all reachable and operable in a logical order with visible focus. |
| 4 | Inspect chart accessibility with a screen reader | Each chart exposes an accessible name and its data (via aria-label / linked data table / text summary); SR announces KPI values and the funnel/source/trend numbers. |
| 5 | Verify status/trend color encoding | Vacancy-status and trend up/down are NOT conveyed by color alone (icon/label/pattern also used); segment colors meet >= 3:1 against background. |
| 6 | Tab to the empty-state widgets (where data absent) | "No data" message is reachable and announced. |

## 6. Postconditions
- No data mutated; dashboard passes WCAG 2.1 AA checks and reflows correctly across viewports.
