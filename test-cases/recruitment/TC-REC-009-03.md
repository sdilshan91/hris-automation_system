# TC-REC-009-03: Recruitment funnel renders stage counts with correct adjacent-stage conversion rates (BR-3)

## 1. Test Objective
Verify AC-3 / FR-2 / BR-3: the funnel chart shows applicant counts at each pipeline stage (Applied, Screening, Interview, Offer, Hired) for the selected period and the conversion-rate percentage between each adjacent stage pair, computed per BR-3 as `(count at stage N+1 / count at stage N) * 100`. Uses a seeded dataset with clean arithmetic (e.g. 100 -> 60 -> 30 -> 10 -> 5) so conversions are 60%, 50%, 33.3%, 50% and are asserted exactly. Also confirms the funnel honours the global date filter and reuses the same stage definitions as the pipeline (US-REC-003/004).

## 2. Related Requirements
- User Story: US-REC-009
- Acceptance Criteria: AC-3
- Functional Requirements: FR-2 (funnel chart with conversion %)
- Business Rules: BR-3 (conversion = count[N+1]/count[N]*100)

## 3. Preconditions
- Tenant "acme" seeded for the selected period with applicant stage distribution: Applied 100, Screening 60, Interview 30, Offer 10, Hired 5 (counts represent applicants who reached at least that stage in the period).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Applied | 100 | funnel top |
| Screening | 60 | 60% of Applied |
| Interview | 30 | 50% of Screening |
| Offer | 10 | 33.3% of Interview |
| Hired | 5 | 50% of Offer |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | View the funnel chart on the dashboard | Five stage bars/segments render with counts 100, 60, 30, 10, 5 (FR-2). |
| 2 | Inspect the conversion label between Applied and Screening | Shows 60% = 60/100*100 (BR-3). |
| 3 | Inspect Screening -> Interview | Shows 50% = 30/60*100. |
| 4 | Inspect Interview -> Offer | Shows 33.3% (or 33%, per rounding convention) = 10/30*100. |
| 5 | Inspect Offer -> Hired | Shows 50% = 5/10*100. |
| 6 | Change the date filter to a period with zero applicants | Funnel shows all-zero counts and a "No data for the selected period" empty state; no divide-by-zero error (conversion shown as 0% or "--"). |
| 7 | Hover a funnel segment | Tooltip shows the exact stage name, count, and conversion from the prior stage. |

## 6. Postconditions
- No data mutated; funnel counts and conversion rates match BR-3 arithmetic; empty period handled gracefully.
