# TC-REC-003-11: Boundary -- empty pipeline shows friendly empty state; single-applicant and all-in-one-stage distributions render correctly

## 1. Test Objective
Verify boundary/edge rendering of the Kanban board (FR-1/FR-2/FR-5): a vacancy with zero applicants shows a friendly empty state; columns with zero cards show count 0 (not hidden); a vacancy with all applicants in a single stage and a vacancy with exactly one applicant render correctly with accurate counts.

## 2. Related Requirements
- User Story: US-REC-003
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-2, FR-5
- UI/UX: S8 (empty state)

## 3. Preconditions
- Tenant "acme" is active; a recruiter with `Recruitment.Read.All` is authenticated.
- Three vacancies exist: "Empty Role" (0 applicants), "Solo Role" (1 applicant in Applied), "Clustered Role" (10 applicants all in Screening).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Empty Role | 0 applicants | Empty state |
| Solo Role | 1 applicant (Applied) | Minimum non-empty |
| Clustered Role | 10 applicants (Screening) | All in one stage |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open "Empty Role" pipeline | The board shows all configured stage columns each with count (0) and a friendly "No applicants yet" empty-state illustration/message; no error (S8). |
| 2 | Open "Solo Role" pipeline | Applied column shows one card with count (1); all other columns show (0); total = 1. |
| 3 | Open "Clustered Role" pipeline | Screening shows 10 cards with count (10); all other columns (0); total = 10; left-to-right stage order preserved. |
| 4 | Verify empty columns are present, not collapsed | Stages with zero applicants still render as columns with a (0) badge -- the board never hides a configured stage. |
| 5 | Verify totals across all three | Each board's displayed total equals the sum of its column counts and the persisted applicant rows for that vacancy in acme. |

## 6. Postconditions
- No data modified; boundary distributions render with accurate counts and a friendly empty state where applicable.
