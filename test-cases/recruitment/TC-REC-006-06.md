# TC-REC-006-06: Only the assigned interviewer may submit a scorecard; non-assigned users (incl. recruiters/managers) are rejected (403)

## 1. Test Objective
Verify BR-1: a scorecard for an interview assignment can be submitted ONLY by the interviewer assigned to that interview. No one can submit on another interviewer's behalf -- not a recruiter, not a manager, not a different assigned interviewer impersonating a peer, not an unassigned employee. The interviewer_employee_id is derived from the auth context (never a client-supplied value). Unauthenticated requests are also rejected.

## 2. Related Requirements
- User Story: US-REC-006
- Business Rules: BR-1
- Acceptance Criteria: AC-1
- Data Requirements: S7 (interviewer_employee_id from auth, not body)

## 3. Preconditions
- Tenant "acme" active; interview {acme_interviewId} assigned to empA only.
- Users: empA (assigned), empC (acme employee, NOT assigned to this interview), recruiter@acme (Recruitment.Read.All / Manage.All), an unauthenticated client.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Interview | {acme_interviewId} | Assigned to empA |
| Non-assigned employee | empC | Same tenant, not assigned |
| Recruiter/Manager | recruiter@acme | Cannot submit on empA's behalf |
| Injected interviewer_employee_id | empA in body while authed as empC | Must be ignored |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As empC (not assigned), `POST` a scorecard to {acme_interviewId} | 403; only the assigned interviewer may submit (BR-1); no row written. |
| 2 | As recruiter@acme (Manage.All but not an assigned interviewer), `POST` a scorecard to {acme_interviewId} | 403; managers/recruiters cannot submit on an interviewer's behalf (BR-1). |
| 3 | As empC, `POST` with body `interviewer_employee_id=empA` (impersonation attempt) | 403/422; the body value is ignored -- interviewer identity is taken from the auth context, so empC cannot masquerade as empA. No card is written for empA. |
| 4 | Unauthenticated client `POST` a scorecard | 401; scorecard submission requires authentication. |
| 5 | As empA (assigned), `POST` a valid scorecard | 201; the assigned interviewer's submission succeeds and interviewer_employee_id=empA is stamped from auth. |
| 6 | Verify no leakage of who is assigned | The 403 responses do not disclose other interviewers' identities or scorecard contents. |

## 6. Postconditions
- Only empA could submit for {acme_interviewId}; all non-assigned and unauthenticated attempts were rejected; interviewer identity was server-derived.
