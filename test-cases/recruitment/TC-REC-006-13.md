# TC-REC-006-13: Scorecard form + recruiter consolidated view WCAG 2.1 AA; rich-text feedback sanitized; mobile-responsive 360px

## 1. Test Objective
Verify NFR-3 (mobile-responsive 360px+) plus WCAG 2.1 AA for the scorecard surface: the interviewer's scorecard form and the recruiter's consolidated view are keyboard-operable, screen-reader friendly, meet contrast, and remain usable at 360px (criteria stacked vertically, large touch targets for the 1-5 ratings, collapsible comment fields). Also asserts that interviewer-supplied feedback (per-criterion comments + general notes) is sanitized so it cannot inject script when rendered to the recruiter (XSS defense on the render path referenced by TC-REC-006-04).

## 2. Related Requirements
- User Story: US-REC-006
- Non-Functional Requirements: NFR-3
- Acceptance Criteria: AC-1 (form), AC-2 (recruiter view)
- UI/UX: S8 (form layout, color-coded recommendation, mobile stacking)

## 3. Preconditions
- Tenant "acme" active; empA can reach the scorecard form; a recruiter can reach the consolidated view.
- Accessibility tooling (axe/Lighthouse) + screen reader (NVDA/VoiceOver) available; viewport set to 360px.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewport | 360px, 768px, 1280px | Mobile to desktop |
| XSS payload in comment | `<img src=x onerror=alert(1)>` | Must be neutralized |
| Recommendation control | segmented Strong Hire/Hire/No Hire/Strong No Hire | Color + non-color label |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Operate the entire scorecard form by keyboard only (tab order, rate criteria, set recommendation, submit) | All controls reachable + operable via keyboard; visible focus indicators; logical tab order; the 1-5 rating control has an accessible name and value (FR-1). |
| 2 | Run axe/Lighthouse on the form and the recruiter consolidated view | Zero WCAG 2.1 AA violations (contrast >= 4.5:1 for text, labelled inputs, ARIA on rating + segmented control + any chart alt/summary). |
| 3 | Screen-reader pass | Each criterion, its score, the overall recommendation, and the average are announced meaningfully; the recommendation is conveyed by label, not color alone (color-coding is supplementary). |
| 4 | Resize to 360px | Criteria stack vertically with large touch targets; comment fields collapse/expand; the recommendation control and submit are reachable without horizontal scroll (NFR-3). |
| 5 | XSS render check | Submit a comment containing `<img src=x onerror=alert(1)>`; when the recruiter views it, the payload renders inert (escaped/stripped) -- no script executes (sanitization on the render path, complements TC-REC-006-04). |
| 6 | Cross-browser smoke | Form + consolidated view render and submit correctly on Chrome, Edge, Firefox, Safari. |

## 6. Postconditions
- Scorecard form + recruiter view pass WCAG 2.1 AA, are usable at 360px, and render interviewer feedback safely (no XSS).
