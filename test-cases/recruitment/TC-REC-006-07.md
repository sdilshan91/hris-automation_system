# TC-REC-006-07: Overall recommendation is mandatory -- submission without it is rejected

## 1. Test Objective
Verify BR-3 / FR-1: the overall recommendation (Strong Hire / Hire / No Hire / Strong No Hire) is a MANDATORY field. A scorecard submitted without an overall recommendation is rejected with a validation error and nothing is persisted, even if all criterion ratings are present. The recommendation must be one of the four allowed enum values; an out-of-enum value is also rejected.

## 2. Related Requirements
- User Story: US-REC-006
- Business Rules: BR-3
- Functional Requirements: FR-1
- Acceptance Criteria: AC-1

## 3. Preconditions
- Tenant "acme" active; empA assigned to interview {acme_interviewId}; 4 configured criteria.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Criterion ratings | 4 / 4 / 4 / 4 | All present + valid |
| overall_recommendation (case A) | (omitted/null) | Must be rejected |
| overall_recommendation (case B) | "Maybe" | Out-of-enum, must be rejected |
| overall_recommendation (case C) | Hire | Valid -> accepted |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As empA, `POST` a scorecard with all 4 criteria rated but overall_recommendation OMITTED | 400/422 validation error citing the mandatory recommendation (BR-3); NO `interview_scorecard` row and NO criterion rows persisted. |
| 2 | As empA, `POST` with overall_recommendation="Maybe" (not in enum) | 400/422; rejected as an invalid recommendation value (allowed: Strong Hire/Hire/No Hire/Strong No Hire) (FR-1). |
| 3 | Verify atomicity of rejection | After steps 1-2, no partial card exists for empA on {acme_interviewId} -- criterion ratings were not written without a valid card. |
| 4 | As empA, `POST` the same ratings WITH overall_recommendation=Hire | 201; card persists with recommendation=Hire. |
| 5 | Verify the form blocks client-side too | The submit button / confirmation step prevents final submission until a recommendation is chosen (defense-in-depth; server validation in steps 1-2 is authoritative). |

## 6. Postconditions
- No scorecard persisted while the overall recommendation was missing/invalid; the card persisted only once a valid recommendation was supplied.
