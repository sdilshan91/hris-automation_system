# TC-REC-009-06: Vacancy status summary shows correct counts by status (Draft/Open/On Hold/Closed) (FR-5)

## 1. Test Objective
Verify FR-5: the vacancy status summary (donut or horizontal stacked bar) shows the count of vacancies per status — Draft, Open, On Hold, Closed — for the tenant, with the total equal to the sum of segments. Asserts each segment against a seeded set and confirms the chart honours the department/vacancy drill-down filter where applicable and renders an empty state when there are no vacancies.

## 2. Related Requirements
- User Story: US-REC-009
- Functional Requirements: FR-5 (vacancy status summary chart)
- Acceptance Criteria: AC-1 (dashboard composition)

## 3. Preconditions
- Tenant "acme" with vacancies: 3 Draft, 5 Open, 2 On Hold, 4 Closed (total 14).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Draft | 3 | |
| Open | 5 | matches Open-Vacancies KPI |
| On Hold | 2 | |
| Closed | 4 | |
| Total | 14 | sum of segments |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | View the vacancy status summary chart | Four segments render: Draft 3, Open 5, On Hold 2, Closed 4 (FR-5). |
| 2 | Verify the total | Sum of segments = 14; legend/labels show each status count. |
| 3 | Cross-check against the "Open Vacancies" KPI | The Open segment (5) matches the Open Vacancies KPI card. |
| 4 | Filter to a department with only 2 Open vacancies | Status summary reflects the drill-down scope (Open 2; others per that department). |
| 5 | View for a tenant/department with no vacancies | Empty state "No data for the selected period" shown; no chart error. |

## 6. Postconditions
- No data mutated; status counts sum correctly and stay consistent with the Open KPI.
