# TC-REC-004-09: Headcount-filled warning when reaching Offer/Hired at full capacity (BR-4)

## 1. Test Objective
Verify BR-4: when a vacancy's headcount is fully filled (all positions already have Hired applicants), the system WARNS before allowing another applicant to reach "Offer" or "Hired". As a Phase-1 soft control, a `Recruitment.Manage.All` user may acknowledge the warning and proceed (overcommit), but the warning must surface; it is not silently allowed.

## 2. Related Requirements
- User Story: US-REC-004
- Business Rules: BR-4
- Functional Requirements: FR-1 (gate/soft-control family)
- Dependencies: US-REC-001 (vacancy headcount)

## 3. Preconditions
- Tenant "acme"; recruiter with `Recruitment.Manage.All`.
- Vacancy "QA Lead" has headcount = 1, and one applicant "Already Hired" is already at "Hired" (capacity full).
- Applicant "Casey Vu" at "Interview" under the same vacancy.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Vacancy | QA Lead | headcount=1, 1 already Hired (full) |
| Applicant | Casey Vu ({acme_applicantId}) | At Interview |
| Capacity state | filled (hired == headcount) | Warning trigger |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Attempt to move Casey Interview -> Offer on the full vacancy | A headcount-filled WARNING is shown (e.g. "All 1 position(s) already filled") before the move (BR-4); not silently allowed. |
| 2 | Acknowledge/override as a Manage user | 200; move proceeds to Offer; the override/overcommit is noted in audit/notes. |
| 3 | Attempt to move Casey Offer -> Hired (still over capacity) | Warning shown again at the Hired gate; overridable by Manage. |
| 4 | Repeat with capacity NOT full (headcount=2, 1 hired) | No headcount warning; the move to Offer/Hired proceeds normally. |
| 5 | Non-Manage user faces the warning | A non-Manage user cannot override the headcount warning (consistent with soft-gate override authz, TC-REC-004-04). |
| 6 | CONDITIONAL note | If the live headcount count derives from data owned by US-REC-010 conversion, assert the warning evaluator using Hired-applicant counts available in this increment; CONDITIONAL on full conversion wiring. |

## 6. Postconditions
- Reaching Offer/Hired beyond capacity required an explicit Manage acknowledgement; under-capacity moves were unaffected.
