# TC-REC-002-07: Same email may apply to a different vacancy in the same tenant (alternative path)

## 1. Test Objective
Verify BR-2: the duplicate restriction is scoped per vacancy, not per tenant. An applicant who has already applied to one vacancy may apply with the same email to a different `Open` vacancy in the same tenant, producing a distinct `applicant` record.

## 2. Related Requirements
- User Story: US-REC-002
- Acceptance Criteria: AC-3 (boundary of the duplicate rule)
- Business Rules: BR-2, BR-1
- Functional Requirements: FR-6

## 3. Preconditions
- Tenant "acme" exists with two `Open` vacancies: "Senior Backend Engineer" (Vacancy A) and "Platform Engineer" (Vacancy B).
- An existing application from jordan.rivera@example.com to Vacancy A already exists.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Email | jordan.rivera@example.com | Already applied to Vacancy A |
| Vacancy A | Senior Backend Engineer (Open) | Prior application |
| Vacancy B | Platform Engineer (Open) | New application target |
| Resume | jordan-resume.pdf | Allowed type |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Submit an application to Vacancy B with `jordan.rivera@example.com` and a valid resume | Accepted (201 Created); a new `applicant` row is created for (acme, this email, Vacancy B). |
| 2 | Inspect the response | `vacancy_id` = Vacancy B, `stage: "Applied"`, distinct applicant `id` and reference number from the Vacancy A application. |
| 3 | Verify the database | Two `applicant` rows now exist for this email in acme -- one per vacancy; neither blocks the other (BR-2). |
| 4 | Re-attempt a duplicate to Vacancy B with the same email | Rejected per BR-1 (already applied to Vacancy B) -- confirming per-vacancy uniqueness still holds. |
| 5 | Verify the resume blobs | Each application has its own resume object under its own `{tenantId}/recruitment/{vacancyId}/{applicantId}/` path. |

## 6. Postconditions
- Two distinct applications (one per vacancy) exist for the same email in acme; per-vacancy duplicate protection remains intact.
