# TC-REC-002-12: Resume upload completes within 5s for 25 MB; public careers page/form load within 2.5s P95 on 4G

## 1. Test Objective
Verify NFR-1 and NFR-6: a 25 MB resume upload completes within 5 seconds on a standard broadband connection, and the public careers page and application form load within 2.5 seconds (P95) on a simulated 4G connection.

## 2. Related Requirements
- User Story: US-REC-002
- Acceptance Criteria: AC-1
- Non-Functional Requirements: NFR-1, NFR-6

## 3. Preconditions
- Tenant "acme" exists with the public careers page enabled and an `Open` vacancy "Senior Backend Engineer".
- A representative dataset of open vacancies exists on the careers page (e.g. 50-100) to make load timing realistic.
- A performance/timing harness (e.g. k6/Lighthouse with network throttling) is available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Upload file | resume-25mb.pdf, 25 MB | Upper-bound resume size |
| Upload SLA | <= 5 s | NFR-1, standard broadband |
| Careers/form load SLA | <= 2.5 s P95 | NFR-6, throttled to 4G |
| Network profile (load) | Simulated 4G (~9 Mbps, ~170ms RTT) | NFR-6 condition |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | On a standard broadband profile, upload the 25 MB resume as part of a submission and measure end-to-end upload duration | Upload completes within 5 seconds (NFR-1); the progress indicator reaches 100% and submission succeeds. |
| 2 | Repeat the upload across several runs and record the distribution | The upload consistently meets the 5 s target; record P95. |
| 3 | Under a simulated 4G profile, load `https://acme.yourhrm.com/careers` and capture the load time | The careers page loads within 2.5 s (P95 across runs) -- NFR-6. |
| 4 | Under the same 4G profile, open the application form and capture its load time | The form loads within 2.5 s (P95). |
| 5 | Confirm timings are tenant-scoped (acme only) | The measured pages serve only acme data; no cross-tenant fan-out inflates timing. |

## 6. Postconditions
- 25 MB upload <= 5 s; careers page + form load <= 2.5 s P95 on 4G; SLAs recorded.
