# TC-REC-007-09: Offer expiry date mandatory; defaults to generate+7d; required-field + form validation (BR-6, FR-1)

## 1. Test Objective
Verify the offer form validation (FR-1, BR-6): the expiry date is MANDATORY and, when not supplied by the recruiter, defaults to 7 days from generation (configurable per tenant). Required fields (template, position, department, salary amount+currency+frequency, start date) must be present; invalid values (e.g. expiry date in the past, expiry before start date, negative salary) are rejected and nothing is persisted. This locks down the BR-6 default + the FR-1 field set as negatives/boundaries around the happy-path generation (TC-REC-007-01).

## 2. Related Requirements
- User Story: US-REC-007
- Functional Requirements: FR-1 (form fields)
- Business Rules: BR-6 (expiry mandatory; default +7d; tenant-configurable)
- Acceptance Criteria: AC-1 (generation respects validation)

## 3. Preconditions
- Tenant "acme" active; recruiter `recruiter@acme` with `Recruitment.Offer.All`.
- Applicant {acme_applicantId}/{acme_vacancyId} in "Offer" stage; at least one template configured.
- Tenant default expiry window = 7 days (BR-6).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Generate date | T0 | reference |
| Expiry (omitted) | -> T0 + 7 days | default (BR-6) |
| Expiry (past) | T0 - 1 day | rejected |
| Expiry (before start) | < start_date | rejected |
| Salary | -100 / 0 | invalid amount |
| Missing template | (none selected) | rejected |
| Missing start date | (blank) | rejected |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Generate an offer with expiry date OMITTED | Accepted; `expiry_date` defaults to generate date + 7 days (tenant default) (BR-6). |
| 2 | Generate with a custom expiry date in the future | Accepted; the supplied expiry date is used (overrides the default). |
| 3 | Generate with expiry date in the PAST | 422; rejected -- expiry must be in the future; nothing persisted, no PDF generated. |
| 4 | Generate with expiry BEFORE start date | 422; rejected -- expiry must be on/after the start date; nothing persisted. |
| 5 | Generate with missing required fields (no template / no start date / no salary) | 422; rejected with field-level errors; no offer row, no PDF (FR-1). |
| 6 | Generate with invalid salary (negative or zero) | 422; rejected -- salary amount must be positive; currency + frequency required. |

## 6. Postconditions
- Expiry defaults to +7d when omitted; invalid offers are rejected with no persistence and no PDF generation.
