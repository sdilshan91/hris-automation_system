# TC-REC-010-03: Auto-create user account enabled -> User + UserTenant + Employee role created; welcome email queued async (AC-3, FR-5, FR-9, BR-7, NFR-5)

## 1. Test Objective
Verify the optional account-provisioning branch (AC-3, FR-5, FR-9, BR-7, NFR-5): when the tenant setting "Auto-create user accounts on hire" is ENABLED, converting the applicant additionally creates, within the same atomic transaction, a `User` (email = applicant email), a `UserTenant` linking the user to the tenant, and a `user_tenant_role` assigning the DEFAULT "Employee" role; and enqueues a welcome/onboarding email via Hangfire (asynchronous, non-blocking — NFR-5). The welcome email carries login/credential-invite instructions (set-password link or social-login per assumptions). Email DELIVERY depends on the Notification System (S25) — this case asserts the queued outbox/Hangfire job + recipient + the account records; delivery is CONDITIONAL (see Note).

NOTE: Welcome-email delivery (FR-9) depends on the Notification System (S25) + tenant "Welcome/Onboarding" template + Hangfire (S28). If delivery is a LOG-ONLY/stub in this increment, assert the enqueued job/outbox row (tenant_id, recipient, template) — do NOT weaken to "no email". Onboarding-checklist generation (FR-8) is owned by the Onboarding module and is asserted only at the trigger seam in TC-REC-010-05.

## 2. Related Requirements
- User Story: US-REC-010
- Acceptance Criteria: AC-3
- Functional Requirements: FR-5 (User + UserTenant + Employee role if enabled), FR-9 (welcome email)
- Non-Functional Requirements: NFR-5 (email async via Hangfire, non-blocking)
- Business Rules: BR-7 (account creation optional, controlled by tenant setting)
- Dependencies: Authentication module (user/user_tenant/role), Notification System S25, Hangfire S28

## 3. Preconditions
- Tenant "acme"; setting "Auto-create user accounts on hire" = ENABLED.
- Applicant {acme_applicantId} Hired with Accepted offer; email maya.f@example.com NOT already a user in acme.
- Default "Employee" role exists in acme.
