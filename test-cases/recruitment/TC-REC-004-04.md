# TC-REC-004-04: Soft gates -- moving to Offer with no scorecard / to Interview with no schedule warns (overridable by Manage), not hard-blocked (FR-1, BR-1)

## 1. Test Objective
Verify FR-1 / BR-1 with the Phase-1 "soft gate" constraint (S10/S34, story assumptions): gate criteria for gated stages are enforced as WARNINGS that a `Recruitment.Manage.All` user can override, not hard blocks. Specifically: moving to "Offer" with zero completed interview scorecards, and moving to "Interview" with no scheduled interview, surface a confirmation dialog listing each gate criterion with pass/fail status; the user may proceed with override. NOTE: the gate data sources are US-REC-005 (interview scheduling) and US-REC-006 (scorecards). If those are not yet delivered, the gate evaluator is STUBBED -- this case asserts the soft-gate contract (warn + pass/fail list + overridable), CONDITIONAL on the gate dependencies, NOT a hard pass/fail of real scorecard data.

## 2. Related Requirements
- User Story: US-REC-004
- Functional Requirements: FR-1
- Business Rules: BR-1
- Dependencies: US-REC-005 (interview schedule gate), US-REC-006 (scorecard gate), US-REC-007 (offer workflow)

## 3. Preconditions
- Tenant "acme"; recruiter with `Recruitment.Manage.All` authenticated.
- Applicant "Pat Kim" at "Interview" with NO completed scorecard (gate for Offer not met).
- Applicant "Lee Ray" at "Screening" with NO scheduled interview (gate for Interview not met).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Default gates (BR-1) | Screening->notes; Interview->>=1 scheduled interview; Offer->>=1 completed scorecard | Tenant-configurable |
| Gate mode (Phase 1) | Soft (warn + override) | S10/story assumption #10.1 |
| Override actor | Recruitment.Manage.All | Required to override |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Attempt to move Pat Kim "Interview" -> "Offer" (no scorecard) | A confirmation dialog appears listing gate criteria with pass/fail icons; the "completed scorecard" criterion shows FAIL (red); the move is NOT silently allowed without acknowledgement (FR-1). |
| 2 | Confirm/override the gate as a Manage user | 200; the move proceeds (soft gate); stage=Offer; history row created; an override is recorded in notes/audit (overridden gate noted). |
| 3 | Attempt to move Lee Ray "Screening" -> "Interview" (no scheduled interview) | Confirmation dialog shows the "scheduled interview" criterion FAIL; warns before proceeding. |
| 4 | A user WITHOUT Manage attempts the same override | The override is not permitted for non-Manage users (cross-ref authz TC-REC-003-06); the gated move is blocked for them. |
| 5 | When gate criteria ARE met (scorecard exists) | The dialog shows all criteria PASS (green) and the move proceeds without an override prompt. |
| 6 | CONDITIONAL note | If US-REC-005/006 are not yet delivered, the gate evaluator is stubbed: assert that the soft-gate seam (warn + pass/fail list + overridable-by-Manage) exists and defaults to allowing the move with a warning; do NOT weaken to "no gate at all". |

## 6. Postconditions
- Gated moves either surfaced a pass/fail warning and proceeded under a Manage override, or proceeded cleanly when criteria were met; the soft-gate contract held.
