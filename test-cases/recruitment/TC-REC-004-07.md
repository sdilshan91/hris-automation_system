# TC-REC-004-07: "Hired" is terminal and irreversible and triggers the applicant-to-employee conversion workflow (BR-3)

## 1. Test Objective
Verify BR-3: reaching "Hired" is a terminal, IRREVERSIBLE state -- no forward, backward, reactivation, or rejection move is permitted out of Hired -- and it fires the applicant-to-employee conversion workflow seam (owned by US-REC-010). This extends TC-REC-003-09 (which asserted the convert seam) with explicit irreversibility from every move type.

## 2. Related Requirements
- User Story: US-REC-004
- Business Rules: BR-3
- Functional Requirements: FR-2, FR-5
- Dependencies: US-REC-010 (applicant-to-employee conversion)

## 3. Preconditions
- Tenant "acme".
- Applicant "Morgan Tate" at "Offer" with headcount available.
- Recruiter with `Recruitment.Manage.All` authenticated.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Applicant | Morgan Tate ({acme_applicantId}) | At Offer |
| Terminal stage | Hired | Irreversible |
| Conversion workflow | US-REC-010 seam | Triggered on Hired |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Move Offer -> Hired | 200; stage=Hired; history row from=Offer, to=Hired; the convert-to-employee workflow is triggered (event/outbox/job seam observable). |
| 2 | Attempt Hired -> any forward stage | Rejected; there is no forward stage past Hired; no change. |
| 3 | Attempt Hired -> Offer (backward) even as Manage | Rejected: Hired is irreversible (BR-3); no history row; no change. |
| 4 | Attempt to Reject a Hired applicant | Rejected: cannot reject from a terminal Hired state (cross-ref TC-REC-004-03 step 6). |
| 5 | Verify the conversion trigger | A conversion request/event is enqueued (Hangfire/outbox) referencing the applicant; the actual employee-record creation is owned by US-REC-010 (asserted as a seam here, CONDITIONAL on that story). |
| 6 | Verify idempotency of the trigger | Re-issuing the same Offer->Hired (e.g. retried request) does not double-trigger conversion or create a duplicate Hired history row. |

## 6. Postconditions
- Morgan Tate is permanently "Hired"; the conversion workflow is triggered exactly once; no move escapes the terminal state.
