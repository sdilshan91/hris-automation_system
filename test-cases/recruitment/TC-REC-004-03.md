# TC-REC-004-03: Rejection is allowed from EVERY active stage (Applied, Screening, Interview, Offer) with reason recorded (AC-4, FR-3)

## 1. Test Objective
Verify FR-3 / AC-4: an applicant can be rejected from ANY active (non-terminal) stage -- Applied, Screening, Interview, and Offer -- not only from Screening. Each rejection records the correct from_stage in the history row and the structured reason. This is the per-stage coverage of the rejection path that TC-REC-004-02 establishes for a single stage.

## 2. Related Requirements
- User Story: US-REC-004
- Acceptance Criteria: AC-4
- Functional Requirements: FR-3
- Business Rules: BR-2 (rejection is a terminal state until reactivation -- see TC-REC-004-05)

## 3. Preconditions
- Tenant "acme"; recruiter with `Recruitment.Manage.All` authenticated.
- Four distinct applicants positioned one at each active stage: A@Applied, B@Screening, C@Interview, D@Offer.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Applicant A | at Applied | reject reason=PositionFilled |
| Applicant B | at Screening | reject reason=NotQualified |
| Applicant C | at Interview | reject reason=Withdrew |
| Applicant D | at Offer | reject reason=Other + notes |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Reject Applicant A (from Applied) with reason=PositionFilled | 200; stage=Rejected; history row from=Applied, to=Rejected, reason stored. |
| 2 | Reject Applicant B (from Screening) with reason=NotQualified | 200; history row from=Screening, to=Rejected. |
| 3 | Reject Applicant C (from Interview) with reason=Withdrew | 200; history row from=Interview, to=Rejected. |
| 4 | Reject Applicant D (from Offer) with reason=Other + notes | 200; history row from=Offer, to=Rejected, reason=Other, notes stored. |
| 5 | Attempt to reject an already-Rejected applicant | Blocked / no-op (already terminal); no second Rejected->Rejected history row created. |
| 6 | Attempt to reject a Hired applicant | Blocked: Hired is terminal and irreversible (cross-ref BR-3 / TC-REC-004-07); rejection from Hired is not permitted. |

## 6. Postconditions
- Four applicants are Rejected, each with the correct from_stage and a structured reason; terminal stages cannot be re-rejected.
