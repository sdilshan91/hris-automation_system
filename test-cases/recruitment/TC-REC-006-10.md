# TC-REC-006-10: Rating boundaries (1-5) + completeness -- out-of-range, non-integer, or missing-criterion ratings rejected; average computed correctly

## 1. Test Objective
Verify FR-1 / FR-3 boundary + completeness rules: each criterion score must be an integer in the inclusive range 1-5. Scores at the boundaries (1 and 5) are accepted; 0, 6, negative, non-integer, and missing values are rejected. A submission missing a rating for any configured criterion is rejected (all configured criteria must be rated; comments remain optional). The average is computed correctly across edge distributions (all-1s, all-5s, mixed) with the documented rounding behaviour.

- User Story: US-REC-006
- Functional Requirements: FR-1, FR-3
- Acceptance Criteria: AC-1
