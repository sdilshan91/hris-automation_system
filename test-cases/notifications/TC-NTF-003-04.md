# TC-NTF-003-04: "Reset to Defaults" restores tenant-level default preferences

## 1. Test Objective
Verify that after a user customizes several preferences, invoking "Reset to Defaults" (with
confirmation) discards all personal overrides and restores the user's effective preferences to the
tenant-level defaults.

## 2. Related Requirements
- User Story: US-NTF-003
- Acceptance Criteria: AC-1 (matrix reflects restored toggle states)
- Functional Requirements: FR-7 ("Reset to Defaults" restores tenant-level defaults), FR-5 (cascade)
- Business Rules: BR-1 (tenant defaults are the baseline)

## 3. Preconditions
- Tenant A defaults: e.g. "Leave Updates" In-App ON / Email ON; "Payroll Notifications" In-App ON / Email ON.
- Employee `emp1` has customized: "Leave Updates" Email = OFF and "Payroll Notifications" In-App = OFF.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| custom: Leave Updates Email | false | personal override |
| custom: Payroll Notifications In-App | false | personal override |
| tenant default: Leave Updates | in-app ON / email ON | restore target |
| tenant default: Payroll Notifications | in-app ON / email ON | restore target |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `emp1`, confirm current customized state on the preferences page | "Leave Updates" Email = OFF; "Payroll Notifications" In-App = OFF |
| 2 | Click "Reset to Defaults" | A confirmation dialog appears asking the user to confirm restoring tenant defaults |
| 3 | Cancel the dialog | No change; customized state preserved (negative branch) |
| 4 | Click "Reset to Defaults" again and confirm | Personal overrides are removed; a "Saved"/success toast appears |
| 5 | Inspect every toggle on the matrix | All categories now match Tenant A defaults: "Leave Updates" Email = ON, "Payroll Notifications" In-App = ON (FR-7) |
| 6 | Reload the page | Restored (tenant-default) state persists |

## 6. Postconditions
- `emp1`'s effective preferences equal Tenant A defaults; no personal overrides remain.
