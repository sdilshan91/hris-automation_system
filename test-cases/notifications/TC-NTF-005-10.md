# TC-NTF-005-10: Pagination 50/page with working "next"; keyset (FR-6) DEFERRED — offset pagination in force today

## 1. Test Objective
Verify pagination boundary behavior: results paginate at 50 per page (default), the "next" page
control returns the subsequent 50 rows in correct reverse-chronological order with no duplicates or
gaps, and the configured page size respects the max of 100. The FR-6 KEYSET (cursor) pagination is
DEFERRED -- offset-based pagination is in force today; the cursor expectation is asserted conditionally.

## 2. Related Requirements
- User Story: US-NTF-005
- Acceptance Criteria: AC-1 (paginated table)
- Functional Requirements: FR-6 (50/page, server-side pagination; keyset/cursor -- DEFERRED)
- Data spec: page_size default 50, max 100; page_cursor (DEFERRED)
- Base coverage (reference): US-ADM-008 TC-ADM-008-02 (pagination boundaries)

## 3. Preconditions
- `adminA` (Audit.View) authenticated in Tenant A.
- >= 120 audit rows exist for Tenant A so at least 3 pages are produced.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| total rows | >= 120 | spans 3 pages |
| default page size | 50 | per FR-6 |
| max page size | 100 | per data spec |
| oversize request | page_size = 500 | must be clamped/rejected |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the audit log (default) | First page shows 50 rows, newest first |
| 2 | Click "next" | Next 50 rows (rows 51-100) shown; correct reverse-chronological continuation; no duplicates or skipped rows vs page 1 |
| 3 | Click "next" again | Final page shows the remaining rows (e.g. 101-120) |
| 4 | Page back to page 1 | Same first 50 rows returned (stable ordering) |
| 5 | [Boundary] Request page_size = 500 | Clamped to 100 or rejected per the max-100 rule (US-ADM-008 TC-ADM-008-02) |
| 6 | [DEFERRED -- FR-6 keyset] Where cursor pagination is wired | A `next page_cursor` (keyset) is returned and used instead of OFFSET for stable, performant deep paging. Documented as DEFERRED -- offset pagination is the mechanism in force today; the SLA (NFR-2 <= 3s) is not relaxed on the dev box |

## 6. Postconditions
- Pagination returns consistent 50-row pages; deep paging works (offset today, keyset deferred).
