# TC-NTF-004-09: Performance -> bulk operation (payroll 500 employees) adds <= 50ms/save overhead and does not block the transaction

## 1. Test Objective
Verify that audit capture during a high-throughput bulk operation (e.g. a payroll run over 500
employees) adds no more than 50 ms overhead per save operation (P95) and does not noticeably degrade
or block the business transaction. Confirms NFR-1 (<=50ms overhead P95) and NFR-5 (high-throughput,
non-blocking).

## 2. Related Requirements
- User Story: US-NTF-004
- Acceptance Criteria: AC-1 (capture must not impair the operation)
- Non-Functional: NFR-1 (audit overhead <= 50ms per save, P95), NFR-5 (handle bulk without blocking the business transaction)
- (Supporting) NFR-3 (BRIN index keeps append cheap)

## 3. Preconditions
- A perf-representative environment with 500+ employees in Tenant A. NOTE: on a dev box, record
  indicative numbers and do NOT relax the 50ms threshold (perf env owns the pass/fail call).
- Audit interceptor enabled; a baseline measurement of the same operation with auditing disabled is available for the delta.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| operation | payroll run | generates one+ write per employee |
| employee count | 500 | bulk scale |
| overhead threshold | <= 50ms/save (P95) | NFR-1 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Measure the payroll run for 500 employees with auditing DISABLED (baseline) | Baseline per-save and total duration captured |
| 2 | Measure the same payroll run with auditing ENABLED | Audit rows are produced for every write; total + per-save duration captured |
| 3 | Compute the per-save audit overhead (enabled - baseline), P95 | P95 overhead per save <= 50 ms (NFR-1) |
| 4 | Confirm the business transaction is not blocked | The payroll run completes successfully; audit writes participate without deadlock/timeout and without holding the transaction open beyond the business work (NFR-5) |
| 5 | Confirm audit completeness under load | The audit row count equals the number of write operations -- no rows dropped under bulk throughput |
| 6 | Inspect tenant scoping at scale | Every produced audit row carries tenant_id = Tenant A |

## 6. Postconditions
- Bulk run completes within SLA; audit overhead <= 50ms/save P95; all writes audited; nothing blocked.
