# TC-NTF-005-04: Actor autocomplete type-ahead returns tenant-scoped matches by name/email

## 1. Test Objective
Verify the FR-2 actor autocomplete DELTA: typing into the actor filter returns type-ahead suggestions
matching by name or email, and the suggestion list is strictly tenant-scoped (no users from other
tenants appear). Selecting a suggestion resolves to that actor's user id and filters the table.

## 2. Related Requirements
- User Story: US-NTF-005
- Acceptance Criteria: AC-2 (actor filter)
- Functional Requirements: FR-2 (actor search with autocomplete by name/email)
- Base coverage (reference): US-ADM-008 TC-ADM-008-04 (filter by actor, without autocomplete lookup)
- Isolation companion: TC-NTF-ISO-018

## 3. Preconditions
- `adminA` (Audit.View) authenticated in Tenant A.
- Tenant A users include "John Doe <john.doe@a.example>" and "Joan Davis <joan.davis@a.example>".
- Tenant B has a user "John Diaz" (must NOT appear in adminA's autocomplete).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| type-ahead query | "joh" | prefix matching name |
| type-ahead query (email) | "joan.dav" | prefix matching email |
| expected suggestions | John Doe, Joan Davis (by name); Joan Davis (by email) | Tenant A only |
| cross-tenant user | John Diaz (Tenant B) | must NOT appear |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | In the actor filter, type "joh" | Type-ahead suggestions appear including "John Doe" (name match); list updates as typing |
| 2 | Confirm tenant scoping | Tenant B's "John Diaz" does NOT appear in suggestions regardless of query |
| 3 | Clear and type an email fragment "joan.dav" | "Joan Davis" suggested via email match (FR-2 name/email search) |
| 4 | Select "John Doe" from the dropdown | Actor filter resolves to John Doe's actor_user_id; the table filters to John Doe's rows |
| 5 | Inspect the URL | actor_user_id query param is set (FR-3); the human-readable name is a display label only |
| 6 | Type a string matching no Tenant A user | Empty/"no matches" state shown; no error |

## 6. Postconditions
- Actor autocomplete returns tenant-scoped matches only; selection drives a tenant-scoped filter.
