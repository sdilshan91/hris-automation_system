# TC-NTF-005-05: Keyword search matches content inside before/after JSONB payloads

## 1. Test Objective
Verify the FR-2 keyword-search DELTA: a keyword search matches text occurring anywhere within the
`before`/`after` JSONB payloads of audit rows (not just the change summary), so an admin can find
records by a value that was changed (e.g. an old job title or a department name). US-ADM-008
TC-ADM-008-07 covered keyword over the change summary; this re-affirms and extends to JSONB content.

## 2. Related Requirements
- User Story: US-NTF-005
- Acceptance Criteria: AC-2 (keyword filter)
- Functional Requirements: FR-2 (keyword full-text search across before/after JSONB)
- Non-Functional: NFR-7 (GIN index on JSONB leveraged -- assert behavior; index existence is infra-conditional)
- Base coverage (reference): US-ADM-008 TC-ADM-008-07

## 3. Preconditions
- `adminA` (Audit.View) authenticated in Tenant A.
- Seeded rows include an Employee.Update whose `before` JSONB contains jobTitle "Analyst" and `after`
  contains jobTitle "Senior Analyst"; plus unrelated rows with no occurrence of the keyword.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| keyword (in after) | "Senior Analyst" | present only in `after` JSONB of the target row |
| keyword (in before) | "Analyst" | present in `before` JSONB |
| keyword (no match) | "Nonexistent-XYZ" | matches no row |
| max length | 200 chars | per data spec |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Enter keyword "Senior Analyst"; apply | The Employee.Update row whose `after` JSONB contains "Senior Analyst" is returned |
| 2 | Enter keyword "Analyst"; apply | Rows whose `before` OR `after` JSONB contains "Analyst" are returned (matches inside JSONB, both sides) |
| 3 | Enter "Nonexistent-XYZ"; apply | Empty result set + zero count; no error |
| 4 | Combine keyword with a date range; apply | AND logic: only rows that match the keyword AND fall within the date window are returned |
| 5 | Inspect the URL | keyword query param is encoded (FR-3); special characters URL-escaped |
| 6 | [Performance note] On a large tenant dataset, observe response | Query completes within NFR-2 (<= 3s P95); GIN index on JSONB leveraged where provisioned (NFR-7, infra-conditional) |

## 6. Postconditions
- Keyword search resolves against JSONB payload content; results remain tenant-scoped.
