# TC-NTF-004-11: System-level actions audited separately and visible only to System Admins (tenant admins cannot see them)

## 1. Test Objective
Verify that audit records for system-level actions (tenant lifecycle, impersonation) are kept in a
separate system-audit visibility scope (`system_audit_log` per BR-4) and are visible ONLY to System
Admins -- a Tenant Admin querying the tenant audit log never sees system-level rows. Confirms BR-4.

## 2. Related Requirements
- User Story: US-NTF-004
- Acceptance Criteria: AC-5 (tenant-scoped visibility) -- extended to the system/tenant audit separation
- Business Rules: BR-4 (system-level audit -> separate system_audit_log, visible only to System Admins)

## 3. Preconditions
- A System Admin `sysadmin` and a Tenant A Admin `tadminA` both exist and are authenticated in their respective contexts.
- A system-level action has occurred (e.g. a tenant lifecycle change, or an impersonation session).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| system action | tenant suspend / impersonation start | system-level |
| tenant action | an Employee.Update in Tenant A | tenant-level |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Trigger a system-level action (e.g. impersonation start by `sysadmin`) | A system-level audit record is created |
| 2 | As `sysadmin`, query the system audit visibility | The system-level record is returned to the System Admin |
| 3 | As `tadminA`, query the Tenant A audit log | Only TENANT-level Tenant A rows are returned; the system-level record is NOT visible to the tenant admin |
| 4 | Confirm separation of concern | System-level records are stored/scoped separately (BR-4 `system_audit_log`) from tenant business-data audit rows |
| 5 | [PLATFORM NOTE -- CONDITIONAL] If the current implementation uses a SINGLE audit table with a system/tenant discriminator rather than a separate `system_audit_log` table | The discriminator + the tenant query path MUST still exclude system-level rows from a tenant admin's view; record this single-table reality as the current state and BR-4's dedicated table as a deferred refinement |

## 6. Postconditions
- System-level audit is visible to System Admins only; tenant admins see tenant rows only.
