# TC-NTF-005-08: Permission — only Audit.View roles can read; Auditor cannot export; no write/delete via UI

## 1. Test Objective
Verify the FR-8 / BR-1/2/6 authorization model for the viewer: only users with the Audit.View
permission (Tenant Admin, Tenant Owner, Auditor) can open the audit log; users without it are denied;
the Auditor role is read-only (cannot export); and the viewer exposes NO path to write, edit, or delete
audit records. Base authz is in US-ADM-008 TC-ADM-008-12/-13/-17; this re-affirms under US-NTF-005.

## 2. Related Requirements
- User Story: US-NTF-005
- Acceptance Criteria: AC-1 (only authorized admins view), AC-4 (export -- gated for Auditor)
- Functional Requirements: FR-8 (Audit.Read/Audit.View permission), FR-5 (export gating)
- Business Rules: BR-1 (only Audit.Read can access), BR-2 (read-only, no modify/delete via UI), BR-6 (Auditor read-only)
- Base coverage (reference): US-ADM-008 TC-ADM-008-12, TC-ADM-008-13, TC-ADM-008-17

## 3. Preconditions
- Tenant A has: `adminA` (Tenant Admin), `ownerA` (Tenant Owner), `auditorA` (Auditor), `hrA` (HR Officer, no Audit.View).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Tenant Admin | adminA | full view + export |
| Tenant Owner | ownerA | full view + export |
| Auditor | auditorA | view only, NO export |
| HR Officer | hrA | NO Audit.View |
| anonymous | (no token) | unauthenticated |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `adminA` / `ownerA`, open the audit log | Access granted; list renders (FR-8) |
| 2 | As `auditorA`, open the audit log | Access granted (read) -- Auditor has Audit.View (BR-6) |
| 3 | As `auditorA`, attempt Export | Export is denied -- Auditor is read-only (no export control / API returns 403) (AC-4, BR-6) |
| 4 | As `hrA`, attempt to open the audit log (UI + direct API) | Denied -- 403 (lacks Audit.View) (BR-1) |
| 5 | Unauthenticated request to the audit list endpoint | 401 |
| 6 | Inspect the viewer + API surface for any write path | No create/update/delete endpoint or UI control exists for audit records (BR-2) -- attempting a mutating verb on an audit resource returns 404/405 |

## 6. Postconditions
- Read access limited to Audit.View roles; Auditor cannot export; audit data is read-only.
