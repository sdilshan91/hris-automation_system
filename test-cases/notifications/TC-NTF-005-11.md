# TC-NTF-005-11: Table + filters keyboard-navigable with ARIA; responsive card list at 360px (WCAG 2.1 AA)

## 1. Test Objective
Verify NFR-5 / NFR-4: the audit log table and the new filter controls (multi-select dropdowns, actor
autocomplete, date range picker, keyword box) are fully keyboard-operable and expose correct ARIA
roles/labels for screen readers, and the table collapses to a responsive card list at 360px width.

## 2. Related Requirements
- User Story: US-NTF-005
- Non-Functional: NFR-5 (WCAG 2.1 AA -- keyboard nav, screen reader for data cells), NFR-4 (responsive 360px-4K)
- Functional Requirements: FR-1 (table), FR-2 (filter controls)

## 3. Preconditions
- `adminA` (Audit.View) authenticated in Tenant A on a desktop browser + a 360px viewport.
- An automated a11y checker (e.g. axe) is available; a screen reader is available for spot checks.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| viewport (mobile) | 360px wide | card-list breakpoint |
| viewport (desktop) | >= 1280px | full table |
| a11y target | WCAG 2.1 AA | contrast, roles, focus |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Tab through the filter bar with the keyboard | Date range picker, action multi-select, resource-type multi-select, actor autocomplete, keyword box, Apply are all reachable and operable by keyboard; visible focus indicator on each |
| 2 | Open the action multi-select via keyboard | Checkboxes toggle with Space/Enter; "Select All" reachable; dropdown closes with Esc; ARIA listbox/option roles + aria-checked present |
| 3 | Operate the actor autocomplete via keyboard | Arrow keys move through suggestions, Enter selects; combobox/aria-activedescendant semantics present |
| 4 | Tab into the table and select a row | Row focusable and openable via keyboard (Enter); column headers expose sortable state via ARIA; data cells associated with headers for screen-reader announcement |
| 5 | Run the automated a11y checker on the viewer | No WCAG 2.1 AA violations (contrast, names/roles/values, focus order) |
| 6 | Resize to 360px | Table collapses to a card list; each card shows key fields; tapping a card opens the full detail panel (NFR-4) |

## 6. Postconditions
- Viewer is operable by keyboard and screen reader and responsive down to 360px.
