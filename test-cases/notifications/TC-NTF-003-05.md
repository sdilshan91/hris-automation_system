# TC-NTF-003-05: Cannot disable BOTH channels for a non-mandatory category (at least one must remain)

## 1. Test Objective
Verify that for a non-mandatory category, the system enforces BR-3: at least one channel (In-App or
Email) must remain enabled. An attempt to turn off the second/last channel is blocked in the UI and
rejected by the API; disabling only one channel is allowed.

## 2. Related Requirements
- User Story: US-NTF-003
- Acceptance Criteria: AC-2 (channel toggles; preference persisted)
- Functional Requirements: FR-3 (channel toggles), FR-6 (applied at dispatch)
- Business Rules: BR-3 (at least one channel must remain enabled for non-mandatory categories)

## 3. Preconditions
- "Leave Updates" is non-mandatory for Tenant A; `emp1` has both channels ON.
- Employee `emp1` is authenticated within Tenant A and on the preferences page.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| category | Leave Updates | non-mandatory |
| step: disable Email | allowed | one channel remains (In-App) |
| step: then disable In-App | blocked | would leave zero channels |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Disable Email for "Leave Updates" | Allowed; In-App remains ON; auto-save persists channel_in_app=true, channel_email=false |
| 2 | Attempt to also disable In-App for "Leave Updates" (UI) | The toggle is prevented/reverts; a validation message explains at least one channel must stay enabled; no change persisted |
| 3 | Attempt the same via the API (PUT channel_in_app=false AND channel_email=false for a non-mandatory category) | API rejects with 400/422 and a clear validation error; record unchanged (channel_in_app=true, channel_email=false) |
| 4 | Re-enable Email, then attempt to disable In-App only (leaving Email ON) | Allowed; record now channel_in_app=false, channel_email=true (the inverse single-channel state is valid) |
| 5 | Reload the page | Persisted state reflects exactly one enabled channel; never zero |

## 6. Postconditions
- "Leave Updates" for `emp1` always has >= 1 channel enabled; no zero-channel state was ever saved.
