# TC-NTF-003-09: A user cannot modify another user's preferences (endpoint operates on current user only)

## 1. Test Objective
Verify that the preference endpoints operate strictly on the authenticated current user. A user
cannot read or write another user's preferences, whether by supplying a different user_id in the
body/path or by guessing a preference_id (IDOR). Cross-user access is denied without disclosing
existence.

## 2. Related Requirements
- User Story: US-NTF-003
- Acceptance Criteria: AC-2 (preference persisted with tenant_id + user_id)
- Functional Requirements: FR-1 (preference matrix per user), FR-8 (tenant_id + user_id set from session)
- Business Rules: BR-4 (preferences are per user, per tenant membership)

## 3. Preconditions
- Tenant A has two employees: `emp1` and `emp2`, each with their own preference set.
- `emp1` is authenticated within Tenant A.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| attacker | emp1 | authenticated |
| victim | emp2 | same tenant |
| victim preference_id | <emp2's record id> | for IDOR attempt |
| forged body user_id | emp2 | injected into write payload |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `emp1`, GET own preferences | Returns ONLY `emp1`'s matrix; user_id scoped to emp1 from the session, never from a client-supplied value |
| 2 | As `emp1`, GET `emp2`'s preference by emp2's preference_id (IDOR) | 404 Not Found (existence not disclosed); emp2's data never returned |
| 3 | As `emp1`, PUT a preference change with a forged body user_id = emp2 | The server IGNORES the client user_id and applies the change to emp1 only (or rejects); emp2's preferences are NOT modified |
| 4 | As `emp1`, attempt to PUT directly against emp2's preference_id | 404 Not Found; no write performed; emp2 record unchanged |
| 5 | As `emp2`, GET own preferences | emp2's preferences are exactly as before -- unaffected by emp1's attempts |

## 6. Postconditions
- Preference writes always bind to the authenticated user; no cross-user read/write succeeded.
