# TC-NTF-001-09: Unread badge "99+" display cap (boundary)

## 1. Test Objective
Verify the unread-count badge displays the actual number up to 99 and renders "99+" for any
unread count of 100 or more, without layout breakage. Validates the FR-5 max-display rule and
its boundary at 99/100.

## 2. Related Requirements
- User Story: US-NTF-001
- Acceptance Criteria: AC-2
- Functional Requirements: FR-5 (badge, max display "99+")

## 3. Preconditions
- `emp1` (Tenant A) logged in, SignalR connected.

## 4. Test Data
| Field | Value | Expected badge |
|-------|-------|----------------|
| unread = 1 | 1 | "1" |
| unread = 99 | 99 | "99" |
| unread = 100 | 100 | "99+" |
| unread = 250 | 250 | "99+" |
| unread = 0 | 0 | hidden / no badge |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Set `emp1`'s unread count to 99 | Badge displays "99" |
| 2 | Push 1 more notification (unread = 100) | Badge updates to "99+" in real time |
| 3 | Push more to reach 250 | Badge stays "99+" (no overflow / layout break) |
| 4 | Mark notifications read until unread = 99 | Badge returns to "99" |
| 5 | Mark all read (unread = 0) | Badge hidden entirely |
| 6 | Verify badge container at "99+" across 360px and desktop widths | No clipping, wrapping, or overlap with the bell icon |

## 6. Postconditions
- Badge correctly capped; no visual defects at any tested count.
