# TC-NTF-002-12: Template list/editor load and email render within SLA; persistence + versioning

## 1. Test Objective
Verify the template list correctly reflects Default/Custom status with versioning and last-modified
metadata (AC-1), that saving persists/version-increments the override (AC-3), and that load and render
operations meet their performance SLAs.

## 2. Related Requirements
- User Story: US-NTF-002
- Acceptance Criteria: AC-1 (list shows event types + Default/Custom status), AC-3 (persist; version)
- Non-Functional: NFR-1 (editor page load <= 1s P95), NFR-3 (email render <= 200ms/email)
- Supporting: BR-3 (HTML + plain-text)

## 3. Preconditions
- Tenant A active with several default templates and at least one custom override.
- Tenant Admin A is authenticated.
- A perf-representative environment for the timed measurements (record indicative numbers on a dev box).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| event types | leave_approved, onboarding_welcome, payslip_published, password_reset | from the list |
| NFR-1 budget | <= 1000ms P95 | editor page load |
| NFR-3 budget | <= 200ms | template + data merge per email |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the template list | All available event types are listed, each with a Default/Custom badge, language, and last-modified date (AC-1) |
| 2 | Edit and save a template; reopen the list | Status flips to "Custom"; version is incremented; last-modified updated; both HTML and plain-text persisted (AC-3, BR-3) |
| 3 | Measure editor page load (P95 over repeated loads) | <= 1000ms P95 (NFR-1) on the perf-representative env; record the figure |
| 4 | Measure template+data render time per email during dispatch | <= 200ms per email (NFR-3); record the figure |
| 5 | Save with a missing required field (e.g. empty subject) | Validation blocks save; no version increment; clear error shown |
| 6 | If on a dev box | Record indicative numbers; do NOT relax the NFR-1/NFR-3 thresholds |

## 6. Postconditions
- List/status/versioning verified; load and render timings recorded against SLA.
