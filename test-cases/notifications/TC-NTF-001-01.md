# TC-NTF-001-01: Leave approval triggers a real-time in-app notification within 2s (happy path)

## 1. Test Objective
Verify that when a manager approves an employee's leave request, the employee receives a
real-time in-app notification through SignalR within 2 seconds: the bell badge increments and,
if the panel is open, the notification slides in at the top. Validates the primary success path.

## 2. Related Requirements
- User Story: US-NTF-001
- Acceptance Criteria: AC-2
- Functional Requirements: FR-3 (persist), FR-4 (push), FR-5 (badge)
- Non-Functional: NFR-1 (<= 2s delivery)

## 3. Preconditions
- Tenant A is active; employee `emp1` and manager `mgr1` both belong to Tenant A.
- `emp1` is logged in, SPA loaded, SignalR connection established (see TC-NTF-001-05), badge = 0.
- `emp1` has a pending leave request awaiting `mgr1`'s approval.
- Redis backplane is available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| recipient user_id | emp1 | Tenant A |
| approver user_id | mgr1 | Tenant A |
| notification type | leave_approved | |
| resource_type | LeaveRequest | |
| resource_id | LR-1001 | the approved request |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `emp1`, open the notification panel and confirm starting state | Badge = 0, panel shows no unread items |
| 2 | As `mgr1` (separate session), approve `emp1`'s leave request LR-1001 | Approval saved successfully |
| 3 | Start a stopwatch at the moment the approval is persisted | Timer running |
| 4 | Observe `emp1`'s client | Within <= 2s a `leave_approved` notification is pushed via SignalR; badge increments 0 -> 1 with bounce animation |
| 5 | Observe the open panel on `emp1`'s client | The new notification slides in at the top (200ms ease-out) showing type icon, title, message, relative timestamp, unread (bold + blue dot) |
| 6 | Inspect the `notification` table | A row exists with tenant_id=Tenant A, user_id=emp1, type=leave_approved, resource_type=LeaveRequest, resource_id=LR-1001, is_read=false, created_at set |

## 6. Postconditions
- One unread notification persisted for `emp1`; badge = 1.
