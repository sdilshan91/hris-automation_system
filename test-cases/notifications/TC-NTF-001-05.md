# TC-NTF-001-05: SignalR connection established and tenant/user/role groups joined on bootstrap

## 1. Test Objective
Verify that on Angular app bootstrap a SignalR WebSocket connection to `/hubs/notifications` is
established, authenticated via JWT, and the client is joined to the correct tenant-scoped
(`t:{tenantId}:user:{userId}`) and role-scoped (`t:{tenantId}:role:{role}`) groups.

## 2. Related Requirements
- User Story: US-NTF-001
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1 (connect on bootstrap, JWT), FR-2 (join groups)

## 3. Preconditions
- `emp1` (Tenant A) has a valid authenticated session with a JWT containing tenant + user + role claims.
- Redis backplane available; SignalR hub running.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| tenantId | TA | Tenant A id |
| userId | emp1 | |
| role | Employee | |
| expected user group | t:TA:user:emp1 | |
| expected role group | t:TA:role:Employee | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the SPA as authenticated `emp1`; inspect network (WS) traffic | A WebSocket connection to `/hubs/notifications` is negotiated and opens; state = Connected |
| 2 | Inspect the connection request | JWT supplied via query string (`access_token`) or Authorization header; hub accepts it |
| 3 | Inspect hub-side group membership for this connection | Connection is added to `t:TA:user:emp1` and `t:TA:role:Employee` |
| 4 | Push a test notification to group `t:TA:user:emp1` | `emp1`'s client receives it (confirms user-group join) |
| 5 | Push a test notification to group `t:TA:role:Employee` | `emp1`'s client receives it (confirms role-group join) |
| 6 | Confirm group names are derived server-side from JWT claims | Client-supplied tenant/user/role values are NOT trusted for group naming |

## 6. Postconditions
- `emp1` connected and subscribed to its tenant/user/role groups.
