# TC-NTF-003-02: Mandatory "Security Alerts" toggle is locked, tooltip shown, cannot be disabled

## 1. Test Objective
Verify that a notification category configured as mandatory by the Tenant Admin (e.g. "Security
Alerts") presents a disabled (greyed-out) opt-out toggle with a lock icon and an explanatory
tooltip, and that any attempt to disable it is prevented both in the UI and at the API.

## 2. Related Requirements
- User Story: US-NTF-003
- Acceptance Criteria: AC-3 (cannot disable all channels for a mandatory category -> blocking message), AC-4 (mandatory toggle greyed out with tooltip)
- Functional Requirements: FR-4 (enforce mandatory categories that cannot be opted out)
- Business Rules: BR-2 (mandatory categories cannot be disabled by users)

## 3. Preconditions
- Tenant A's Tenant Admin has marked "Security Alerts" as mandatory (is_mandatory=true) for all users.
- Employee `emp1` is authenticated within Tenant A and on the Notification Preferences page.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| category | Security Alerts | is_mandatory = true |
| tooltip (AC-4) | "This notification is required by your organization." | on disabled toggle |
| block message (AC-3) | "Security alerts cannot be disabled. This is required by your organization's policy." | if disable attempted |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | View the "Security Alerts" row | Row shows a lock icon; both channel toggles are rendered ON and disabled (greyed out) and are not interactive |
| 2 | Hover / focus the disabled toggle | Tooltip displays: "This notification is required by your organization." (AC-4) |
| 3 | Attempt to click/toggle the disabled control | The toggle does not change state; no preference change is persisted |
| 4 | Attempt to disable the mandatory category directly via the API (PUT preference with channel_in_app=false AND channel_email=false for Security Alerts) | API rejects with 400/422; response message: "Security alerts cannot be disabled. This is required by your organization's policy." (AC-3); record remains with both channels enabled |
| 5 | Reload the page | "Security Alerts" remains enabled and locked; no change persisted |

## 6. Postconditions
- "Security Alerts" remains mandatory and enabled for `emp1`; no opt-out persisted.
