# TC-NTF-001-06: Unauthenticated SignalR connection rejected; no group join

## 1. Test Objective
Verify the `/hubs/notifications` hub rejects connection attempts that lack a valid JWT (missing,
expired, malformed, or tampered token). No groups are joined and no notifications can be received.

## 2. Related Requirements
- User Story: US-NTF-001
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1 (JWT-authenticated connection)

## 3. Preconditions
- SignalR hub running; Redis backplane available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| no token | (omitted) | |
| expired token | JWT exp in past | |
| malformed token | "abc.def" | not a valid JWT |
| tampered token | valid JWT w/ altered signature | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Attempt to connect to `/hubs/notifications` with NO token | Connection refused (401 during negotiate / handshake fails); not Connected |
| 2 | Attempt to connect with an EXPIRED token | Connection rejected; no group membership created |
| 3 | Attempt to connect with a MALFORMED token | Connection rejected |
| 4 | Attempt to connect with a token whose signature was TAMPERED | Connection rejected (signature validation fails) |
| 5 | Verify hub-side state after each failed attempt | No connection added to any `t:*:user:*` or `t:*:role:*` group |
| 6 | Push a notification to any group and observe the rejected client | The rejected client receives nothing |

## 6. Postconditions
- No unauthenticated connection persists; no group membership granted.
