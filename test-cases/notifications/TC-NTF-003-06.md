# TC-NTF-003-06: Invalid IANA timezone for Quiet Hours is rejected; valid one accepted (boundary)

## 1. Test Objective
Verify that the Quiet Hours timezone selector only accepts valid IANA timezone identifiers. A valid
identifier (e.g. "Asia/Colombo") is saved; an invalid/forged value (e.g. "Mars/Phobos" or an empty
string when start/end are set) is rejected by validation and not persisted.

## 2. Related Requirements
- User Story: US-NTF-003
- Acceptance Criteria: AC-2 (preferences persisted with tenant_id + user_id)
- Functional Requirements: FR-9 (Quiet Hours setting in the user's timezone)
- Data Requirements: quiet_hours_timezone varchar(50), IANA timezone

## 3. Preconditions
- Employee `emp1` is authenticated within Tenant A and on the preferences page Quiet Hours card.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| valid timezone | Asia/Colombo | valid IANA id |
| valid quiet_hours_start | 22:00 | |
| valid quiet_hours_end | 07:00 | |
| invalid timezone | Mars/Phobos | not an IANA id |
| invalid timezone (forged) | '; DROP TABLE preferences;-- | injection attempt |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Set quiet hours 22:00-07:00 with timezone "Asia/Colombo" and save | Save succeeds; record persisted with quiet_hours_timezone="Asia/Colombo", start=22:00, end=07:00, tenant_id=Tenant A, user_id=emp1 |
| 2 | Attempt to submit quiet_hours_timezone = "Mars/Phobos" via the API | Rejected with 400/422 ("invalid timezone"); prior valid value unchanged |
| 3 | Attempt to submit the injection-style timezone string via the API | Rejected by validation/sanitization; no SQL executed; value not persisted |
| 4 | Attempt to set start/end times with an empty/missing timezone via the API | Rejected with a validation error (timezone required when quiet hours are set) OR documented default; no malformed record saved |
| 5 | Reload the Quiet Hours card | Shows the last VALID state ("Asia/Colombo", 22:00-07:00); no invalid value displayed |

## 6. Postconditions
- Only a valid IANA timezone is persisted; invalid/forged inputs rejected without side effects.
