# TC-NTF-005-01: Audit log page loads paginated table newest-first with required columns; first page < 2s (re-affirm headline AC)

## 1. Test Objective
Re-affirm the headline viewer behavior for US-NTF-005: navigating to Security & Audit > Audit Log
shows a paginated, reverse-chronological table with the required columns and the first page renders
within the 2s SLA. The base list mechanics are covered in depth by US-ADM-008 (TC-ADM-008-01); this
TC re-affirms them under the Notifications story and serves as the entry point for the deltas tested
in TC-NTF-005-02..10.

## 2. Related Requirements
- User Story: US-NTF-005
- Acceptance Criteria: AC-1 (paginated table, newest first, required columns, first page < 2s)
- Functional Requirements: FR-1 (table columns), FR-7 (summary bar / retention period)
- Non-Functional: NFR-1 (first page <= 2s P95)
- Base coverage (reference, not duplicated): US-ADM-008 TC-ADM-008-01

## 3. Preconditions
- Tenant A is active; `adminA` has the Tenant Admin role (Audit.View permission).
- >= 60 audit rows exist for Tenant A (so pagination at 50/page is exercised).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| actor | adminA | Tenant Admin, Audit.View |
| tenant | Tenant A | session context |
| audit rows | >= 60 | spans multiple distinct timestamps |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `adminA`, navigate to Security & Audit > Audit Log | The viewer loads; a paginated table is shown |
| 2 | Observe column headers | Columns present: Timestamp, Actor (name + employee_no), Action, Resource Type, Resource ID, IP Address (FR-1) |
| 3 | Observe row order | Rows are reverse-chronological (newest timestamp first) |
| 4 | Observe the summary bar | Total record count for the current (unfiltered) view + tenant retention period are shown (FR-7) |
| 5 | Measure first-page render time | First 50 records render within 2 seconds (NFR-1; record indicative number on dev box, do not relax the SLA) |
| 6 | Confirm row count on first page | At most 50 rows on the first page (default page size) |

## 6. Postconditions
- The viewer is displayed with Tenant A rows only; no data is modified by viewing (see TC-NTF-005-09 for meta-audit side effect).
