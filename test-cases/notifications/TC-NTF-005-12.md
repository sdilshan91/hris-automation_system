# TC-NTF-005-12: First page < 2s and filtered queries <= 3s P95 on a large tenant dataset

## 1. Test Objective
Verify NFR-1 / NFR-2: with a large tenant audit dataset, the unfiltered first page (50 rows) loads
within 2s P95 and filtered queries (date + multi-select action + keyword over JSONB) complete within
3s P95. Confirms the deltas (multi-select, JSONB keyword) do not break the performance budget.

## 2. Related Requirements
- User Story: US-NTF-005
- Acceptance Criteria: AC-1 (first page < 2s), AC-2 (filtered refresh)
- Non-Functional: NFR-1 (first page <= 2s P95), NFR-2 (filtered <= 3s P95 up to 10M rows/tenant),
  NFR-7 (BRIN on timestamp + GIN on JSONB leveraged -- infra-conditional)
- Base coverage (reference): US-ADM-008 TC-ADM-008-21 [DEFERRED] (millions-of-rows first page < 2s)

## 3. Preconditions
- `adminA` (Audit.View) authenticated in Tenant A.
- A representative volume of audit rows is seeded for Tenant A (target: scale toward NFR-2's 10M; on a
  dev box use the largest feasible volume and record indicative numbers without relaxing the SLA).
- BRIN index on timestamp + GIN index on before/after JSONB are present where provisioned (NFR-7).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| seeded rows | as large as feasible (target ~10M) | NFR-2 scale |
| first-page SLA | <= 2s P95 | NFR-1 |
| filtered SLA | <= 3s P95 | NFR-2 |
| filter under test | last 30 days + action multi-select + keyword (JSONB) | exercises deltas |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the unfiltered first page; measure across repeated runs | First 50 rows render within 2s at P95 (NFR-1) |
| 2 | Apply date range + multi-select action + keyword; measure | Filtered query completes within 3s at P95 (NFR-2) |
| 3 | Apply a deep page navigation (e.g. page 100) | Response stays within the SLA budget (note offset-vs-keyset; keyset deferred per TC-NTF-005-10) |
| 4 | Inspect the query plan (where DB access available) | BRIN index used for the timestamp range; GIN index used for the JSONB keyword predicate (NFR-7, infra-conditional) |
| 5 | Record environment + indicative numbers | Dev-box numbers recorded; SLA thresholds NOT relaxed; flagged where a perf-representative env is needed for a true P95 |

## 6. Postconditions
- Performance budget validated (or indicative numbers + env caveat recorded); no SLA relaxation.
