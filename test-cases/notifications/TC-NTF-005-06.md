# TC-NTF-005-06: Detail panel — before/after diff highlights changed fields; full user agent + trace id with observability link

## 1. Test Objective
Re-affirm AC-3: clicking an audit row opens a detail panel that renders the before/after JSONB as a
diff, highlighting changed fields (added/green, removed/red, modified), and shows the FULL user agent
string and the trace id with a link to the observability platform. The diff-rendering base is covered
by US-ADM-008 TC-ADM-008-09/-16; this re-affirms under US-NTF-005 with emphasis on the full UA +
trace-id-link DELTA.

## 2. Related Requirements
- User Story: US-NTF-005
- Acceptance Criteria: AC-3 (detail panel with diff view, full UA, trace id + observability link)
- Functional Requirements: FR-4 (detail view with visual diff)
- Base coverage (reference): US-ADM-008 TC-ADM-008-09, TC-ADM-008-16

## 3. Preconditions
- `adminA` (Audit.View) authenticated in Tenant A.
- An Employee.Update row exists with a known field change (e.g. jobTitle Analyst -> Senior Analyst,
  one added field, one removed field) and a populated user_agent + trace_id.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| target row | Employee.Update | has before/after diff |
| modified field | jobTitle: "Analyst" -> "Senior Analyst" | highlighted modified |
| added field | phoneExt: (none) -> "204" | highlighted green/added |
| removed field | nickname: "AJ" -> (none) | highlighted red/removed |
| user_agent | full UA string | shown untruncated |
| trace_id | e.g. 00-abc...-01 | links to observability platform |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Click the Employee.Update row | A side panel/modal opens showing the full audit record |
| 2 | Inspect the diff region | before/after JSONB rendered as a diff; the modified field is highlighted; added field highlighted green; removed field highlighted red (FR-4) |
| 3 | Confirm unchanged fields | Unchanged fields are shown but not highlighted as changed |
| 4 | Inspect the user agent | The COMPLETE user agent string is displayed (not truncated) |
| 5 | Inspect the trace id | trace_id is shown and rendered as a link to the observability platform (AC-3) |
| 6 | Confirm read-only | The panel exposes no edit/save/delete controls for the audit record (BR-2) |

## 6. Postconditions
- Detail panel accurately presents the record and its diff; no mutation possible.
