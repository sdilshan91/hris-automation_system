# TC-NTF-002-11: Template editor meets WCAG 2.1 AA; keyboard-operable; responsive

## 1. Test Objective
Verify the template editor (split-pane editor + live preview, rich text toolbar, placeholder panel,
Send Test / Reset dialogs) is accessible to WCAG 2.1 AA, fully keyboard-operable, screen-reader
friendly, and responsive from 360px to 4K.

## 2. Related Requirements
- User Story: US-NTF-002
- Non-Functional: NFR-5 (WCAG 2.1 AA), NFR-4 (responsive 360px-4K)
- Supporting: FR-1 (editor), FR-3 (variable panel), FR-4 (preview), FR-8 (test email modal)

## 3. Preconditions
- Tenant Admin A is authenticated and on the "Leave Approved" editor.
- axe-core (or equivalent) and a screen reader (NVDA/VoiceOver) are available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| viewports | 360px, 768px, 1280px, 4K | responsive checks |
| tool | axe-core automated scan | zero serious/critical violations target |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run an axe-core scan on the editor page | No serious/critical WCAG 2.1 AA violations |
| 2 | Tab through the page using only the keyboard | Logical focus order reaches subject field, rich-text editor, plain-text field, variable panel items, preview toggle, Save, Send Test, Reset; visible focus indicators throughout |
| 3 | Operate the rich-text toolbar via keyboard | Formatting controls (bold/link/etc.) are reachable and operable by keyboard; have accessible names |
| 4 | Insert a placeholder from the reference panel via keyboard | Placeholder items are focusable buttons with accessible names; activation inserts at cursor |
| 5 | Open "Send Test Email" and "Reset to Default" dialogs | Focus moves into the dialog, is trapped, Esc/Cancel returns focus to the trigger; dialogs have an accessible name (role=dialog + label) |
| 6 | Verify color contrast and non-color cues | Status badges ("Default"/"Custom"), validation errors, and required fields meet >= 4.5:1 contrast and are not signalled by color alone |
| 7 | Resize from 4K down to 360px | Layout reflows to tabbed editor/preview/variables on mobile; no horizontal scroll or clipped controls; preview remains reachable |

## 6. Postconditions
- Editor passes WCAG 2.1 AA checks and is usable by keyboard and screen reader across viewports.
