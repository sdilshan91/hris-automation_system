# TC-NTF-005-03: Multi-select action & resource-type filters — OR within a group, AND across groups

## 1. Test Objective
Verify the FR-2 multi-select DELTA: selecting multiple values in the action dropdown (and/or the
resource-type dropdown) applies OR logic WITHIN each group and AND logic ACROSS groups. US-ADM-008
tested single-value action/resource-type filters; this TC validates the multi-value set semantics
plus "Select All".

## 2. Related Requirements
- User Story: US-NTF-005
- Acceptance Criteria: AC-2 (filters refresh table)
- Functional Requirements: FR-2 (action multi-select, resource type multi-select)
- Base coverage (reference): US-ADM-008 TC-ADM-008-05/-06 (single-value action/resource filters)

## 3. Preconditions
- `adminA` (Audit.View) authenticated in Tenant A.
- Seeded rows cover actions {Employee.Update, Employee.Create, Leave.Approve} across resource types
  {Employee, LeaveRequest}, with enough variety to distinguish OR vs AND.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| action multi-select | ["Employee.Update", "Leave.Approve"] | OR within group |
| resource type multi-select | ["Employee"] | AND across groups |
| distractor rows | Employee.Create / LeaveRequest rows | must be excluded or included per logic |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Select actions {Employee.Update, Leave.Approve} only; apply | Rows with action Employee.Update OR Leave.Approve are returned (OR within action group); Employee.Create rows excluded |
| 2 | Add resource-type filter {Employee}; apply | Only rows where (action in {Employee.Update, Leave.Approve}) AND (resource_type = Employee) are returned -- a Leave.Approve row whose resource_type is LeaveRequest is now EXCLUDED (AND across groups) |
| 3 | Add resource type LeaveRequest to the resource group; apply | Resource group is now {Employee, LeaveRequest} (OR within); a Leave.Approve/LeaveRequest row reappears |
| 4 | Use "Select All" on the action dropdown; apply | Action filter no longer narrows results (all known actions selected); only the resource-type group constrains the set |
| 5 | Inspect the URL after each apply | Multi-valued action and resource_type params are encoded (e.g. repeated params or comma list) consistent with FR-3 |
| 6 | Clear both multi-selects; apply | Filters removed; full (tenant-scoped) set returned |

## 6. Postconditions
- Multi-select set semantics confirmed: OR inside a group, AND between groups.
