# TC-ONB-003-02: Dashboard "Onboarding Progress" widget shows %/pending/completed/overdue + checklist link

## 1. Test Objective
Verify AC-1 and FR-4: on first login the new hire's dashboard shows a prominent "Onboarding Progress" widget displaying overall completion percentage, counts of pending / completed / overdue tasks, and a link to the full checklist. Counts reflect only the logged-in employee's own assigned tasks (FR-1).

## 2. Related Requirements
- User Story: US-ONB-003
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-4

## 3. Preconditions
- Employee "Alex Reed" authenticated in tenant `acme` with a checklist of 5 tasks: 2 completed, 2 pending (not overdue), 1 pending past due (overdue).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| total | 5 | own tasks only |
| completed | 2 | |
| pending (not overdue) | 2 | |
| overdue | 1 | due date in the past, not completed |
| expected % | 40% | 2/5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Log in as Alex Reed and land on the dashboard | The "Onboarding Progress" widget is prominently displayed (AC-1). |
| 2 | Read the completion ring/percentage | Shows 40% (2/5) (FR-4). |
| 3 | Read the task-count summary | Pending = 2 (or 3 incl. overdue per UI convention), Completed = 2, Overdue = 1 — counts derive only from Alex's own tasks, not other employees' (AC-1, FR-1). |
| 4 | Verify another employee's tasks are excluded | Tasks assigned to a different employee in the same tenant do not affect Alex's widget counts. |
| 5 | Click the "View Checklist" link | Navigates to Alex's full onboarding checklist (AC-1). |

## 6. Postconditions
- No state change; widget accurately reflects the employee's own task statuses with a working checklist link.
