# TC-ONB-006-10: Input sanitization + linkage integrity — XSS/SQLi in free text neutralized; offboarding_id/question_id must belong to tenant; client tenant_id ignored

## 1. Test Objective
Verify FR-6 and input-handling robustness: free-text answers and additional_comments containing XSS/SQL-injection payloads are stored/rendered safely (no script execution, no SQL side effects); `offboarding_id` and `responses[].question_id` must belong to the caller's tenant/template or the request is rejected; and a client-supplied `tenant_id` is ignored in favour of the session context.

## 2. Related Requirements
- US-ONB-006
- Functional Requirement: FR-6 (tenant_id from session, never client input)
- Data Requirements (S7): offboarding_id must belong to the tenant; question_id must exist in the tenant's template

## 3. Preconditions
- HR Officer authenticated in tenant `acme`; offboarding OB-A300 and its template belong to acme.
- A foreign offboarding OB-B900 and a foreign question Q-B exist in tenant `globex`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| free_text XSS | `<script>alert('x')</script>` | must be neutralized |
| free_text SQLi | `'; DROP TABLE exit_interviews;--` | must be neutralized |
| forged tenant_id | T-globex (in body) | must be ignored |
| foreign offboarding_id | OB-B900 | must be rejected (404) |
| foreign question_id | Q-B | must be rejected |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Record an interview with the XSS payload in a free_text answer | Saved/escaped; on render the payload displays as inert text, no script executes. |
| 2 | Record with the SQLi payload in additional_comments | Stored as literal text via parameterized queries; no SQL executed; table intact. |
| 3 | Submit a record with `tenant_id` = T-globex in the body but session = acme | The session tenant (T-acme) is stamped; the client value is ignored (FR-6). |
| 4 | Submit a record with offboarding_id = OB-B900 (foreign) | Rejected with 404 (existence not disclosed); no record created. |
| 5 | Submit a response whose question_id = Q-B (not in acme's template) | Rejected — question must exist in the tenant's template. |

## 6. Postconditions
- Malicious input is neutralized; tenant_id always derives from session; cross-tenant offboarding/question references are rejected.
