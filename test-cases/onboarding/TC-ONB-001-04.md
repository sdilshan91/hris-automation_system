# TC-ONB-001-04: Saving a template with zero tasks rejected (negative)

## 1. Test Objective
Verify BR-2: a template must contain at least one task to be saved. An attempt to save a template with an empty task list is rejected with a clear validation error, server-side (not only client-side).

## 2. Related Requirements
- User Story: US-ONB-001
- Acceptance Criteria: AC-2
- Business Rules: BR-2
- Data Requirements: tasks[] (≥1 required)

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Onboarding.Manage`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| template_name | Empty Template | valid name |
| tasks | [] (empty) | violates BR-2 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the builder, enter a valid template_name, add NO tasks, click Save | The Save action is blocked; a validation message indicates at least one task is required (BR-2). |
| 2 | Bypass the UI and send `POST /api/v1/onboarding/templates` with `tasks: []` directly | Response 400/422 with a field-level error on `tasks` (e.g. "At least one task is required."); NO `onboarding_template` row is created. Server-side enforcement, not UI-only. |
| 3 | Inspect the DB | No template or task rows written for tenant `acme`. |

## 6. Postconditions
- No empty template persisted.
