# TC-ONB-006-08: Boundary / negative validation — rating range, interview_date not future, free-text length caps, required answers, valid offboarding/question linkage

## 1. Test Objective
Verify the Data Requirements (S7) validation rules: rating answers must be within 1-5, `interview_date` cannot be in the future, `free_text` <= 2000 chars, `additional_comments` <= 5000 chars, `overall_experience_rating` 1-5, required questions must be answered, `interview_mode` must be a valid enum, and `conducted_by` is required when mode = hr_conducted. Invalid inputs are rejected server-side; valid boundary values are accepted.

## 2. Related Requirements
- US-ONB-006
- Functional Requirement: FR-1 (question types incl. rating 1-5)
- Data Requirements (S7): rating 1-5, interview_date not future, free_text<=2000, additional_comments<=5000, interview_mode enum, conducted_by conditional
- Acceptance Criteria: AC-2 (save with valid data)

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with the record permission.
- Offboarding OB-A300 with an in-progress exit-interview task and a template containing a required rating question, a required free-text question, and a yes/no question.
