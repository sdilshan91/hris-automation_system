# TC-ONB-002-12: Assignment UI keyboard-navigable + responsive 360px-4K (NFR-4, WCAG 2.1 AA)

## 1. Test Objective
Verify NFR-4 and the UI/UX notes: the assignment flow (template selector, task timeline preview, inline due-date/responsible-party editors, confirmation dialog) is fully keyboard-operable and screen-reader friendly (WCAG 2.1 AA), and the layout is responsive from 360px to 4K — collapsing the timeline to a vertical task list below 768px.

## 2. Related Requirements
- User Story: US-ONB-002
- Acceptance Criteria: AC-1, AC-2, AC-3
- Functional Requirements: FR-1, FR-6
- Non-Functional Requirements: NFR-4

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Onboarding.Manage`.
- An employee with no active checklist and at least one applicable active template exist.
- Tested across Chrome, Edge, Firefox, Safari at 360px, 768px, 1280px, 1920px, and 4K; screen reader available (NVDA/VoiceOver).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360 / 768 / 1280 / 1920 / 3840 px | responsive range |
| Inputs | keyboard only (Tab/Shift+Tab/Enter/Space/Esc/arrows) | no mouse |
| AT | NVDA / VoiceOver | screen reader |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the assignment flow and Tab through it using only the keyboard | Template selector, task cards, inline due-date pickers, responsible-party editors, and confirm/cancel are all reachable with a visible focus indicator in logical order. |
| 2 | Open the searchable template dropdown and select via keyboard | Options are navigable with arrow keys and selectable with Enter; the combobox exposes correct ARIA roles/state to the screen reader. |
| 3 | Edit a task due date via keyboard (date picker) | Date picker is operable by keyboard; changes commit without a mouse (FR-6). |
| 4 | Trigger the duplicate-assignment Replace/Merge dialog (AC-3) | Focus moves into the dialog, is trapped within it, Esc/closes return focus to the trigger; options are reachable and announced. |
| 5 | Run an automated a11y scan (e.g. axe) on each step | No WCAG 2.1 AA violations (contrast, names/roles/values, focus order). |
| 6 | Resize from 360px to 4K | Layout reflows with no horizontal scroll or clipping; below 768px the timeline collapses to a vertical task list sorted by due date; verified across Chrome/Edge/Firefox/Safari. |

## 6. Postconditions
- The assignment UI is operable by keyboard, screen-reader friendly, and responsive across the full viewport range and target browsers.
