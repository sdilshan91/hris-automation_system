# TC-ONB-002-08: Negative & boundary — inactive template, missing employee/template, idempotent retry

## 1. Test Objective
Verify negative and boundary handling: assignment is rejected when the template is inactive (BR-1) or when the employee or template does not exist in the tenant; and the operation is idempotent when retried within the same session (NFR-5) so a duplicate request does not create a second checklist or duplicate task instances.

## 2. Related Requirements
- User Story: US-ONB-002
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-2, FR-7
- Non-Functional Requirements: NFR-5
- Business Rules: BR-1

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Onboarding.Manage`.
- A deactivated template "Old Onboarding" exists in `acme`.
- An active template "Standard Engineer Onboarding" exists in `acme`.
- Employee "Alex Reed" exists in `acme`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| inactive template_id | "Old Onboarding" uuid | is_active = false |
| missing employee_id | random uuid not in tenant | should 404 |
| missing template_id | random uuid not in tenant | should 404 |
| idempotency key / retry | same request twice in session | NFR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | `POST /api/v1/onboarding/assignments` with the deactivated template | Rejected (422/409) — inactive templates cannot be assigned (BR-1); no instance created. |
| 2 | Assign with a non-existent employee_id | 404 (or 422) — employee not found in tenant; no instance created. |
| 3 | Assign with a non-existent template_id | 404 (or 422) — template not found in tenant; no instance created. |
| 4 | Submit a valid assignment, then immediately retry the identical request within the same session | The retry is idempotent (NFR-5): the same checklist instance is returned; NO second active checklist and no duplicate task instances are created. |
| 5 | Inspect persisted data | Exactly one active checklist with the expected single set of task instances exists for the employee. |

## 6. Postconditions
- Invalid assignments are rejected with no partial writes; a retried valid assignment yields a single checklist.
