# TC-ONB-006-11: Performance — exit interview form load <= 500 ms P95; analytics render <= 2 s for 1000 interviews

## 1. Test Objective
Verify NFR-1 and NFR-3: the exit interview questionnaire form loads within 500 ms (P95), and the analytics charts (reason pie, rating bars, trend line) render within 2 seconds for a dataset of up to 1000 exit interviews. Measurements must be taken on a performance-representative environment; on a dev box record indicative numbers and do NOT relax the thresholds.

## 2. Related Requirements
- US-ONB-006
- Non-Functional Requirements: NFR-1 (form load <= 500 ms P95), NFR-3 (analytics render <= 2 s for up to 1000 interviews)

## 3. Preconditions
- Tenant `acme` seeded with 1000 completed exit interviews and a representative questionnaire template.
- A performance-representative environment (warm caches/connection pool); load tool configured for the questionnaire-load and analytics endpoints.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| seeded interviews | 1000 | tenant acme (NFR-3 dataset) |
| form-load samples | >= 200 requests | for P95 |
| analytics dataset | 1000 interviews | charts aggregate |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Issue >= 200 questionnaire-form-load requests under representative concurrency | P95 latency <= 500 ms (NFR-1). |
| 2 | Record P50/P95/P99 and error rate for form load | P95 within budget; error rate ~0%. |
| 3 | Load the Exit Interview Summary analytics over the 1000-interview dataset | End-to-end chart render completes within 2 s (NFR-3). |
| 4 | Repeat analytics load several times and record timings | Consistently <= 2 s; if measured on a dev box, record indicative numbers and flag the environment — do NOT relax the threshold. |

## 6. Postconditions
- Recorded latency percentiles confirm NFR-1 and NFR-3 (or are flagged as indicative pending a perf-representative run).
