# TC-ONB-005-12: Accessibility + responsive — clearance dashboard keyboard navigable, WCAG 2.1 AA; 360px Kanban -> accordion

## 1. Test Objective
Verify NFR-5 and NFR-4: the offboarding clearance dashboard (Kanban board, traffic-light summary, asset-return list, completion confirmation modal) is fully keyboard navigable and screen-reader accessible to WCAG 2.1 AA, and is responsive from 360px to 4K — collapsing the Kanban into a vertical accordion on small screens (< 768px).

## 2. Related Requirements
- User Story: US-ONB-005
- Non-Functional Requirements: NFR-5 (WCAG 2.1 AA), NFR-4 (responsive 360px-4K)
- Acceptance Criteria: AC-3 (dashboard), AC-4 (completion modal)

## 3. Preconditions
- An offboarding instance with clearance tasks across four departments is open.
- Test tooling: keyboard-only navigation, a screen reader (NVDA/VoiceOver), an axe-core run, and responsive emulation at 360px / 768px / 1920px / 4K.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| viewport small | 360px | Kanban -> accordion |
| viewport breakpoint | 768px | collapse boundary |
| viewport large | 1920px / 4K | full Kanban |
| contrast target | >= 4.5:1 text, traffic-light not color-only | WCAG 2.1 AA |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate the entire clearance dashboard using only the keyboard (Tab/Shift+Tab/Enter/Space) | All clearance cards, approve/pending controls, asset "Mark Returned" buttons, and the "Complete Offboarding" button are reachable and operable; focus order is logical; focus is visible (NFR-5). |
| 2 | Inspect traffic-light indicators with a screen reader | Status is conveyed by text/ARIA (e.g. "IT clearance: approved"), not by color alone; meets non-color-only requirement (NFR-5). |
| 3 | Open the completion confirmation modal via keyboard | Focus is trapped in the modal, it is announced, and Esc/cancel returns focus to the trigger (NFR-5). |
| 4 | Run axe-core on the dashboard and modal | No serious/critical WCAG 2.1 AA violations; contrast >= 4.5:1. |
| 5 | Resize to 360px | Kanban columns collapse into a vertical accordion grouped by department; no horizontal scroll; all controls usable (NFR-4). |
| 6 | Resize to 1920px and 4K | Full multi-column Kanban renders; layout intact (NFR-4). |
| 7 | Verify in Chrome, Edge, Firefox, Safari | Layout and keyboard behavior consistent across browsers (cross-browser). |

## 6. Postconditions
- The clearance dashboard is accessible (WCAG 2.1 AA) and responsive across the full 360px-4K range and major browsers.
