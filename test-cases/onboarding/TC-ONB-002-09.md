# TC-ONB-002-09: Onboarding.Manage authorization required to assign / modify checklist

## 1. Test Objective
Verify authentication and authorization: assigning, modifying, or deleting tasks on an onboarding checklist requires an authenticated session with the `Onboarding.Manage` permission. Unauthenticated requests are rejected (401) and authenticated-but-unprivileged users are denied (403); no checklist or task instance is created or modified on a denied request.

## 2. Related Requirements
- User Story: US-ONB-002
- Acceptance Criteria: AC-1, AC-2, AC-4
- Functional Requirements: FR-3, FR-5, FR-7
- Cross-cutting: authentication + role-based authorization

## 3. Preconditions
- Tenant `acme` exists with an active template and an employee with no active checklist.
- Three callers: (a) no token; (b) a valid `acme` user WITHOUT `Onboarding.Manage` (e.g. plain Employee); (c) a valid `acme` user WITH `Onboarding.Manage` (HR Officer).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| endpoint (assign) | POST /api/v1/onboarding/assignments | requires Onboarding.Manage |
| endpoint (modify) | PATCH/DELETE /api/v1/onboarding/assignments/{id}/tasks/... | requires Onboarding.Manage |
| caller a | no Authorization header | expect 401 |
| caller b | token without Onboarding.Manage | expect 403 |
| caller c | token with Onboarding.Manage | expect 2xx |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Caller (a) POSTs an assignment with no token | 401 Unauthorized; no checklist created. |
| 2 | Caller (b) POSTs an assignment (authenticated, lacks Onboarding.Manage) | 403 Forbidden; no checklist created. |
| 3 | Caller (b) attempts to modify/soft-delete a task on an existing checklist | 403 Forbidden; no modification persisted. |
| 4 | Caller (c) POSTs the same assignment | 201 Created; checklist and task instances created. |
| 5 | Confirm no leakage of authz state | 401 vs 403 responses do not reveal whether the target employee/template exists. |

## 6. Postconditions
- Only `Onboarding.Manage` holders can assign/modify; denied callers leave system state unchanged.
