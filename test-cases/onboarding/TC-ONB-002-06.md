# TC-ONB-002-06: Notification dispatch via outbox (Manager + IT) on assignment

## 1. Test Objective
Verify AC-2, AC-5, FR-4 and NFR-3: on assignment, notification intent rows are written to the outbox in the SAME transaction as the checklist/task instances, and a Hangfire job is enqueued to dispatch them to all responsible parties — including the employee's reporting Manager and tenant IT-role users. Actual SignalR real-time push and email delivery are out of scope here (deferred to US-NTF-001 / US-NTF-002); this test asserts the outbox/intent rows and the Hangfire enqueue.

## 2. Related Requirements
- User Story: US-ONB-002
- Acceptance Criteria: AC-2, AC-5
- Functional Requirements: FR-4
- Non-Functional Requirements: NFR-3
- Dependencies (deferred delivery): US-NTF-001 (in-app SignalR), US-NTF-002 (email templates)

> PLATFORM NOTE: AC-2/AC-5 describe end-user delivery via SignalR + email. Real delivery is owned by the Notifications module (US-NTF-001/002). This test verifies the onboarding side of the contract: outbox intent rows written transactionally (NFR-3) and a Hangfire dispatch job enqueued. End-to-end delivery assertions belong to US-NTF test cases; flag to caller if a stub delivery channel is unavailable.

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Onboarding.Manage`.
- Employee "Alex Reed" has reporting manager "Dana Lee"; tenant has IT-role user "Ivo Tan".
- A template containing at least one Manager task and one IT task is active.
- Outbox table and Hangfire storage are available (Hangfire on PostgreSQL).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| recipients expected | Alex Reed, Dana Lee (Manager), Ivo Tan (IT) | per FR-4 / AC-5 |
| outbox table | notification outbox / intent rows | written in assignment transaction |
| dispatcher | Hangfire enqueued job | worker dispatches later |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Assign the template to Alex Reed via `POST /api/v1/onboarding/assignments` | 201 Created. |
| 2 | Inspect the outbox table within the same transaction boundary | Notification intent rows exist for the employee, the Manager (Dana Lee), and the IT user (Ivo Tan) (FR-4, AC-5); each carries `tenant_id` = acme. |
| 3 | Verify transactional coupling | The outbox rows and the checklist/task instances were committed together (NFR-3) — if the assignment rolls back, no outbox rows remain (verify via a forced-failure variant). |
| 4 | Inspect Hangfire | A dispatch job is enqueued referencing the outbox entries; no synchronous SignalR/email send occurs in the request path. |
| 5 | Confirm deferral boundary | No assertion is made on actual SignalR receipt or email send here — those are covered by US-NTF-001/002. |

## 6. Postconditions
- Tenant-scoped outbox intent rows for Manager + IT + Employee exist, committed atomically with the assignment, with a Hangfire dispatch job enqueued.
