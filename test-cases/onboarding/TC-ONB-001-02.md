# TC-ONB-001-02: Universal template (no department/job-title scoping) saved successfully

## 1. Test Objective
Verify the alternative valid path of FR-4 and AC-2: a template saved with empty `applicable_departments` and empty `applicable_job_titles` is persisted as "universal" (applies to all) rather than rejected.

## 2. Related Requirements
- User Story: US-ONB-001
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-4, FR-3, FR-5
- Data Requirements: applicable_departments (empty = universal), applicable_job_titles (empty = universal)

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Onboarding.Manage`.
- No template named "Company-wide Welcome" exists in tenant `acme`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| template_name | Company-wide Welcome | unique per tenant |
| applicable_departments | [] (empty) | universal scope |
| applicable_job_titles | [] (empty) | universal scope |
| tasks | 2 tasks, ≥1 mandatory | satisfies BR-2 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the template builder and enter template_name | Form accepts input. |
| 2 | Leave department and job-title selectors empty | No "required" validation fires on these fields (they are optional, FR-4). |
| 3 | Add 2 tasks and click Save | Response 201 Created. |
| 4 | Inspect the persisted template | `applicable_departments` and `applicable_job_titles` are empty/null; the template is treated as universal (applies to all) per FR-4; `tenant_id` set from session. |

## 6. Postconditions
- A universal-scope template exists and is eligible for any department/job title within the tenant.
