# TC-ONB-005-07: BR-1 status gate — cannot initiate offboarding for an active employee (only resignation_accepted / terminated / contract_ended)

## 1. Test Objective
Verify BR-1: offboarding can only be initiated for employees whose status is "resignation_accepted", "terminated", or "contract_ended". Attempting to initiate for an employee in any other status (e.g. "active"/"probation") is rejected.

## 2. Related Requirements
- User Story: US-ONB-005
- Business Rules: BR-1
- Acceptance Criteria: AC-1 (initiation)
- Data: employee_id (must exist with appropriate status)

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Offboarding.Manage`.
- Employee E310 has status "active"; E311 has "resignation_accepted"; E312 has "contract_ended".

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| E310 status | active | NOT eligible (BR-1) |
| E311 status | resignation_accepted | eligible |
| E312 status | contract_ended | eligible |
| last_working_day | 2026-07-15 | valid |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Attempt "Initiate Offboarding" for E310 (active) | Rejected (422/409); message indicates offboarding requires a resignation_accepted / terminated / contract_ended status; no offboarding instance created (BR-1). |
| 2 | Initiate offboarding for E311 (resignation_accepted) | 201; offboarding instance created (BR-1 satisfied). |
| 3 | Initiate offboarding for E312 (contract_ended) | 201; offboarding instance created (BR-1 satisfied). |
| 4 | Verify no instance/tasks were created for E310 | E310 has no offboarding instance; no orphaned tasks. |

## 6. Postconditions
- Offboarding instances exist only for E311 and E312; the active employee E310 is untouched.
