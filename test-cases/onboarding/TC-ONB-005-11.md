# TC-ONB-005-11: Performance — initiation API <= 1000 ms P95 (NFR-1); deactivation + session revocation complete within 30 s (NFR-3)

## 1. Test Objective
Verify NFR-1 and NFR-3: the offboarding-initiation API responds within 1000 ms at P95, and upon completion the employee's account deactivation and session revocation complete within 30 seconds.

## 2. Related Requirements
- User Story: US-ONB-005
- Non-Functional Requirements: NFR-1 (initiation <= 1000 ms P95), NFR-3 (deactivation + revocation <= 30 s)

> PLATFORM NOTE: Thresholds require a performance-representative environment (prod-like data volume + warm caches). On a dev box, record indicative numbers and do NOT relax the thresholds. Session revocation via Redis denylist is deferred (see TC-ONB-005-06); NFR-3 is measured against the account-deactivation effect in force today plus any wired revocation.

## 3. Preconditions
- Performance-representative environment with seeded offboarding templates and assigned assets.
- A load tool capable of recording P95 latency.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| initiation sample size | >= 100 requests | for stable P95 |
| NFR-1 threshold | 1000 ms P95 | initiation API |
| NFR-3 threshold | 30 s | deactivation + revocation after completion |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Issue >= 100 offboarding-initiation requests (eligible employees) and record latency distribution | P95 latency <= 1000 ms (NFR-1). |
| 2 | Complete an offboarding and timestamp the completion request | Completion accepted. |
| 3 | Poll the account state and session validity after completion | Account is deactivated and active sessions are revoked within 30 s of completion (NFR-3). |
| 4 | Confirm a previously-valid JWT is rejected within the 30 s window | Old token -> 401 within the NFR-3 window. |

## 6. Postconditions
- Initiation latency and post-completion deactivation/revocation timing meet the documented SLAs (or indicative numbers recorded with thresholds unchanged on a dev box).
