# TC-ONB-006-01: HR-conducted exit interview happy path — record 10-question questionnaire; responses persisted with tenant_id + offboarding linkage; exit-interview task completed

## 1. Test Objective
Verify AC-1, AC-2 and FR-1/3/6/7: an HR Officer opens a departing employee's offboarding record, launches the structured exit interview questionnaire (pre-loaded from the tenant's template, grouped by category with rating/multiple-choice/free-text/yes-no question types), records the employee's responses, and saves. All responses persist against the offboarding record with `tenant_id` from session context, the exit-interview offboarding task is marked "completed", and the completion is recorded as an audit event.

## 2. Related Requirements
- User Story: US-ONB-006
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-1, FR-3, FR-6, FR-7

## 3. Preconditions
- HR Officer authenticated in tenant `acme` (tenantId T-acme) with the exit-interview record permission (HR / `Offboarding.Manage`).
- An offboarding instance OB-A300 (employee E300, US-ONB-005) exists with status in progress and an exit-interview task in its checklist.
- An exit interview questionnaire template exists for the tenant with 10 questions across categories "Reason for Leaving", "Work Environment", "Management", "Recommendations" using all four question types (rating 1-5, multiple choice, free text, yes/no).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| offboarding_id | OB-A300 | belongs to T-acme (FR-3) |
| interview_mode | hr_conducted | (FR-2) |
| conducted_by | (HR user id) | required for hr_conducted |
| interview_date | 2026-06-17 | today, not future |
| responses | 10 answers (ratings 1-5, one multi-choice "Reason"=Compensation, free text, yes/no) | one per template question |
| overall_experience_rating | 4 | 1-5 |
| would_recommend_employer | true | boolean |
| additional_comments | "Positive overall." | <= 5000 chars |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open OB-A300 and click "Conduct Exit Interview" | A structured questionnaire form opens with the 10 questions grouped under category headers, pre-loaded from the tenant's template; question types render correctly (rating selector, radio/chips, free-text area, yes/no) (AC-1, FR-1). |
| 2 | Answer all 10 questions plus overall rating, would-recommend, and additional comments; click "Save" | 200/201; success state shown (AC-2). |
| 3 | Inspect the persisted exit interview record | Record persisted with `tenant_id`=T-acme (from session, not client input), `offboarding_id`=OB-A300, interview_mode=hr_conducted, conducted_by=HR user, all 10 responses stored with their question_id and the correct answer field per type (FR-3, FR-6). |
| 4 | Inspect the offboarding checklist for OB-A300 | The exit-interview task status = "completed" (AC-2). |
| 5 | Inspect the tenant audit log | An exit-interview-completed audit event is recorded with actor=HR Officer, timestamp, and offboarding linkage (FR-7). |

## 6. Postconditions
- One exit interview record exists for OB-A300, tenant-scoped, immutable (BR-2), with the offboarding exit-interview task marked completed and an audit entry present.
