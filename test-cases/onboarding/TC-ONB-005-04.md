# TC-ONB-005-04: Clearance dashboard — 4 departments, approve 2 / pending 2, overall NOT fully cleared, traffic-light status correct

## 1. Test Objective
Verify AC-3 and FR-4: with clearance tasks from four departments (IT, Finance, Admin, Manager), when two are approved and two remain pending, the overall clearance status is computed as NOT "fully cleared", and the HR clearance dashboard shows the correct per-department traffic-light indicators (green=approved, red=pending, yellow=pending_issues).

## 2. Related Requirements
- User Story: US-ONB-005
- Acceptance Criteria: AC-3
- Functional Requirements: FR-4

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Offboarding.Manage`.
- Offboarding instance for E300 has clearance tasks for IT, Finance, Admin, Manager (all pending).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| IT clearance | approved | green |
| Finance clearance | approved | green |
| Admin clearance | pending | red |
| Manager clearance | pending_issues | yellow |
| expected overall | NOT fully cleared | not all approved (BR-2) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As the IT department head, mark IT clearance "approved"; as Finance, mark Finance "approved" | Both clearances recorded as approved (AC-3). |
| 2 | Leave Admin clearance untouched (pending); mark Manager clearance "pending_issues" with remarks | Admin remains pending; Manager set to pending_issues with remarks captured (AC-3). |
| 3 | Open the HR clearance dashboard | Department-wise status shown: IT=green, Finance=green, Admin=red, Manager=yellow (FR-4). |
| 4 | Inspect the overall clearance status indicator | Overall = NOT "fully cleared" (fully cleared requires all four approved) (AC-3, BR-2). |
| 5 | Now mark Admin and Manager both "approved" | Overall clearance status recomputes to "fully cleared"; all four indicators green (AC-3). |

## 6. Postconditions
- Per-department traffic-light statuses reflect inputs; overall status is "fully cleared" only when all departments are approved.
