# TC-ONB-006-02: Self-service exit interview happy path — departing employee completes the questionnaire; saved + linked; HR notified via outbox intent

## 1. Test Objective
Verify AC-3 and FR-2/8: the departing employee logs in (account still active before LWD) and completes the same structured questionnaire themselves in self-service mode. Responses are saved and linked to the offboarding record with `tenant_id` from session, and an HR notification INTENT is written to the outbox transactionally. Real-time SignalR + email delivery is owned by the Notifications module (US-NTF-001 in-app, US-NTF-002 email) and is deferred — this test asserts the outbox/notification-intent row, not end-to-end receipt.

## 2. Related Requirements
- User Story: US-ONB-006
- Acceptance Criteria: AC-3
- Functional Requirements: FR-2, FR-8
- Deferred: real SignalR/email delivery -> US-NTF-001 / US-NTF-002

## 3. Preconditions
- Employee E300 has an active user account in tenant `acme` and an in-progress offboarding OB-A300 with an exit-interview task; the LWD (2026-06-30) has not yet passed.
- The tenant's exit interview template exists.
- No exit interview yet recorded for OB-A300.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| offboarding_id | OB-A300 | the employee's own offboarding |
| interview_mode | self_service | conducted_by not required (FR-2) |
| interview_date | 2026-06-17 | today |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Log in as employee E300 and open the self-service exit interview link | The same questionnaire (same 10 questions/categories/types) as the HR-conducted form is presented (AC-3, FR-2). |
| 2 | Complete all questions and submit | 200/201; warm success state "Exit interview recorded. Thank you for the feedback." (AC-3). |
| 3 | Inspect the persisted record | Record saved with interview_mode=self_service, `tenant_id`=T-acme, linked to OB-A300; conducted_by is null/employee self; responses stored (AC-3, FR-2). |
| 4 | Inspect the notification outbox / intent table | A "self-service exit interview submitted" notification INTENT row addressed to HR is written in the SAME transaction as the interview save, tenant-stamped T-acme; a Hangfire dispatch job is enqueued (FR-8; delivery deferred to US-NTF). |
| 5 | Inspect the offboarding checklist | The exit-interview task is marked "completed" for OB-A300. |

## 6. Postconditions
- Self-service exit interview saved, linked, tenant-scoped; HR-notify outbox intent persisted transactionally; no actual SignalR/email asserted here (deferred).
