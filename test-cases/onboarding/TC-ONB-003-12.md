# TC-ONB-003-12: Accessibility + responsive — keyboard nav, screen-reader status announcements, 360px mobile upload

## 1. Test Objective
Verify NFR-4 and NFR-5: the onboarding checklist is fully keyboard-operable, screen readers announce task status and due dates, and the UI (including document upload) is usable and responsive from 360px mobile through 4K, meeting WCAG 2.1 AA.

## 2. Related Requirements
- User Story: US-ONB-003
- Acceptance Criteria: AC-1, AC-2
- Non-Functional Requirements: NFR-4 (responsive 360px-4K), NFR-5 (WCAG 2.1 AA)

## 3. Preconditions
- Employee authenticated in tenant `acme` with a checklist containing pending, completed, and overdue tasks plus a document-upload task.
- Screen reader (NVDA/VoiceOver) and axe accessibility tooling available; browsers: Chrome, Edge, Firefox, Safari.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| viewports | 360px, 768px, 1280px, 4K | NFR-4 |
| AT | NVDA / VoiceOver | status announcements |
| contrast target | WCAG 2.1 AA (4.5:1 text) | incl. red overdue highlight |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate the entire checklist with keyboard only (Tab/Shift+Tab/Enter/Space) | All categories, tasks, "Mark Complete", and upload controls reachable and operable; visible focus indicators (NFR-5). |
| 2 | Complete a task via keyboard | Status updates; screen reader announces the change to "completed" and the progress update (NFR-5). |
| 3 | Move focus across tasks with a screen reader | Each task announces title, status (pending/in-progress/completed/overdue), due date, and responsible party (AC-2, NFR-5). |
| 4 | Verify the overdue red highlight is not color-only | Conveyed also by a warning icon + text ("X days overdue") so it is perceivable without color (WCAG 1.4.1). |
| 5 | Resize to 360px and upload a document | Layout is single-column full-width; the upload control (bottom sheet) is usable on mobile; file uploads successfully (NFR-4). |
| 6 | Run axe scan at 360px and 1280px across Chrome/Edge/Firefox/Safari | No WCAG 2.1 AA violations; contrast (incl. red highlight) meets 4.5:1 (NFR-5). |

## 6. Postconditions
- Checklist and document upload are keyboard-operable, screen-reader-friendly, and responsive 360px-4K with no AA violations.
