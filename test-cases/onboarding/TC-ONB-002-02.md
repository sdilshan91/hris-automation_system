# TC-ONB-002-02: Template selection auto-filtered by dept/job title + universal; deactivated excluded

## 1. Test Objective
Verify AC-1, FR-1 and BR-1: when assigning a checklist, the selectable template list is auto-filtered to templates applicable to the employee's department and job title, plus universal (empty-scope) templates. Templates scoped to other departments/job titles are absent, and deactivated templates never appear regardless of scope.

## 2. Related Requirements
- User Story: US-ONB-002
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1
- Business Rules: BR-1

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Onboarding.Manage`.
- Employee "Alex Reed" is in department Engineering with job title Software Engineer.
- Templates in `acme`: T1 active scoped to Engineering; T2 active scoped to Sales; T3 active universal (empty dept/job scope); T4 active scoped to Engineering + Software Engineer; T5 deactivated scoped to Engineering.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| employee dept | Engineering | filter input |
| employee job title | Software Engineer | filter input |
| T1 | active / Engineering | should appear |
| T2 | active / Sales | should NOT appear |
| T3 | active / universal | should appear |
| T4 | active / Engineering + Software Engineer | should appear |
| T5 | deactivated / Engineering | should NOT appear (BR-1) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open Alex Reed's profile and click "Assign Onboarding Checklist" | The template selector opens. |
| 2 | Inspect the selectable template list | T1, T3, T4 appear (Engineering-scoped + universal + dept/job match). |
| 3 | Confirm exclusions | T2 (Sales) is absent — out-of-scope dept (FR-1). |
| 4 | Confirm deactivated exclusion | T5 is absent even though its scope matches — deactivated templates are not assignable (BR-1). |
| 5 | Inspect the assignment API filter `GET /api/v1/onboarding/assignments/templates?employeeId=...` | Returns only T1, T3, T4; filtering enforced server-side, not just in the UI. |

## 6. Postconditions
- No assignment performed; the filtered candidate list correctly reflects dept/job-title scope, universal templates, and active-only status.
