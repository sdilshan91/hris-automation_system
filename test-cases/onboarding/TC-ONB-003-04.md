# TC-ONB-003-04: Document upload — valid PDF stored at tenant-isolated path, task completed with file ref, HR notified

## 1. Test Objective
Verify AC-4, FR-3 and NFR-6: for a document-upload task, the employee uploads a valid PDF (<=10 MB); the file is persisted to tenant-isolated object storage at `{tenantId}/onboarding/{employeeId}/{taskId}/{filename}`; the task transitions to "completed" with the file reference attached and completion timestamp + actor recorded; and an HR notification intent is raised.

## 2. Related Requirements
- User Story: US-ONB-003
- Acceptance Criteria: AC-4
- Functional Requirements: FR-3
- Non-Functional Requirements: NFR-6 (10 MB limit)
- Dependencies (deferred delivery): US-NTF-001 / US-NTF-002

> PLATFORM NOTE: AC-4 says "HR receives a notification". Real delivery is owned by Notifications (US-NTF-001/002); this test asserts the HR notification intent (outbox) is raised. Object storage backend is Azure Blob / S3 / MinIO per story assumptions; the key/path shape is the contract under test.

## 3. Preconditions
- Employee "Alex Reed" (employeeId E123) authenticated in tenant `acme` (tenantId T-acme).
- Task "Submit ID proof" (taskId TK77) is of type `document_upload`, status "pending".
- Object storage is available.

| Field | Value | Notes |
|-------|-------|-------|
| file | id-proof.pdf, 2 MB, application/pdf | valid type and size |
| expected storage key | T-acme/onboarding/E123/TK77/id-proof.pdf | tenant-isolated path (AC-4) |
| task | TK77 (document_upload) | requires attachment |

| Step | Action | Expected Result |

| 1 | Upload id-proof.pdf and mark TK77 complete via the document-upload endpoint | 200/201; upload accepted (valid MIME + size, FR-3, NFR-6). |

## 6. Postconditions
- TK77 completed with file stored at the tenant-isolated path and file reference attached; HR notification queued; audit event written.
