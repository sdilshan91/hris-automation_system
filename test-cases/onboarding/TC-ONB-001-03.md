# TC-ONB-001-03: Duplicate template name rejected within the same tenant (negative)

## 1. Test Objective
Verify AC-3 and BR-1: attempting to save a second template with a name that already exists in the same tenant is rejected with the validation error "A checklist template with this name already exists." The same name MUST succeed in a different tenant (uniqueness is per-tenant, not global) — covered as the second assertion here and reinforced by TC-ONB-ISO-001.

## 2. Related Requirements
- User Story: US-ONB-001
- Acceptance Criteria: AC-3
- Business Rules: BR-1
- Data Requirements: template_name (unique per tenant)

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Onboarding.Manage`.
- A template named "Standard Engineer Onboarding" already exists in tenant `acme` (e.g. from TC-ONB-001-01).
- A second tenant `globex` exists with no template named "Standard Engineer Onboarding".

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| template_name | Standard Engineer Onboarding | already exists in acme |
| tasks | 1 valid task | satisfies BR-2 so name is the only failing rule |
| Cross-tenant probe | same name in globex | must succeed |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | In tenant `acme`, open the builder and enter "Standard Engineer Onboarding" with 1 valid task; click Save | Save is rejected; response 409 Conflict (or 422). Inline error displays exactly "A checklist template with this name already exists." (AC-3). |
| 2 | Confirm no new row was written | The `onboarding_template` count for tenant `acme` is unchanged. |
| 3 | Retry with a case/whitespace variant ("standard engineer onboarding ") | Rejected consistently — uniqueness is case-insensitive and trimmed (documented assumption; if the implementation is case-sensitive, flag the divergence to the caller rather than weakening this assertion). |
| 4 | As an HR Officer in tenant `globex`, save a template named "Standard Engineer Onboarding" with 1 valid task | Save succeeds (201); the name collides only across tenants, which is allowed (BR-1). |

## 6. Postconditions
- No duplicate-named template in tenant `acme`; the same name exists independently in tenant `globex`.
