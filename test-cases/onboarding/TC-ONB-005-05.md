# TC-ONB-005-05: Blocked completion — pending mandatory task blocks "Complete Offboarding" with explicit pending list

## 1. Test Objective
Verify AC-5 and BR-2: when HR clicks "Complete Offboarding" while one or more mandatory clearance/exit tasks are still pending, the system blocks the action and displays the specific list of pending mandatory items; no termination, deactivation, or F&F trigger occurs.

## 2. Related Requirements
- User Story: US-ONB-005
- Acceptance Criteria: AC-5
- Business Rules: BR-2

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Offboarding.Manage`.
- Offboarding instance for E300 has all tasks approved EXCEPT two mandatory tasks: Finance F&F clearance (pending) and IT asset-return (pending).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| pending mandatory #1 | Finance F&F clearance | mandatory, pending |
| pending mandatory #2 | IT asset-return | mandatory, pending |
| optional task | parking pass return | optional, pending (must NOT block) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Observe the "Complete Offboarding" button | Button is disabled/greyed out; hovering shows the remaining mandatory items (UI hint). |
| 2 | Attempt to invoke the complete-offboarding API directly while mandatory tasks are pending | Request rejected (422/409); message: "Cannot complete offboarding. The following mandatory items are pending: [Finance F&F clearance, IT asset-return]." (AC-5, BR-2). |
| 3 | Confirm the pending list content | The message enumerates exactly the two pending MANDATORY items; the optional pending task is NOT listed as blocking (BR-2). |
| 4 | Inspect the employee record and account | Status unchanged (still resignation_accepted/terminated-pending); account still active; no F&F notification sent (AC-5). |
| 5 | Approve both pending mandatory tasks, then retry completion | Completion now succeeds (AC-4). |

## 6. Postconditions
- Offboarding cannot be completed while mandatory tasks are pending; no side effects occur on a blocked attempt.
