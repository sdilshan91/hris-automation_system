# TC-ONB-006-06: Anonymization — analytics show aggregates only; individual free-text hidden without ExitInterview.ViewDetail; PII access flagged in audit

## 1. Test Objective
Verify FR-5 and NFR-6: in analytics/summary views, individual exit interview answers (especially free-text) are NOT shown to users without the `ExitInterview.ViewDetail` permission — only aggregates are visible. A user WITH `ExitInterview.ViewDetail` can drill into individual free-text responses, and that access to PII-bearing free text is flagged in the audit log.

## 2. Related Requirements
- User Story: US-ONB-006
- Functional Requirement: FR-5 (anonymize individual responses in analytics unless ViewDetail)
- Non-Functional Requirement: NFR-6 (free-text PII access flagged in audit)

## 3. Preconditions
- Tenant `acme` has multiple completed exit interviews including free-text answers containing identifying detail.
- User U-agg authenticated WITHOUT `ExitInterview.ViewDetail` (analytics-only).
- User U-detail authenticated WITH `ExitInterview.ViewDetail`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| aggregate-only user | U-agg | no ViewDetail |
| detail user | U-detail | has ExitInterview.ViewDetail |
| free_text sample | "Manager Jane Doe was unfair..." | PII-bearing |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As U-agg, open the Exit Interview Summary | Only aggregates (pie/bar/line) shown; no individual free-text answers or per-respondent rows are exposed (FR-5). |
| 2 | As U-agg, attempt to access an individual interview's free-text via API/deep link | Denied (403) or free-text redacted; individual answers not disclosed (FR-5). |
| 3 | As U-detail, open an individual interview and view its free-text answers | Permitted — free-text visible because U-detail holds `ExitInterview.ViewDetail` (FR-5). |
| 4 | Inspect the audit log after U-detail's access | An audit entry flags the PII free-text access by U-detail with actor, timestamp, and the accessed interview, tenant-scoped (NFR-6). |
| 5 | Confirm U-agg's earlier aggregate view did NOT raise a PII-access flag | Aggregate viewing is not flagged as PII access (only individual free-text access is, NFR-6). |

## 6. Postconditions
- Individual free-text remains hidden from non-privileged users; privileged free-text access is recorded as a flagged audit event.
