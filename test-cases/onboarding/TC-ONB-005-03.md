# TC-ONB-005-03: Asset return — mark laptop returned, asset register status -> Available, task complete, audit

## 1. Test Objective
Verify AC-2 and BR-3: when IT marks an assigned asset (laptop) as returned during offboarding, the asset register status transitions from "assigned" to "available" (or "disposed"), the asset-return task is marked complete, and an audit record with before/after state is written.

## 2. Related Requirements
- User Story: US-ONB-005
- Acceptance Criteria: AC-2
- Business Rules: BR-3
- Functional Requirements: FR-3 (asset-return clearance category)

## 3. Preconditions
- IT user authenticated in tenant `acme` with permission to action IT clearance tasks.
- Offboarding instance for E300 has an "Asset Return" task (TK-RET-1, pending).
- Asset register has laptop LAP-001 currently status="assigned", assigned_employee_id=E300.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| asset_tag | LAP-001 | currently assigned to E300 |
| return action | Mark Returned | condition dropdown = "Good" |
| target status | available | (or "disposed" if condition warrants) |
| task | TK-RET-1 (asset_return) | pending |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | In the offboarding asset-return section, select LAP-001, choose condition "Good", and click "Mark Returned" | 200; success toast "Asset LAP-001 returned". |
| 2 | Inspect the asset register entry for LAP-001 | status changed from "assigned" to "available"; assigned_employee_id cleared (BR-3, AC-2). |
| 3 | Mark a damaged asset with condition warranting disposal | status set to "disposed" instead of "available" (AC-2). |
| 4 | Inspect the asset-return task TK-RET-1 | status = "completed" (AC-2). |
| 5 | Inspect the tenant audit log | An audit record exists for the return with before (assigned/E300) and after (available/null) states, actor=IT user, timestamp (AC-2, FR-9). |

## 6. Postconditions
- LAP-001 register status = available (or disposed); asset-return task completed; before/after audit recorded.
