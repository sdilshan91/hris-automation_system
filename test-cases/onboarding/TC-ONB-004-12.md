# TC-ONB-004-12: Accessibility + responsive — issuance form keyboard navigable, 360px mobile, WCAG 2.1 AA

## 1. Test Objective
Verify NFR-3 and accessibility expectations: the asset issuance form (asset-type dropdown with type-ahead, condition chips, "Add Another Asset" cards, drag-and-drop acknowledgment upload) is fully keyboard-operable and screen-reader friendly, and the layout is responsive and usable from 360px mobile (single-column, full-width cards) through 4K, meeting WCAG 2.1 AA.

## 2. Related Requirements
- User Story: US-ONB-004
- Non-Functional Requirements: NFR-3 (responsive 360px-4K)
- UI/UX: searchable type-ahead dropdown, condition chips, removable asset cards, drag-and-drop upload; mobile single-column

## 3. Preconditions
- HR Officer authenticated in tenant `acme` on the asset issuance form for an employee with a pending task.
- Screen reader (NVDA/VoiceOver) and axe tooling available; browsers: Chrome, Edge, Firefox, Safari.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| viewports | 360px, 768px, 1280px, 4K | NFR-3 |
| AT | NVDA / VoiceOver | label + state announcements |
| contrast target | WCAG 2.1 AA (4.5:1 text) | incl. colored condition chips |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate the full issuance form with keyboard only (Tab/Shift+Tab/Enter/Space/Arrows) | All fields, the type-ahead dropdown, condition chips, "Add Another Asset", remove-card, and upload controls are reachable and operable with visible focus. |
| 2 | Operate the searchable asset dropdown via keyboard + screen reader | Options announced; selection works with arrows/Enter; the combobox exposes a proper accessible name/role. |
| 3 | Verify the condition chips are not color-only | Each condition (New/Good/Fair/Poor) is conveyed by text/label in addition to color (WCAG 1.4.1). |
| 4 | Operate the drag-and-drop acknowledgment upload via keyboard | A keyboard-accessible alternative (file button) is available; selected file name is announced. |
| 5 | Resize to 360px | Layout is single-column, full-width removable cards; all controls usable; no horizontal scroll/overlap (NFR-3). |
| 6 | Run axe scan at 360px and 1280px across Chrome/Edge/Firefox/Safari | No WCAG 2.1 AA violations; contrast (incl. condition chips) meets 4.5:1. |

## 6. Postconditions
- Issuance form is keyboard-operable, screen-reader-friendly, and responsive 360px-4K with no AA violations.
