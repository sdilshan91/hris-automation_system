# TC-ONB-001-12: Keyboard-navigable task reordering + responsive builder (NFR-4 / NFR-3)

## 1. Test Objective
Verify NFR-4 (WCAG 2.1 AA): the drag-and-drop task builder is fully operable by keyboard and provides a non-pointer alternative (up/down arrow buttons) for reordering tasks within and across categories; the builder is screen-reader friendly. Also verify NFR-3 responsiveness from 360px to 4K, where the drag handle becomes up/down buttons on mobile.

## 2. Related Requirements
- User Story: US-ONB-001
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-1
- Non-Functional Requirements: NFR-4, NFR-3
- UI/UX: §8 (drag handle, mobile up/down buttons)

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Onboarding.Manage`, with the builder open and several tasks across 2+ categories.
- An automated a11y checker (e.g. axe-core) and a screen reader (NVDA/VoiceOver) available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360px, 768px, 1024px, 1920px, 4K | NFR-3 |
| Task set | 2 categories, 3 tasks each | reorder targets |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Using Tab/Shift+Tab only, traverse all form fields, category sections, task cards, and action buttons | Every interactive element is reachable in a logical order with a visible focus indicator (WCAG 2.4.7). |
| 2 | Focus a task and reorder it within its category using the keyboard drag affordance and/or the up/down buttons | Task moves up/down; new order is announced/visible; no pointer required (WCAG 2.1.1 keyboard). |
| 3 | Reorder a task ACROSS categories via keyboard | Task moves to the adjacent category; sort_order and category update accordingly. |
| 4 | Run axe-core on the builder | Zero serious/critical violations; form inputs have programmatic labels; the drag handle/buttons have accessible names; color contrast >= 4.5:1 (WCAG 1.4.3). |
| 5 | Resize to 360px | Tasks stack vertically; the drag handle is replaced by up/down arrow buttons (§8); all controls remain operable and labeled. |
| 6 | Verify at 768px / 1024px / 1920px / 4K | Layout reflows without horizontal scroll or clipping (NFR-3). |

## 6. Postconditions
- The builder is keyboard-operable, has a non-drag reorder alternative, passes automated a11y checks, and is responsive 360px-4K.
