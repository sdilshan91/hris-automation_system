# TC-ONB-006-04: Immutability / versioning — edit after submit preserves the original and creates a new version

## 1. Test Objective
Verify BR-2: exit interview responses are immutable once submitted. When HR edits a submitted exit interview, the original responses are preserved unchanged and a NEW version is created (rather than an in-place overwrite). Both versions are linked to the same offboarding and tenant-scoped; the version change is auditable.

## 2. Related Requirements
- User Story: US-ONB-006
- Business Rule: BR-2 (immutable after submit; edits create a new version, original preserved)
- Functional Requirements: FR-3 (linkage), FR-7 (audit)

## 3. Preconditions
- A submitted exit interview (version 1) exists for OB-A300 in tenant `acme` with known responses.
- HR Officer authenticated with the record/edit permission.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| offboarding_id | OB-A300 | existing v1 interview |
| original overall_experience_rating | 4 | recorded in v1 |
| edited overall_experience_rating | 2 | submitted as the edit |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Note the v1 record id, version number, and overall rating (4) | Baseline captured. |
| 2 | Open the interview, change overall rating to 2 (and a free-text answer), and save the edit | 200; a NEW version (v2) is created; the request does not overwrite v1 in place (BR-2). |
| 3 | Re-fetch v1 by its version/id | v1 is unchanged — overall rating still 4, original free-text intact (BR-2). |
| 4 | Fetch the current/latest version | v2 reflects the edited values (rating 2); both versions share offboarding_id=OB-A300 and tenant_id=T-acme (FR-3). |
| 5 | Inspect the audit log | The version creation/edit is recorded with actor and timestamp; the original is retained (FR-7, BR-2). |

## 6. Postconditions
- Two versions exist for OB-A300's exit interview; v1 immutable/preserved, v2 current; both tenant-scoped and audited.
