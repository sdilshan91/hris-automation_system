# TC-ONB-005-01: Full offboarding happy path — initiate, complete all clearances, complete offboarding; employee terminated, account deactivated, F&F notification triggered

## 1. Test Objective
Verify AC-1, AC-4 and FR-2/5/6/9: an HR Officer initiates offboarding for a departing employee, completes every mandatory clearance/exit task, and clicks "Complete Offboarding". The employee status changes to "terminated", the user account is deactivated (cannot log in), a Full & Final (F&F) settlement trigger notification is sent to Payroll, and each step is audit-logged.

## 2. Related Requirements
- User Story: US-ONB-005
- Acceptance Criteria: AC-1, AC-4
- Functional Requirements: FR-2, FR-5, FR-6, FR-9

## 3. Preconditions
- HR Officer authenticated in tenant `acme` (tenantId T-acme) with `Offboarding.Manage` (HR) permission.
- Employee "Liam Patel" (employeeId E300) exists with status "resignation_accepted" and an active user account.
- A default offboarding template exists for the tenant with tasks across HR, IT, Finance, Manager, Employee.
- Employee LWD is set (e.g. 2026-06-30, in the future).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| employee_id | E300 | status resignation_accepted (BR-1 ok) |
| last_working_day | 2026-06-30 | today-or-future (valid) |
| reason | Resignation | valid enum |
| offboarding_template_id | (omitted) | default tenant template used (FR-1) |
| notes | "Standard exit" | <= 2000 chars |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open E300's profile and click "Initiate Offboarding"; supply LWD 2026-06-30, reason Resignation; submit | 200/201; an offboarding instance is created with an exit checklist of tasks assigned to HR, IT, Finance, Manager, Employee, each with a due date = LWD - offset (AC-1, FR-2). |
| 2 | Inspect the generated tasks | Each task has tenant_id=T-acme, responsible party resolved, status "pending", and a due date relative to 2026-06-30 (AC-1, FR-2). |
| 3 | Approve/complete every mandatory clearance and exit task (IT asset return, Finance F&F clearance, Admin, Manager handover, Employee items) | All tasks reach status "approved"/"completed"; overall clearance status = "fully cleared" (AC-3 dependency satisfied). |
| 4 | Click "Complete Offboarding" and confirm in the summary modal | 200; success toast; the action is permitted because all mandatory tasks are done (AC-4). |
| 5 | Inspect the employee record | Employee status = "terminated"; record retained, not deleted (AC-4, BR-5). |
| 6 | Attempt to log in as the offboarded employee's account | Login is denied — the user account is deactivated (AC-4, FR-5). |
| 7 | Inspect the Payroll notification queue/outbox | An F&F settlement trigger notification was sent to Payroll, linked to E300 (AC-4, FR-6). |
| 8 | Inspect the tenant audit log | Initiation, each clearance approval, and the final completion are recorded with actor=HR Officer and timestamps (FR-9). |

## 6. Postconditions
- E300 status = terminated; user account deactivated; F&F notification dispatched to Payroll; full audit trail present; offboarding instance closed (irreversible per BR-6).
