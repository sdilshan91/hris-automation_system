# TC-ADM-010-09: Suspended tenant — export REJECTED for Tenant Admin, ALLOWED for System Admin

## 1. Test Objective
Verify BR-2 / AC-4 status gate Test Hint ("Suspended tenant export"): a Tenant Admin in a `Suspended` tenant CANNOT initiate an export (rejected), but a System Admin CAN initiate it on the tenant's behalf. This is the dual-persona split of the status gate.

## 2. Related Requirements
- User Story: US-ADM-010
- Acceptance Criteria: AC-4 (allowed statuses), AC-6 (system admin acts on behalf)
- Business Rules: BR-1 (System Admin any tenant), BR-2 (suspended -> Tenant Admin blocked; System Admin allowed)
- Test Hints: "Suspended tenant export: set a tenant to suspended; attempt export as Tenant Admin -> rejection; attempt as System Admin -> success."

## 3. Preconditions
- Tenant "Gamma" is in `Suspended` status.
- Tenant Admin "Gita" exists for Gamma; System Admin "Pat" authenticated at `admin.yourhrm.com`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| tenant | gamma (Suspended) | |
| allowed statuses | Active, Trial, PastDue, Terminating | per AC-4 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Gita (Tenant Admin), attempt to initiate an export for Gamma | Rejected — status gate blocks export for a suspended tenant by a Tenant Admin (e.g. 403/409 with a status message); no ExportRequest enters Processing. |
| 2 | As Pat (System Admin), initiate an export for Gamma with explicit `tenantId` = Gamma | Accepted — System Admin override permitted for Suspended (BR-2); ExportRequest Queued. |
| 3 | Let the System Admin job complete | ExportRequest Completed; bundle generated for Gamma; action attributed to Pat (see TC-ADM-010-13). |
| 4 | Verify the Tenant-Admin rejection was recorded | The blocked attempt surfaces an appropriate status/security signal (per platform; initiation-attempt auditing per NFR-4). |

## 6. Postconditions
- No Tenant-Admin export for the suspended tenant; a System-Admin export Completed.
