# TC-ADM-007-01: Workflow list — grouped by entity type, tenant-scoped, Default flag shown

## 1. Test Objective
Verify AC-1: the Workflows settings page returns the current tenant's configured workflow definitions, GROUPED by entity type (Leave, Attendance, Expense, Offer, SalaryRevision), each showing workflow name, number of steps, status (active/draft/archived), and last-modified date. Only workflows belonging to the current tenant are returned (EF global query filter on `TenantId`). Default workflows (seeded during provisioning, US-ADM-001) carry an `is_default = true` flag and remain editable.

## 2. Related Requirements
- User Story: US-ADM-007
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1 (definition shape), FR-7 (tenant-scoped via ITenantContext)
- Business Rules: BR-7 (tenant-scoped, A invisible to B)

## 3. Preconditions
- Tenant Admin "Dana" is authenticated at `acme.yourhrm.com` with `TenantAdmin`; tenant Acme is `active`/`trial`.
- Acme has: 1 seeded Default Leave workflow (`is_default = true`), 1 custom active Expense workflow, 1 archived Attendance workflow (draft/archived statuses present).
- No `tenant_id` parameter is accepted on the list endpoint — current tenant resolved from `ITenantContext`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| WF-Leave-Default | entity=Leave, is_active=true, is_default=true, steps=1 | seeded |
| WF-Expense-Custom | entity=Expense, is_active=true, is_default=false, steps=2 | custom |
| WF-Att-Archived | entity=Attendance, is_active=false, steps=2 | archived |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Dana, GET the workflow list | 200; response groups workflows by `entity_type`. |
| 2 | Inspect the Leave group | Contains WF-Leave-Default with `name`, `step_count = 1`, `status = active`, `last_modified` timestamp, and `is_default = true`. |
| 3 | Inspect the Expense group | Contains WF-Expense-Custom with `is_default = false`, `step_count = 2`, `status = active`. |
| 4 | Inspect the Attendance group | Contains WF-Att-Archived with `status = archived`. |
| 5 | Confirm the Default workflow is editable | The Default workflow exposes an edit affordance (not locked). |
| 6 | Confirm tenant scoping | Only Acme's workflows are present; no Tenant Beta workflow appears (BR-7). |

## 6. Postconditions
- No state change; list reflects only the current tenant's definitions.
