# TC-ADM-010-14: Audit trail — initiation, completion, and download events all recorded

## 1. Test Objective
Verify NFR-4 / AC-1 / AC-3 Test Hint ("Audit trail"): the three export lifecycle events — initiation, completion, and download — are each written to the audit log with actor, tenant, export_id, and timestamp. This is the end-to-end auditability sweep for a tenant-initiated export.

## 2. Related Requirements
- User Story: US-ADM-010
- Acceptance Criteria: AC-1 (initiation logged), AC-3 (download logged)
- Non-Functional Requirements: NFR-4 (all export events audited)
- Test Hints: "Audit trail: verify export initiation, completion, and download events are all recorded in the audit log."

## 3. Preconditions
- Tenant Admin "Tara" authenticated at `acme.yourhrm.com`; Acme `Active`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| events | initiation, completion, download | each must be audited |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Initiate an export as Tara | An INITIATION audit row exists (actor=Tara, tenant=Acme, export_id, timestamp). |
| 2 | Let the job complete | A COMPLETION audit row exists for the same export_id. |
| 3 | Download the bundle within 72h | A DOWNLOAD audit row exists for the same export_id (actor=downloader, timestamp). |
| 4 | Correlate the three rows | All three reference the same export_id and the same tenant; ordering initiation < completion <= download. |
| 5 | (Expiry note) When the cleanup job marks Expired (TC-ADM-010-12) | An expiry event is auditable per NFR-4 (initiation/completion/download/expiry family). |

## 6. Postconditions
- Full audit trail present for the export lifecycle.
