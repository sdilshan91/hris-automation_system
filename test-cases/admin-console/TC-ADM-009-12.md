# TC-ADM-009-12: Authorization — only SystemAdmin writes; SystemSupport/Billing read-only; tenant admins cannot view or modify plans

## 1. Test Objective
Verify BR-1 + NFR-5: plan create/edit/archive/delete and override management are restricted to the `SystemAdmin` role. `SystemSupport` and `Billing` roles have read-only access (can list/get but not write). Tenant admin users (and other tenant roles) cannot view OR modify plans at all — plan management is system-context-only.

## 2. Related Requirements
- User Story: US-ADM-009
- Business Rules: BR-1 (only SystemAdmin writes; SystemSupport/Billing read-only)
- Non-Functional Requirements: NFR-5 (system-console-only; tenant admins cannot view/modify)
- Functional Requirements: FR-1 (system-admin-context CRUD)

## 3. Preconditions
- Users available: SystemAdmin "Pat"; SystemSupport "Sam"; Billing "Bill"; Tenant Admin "Dana" (Acme tenant); unauthenticated client.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| write ops | create / update / archive / delete / override | SystemAdmin only |
| read ops | list / get | SystemAdmin, SystemSupport, Billing |
| tenant admin | Dana | no access at all |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Pat (SystemAdmin), create/update/archive a plan + add an override | All succeed (2xx). |
| 2 | As Sam (SystemSupport), GET plans list + a plan | 200 — read allowed. |
| 3 | As Sam, POST create / PUT update / archive / DELETE / add override | 403 — write forbidden for SystemSupport. |
| 4 | As Bill (Billing), GET plans | 200 — read allowed; any write -> 403. |
| 5 | As Dana (Tenant Admin at acme.yourhrm.com), GET the plan-management endpoints | 403/404 — tenant admins cannot view plans (system-context-only); no plan data disclosed. |
| 6 | As Dana, attempt any plan write or override | 403/404 — rejected. |
| 7 | As an unauthenticated client, call any plan endpoint | 401. |

## 6. Postconditions
- Only SystemAdmin mutated plans; reads limited to system roles; tenant roles fully excluded.
