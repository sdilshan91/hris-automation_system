# TC-ADM-001-11: Create Tenant form meets WCAG 2.1 AA and is responsive 360px-4K

## 1. Test Objective
Verify NFR-4: the "Create Tenant" form is fully accessible (WCAG 2.1 AA) — operable by keyboard alone, exposed correctly to screen readers, with sufficient colour contrast and error announcements — and renders responsively from 360px to 4K.

## 2. Related Requirements
- User Story: US-ADM-001
- Non-Functional: NFR-4
- UI/UX Notes: S8 (keyboard navigation, screen readers), real-time subdomain feedback

## 3. Preconditions
- System Admin authenticated at `admin.yourhrm.com` with the `SystemAdmin` role.
- Axe (or equivalent) automated a11y scanner available; a screen reader (NVDA/VoiceOver) available for manual checks.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 360px, 768px, 1280px, 1920px, 3840px (4K) | responsive range |
| Form fields | name, subdomain, plan picker, owner email, region, trial days | full form |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run the automated a11y scan on the Create Tenant form | Zero WCAG 2.1 AA violations (labels, roles, contrast, names). |
| 2 | Navigate the entire form using only Tab/Shift+Tab/Enter/Space/arrows | Logical focus order; every field, the plan card picker, and the submit button are reachable and operable; focus is always visible. |
| 3 | Trigger a validation error (e.g. invalid subdomain) | The error is programmatically associated with its field (`aria-describedby`) and announced via an `aria-live` region; the red-X/green-check subdomain indicator also has a text/aria equivalent (not colour-alone). |
| 4 | Inspect colour contrast of labels, helper text, error text, and the subdomain availability indicator | All meet >= 4.5:1 (normal text) / 3:1 (large text & UI components). |
| 5 | Resize/emulate each viewport from 360px to 4K | No clipping, overlap, or horizontal scroll of primary content; the plan picker reflows; the form remains usable at 360px. |
| 6 | Drive the form with a screen reader end-to-end | Each field's label, required state, and current value are announced; the success toast with the tenant URL is announced on creation. |

## 6. Postconditions
- The Create Tenant form passes WCAG 2.1 AA and is fully responsive 360px-4K.
