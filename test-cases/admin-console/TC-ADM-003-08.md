# TC-ADM-003-08: BR-2 — cannot impersonate a system-tenant user (rejected)

## 1. Test Objective
Verify BR-2: system-tenant users (e.g. another System Admin / System Support) are excluded from impersonation targets. An attempt to start a session whose target is a system-tenant user is rejected before any token or session is created.

## 2. Related Requirements
- User Story: US-ADM-003
- Business Rules: BR-2
- Test Hints: Cannot impersonate system admin

## 3. Preconditions
- Initiator is a `SystemAdmin`.
- A target user belongs to the SYSTEM tenant (`is_system = true`) — e.g. another SystemAdmin or SystemSupport account.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| target_tenant_id | system tenant uuid | is_system=true |
| target_user_id | another-sysadmin uuid | system-tenant member |
| reason | "Trying to impersonate a sysadmin" | valid length, irrelevant — request must still fail |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | `POST /impersonation/start` targeting a system-tenant user | Rejected (403/422) — system-tenant users cannot be impersonated (BR-2). |
| 2 | Inspect side effects | NO `impersonation_sessions` row, NO impersonation token, NO audit "Started" row, NO notification created. |
| 3 | (Variant) Target the system tenant id with any user | Rejected for the same reason — impersonation targets must be non-system tenant members. |

## 6. Postconditions
- System-tenant users remain non-impersonatable; the attempt leaves no session/token/audit side effects.
