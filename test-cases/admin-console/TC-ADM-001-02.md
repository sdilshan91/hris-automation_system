# TC-ADM-001-02: Owner email already a global user is linked, not duplicated

## 1. Test Objective
Verify AC-3: when the System Admin provisions a tenant with an owner email that already belongs to an existing global `users` record, the platform links the existing user to the new tenant via a new `user_tenant` row (with the `TenantOwner` role) without creating a duplicate `users` record, and the welcome email references the existing account.

## 2. Related Requirements
- User Story: US-ADM-001
- Acceptance Criteria: AC-3, AC-1
- Functional Requirements: FR-3, FR-4
- Business Rules: BR-4
- Data Requirements: users, user_tenant, user_tenant_role

## 3. Preconditions
- System Admin "Olivia Park" is authenticated at `admin.yourhrm.com` with the `SystemAdmin` role.
- A global user `shared.owner@acme.com` already exists (e.g. an owner of an existing tenant "acme").
- No tenant with subdomain `umbrella` exists.
- An active subscription plan with `trial_days = 0` exists ("Starter").

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Organization name | Umbrella Inc | new tenant |
| Subdomain | umbrella | unique |
| Owner email | shared.owner@acme.com | EXISTING global user |
| Plan | Starter (trial_days = 0) | -> status active (BR-3) |
| Region | us-east | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Record the current `users` row count and the `id` of `shared.owner@acme.com`. | Baseline captured. |
| 2 | Submit the Create Tenant form for Umbrella Inc with owner `shared.owner@acme.com`; observe `POST /api/v1/admin/tenants` | Response 201 Created; tenant `umbrella` created with `status = active`. |
| 3 | Re-count `users` and look up `shared.owner@acme.com` | The `users` row count is unchanged (no duplicate); the SAME `users.id` is reused. |
| 4 | Inspect `user_tenant` and `user_tenant_role` for the new tenant | A NEW `user_tenant` row links the existing `users.id` to `umbrella`; a `user_tenant_role` grants `TenantOwner`. The user's pre-existing membership of "acme" is untouched. |
| 5 | Verify welcome email | The welcome email to `shared.owner@acme.com` references the existing account (no new set-password reset for an account that already has a password); content reflects the `active_welcome` template. |

## 6. Postconditions
- The existing global user now owns two tenants (acme + umbrella) via two distinct `user_tenant` rows; exactly one `users` record exists for that email.
