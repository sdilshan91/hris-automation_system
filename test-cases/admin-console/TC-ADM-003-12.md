# TC-ADM-003-12: Impersonation banner — persistent, non-dismissable, un-overridable by tenant content; i18n + End Session

## 1. Test Objective
Verify NFR-4 / AC-2 / BR-6: while `is_impersonation=true`, the tenant UI shows a global high-contrast top banner rendered by the main layout. It is persistent and non-dismissable, cannot be hidden or overridden by tenant-level content/CSS, displays the session reference, exposes an "End Session" button, and its text is i18n-driven (renders in each supported language).

## 2. Related Requirements
- User Story: US-ADM-003
- Acceptance Criteria: AC-2
- Non-Functional Requirements: NFR-4
- Business Rules: BR-6
- Test Hints: (derived from NFR-4 banner + BR-6 i18n)

## 3. Preconditions
- An Active impersonation session; the browser is loaded on the tenant subdomain with the impersonation token (`is_impersonation=true`).
- Tenant supports >= 2 languages (e.g. en + one more).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| session ref | imp_session_id | shown in banner |
| languages | en, plus a second supported locale | BR-6 i18n |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load any tenant page under impersonation | The global top banner is shown (high-contrast), states it is a support/impersonation session, and shows the session reference (AC-2). |
| 2 | Attempt to dismiss/close the banner (no close control; try removing via tenant content) | The banner cannot be dismissed; it persists across navigation between tenant pages. |
| 3 | Inject tenant-level CSS / content attempting to hide or overlay the banner | The banner remains visible and on top — it is rendered by the global main layout and cannot be overridden by tenant customization (NFR-4). |
| 4 | Switch the active language to each supported locale | The banner text re-renders via i18n keys in each language (BR-6) — no hard-coded strings, no missing-key fallbacks. |
| 5 | Click "End Session" in the banner | Triggers the end-session flow (AC-3 / TC-ADM-003-06) and returns the operator to the admin console. |
| 6 | Run an accessibility check on the banner | Contrast meets WCAG 2.1 AA; the banner and End Session control are keyboard-reachable and announced by a screen reader. |

## 6. Postconditions
- The banner reliably signals impersonation, survives navigation and tenant overrides, is localized, and offers a working End Session control.
