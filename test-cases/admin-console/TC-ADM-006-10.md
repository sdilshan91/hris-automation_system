# TC-ADM-006-10: Localization rendering — date/number/currency formats applied across the tenant UI

## 1. Test Objective
Verify the AC-3 / Test-Hint rendering contract: after the tenant default date format is set to `DD/MM/YYYY`, date displays across the tenant UI use that format; setting the number format and currency similarly changes numeric/currency rendering. Confirms the chosen formats actually drive output, not just storage.

## 2. Related Requirements
- User Story: US-ADM-006
- Acceptance Criteria: AC-3
- Functional Requirements: FR-1, FR-4
- Test Hints: "Set date format to DD/MM/YYYY; verify all date displays in the tenant UI use the new format."

## 3. Preconditions
- Tenant Admin "Dana" authenticated at `acme.yourhrm.com`; a user without a personal locale preference is available to view rendered output.
- A known date (e.g. 2026-05-11) and a known amount (e.g. 1234567.89) appear in the UI.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| date_format A | "DD/MM/YYYY" | 11/05/2026 |
| date_format B | "MM/DD/YYYY" | 05/11/2026 |
| number_format | "1,234,567.89" vs "1.234.567,89" | grouping/decimal swap |
| currency | "USD" → "EUR" | symbol/placement |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Set `date_format = DD/MM/YYYY`; view a page showing 2026-05-11 | Renders "11/05/2026" everywhere the date appears. |
| 2 | Switch to `MM/DD/YYYY`; reload | Same date now renders "05/11/2026". |
| 3 | Set the alternate number format; view an amount | Grouping/decimal separators match the chosen format. |
| 4 | Switch currency USD → EUR; view a currency value | Currency symbol/code and placement reflect EUR. |
| 5 | Confirm consistency | No page still shows the prior format for the same value. |

## 6. Postconditions
- All tenant UI date/number/currency displays honor the configured tenant defaults.
