# TC-ADM-004-11: Restore a terminating tenant within grace — status -> prior, scheduled_at cleared, deletion + reminder jobs de-queued, lifecycle 'restored'

## 1. Test Objective
Verify AC-6 / FR-6: a System Admin restores a `Terminating` tenant while still within the grace window. The status reverts to its prior state (`Active` or `Suspended` depending on the pre-termination state), `TerminationScheduledAt` is cleared, the scheduled data-deletion job AND the 14/7/1d reminder jobs are de-queued from Hangfire, and a `tenant_lifecycle_event` with `event_type = 'restored'` is written. This confirms deletion is cancellable during grace.

## 2. Related Requirements
- User Story: US-ADM-004
- Acceptance Criteria: AC-6
- Functional Requirements: FR-6, FR-7
- Business Rules: BR-1 (terminating -> suspended | active)
- Test Hints: Restore within grace

## 3. Preconditions
- Tenant "Acme" was `Active`, then terminated (now `Terminating`) with deletion + reminder jobs scheduled (TC-ADM-004-06). Grace not yet expired.
- (Variant) Tenant "Gamma" was `Suspended`, then terminated — to verify it restores to `Suspended`, not `Active`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| acme | prior = Active | restores to Active |
| gamma | prior = Suspended | restores to Suspended |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | `POST /api/v1/admin/tenants/{acme}/restore` within grace | 200/204; success. |
| 2 | Re-read Acme | `status = Active` (prior state); `TerminationScheduledAt` cleared (null). |
| 3 | Inspect Hangfire scheduled jobs for Acme | The deletion job AND all reminder jobs are removed/de-queued — no deletion will fire. |
| 4 | Query `tenant_lifecycle_event` | A `event_type = 'restored'` row is written. |
| 5 | Restore Gamma (prior = Suspended) | Gamma reverts to `Suspended` (its prior state), confirming prior-state-aware restore. |
| 6 | Fast-forward past the original scheduled deletion time | No deletion occurs for Acme or Gamma — jobs were successfully cancelled. |

## 6. Postconditions
- Restored tenants return to their pre-termination state; no deletion fires; transition audited.
