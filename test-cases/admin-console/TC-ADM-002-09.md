# TC-ADM-002-09: Access control — SystemAdmin full, SystemSupport read-only, Tenant Admin gets 403

## 1. Test Objective
Verify BR-1 / AC-5 access control on the monitoring surface: `SystemAdmin` has full access (including suspend/impersonate quick actions); `SystemSupport` has read-only access (dashboard + detail visible, but no suspend/impersonate/terminate quick-action controls and the corresponding mutating endpoints are denied); a `Tenant Admin` (or any non-system role) hitting the monitoring route/endpoints is denied with 403.

## 2. Related Requirements
- User Story: US-ADM-002
- Acceptance Criteria: AC-5
- Business Rules: BR-1
- Test Hints: Tenant Admin at `admin.yourhrm.com/monitoring` -> 403

## 3. Preconditions
- Three identities available: a `SystemAdmin`, a `SystemSupport`, and a tenant-scoped `Tenant Admin`.
- The Monitoring dashboard, tenant-detail, and quick-action endpoints exist.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| SystemAdmin | olivia@system | full access |
| SystemSupport | sam@system | read-only |
| Tenant Admin | admin@acme.com | must be denied |
| Quick actions | suspend, impersonate, terminate | gated to SystemAdmin |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As SystemAdmin, open `/monitoring` and a tenant detail | 200; dashboard, detail, and quick-action buttons (impersonate/suspend) are all visible and enabled. |
| 2 | As SystemSupport, open `/monitoring` and a tenant detail | 200; dashboard and detail render read-only. Suspend/impersonate/terminate quick-action buttons are hidden/disabled. |
| 3 | As SystemSupport, call a quick-action endpoint directly (e.g. `POST /api/v1/admin/tenants/{id}/suspend`) | Denied 403 — server-side authorization, not just hidden UI. |
| 4 | As Tenant Admin, navigate to `admin.yourhrm.com/monitoring` | Access denied 403 (route guard + API authorize); no monitoring data is returned. |
| 5 | As Tenant Admin, call `GET /api/v1/admin/monitoring/overview` and `.../tenants/{id}` directly | Both return 403; no platform/tenant aggregates leak. |
| 6 | Unauthenticated request to any monitoring endpoint | 401 Unauthorized. |

## 6. Postconditions
- Monitoring is restricted to system roles; SystemSupport cannot mutate; tenant/non-system roles are fully blocked. Denied attempts are auditable.
