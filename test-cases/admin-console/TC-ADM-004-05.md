# TC-ADM-004-05: Suspended tenant API returns HTTP 451 to tenant users (Tenant Admin exempt)

## 1. Test Objective
Verify AC-1/AC-2 API-blocking behavior: once a tenant is `Suspended`, ordinary tenant-user API requests are rejected with HTTP 451 (Unavailable For Legal Reasons), while a Tenant Admin retains the limited access needed for the suspension notice / export request. System Admin access at `admin.*` is unaffected.

## 2. Related Requirements
- User Story: US-ADM-004
- Acceptance Criteria: AC-1, AC-2
- Test Hints: API blocking (451)

## 3. Preconditions
- Tenant "Acme" is `Suspended`.
- A valid (limited) Tenant Admin session and a (would-be) regular-user request context exist.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| suspended tenant | Acme | status = Suspended |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Issue a tenant-user API GET against Acme (regular user context) | HTTP 451 returned by the suspension gate. |
| 2 | Issue a tenant-user API write against Acme (regular user context) | HTTP 451 (no data mutated). |
| 3 | As Tenant Admin, access the suspension-notice / export-request endpoints | Permitted (not 451) — Tenant Admin is exempt for the read-only notice/export path. |
| 4 | As System Admin at `admin.yourhrm.com`, read the Acme tenant record | 200 — System Admin console access is unaffected by tenant suspension. |

## 6. Postconditions
- Suspended-tenant API surface returns 451 to ordinary users; Tenant Admin and System Admin retain their scoped access.
