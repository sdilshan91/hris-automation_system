# TC-ADM-010-03: Partial export — only selected entities' CSVs are in the bundle

## 1. Test Objective
Verify FR-1 (scope as an array of entity codes) / FR-2 Test Hint ("Partial export"): when the requester selects only a subset of entities (Employees + Leave), the bundle contains CSVs ONLY for those entities and the manifest `scope` reflects the selected list — no CSV for unselected entities (e.g. Payroll, Attendance) is present.

## 2. Related Requirements
- User Story: US-ADM-010
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1 (scope = array of entity codes), FR-2 (per-entity query + serialize)
- Test Hints: "Partial export: select only Employees and Leave; verify only those CSVs are in the export."

## 3. Preconditions
- Tenant Admin "Tara" authenticated at `acme.yourhrm.com`; Acme `Active` with data across many entities (employees, leave, attendance, payroll, payslips).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| scope | [Employees, LeaveRequests] (+ LeaveBalances if grouped) | partial selection |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | POST export with `scope` = the Employees + Leave entity codes | 202/200; ExportRequest Queued with the selected scope recorded. |
| 2 | Let the job complete and open the ZIP | Contains `employees.csv` and the leave CSV(s); audit_log.jsonl; manifest.json. |
| 3 | Assert unselected entities absent | NO `attendance_records.csv`, `payroll_runs.csv`, or `payslips.csv` in the bundle. |
| 4 | Inspect `manifest.json` `scope` | Reflects the selected entity list (NOT `full`). |
| 5 | Inspect manifest file blocks | Only the selected entities' CSVs (+ audit_log) have manifest entries with row_count/checksum. |

## 6. Postconditions
- ExportRequest Completed; bundle holds only the selected entities.
