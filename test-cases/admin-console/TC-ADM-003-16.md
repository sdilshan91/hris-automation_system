# TC-ADM-003-16: [DEFERRED] traceId end-to-end correlation of impersonation events

## 1. Test Objective
Verify NFR-5: all impersonation events (start, per-action audit, end) are tagged with a `traceId` that allows end-to-end correlation across the impersonation flow in the observability stack.

## 2. Related Requirements
- User Story: US-ADM-003
- Non-Functional Requirements: NFR-5
- Test Hints: (derived from NFR-5)

## 3. Status — DEFERRED / BLOCKED
**Blocked: depends on the observability stack.** End-to-end `traceId` correlation requires the OpenTelemetry/observability pipeline that is itself DEFERRED (the same deferred metrics stack flagged in US-ADM-002's deferred monitoring TCs). Serilog pushes `TenantId`/`TenantSubdomain` into the log context per request today, but a propagated `traceId` correlating start -> actions -> end across services is not yet wired.

**Expected behavior once observability lands:** the start audit, every per-action audit, and the end audit for a single session share one correlatable `traceId`, queryable end-to-end in the observability stack.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| events | Impersonation.Started, per-action, Impersonation.Ended | all in one session |
| correlation key | traceId | must match across events |

## 5. Test Steps (to enable once the observability pipeline lands)
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Start a session, perform actions, end it | Lifecycle completes (AC-1/AC-2/AC-3). |
| 2 | Query the observability stack for the session's events | Start, action, and end events are returned. |
| 3 | Compare the `traceId` across those events | All share a correlatable traceId enabling end-to-end tracing (NFR-5). |

## 6. Postconditions
- (Deferred) impersonation lifecycle is traceable end-to-end via traceId.
