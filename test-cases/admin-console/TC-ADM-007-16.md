# TC-ADM-007-16: [DEFERRED] AC-5 LIVE delegation routing for a submitted request

## 1. Test Objective
Verify the RUNTIME portion of AC-5: when a real request reaches a delegation-enabled step and the primary approver has an active APPROVED leave, the system automatically routes the approval to the configured backup approver, and the delegation is recorded in the workflow instance.

## 2. Related Requirements
- User Story: US-ADM-007
- Acceptance Criteria: AC-5 (LIVE routing portion)
- Functional Requirements: FR-2 (delegation config — stored, see TC-ADM-007-15)
- Test Hint: "Delegation — configure delegation, set the primary approver on-leave, submit a request, verify it routes to the backup approver."

## 3. Preconditions (NOT satisfiable in the current build)
- Requires the DEFERRED runtime engine: per-request `WorkflowInstance` / `StepInstance` creation, the live cross-module request flow (Leave/Attendance/etc. routing through these definitions), and an at-step on-leave lookup of the primary approver.

| Field | Value | Notes |
|-------|-------|-------|
| primary approver | on approved leave during the step | trigger |
| backup approver | configured per TC-ADM-007-15 | target |
