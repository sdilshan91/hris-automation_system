# TC-ADM-008-03: Filter by date range — only rows within [start_date, end_date] returned

## 1. Test Objective
Verify AC-2 / FR-1 (date-range filter): filtering by `start_date`/`end_date` returns only audit rows whose timestamp falls within the inclusive range. Boundary rows (exactly on start/end) are included; rows outside are excluded. Reverse-chron sort and pagination are preserved on the filtered set. (Test Hints — Filter accuracy.)

## 2. Related Requirements
- User Story: US-ADM-008
- Acceptance Criteria: AC-2
- Functional Requirements: FR-1 (timestamp range filter)

## 3. Preconditions
- Dana (`TenantAdmin`, Acme) authenticated.
- Acme `audit_log` has rows dated: 2026-05-01, 2026-05-10, 2026-05-20, 2026-06-01.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| start_date | 2026-05-10 | inclusive lower bound |
| end_date | 2026-05-20 | inclusive upper bound |
| expected | rows of 2026-05-10 and 2026-05-20 | boundary rows included |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | GET list with start_date=2026-05-10, end_date=2026-05-20 | Returns the 2026-05-10 and 2026-05-20 rows. |
| 2 | Confirm boundary inclusion | Rows dated exactly 2026-05-10 and 2026-05-20 are present. |
| 3 | Confirm exclusion | 2026-05-01 and 2026-06-01 rows are absent. |
| 4 | Confirm sort | Filtered rows remain timestamp DESC. |
| 5 | GET with start_date > end_date | 400 validation error (invalid range). |
