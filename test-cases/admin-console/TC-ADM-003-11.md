# TC-ADM-003-11: Access control (BR-1) — only SystemAdmin/SystemSupport may initiate; tenant users & unauth blocked

## 1. Test Objective
Verify BR-1 / AC-6: only `SystemAdmin` (full) and `SystemSupport` (read-only) roles may reach the impersonation initiation/end endpoints. A tenant-scoped user (e.g. Tenant Admin or Employee) is denied with 403, and an unauthenticated request is 401 — server-side, not just UI hiding.

## 2. Related Requirements
- User Story: US-ADM-003
- Acceptance Criteria: AC-6
- Business Rules: BR-1
- Test Hints: (derived from BR-1 access control)

## 3. Preconditions
- Four identities: `SystemAdmin`, `SystemSupport`, a tenant `Tenant Admin`, and a tenant `Employee`. Plus an unauthenticated client.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| SystemAdmin | olivia@system | allowed (full) |
| SystemSupport | sam@system | allowed (read-only) |
| Tenant Admin | admin@acme.com | denied 403 |
| Employee | bob@acme.com | denied 403 |
| Unauthenticated | (no token) | 401 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As SystemAdmin, `POST /impersonation/start` (valid body) | 200 — allowed (full session). |
| 2 | As SystemSupport, `POST /impersonation/start` (valid body) | 200 — allowed, read-only (see TC-ADM-003-04). |
| 3 | As Tenant Admin, `POST /impersonation/start` | 403 — tenant roles cannot initiate impersonation (BR-1). |
| 4 | As Employee, `POST /impersonation/start` | 403. |
| 5 | As Tenant Admin, call the end-session endpoint for some session id | 403 — non-system roles cannot reach impersonation endpoints. |
| 6 | Unauthenticated, `POST /impersonation/start` | 401 Unauthorized. |

## 6. Postconditions
- Impersonation endpoints are restricted to system roles at the server; tenant/non-system roles and anonymous callers are blocked.
