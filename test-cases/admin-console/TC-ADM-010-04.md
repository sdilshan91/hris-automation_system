# TC-ADM-010-04: Sensitive-auth fields excluded — no password/MFA/token hashes in any CSV

## 1. Test Objective
Verify FR-8 / BR-7 Test Hint ("Sensitive field exclusion"): password hashes, MFA secrets, and refresh-token hashes are NEVER present in any CSV in the export bundle. Specifically the Users export contains only name/email/roles — no credential columns and no credential values anywhere in the bundle.

## 2. Related Requirements
- User Story: US-ADM-010
- Functional Requirements: FR-8 (sensitive fields excluded)
- Business Rules: BR-7 (password hashes, MFA secrets, refresh-token hashes never exported)
- Test Hints: "Sensitive field exclusion: verify password hashes, MFA secrets, and token hashes are not present in any CSV file."

## 3. Preconditions
- Acme tenant has users with known BCrypt password hashes, MFA secrets, and active refresh tokens (with stored hashes) in the database.
- A FULL export of Acme has Completed (TC-ADM-010-01).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| known_pw_hash | `$2a$11$...` (BCrypt prefix) | seeded user's hash to grep for |
| users.csv columns | name, email, roles | expected columns ONLY |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open `users.csv` and inspect the header row | Columns are name/email/roles only — NO `password_hash`, `password`, `mfa_secret`, `totp_secret`, `token_hash`, `refresh_token` columns. |
| 2 | Grep the entire bundle (every CSV + jsonl) for the seeded BCrypt hash string | Zero matches — the hash appears in no file. |
| 3 | Grep all files for `$2a$`, `$2b$` (BCrypt prefixes) | Zero matches in any CSV. |
| 4 | Grep all files for the known MFA/TOTP secret value | Zero matches. |
| 5 | Grep all files for a known refresh-token hash | Zero matches. |
| 6 | Confirm users still present | `users.csv` contains the seeded users by name/email/roles (export not empty — exclusion is column-level, not row suppression). |

## 6. Postconditions
- No state change; credential material confirmed absent from the bundle.
