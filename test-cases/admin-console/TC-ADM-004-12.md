# TC-ADM-004-12: Full lifecycle transition matrix — invalid transitions rejected (409/400), no state change

## 1. Test Objective
Verify BR-1's allowed-state matrix is enforced exhaustively: valid transitions succeed and every INVALID transition is rejected with 409 (conflict) or 400, with NO state mutation, no lifecycle event, and no audit row. Complements the happy-path TCs (which cover the valid cells) by asserting the negative cells of the matrix.

## 2. Related Requirements
- User Story: US-ADM-004
- Acceptance Criteria: AC-1, AC-3, AC-5, AC-6
- Business Rules: BR-1, BR-3
- Test Hints: Invalid transitions

## 3. Preconditions
- System Admin authenticated with `SystemAdmin`.
- Tenants available (or settable) in each lifecycle state: Active, PastDue, Suspended, Terminating, Terminated. All non-system.

## 4. Test Data — BR-1 matrix (operation x source state)
| Operation | active | past_due | suspended | terminating | terminated |
|-----------|--------|----------|-----------|-------------|------------|
| Suspend | VALID | VALID | INVALID (already) | INVALID | INVALID |
| Terminate | VALID | VALID | VALID | INVALID (already) | INVALID |
| Reactivate | INVALID | INVALID | VALID | INVALID | INVALID |
| Restore | INVALID | INVALID | INVALID | VALID | INVALID (BR-3) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Suspend an already-`Suspended` tenant | 409/400 rejected; status unchanged; no lifecycle event/audit. |
| 2 | Suspend a `Terminating` tenant; suspend a `Terminated` tenant | Both rejected (409/400); no change. |
| 3 | Terminate an already-`Terminating` tenant; terminate a `Terminated` tenant | Both rejected; no change. |
| 4 | Reactivate an `Active`, a `PastDue`, a `Terminating`, and a `Terminated` tenant | All four rejected (reactivate only valid from Suspended); no change. |
| 5 | Restore an `Active`, a `PastDue`, a `Suspended` tenant | All rejected (restore only valid from Terminating); no change. |
| 6 | Restore a `Terminated` tenant | Rejected (BR-3 — terminated cannot be restored via UI/API); cross-ref TC-ADM-004-13. |
| 7 | Across all rejected attempts, re-read each tenant | Every source state is preserved exactly; zero lifecycle events / audit rows generated for rejected attempts. |

## 6. Postconditions
- Only the BR-1 valid cells transition; every invalid transition is a no-op rejection.
