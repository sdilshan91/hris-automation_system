# TC-ADM-008-04: Filter by actor — only the selected user's audit rows returned

## 1. Test Objective
Verify AC-2 / FR-1 (actor filter): filtering by `actor_user_id` returns only audit rows whose actor is that user, scoped to the current tenant. (Test Hints — Filter accuracy: multiple actors.)

## 2. Related Requirements
- User Story: US-ADM-008
- Acceptance Criteria: AC-2
- Functional Requirements: FR-1 (actor_user_id filter)

## 3. Preconditions
- Dana (`TenantAdmin`, Acme) authenticated.
- Acme `audit_log` has rows by actor Dana (3 rows) and actor Mike (2 rows).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| actor_user_id | Mike's user id | |
| expected | Mike's 2 rows | Dana's rows excluded |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | GET list with actor_user_id = Mike | Returns exactly Mike's 2 audit rows. |
| 2 | Confirm exclusion | None of Dana's rows appear. |
| 3 | GET with actor_user_id = a user from another tenant | Empty result (the foreign actor has no rows in Acme's scope). |
| 4 | Confirm each row | actor name + email match Mike. |
