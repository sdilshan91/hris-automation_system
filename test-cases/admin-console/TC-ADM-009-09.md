# TC-ADM-009-09: Delete guard — deleting a referenced plan is rejected; only archiving permitted

## 1. Test Objective
Verify FR-7 + the "Cannot delete referenced plan" Test Hint: deleting a plan is rejected if any tenant references it (including terminated tenants whose records are retained). Only archiving is permitted for referenced plans. A plan referenced by no tenant may be deleted (if the implementation allows hard-delete of orphan plans), otherwise archive is the only path.

## 2. Related Requirements
- User Story: US-ADM-009
- Functional Requirements: FR-7 (no delete if referenced; only archive)
- Test Hints (Cannot delete referenced plan)

## 3. Preconditions
- System Admin "Pat" authenticated at `admin.yourhrm.com` with `SystemAdmin`.
- Plan `growth` is referenced by an ACTIVE tenant "Acme".
- Plan `legacy` is referenced by a TERMINATED tenant "OldCo" (record retained).
- Plan `unused` is referenced by NO tenant.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| growth | referenced by active Acme | delete must be rejected |
| legacy | referenced by terminated OldCo | delete must be rejected (retained record) |
| unused | referenced by no tenant | delete permitted (or archive-only if hard-delete disabled) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Pat, DELETE plan `growth` | 409/400 — rejected: plan is referenced by tenant(s); message advises to archive instead. Plan still exists. |
| 2 | DELETE plan `legacy` (terminated-tenant reference) | 409/400 — rejected; a terminated tenant's retained reference still blocks deletion (FR-7). |
| 3 | Archive `growth` instead | 200 — archive succeeds (the permitted alternative). |
| 4 | DELETE plan `unused` (no references) | Either 200 (hard-delete of orphan plan) OR 409 with archive-only guidance — behavior is consistent and documented; no referenced plan is ever deletable. |

## 6. Postconditions
- No referenced plan deleted; referenced plans only archivable.
