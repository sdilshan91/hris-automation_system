# TC-ADM-006-08: Localization — defaults persisted and become tenant-wide defaults for users without a preference

## 1. Test Objective
Verify AC-3/BR-5/FR-1: a Tenant Admin sets the tenant's default language, date format, number format, time zone, and currency; these persist to the localization columns on the Tenant entity and become the defaults for ALL users who have NOT set a personal preference (configuration hierarchy: user preference overrides tenant default, BR-2/BR-5). A user WITH a personal preference is not overridden. The change is audited.

## 2. Related Requirements
- User Story: US-ADM-006
- Acceptance Criteria: AC-3
- Functional Requirements: FR-1, FR-4
- Business Rules: BR-2 (config hierarchy), BR-5 (default language applies to users w/o preference)
- Non-Functional: NFR-4 (audit)

## 3. Preconditions
- Tenant Admin "Dana" authenticated at `acme.yourhrm.com`.
- User "Noah" has NO personal language preference; user "Ivy" HAS a personal preference (e.g. her own language/date format).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| locale.default_language | "fr" | from supported list |
| locale.date_format | "DD/MM/YYYY" | |
| locale.number_format | "1.234,56" | |
| locale.time_zone | "Europe/Paris" | |
| locale.currency | "EUR" | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Dana, `PUT` localization with the Test Data | 200; values persisted to the current tenant's localization columns. |
| 2 | `GET` localization | Returns the new tenant defaults. |
| 3 | As Noah (no preference), view the app | Language/date/number/currency render using the tenant defaults (fr / DD-MM-YYYY / EUR). |
| 4 | As Ivy (has preference), view the app | Ivy's personal preference still wins (tenant default does NOT override her). |
| 5 | Inspect audit | Before/after entry for the localization change, actor = Dana. |

## 6. Postconditions
- Tenant localization defaults set; users without a preference inherit them; preference-holders unaffected; audited.
