# TC-ADM-008-17: Audit log immutability by code convention — no update/delete API path exists

## 1. Test Objective
Verify the application-layer portion of AC-5 / NFR-3: the audit log is append-only as enforced TODAY — there is NO application code path (controller/command/handler) that updates or deletes an individual audit record; the only mutating operations on `audit_log` are inserts (the SaveChanges interceptor) and the scheduled retention purge (TC-ADM-008-14). The DB-role append-only GRANT (no UPDATE/DELETE permission) is a DEFERRED platform-infra hardening layer (TC-ADM-008-18); this case asserts the code-convention immutability in force now.

## 2. Related Requirements
- User Story: US-ADM-008
- Acceptance Criteria: AC-5 (audit_log append-only; modify/delete rejected)
- Non-Functional Requirements: NFR-3 (immutable; DB role lacks UPDATE/DELETE — DB-grant deferred)

## 3. Preconditions
- Dana (`TenantAdmin`, Acme) authenticated.
- An Acme audit row A1 exists.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| audit_id | A1 | target of tamper attempts |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Survey the API surface for audit endpoints | Only read (list/detail) + export exist; NO PUT/PATCH/DELETE endpoint for an audit record is exposed. |
| 2 | Attempt PUT/PATCH /audit-logs/A1 | 404/405 — no such route/method (no update path). |
| 3 | Attempt DELETE /audit-logs/A1 | 404/405 — no such route/method (no delete path). |
| 4 | Confirm only insert + purge mutate audit_log | The single mutation paths are the SaveChanges interceptor (insert) and AuditLogPurgeJob (bulk retention delete) — no per-record edit/delete handler exists. |
| 5 | Note deferred DB-role grant | DB-level UPDATE/DELETE revocation is deferred (TC-ADM-008-18); today immutability is by code convention. |

## 6. Postconditions
- A1 unchanged; no audit record edited or individually deleted.
