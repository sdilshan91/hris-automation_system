# TC-ADM-001-07: Trial-days boundary drives status (trial_days = 0 -> active; > 0 -> trial)

## 1. Test Objective
Verify BR-3 / AC-1: when the selected plan (or the supplied trial_days) resolves to `trial_days = 0` the tenant is created with `status = active` and no `trial_ends_at`; when `trial_days > 0` the tenant is created with `status = trial` and `trial_ends_at` set accordingly. This tests the decision boundary at trial_days = 0 vs 1.

## 2. Related Requirements
- User Story: US-ADM-001
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1
- Business Rules: BR-3

## 3. Preconditions
- System Admin authenticated at `admin.yourhrm.com` with the `SystemAdmin` role.
- Two active plans exist: "Starter" (trial_days = 0) and "Growth" (trial_days >= 1, e.g. 1 and 14).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Tenant A subdomain | zerotrial | uses trial_days = 0 |
| Tenant B subdomain | onetrial | uses trial_days = 1 (boundary just above 0) |
| Tenant C subdomain | longtrial | uses trial_days = 14 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Provision `zerotrial` with the Starter plan (trial_days = 0) | 201 Created; `tenant.status = active`; `trial_ends_at` is null/unset (BR-3). |
| 2 | Provision `onetrial` with trial_days = 1 | 201 Created; `tenant.status = trial`; `trial_ends_at` ~= created_at + 1 day. |
| 3 | Provision `longtrial` with trial_days = 14 | 201 Created; `tenant.status = trial`; `trial_ends_at` ~= created_at + 14 days. |
| 4 | Verify welcome template selection | `zerotrial` receives the `active_welcome` template; `onetrial`/`longtrial` receive `trial_welcome` (FR-4). |

## 6. Postconditions
- Status and trial_ends_at correctly reflect the trial_days boundary for all three tenants.
