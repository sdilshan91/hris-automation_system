# TC-ADM-006-01: Organization profile GET+PUT — fields persisted, reflected in UI, before/after audited

## 1. Test Objective
Verify the primary success flow of AC-1: a Tenant Admin reads and then updates the organization profile (company name, legal name, registration number, address, industry, size, fiscal year start). The PUT persists to the current tenant's typed Tenant-entity columns (org profile is realized as TYPED COLUMNS on the Tenant entity, not a separate EAV `tenant_setting` table — codebase convention), the values are reflected immediately on subsequent reads (e.g. company name in header/sidebar), and the change is recorded in the tenant's `audit_log` with before/after values (NFR-4). No other tenant is affected.

## 2. Related Requirements
- User Story: US-ADM-006
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1
- Business Rules: BR-1 (TenantAdmin/TenantOwner), BR-4 (fiscal year start)
- Non-Functional: NFR-4 (before/after audit)

## 3. Preconditions
- Tenant Admin "Dana" is authenticated at `acme.yourhrm.com` with the `TenantAdmin` role; tenant Acme is `active` (or `trial`).
- Org profile endpoints (`GET`/`PUT`) are reachable for the current tenant; no `tenant_id` parameter is accepted — the current tenant is resolved from `ITenantContext`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| org.name | "Acme Robotics" | new company name |
| org.legal_name | "Acme Robotics LLC" | |
| org.registration_number | "REG-99182" | |
| org.address | "12 Mill Rd, Springfield" | |
| org.industry | "Manufacturing" | |
| org.size | "201-500" | |
| org.fiscal_year_start | 4 (April) | BR-4 affects accrual/payroll/reporting |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Dana, `GET` org profile | 200; returns the CURRENT tenant's org profile (current values), no `tenant_id` echoed/required. |
| 2 | `PUT` org profile with the Test Data | 200; all fields persisted to the current Tenant row's typed columns. |
| 3 | `GET` org profile again | 200; every field equals the new value. |
| 4 | Reload a tenant page that renders company name | Header/sidebar reflects "Acme Robotics" immediately (next read, no stale value). |
| 5 | Inspect the tenant `audit_log` | One entry: action = settings update (org profile), actor = Dana, BEFORE = prior values, AFTER = new values, timestamp present. |
| 6 | Confirm no other tenant changed | Tenant Beta's org profile is untouched. |

## 6. Postconditions
- The current tenant's org profile is updated; one before/after audit row exists; no cross-tenant effect.
