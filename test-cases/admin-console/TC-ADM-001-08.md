# TC-ADM-001-08: Only SystemAdmin may provision; SystemSupport and tenant roles are denied

## 1. Test Objective
Verify BR-1 and authentication/authorization on the provisioning endpoint: only a system-tenant user with the `SystemAdmin` role may create a tenant. `SystemSupport` is explicitly denied; ordinary tenant users (e.g. TenantOwner/TenantAdmin of an existing tenant) and unauthenticated callers are denied. No tenant is created on a denied request.

## 2. Related Requirements
- User Story: US-ADM-001
- Acceptance Criteria: AC-1 (precondition guard)
- Business Rules: BR-1, BR-5
- Non-Functional: NFR-3 (denied attempts auditable)

## 3. Preconditions
- A `SystemSupport` user exists in the system tenant.
- A `TenantAdmin` user exists in tenant `acme`.
- The provisioning endpoint is `POST /api/v1/admin/tenants`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| SystemSupport JWT | system tenant, role SystemSupport | must be denied (BR-1) |
| TenantAdmin JWT | acme tenant, role TenantAdmin | wrong context, denied |
| No token | (none) | unauthenticated |
| Valid payload | name/subdomain `denytest`/plan/owner/region | so only authz is at fault |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Call `POST /api/v1/admin/tenants` with the SystemSupport JWT | 403 Forbidden; no tenant created. The UI hides/disables "Create Tenant" for SystemSupport. |
| 2 | Call the endpoint with the acme TenantAdmin JWT | 403 Forbidden (a tenant-context user cannot reach the system-admin provisioning API); no tenant created. |
| 3 | Call the endpoint with no Authorization header | 401 Unauthorized; no tenant created. |
| 4 | Confirm the system tenant cannot be re-created via this flow | Any attempt to set `is_system = true` is ignored/rejected; provisioned tenants always have `is_system = false` (BR-5). |
| 5 | Re-run the same payload with a valid `SystemAdmin` JWT | 201 Created, confirming the endpoint itself works and only authorization gates it. |
| 6 | Inspect `system_audit_log` | Denied attempts are recorded (actor, timestamp, IP, outcome) per NFR-3 where the platform logs authz failures. |

## 6. Postconditions
- No tenant created from any denied caller; provisioning succeeds only for SystemAdmin.
