# TC-ADM-008-08: Combined filters use AND logic; pagination + sort preserved

## 1. Test Objective
Verify AC-2: multiple filters combine with AND logic (a row must satisfy ALL active filters), and the filtered result set still honors reverse-chronological sort and pagination. (Test Hints — Filter accuracy: filters in combination.)

## 2. Related Requirements
- User Story: US-ADM-008
- Acceptance Criteria: AC-2
