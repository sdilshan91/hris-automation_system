# TC-ADM-004-06: Terminate an active tenant with grace — status Terminating, scheduled_at set, deletion + 14/7/1d reminder jobs scheduled, lifecycle event (happy path)

## 1. Test Objective
Verify the primary success flow of AC-3/FR-2: a System Admin terminates an `active` tenant with a grace period (default 30 days). The tenant transitions to `Terminating`, `TerminationScheduledAt = now + graceDays`, the data-deletion Hangfire job is scheduled at that time plus reminder jobs at 14d/7d/1d before deletion, the tenant enters read-only mode with export endpoints active, and a `tenant_lifecycle_event` with `event_type = 'termination_initiated'` plus a `system_audit_log` entry are written (FR-7).

## 2. Related Requirements
- User Story: US-ADM-004
- Acceptance Criteria: AC-3
- Functional Requirements: FR-2, FR-7
- Business Rules: BR-1 (active -> terminating), BR-4 (grace default 30)
- Test Hints: Terminate with grace

## 3. Preconditions
- System Admin "Olivia" authenticated with `SystemAdmin`.
- Active, non-system tenant "Acme".
- Correct typed-subdomain confirmation supplied (see FR-4 / TC-ADM-004-17).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| tenant_id | acme-tenant-uuid | active, non-system |
| reason | "Account closed at customer request — ref CLOSE-77" | mandatory |
| grace_period_days | 30 | default (plan-configurable) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | `POST /api/v1/admin/tenants/{id}/terminate` with `{ reason, grace_period_days: 30 }` (+ confirmation) | 200/204; success. |
| 2 | Re-read the tenant | `status = Terminating`; `TerminationScheduledAt` ~= now + 30 days. |
| 3 | Inspect scheduled Hangfire jobs for the tenant | A data-deletion job is scheduled at `TerminationScheduledAt`; three reminder jobs scheduled at 14d/7d/1d before that instant. |
| 4 | Issue a tenant write API call against Acme | 403 (read-only mode) — cross-ref TC-ADM-004-08; export endpoints remain accessible. |
| 5 | Query `tenant_lifecycle_event` | One new row: `event_type = 'termination_initiated'`, reason + grace captured, actor=Olivia. |
| 6 | Query `system_audit_log` | A termination-initiated entry exists (FR-7). |

## 6. Postconditions
- Acme is `Terminating` with a deletion deadline and reminders queued; read-only with exports live; transition immutably audited. Reminder email DELIVERY is deferred (TC-ADM-004-18) — scheduling is the assertion here.
