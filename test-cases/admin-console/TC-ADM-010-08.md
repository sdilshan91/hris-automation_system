# TC-ADM-010-08: Terminating-tenant export ALLOWED (grace-period data extraction)

## 1. Test Objective
Verify AC-4 / BR-3 Test Hint ("Terminating tenant export"): an export initiated for a tenant in `Terminating` status succeeds — export endpoints remain active during the grace period so the tenant can extract a complete copy before deletion. This is a primary use case, not an exception.

## 2. Related Requirements
- User Story: US-ADM-010
- Acceptance Criteria: AC-4
- Business Rules: BR-3 (export explicitly available during the terminating grace period)
- Dependency: US-ADM-004 (terminating lifecycle state)
- Test Hints: "Terminating tenant export: set a tenant to terminating status; initiate export; verify it succeeds."

## 3. Preconditions
- Tenant "Beta" is in `Terminating` status (grace period active; data not yet deleted).
- Tenant Admin "Ben" authenticated at `beta.yourhrm.com` (Terminating tenants are read-only but export remains permitted per US-ADM-004 AC-3).
- Beta has data across in-scope entities.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| tenant | beta (Terminating) | grace period active |
| scope | full | complete pre-deletion copy |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Ben, POST a full export for Beta | Accepted (NOT rejected by the status gate); ExportRequest Queued. |
| 2 | Let the job complete | ExportRequest Completed; bundle generated at `{betaTenantId}/exports/{export_id}/export_bundle.zip`. |
| 3 | Open the bundle | Contains all in-scope CSVs + audit_log.jsonl + manifest — the full data that would be deleted at grace expiry. |
| 4 | Confirm a normal write to Beta is still blocked | A non-export write still returns 403 (Terminating is read-only) — export is the deliberate exception. |

## 6. Postconditions
- ExportRequest Completed for the terminating tenant; bundle available within the 72h window.
