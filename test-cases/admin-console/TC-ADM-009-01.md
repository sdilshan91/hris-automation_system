# TC-ADM-009-01: Plan list shows all fields + active-tenant-count per plan + sortable by name/price/tenant count

## 1. Test Objective
Verify AC-1 / FR-5: from the System Admin context, the Plans list returns ALL subscription plans showing code, name, monthly/yearly price, currency, active tenant count (computed live per plan), public/private status, and active/archived status. The list is sortable by name, price, and active tenant count.

## 2. Related Requirements
- User Story: US-ADM-009
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1 (CRUD list from system admin context), FR-5 (active-tenant-count per plan)
- Business Rules: BR-2 (is_public flag surfaced)

## 3. Preconditions
- System Admin "Pat" authenticated at `admin.yourhrm.com` with `SystemAdmin`.
- At least 4 plans exist: `starter` (public, active), `growth` (public, active), `business` (public, active), `enterprise-acme` (private/`is_public=false`, active), plus one archived plan `legacy` (`is_active=false`).
- Tenants are assigned across plans: e.g. 3 active tenants on `starter`, 1 active tenant on `growth`, 0 on `business`, 1 on `enterprise-acme`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| starter | price_per_month=29, currency=USD, is_public=true, is_active=true | 3 active tenants |
| growth | price_per_month=99, USD, public, active | 1 active tenant |
| business | price_per_month=299, USD, public, active | 0 tenants |
| enterprise-acme | is_public=false, active | 1 active tenant |
| legacy | is_active=false (archived) | tenant count as computed |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Pat, GET the plans list | 200; all plans returned (active AND archived). |
| 2 | Inspect a plan row | Shows code, name, price_per_month, price_per_year, currency, active_tenant_count, is_public, is_active. |
| 3 | Inspect active_tenant_count | starter=3, growth=1, business=0, enterprise-acme=1 — count of ACTIVE tenants currently referencing each plan. |
| 4 | Sort by name asc | Plans ordered alphabetically by name. |
| 5 | Sort by price desc | Plans ordered by price_per_month descending (business, growth, starter...). |
| 6 | Sort by active tenant count desc | starter (3) first, then growth/enterprise-acme (1), then business (0). |

## 6. Postconditions
- No state change; counts reflect live tenant assignments.
