# TC-ADM-007-17: [DEFERRED] BR-4 SLA breach auto-escalation fires at runtime

## 1. Test Objective
Verify BR-4: when a step's SLA timer expires on a real in-flight request, the system auto-escalates to the configured `escalation_target`; if no escalation target is defined, the SLA breach instead triggers a notification to the Tenant Admin. (Test Hint "SLA escalation": submit a request, let the SLA timer expire or mock time, verify the escalation target is notified and the request is routed.)

## 2. Related Requirements
- User Story: US-ADM-007
- Acceptance Criteria: AC-2 (escalation config — stored & verified in TC-ADM-007-02)
- Business Rules: BR-4 (SLA breach -> escalation target, else notify Tenant Admin)
- Non-Functional: NFR-3 references workflow evaluation timing

## 3. Preconditions (NOT satisfiable in the current build)
- Requires the DEFERRED runtime engine: per-request `WorkflowInstance`/`StepInstance` creation, an SLA timer/scheduler (Hangfire) firing on breach, and the notification dispatch seam (US-NTF) — none of which route live requests through these definitions yet.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| step with escalation_target | SLA 24h, target = DepartmentHead | escalation branch |
| step without escalation_target | SLA 24h, no target | notify-Tenant-Admin branch |

## 5. Test Steps (deferred — to execute once the runtime engine lands)
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Submit a request; advance/mock time past the step SLA | SLA breach detected on the in-flight step instance. |
| 2 | Step has an escalation_target | Approval routed/escalated to the escalation target; escalation recorded on the instance. |
| 3 | Step has NO escalation_target | A notification is sent to the Tenant Admin (no silent stall). |

## 6. Postconditions
- DEFERRED. The escalation CONFIG (target on the step) is stored + verified at definition time (TC-ADM-007-02); the runtime FIRING is blocked on the deferred SLA-timer engine + notification module.
