# TC-ADM-007-06: FR-5 validation — workflow with zero steps is rejected

## 1. Test Objective
Verify FR-5 (first clause): the workflow editor validates that AT LEAST ONE step exists. A create (or edit-to-zero-steps) request with an empty steps array is rejected; no definition is persisted.

## 2. Related Requirements
- User Story: US-ADM-007
- Acceptance Criteria: AC-2 (creation validity)
- Functional Requirements: FR-5 (>= 1 step)

## 3. Preconditions
- Dana (`TenantAdmin`) authenticated; Acme `active`; plan limit not reached.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| name | "Empty WF" | |
| entity_type | Leave | |
| steps | [] | zero steps — invalid |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Dana, POST create workflow with an empty steps array | Rejected (HTTP 400/422); validation error indicating at least one step is required. |
| 2 | GET the workflow list | No "Empty WF" definition exists (nothing persisted). |
| 3 | Edit an existing valid workflow down to zero steps | Equally rejected; the existing workflow is unchanged (no zero-step version created). |

## 6. Postconditions
- No zero-step workflow exists; existing workflows unchanged.
