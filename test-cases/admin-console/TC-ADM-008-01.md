# TC-ADM-008-01: Audit log list — tenant-scoped, paginated (50), reverse-chronological, all columns

## 1. Test Objective
Verify AC-1 / FR-1 / FR-2: the audit log list endpoint returns the CURRENT tenant's `audit_log` rows (EF global query filter on `TenantId == ITenantContext.TenantId`), paginated (default page size 50), sorted reverse-chronological (timestamp DESC) by default. Each entry exposes: timestamp, actor (user name + email), action (e.g. "Employee.Create", "Leave.Approve", "User.Deactivate"), resource type, resource ID, IP address, and a change summary. No rows from another tenant are visible.

## 2. Related Requirements
- User Story: US-ADM-008
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1 (list: tenant filter, default 50, timestamp DESC), FR-2 (record shape)
- Business Rules: BR-1 (read roles), BR-3 (tenant-scoped)

## 3. Preconditions
- Tenant Admin "Dana" authenticated at `acme.yourhrm.com` with `TenantAdmin`; Acme is `active`/`trial`.
- Acme `audit_log` contains >= 60 rows spanning multiple actors/actions/resource types, with distinct timestamps.
- No `tenant_id` parameter is accepted — tenant resolved from `ITenantContext`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Acme audit rows | 60 rows, timestamps t-1..t-60 | reverse-chron expected |
| Sample row | action="Employee.Create", resource_type="Employee", resource_id=E1 | actor Dana |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Dana, GET the audit log list (no params) | 200; returns first page of 50 rows + total count metadata. |
| 2 | Inspect ordering | Rows ordered by timestamp DESC (newest first). |
| 3 | Inspect a row | Shows timestamp, actor name + email, action, resource_type, resource_id, ip_address, and a change summary. |
| 4 | Inspect page metadata | total count reflects all 60 Acme rows; page size = 50. |
| 5 | Confirm tenant scoping | Only Acme rows are present; no Tenant Beta audit row appears (BR-3). |

## 6. Postconditions
- No state change; list reflects only the current tenant's audit rows.
