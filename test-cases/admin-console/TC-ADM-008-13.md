# TC-ADM-008-13: Read authorization — only TenantAdmin/TenantOwner/Auditor; others 403, unauth 401

## 1. Test Objective
Verify BR-1: only `TenantAdmin`, `TenantOwner`, and `Auditor` roles may view the tenant audit log. A regular Employee/Manager without one of these roles is rejected (403); an unauthenticated request is rejected (401).

## 2. Related Requirements
- User Story: US-ADM-008
- Acceptance Criteria: AC-1 (access gating on the list)
- Business Rules: BR-1 (read roles only)

## 3. Preconditions
- Acme has users: Dana (`TenantAdmin`), Olivia (`TenantOwner`), Alex (`Auditor`), Eve (`Employee` only).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| allowed roles | TenantAdmin, TenantOwner, Auditor | 200 |
| denied role | Employee | 403 |
| no token | — | 401 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Dana (TenantAdmin), GET list | 200. |
| 2 | As Olivia (TenantOwner), GET list | 200. |
| 3 | As Alex (Auditor), GET list | 200 (read-only). |
| 4 | As Eve (Employee), GET list | 403 Forbidden. |
| 5 | With no/expired token, GET list | 401 Unauthorized. |
| 6 | As Eve, GET an audit detail | 403 Forbidden. |
