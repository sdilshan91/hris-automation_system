# TC-ADM-006-15: Plan-gating — enterprise-only settings disabled in UI and rejected by API on a constrained plan

## 1. Test Objective
Verify BR-3: settings constrained by the subscription plan are gated. On a "Starter" plan, enterprise-only options (e.g. custom CSS, white-label — Phase-2 features) are disabled in the UI with an "Upgrade your plan" indicator AND the API rejects an attempt to set them (defense in depth, not UI-only). A tenant on a plan that includes the feature is allowed. The standard org/branding/localization/policy settings remain available on all plans.

## 2. Related Requirements
- User Story: US-ADM-006
- Business Rules: BR-3 (plan-constrained settings)
- Assumptions/Constraints: §10 (custom CSS / white-label deferred to Phase 2)

## 3. Preconditions
- Tenant "Starter Co" is on the Starter plan; Tenant "Ent Co" is on a plan that includes enterprise branding (if such a plan tier exists in seed data; otherwise the enterprise-only feature is uniformly gated and the test asserts gating + API rejection only).
- Tenant Admins authenticated on each.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| enterprise-only flag | custom CSS / white-label | Phase-2; gated by plan |
| Starter plan | constrained | option disabled + API rejects |
| standard settings | org/branding-color/localization/policies | available on Starter |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As the Starter Co admin, open Branding/Security tabs | Enterprise-only options (custom CSS, white-label) are disabled with an "Upgrade your plan" indicator. |
| 2 | Attempt the enterprise-only setting via direct API call (bypassing the disabled UI) | 403/422; rejected by the API on plan grounds — not UI-only enforcement. |
| 3 | As the Starter Co admin, set standard settings (primary color, localization, password policy) | 200; standard settings are available on Starter. |
| 4 | (If an enterprise-tier tenant exists) As Ent Co admin, set the enterprise-only feature | Allowed per its plan. |
| 5 | Confirm no Starter-tenant enterprise setting persisted | The enterprise-only value is NOT stored for Starter Co. |

## 6. Postconditions
- Plan-constrained settings are gated in UI and enforced server-side; standard settings available everywhere.
