# TC-ADM-004-14: BR-2 — the system/platform tenant cannot be suspended or terminated

## 1. Test Objective
Verify BR-2: the system tenant (`is_system = true`) is immune to every destructive lifecycle transition. Attempts to suspend or terminate it are rejected, protecting the platform's own admin tenant from self-lockout or self-destruction.

## 2. Related Requirements
- User Story: US-ADM-004
- Business Rules: BR-2
- Test Hints: System tenant protection

## 3. Preconditions
- System Admin authenticated with `SystemAdmin`.
- The system tenant (`is_system = true`) is known and resolvable.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| system tenant | is_system = true | protected |
| reason | "attempt to suspend platform tenant" | valid-length reason |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | `POST .../suspend` against the system tenant with a valid reason | Rejected (403/409/400) — BR-2; status unchanged; no token revocation, no lifecycle event, no audit "suspended". |
| 2 | `POST .../terminate` against the system tenant with valid reason + grace + confirmation | Rejected — BR-2; no Terminating transition, no deletion job scheduled. |
| 3 | Re-read the system tenant | Still active/operational; System Admin console access intact. |

## 6. Postconditions
- The system tenant cannot be suspended or terminated; platform operations are never self-destructed.
