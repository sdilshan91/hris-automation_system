# TC-ADM-006-17: Settings UI — WCAG 2.1 AA, keyboard/SR operable, dirty-tracking Save, responsive 360px–4K

## 1. Test Objective
Verify NFR-5 and the §8 UX contract: the tabbed/sidebar settings layout (Organization Profile, Branding, Localization, Security & Policies) is keyboard-navigable and screen-reader operable, meets WCAG 2.1 AA (labels, focus order, contrast, error association), the per-section Save button is disabled until changes are detected (dirty-form tracking), the color picker and upload zones are accessible, and the layout is responsive from 360px to 4K.

## 2. Related Requirements
- User Story: US-ADM-006
- Non-Functional: NFR-5 (responsive 360px–4K)
- UI/UX: §8 (tabbed layout, color picker, upload preview, dirty-tracking Save)

## 3. Preconditions
- Tenant Admin "Dana" authenticated; settings UI reachable; axe/screen-reader tooling available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| viewports | 360, 768, 1280, 1920, 3840 px | responsive range |
| WCAG target | 2.1 AA | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Tab through each settings section using keyboard only | All controls reachable in logical order; visible focus ring; no keyboard trap. |
| 2 | Run an automated a11y scan (axe) on each tab | No WCAG 2.1 AA violations (labels, contrast, ARIA, error association). |
| 3 | Operate the color picker + upload zones via keyboard/SR | Hex input labeled; upload zones have accessible names; SR announces state. |
| 4 | Open a section, make no change | Save button is disabled (dirty-tracking). |
| 5 | Edit a field | Save becomes enabled; revert → disabled again. |
| 6 | Trigger a validation error (e.g. bad hex) | Error is programmatically associated with the field and announced. |
| 7 | Render at 360, 768, 1280, 1920, 3840 px | Layout reflows without clipping/overlap or horizontal scroll. |

## 6. Postconditions
- Settings UI is accessible (WCAG 2.1 AA), keyboard/SR operable, dirty-tracked, and responsive across the range.
