# TC-ADM-004-08: Terminating tenant is read-only — writes return 403, reads + export endpoints succeed

## 1. Test Objective
Verify BR-6 / AC-3: while a tenant is in `Terminating` status, only GET (read) and export endpoints are accessible to tenant users; all write operations (POST/PUT/PATCH/DELETE that mutate tenant data) return 403. This preserves the grace-period data-export window without allowing new mutations.

## 2. Related Requirements
- User Story: US-ADM-004
- Acceptance Criteria: AC-3
- Business Rules: BR-6
- Test Hints: (read-only during terminating)

## 3. Preconditions
- Tenant "Acme" is in `Terminating` status (via TC-ADM-004-06), within grace.
- A valid Acme user session exists.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| terminating tenant | Acme | status = Terminating |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | GET a tenant-scoped resource (e.g. employee list) | 200 — reads remain available during grace. |
| 2 | Call a data-export endpoint | Accessible (export remains active during grace, per AC-3 / US-ADM-010 seam). |
| 3 | Attempt a write (create/update/delete an employee, leave request, etc.) | 403 Forbidden — write operations are blocked in Terminating state (BR-6); no data mutated. |
| 4 | Confirm no partial state | Repeated write attempts leave all tenant data unchanged. |

## 6. Postconditions
- Terminating tenants are read + export only; writes are uniformly 403; data is frozen pending deletion or restore.
