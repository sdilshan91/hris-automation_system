# TC-ADM-004-16: Grace-period boundaries — 7 and 90 accepted; <7 and >90 rejected; default 30 when omitted

## 1. Test Objective
Verify BR-4 / FR-2 grace-period validation: `grace_period_days` must be an integer 7-90. The boundary values 7 and 90 are accepted; 6 and 91 (and negative/zero/non-integer) are rejected (400) with no Terminating transition; when omitted, the plan default (30) is applied and `TerminationScheduledAt = now + 30 days`.

## 2. Related Requirements
- User Story: US-ADM-004
- Acceptance Criteria: AC-3
- Functional Requirements: FR-2
- Business Rules: BR-4
- Test Hints: (grace boundaries)

## 3. Preconditions
- System Admin authenticated.
- Fresh active, non-system tenants for each boundary case; correct subdomain confirmation supplied each time.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| grace = 6 | below min | rejected |
| grace = 7 | lower boundary | accepted |
| grace = 90 | upper boundary | accepted |
| grace = 91 | above max | rejected |
| grace = 0 / -1 | invalid | rejected |
| grace omitted | -> default 30 | accepted |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Terminate with grace = 6 | 400; rejected; tenant stays in source state; no deletion job. |
| 2 | Terminate with grace = 7 (fresh tenant) | 200/204; `TerminationScheduledAt` ~= now + 7 days; jobs scheduled. |
| 3 | Terminate with grace = 90 (fresh tenant) | 200/204; `TerminationScheduledAt` ~= now + 90 days. |
| 4 | Terminate with grace = 91 | 400; rejected; no change. |
| 5 | Terminate with grace = 0 and grace = -1 | 400 each; rejected. |
| 6 | Terminate omitting grace_period_days (fresh tenant) | 200/204; default 30 applied; `TerminationScheduledAt` ~= now + 30 days. |

## 6. Postconditions
- Only 7-90 day grace values are accepted; the default of 30 applies on omission; out-of-range values never schedule a deletion.
