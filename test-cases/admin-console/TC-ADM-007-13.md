# TC-ADM-007-13: WorkflowEvaluator — BR-3 parallel step requires ALL approvers before proceeding

## 1. Test Objective
Verify BR-3 via the pure `WorkflowEvaluator`: a step with `is_parallel = true` and multiple approvers requires ALL of those approvers to approve before the request proceeds to the next step. The evaluator's parallel-step resolution returns "not satisfied / does not advance" until every parallel approver has approved, and "satisfied / advance" only once all have. (Per the Test Hint "Parallel approval": the request only proceeds when both approve.) NOTE: this exercises the evaluator's parallel-completion logic directly; LIVE gating of a SUBMITTED request (per-request StepInstance state) is DEFERRED engine work (TC-ADM-007-16/-17).

## 2. Related Requirements
- User Story: US-ADM-007
- Functional Requirements: FR-2 (is_parallel)
- Business Rules: BR-3 (parallel step needs all approvers)

## 3. Preconditions
- A workflow has a step `is_parallel = true` with two approvers A1 and A2, followed by a Step N+1.
- The evaluator is invoked with the set of approvals recorded so far for the parallel step.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| parallel approvers | {A1, A2} | both required |
| state-none | approvals = {} | none yet |
| state-partial | approvals = {A1} | one of two |
| state-all | approvals = {A1, A2} | complete |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Evaluate parallel step with approvals = {} | Step NOT satisfied; request does not advance. |
| 2 | Evaluate with approvals = {A1} only | Step NOT satisfied (A2 outstanding); does not advance. |
| 3 | Evaluate with approvals = {A2} only | Step NOT satisfied (A1 outstanding); does not advance. |
| 4 | Evaluate with approvals = {A1, A2} | Step SATISFIED; request advances to Step N+1. |
| 5 | (contrast) Evaluate a SEQUENTIAL (non-parallel) step with a single approver | Satisfied as soon as that one approver approves — confirms parallel semantics are distinct from sequential. |

## 6. Postconditions
- Evaluator advances past a parallel step only when all parallel approvers have approved.
