# TC-ADM-010-18: [DEFERRED] Bundle encrypted at rest + transmitted over HTTPS

## 1. Test Objective
Cover NFR-3: the export bundle is encrypted at rest in storage and transmitted over HTTPS.

DEFERRED — status: blocked. This is INFRA-level (storage-at-rest encryption + TLS termination), not application logic. Today the bundle is written to a local/tenant-scoped path without an asserted at-rest encryption layer, and transport security depends on the deployment's TLS. The tenant-scoping of the storage PATH and the bundle integrity (SHA-256) are run-green (TC-ADM-010-01/-02); the encryption-at-rest + HTTPS guarantees are deferred to infra.

## 2. Related Requirements
- User Story: US-ADM-010
- Non-Functional Requirements: NFR-3 (encrypted at rest + HTTPS in transit)

## 3. Preconditions
- (Deferred prerequisite) Storage with at-rest encryption (e.g. S3 SSE / disk encryption) + enforced HTTPS for the download path.
