# TC-ADM-004-19: [DEFERRED] File-storage (blob) deletion during termination — documents/resumes/payslips

## 1. Test Objective
Verify that during data deletion, the tenant's file-storage artifacts (documents, resumes, payslips, and other blob paths under the tenant's storage prefix) are also deleted, per §10 of the story and the FR-3 / Data-Requirements "file storage paths" target. DEFERRED: no blob/object storage is wired into the platform today — file storage is an unimplemented extension point. The relational hard-delete + tenant-row retention is covered run-green in TC-ADM-004-09.

## 2. Related Requirements
- User Story: US-ADM-004
- Acceptance Criteria: AC-4
- Functional Requirements: FR-3
- Section 7 Data Requirements: "file storage paths"; Section 10: "File storage ... must also be deleted"

## 3. Preconditions
- DEFERRED — requires a configured blob/object store (e.g. S3/Azure Blob) holding per-tenant files. Not present.
