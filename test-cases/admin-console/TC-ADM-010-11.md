# TC-ADM-010-11: Rate limiting — max 3 exports/calendar month + one concurrent export per tenant

## 1. Test Objective
Verify BR-5 / FR-9 Test Hints ("Rate limiting" + "Concurrent export prevention"): a tenant may run at most 3 exports per calendar month — the 4th is rejected with "Monthly export limit reached." — and only one export may be in progress at a time; a second initiated while one is `Queued`/`Processing` is rejected/queued with an in-progress message.

## 2. Related Requirements
- User Story: US-ADM-010
- Functional Requirements: FR-9 (one export job per tenant at a time)
- Business Rules: BR-5 (one concurrent + max 3 per calendar month)
- Test Hints: "Rate limiting: initiate 3 in the same month; attempt a 4th -> 'Monthly export limit reached.'" + "Concurrent export prevention."

## 3. Preconditions
- Tenant Admin "Tara" authenticated at `acme.yourhrm.com`; Acme `Active`.
- Acme has 0 exports recorded in the current calendar month at test start.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| monthly_limit | 3 | per calendar month |
| concurrent_limit | 1 | per tenant |
| limit_message | "Monthly export limit reached." | exact rejection text |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Initiate export #1; let it Complete | Accepted; ExportRequest Completed (month count = 1). |
| 2 | Initiate export #2; let it Complete | Accepted (count = 2). |
| 3 | Initiate export #3; let it Complete | Accepted (count = 3). |
| 4 | Initiate export #4 in the same calendar month | Rejected with exactly "Monthly export limit reached."; no 4th ExportRequest enters Processing. |
| 5 | (Concurrency) Reset to a fresh month / fresh tenant; initiate export A and, while A is still `Queued`/`Processing`, initiate export B | B is rejected (or queued) with an in-progress message; A and B are never both `Processing` for the same tenant. |
| 6 | After A completes, initiate again (within monthly limit) | Accepted — the concurrency lock releases on completion. |

## 6. Postconditions
- Month count reflects only the accepted exports; no concurrent Processing for one tenant.
