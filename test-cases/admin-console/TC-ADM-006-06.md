# TC-ADM-006-06: Branding — valid favicon (ICO and PNG) accepted, stored tenant-scoped, URL persisted

## 1. Test Objective
Verify FR-2 favicon happy path: a valid ICO and a valid PNG favicon (≤500KB) are accepted by magic-byte + size validation, stored under `{tenantId}/branding/`, and `branding.favicon_url` is persisted. Complements TC-ADM-006-03 (logo) so both branding slots have a positive path.

## 2. Related Requirements
- User Story: US-ADM-006
- Acceptance Criteria: AC-2
- Functional Requirements: FR-2
- Business Rules: BR-6
- Non-Functional: NFR-2, NFR-4

## 3. Preconditions
- Tenant Admin "Dana" authenticated at `acme.yourhrm.com`; Acme tenant id known.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| favicon ICO | valid `.ico`, ~50KB | magic bytes `00 00 01 00` |
| favicon PNG | valid PNG, ~30KB | magic bytes `89 50 4E 47` |
| size limit | ≤ 500KB | FR-2 favicon |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Upload the valid ICO favicon | 200; accepted; stored under `{Acme-tenantId}/branding/`. |
| 2 | `GET` branding | `branding.favicon_url` points to the stored ICO. |
| 3 | Replace with the valid PNG favicon | 200; accepted; URL updated. |
| 4 | Inspect audit | Before/after entry for the favicon change. |

## 6. Postconditions
- `branding.favicon_url` persisted; file under Acme branding prefix; audited.
