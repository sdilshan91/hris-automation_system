# TC-ADM-006-05: Branding — oversize and wrong-type uploads rejected at size/type boundaries

## 1. Test Objective
Verify FR-2/NFR-2 size and type boundaries for branding uploads: logo > 2MB is rejected; favicon > 500KB is rejected; files at/just under the limit are accepted; a disallowed type for the slot (e.g. GIF logo, JPEG favicon) is rejected. No partial/oversize file is stored.

## 2. Related Requirements
- User Story: US-ADM-006
- Acceptance Criteria: AC-2
- Functional Requirements: FR-2
- Non-Functional: NFR-2 (server-side size + type validation)

## 3. Preconditions
- Tenant Admin "Dana" authenticated at `acme.yourhrm.com`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| logo over limit | valid PNG, 2.5MB | > 2MB → reject |
| logo at limit | valid PNG, ~2MB | accept |
| favicon over limit | valid PNG/ICO, 600KB | > 500KB → reject |
| favicon at limit | valid ICO, ~480KB | accept |
| wrong-type logo | valid GIF | not PNG/SVG → reject |
| wrong-type favicon | valid JPEG | not ICO/PNG → reject |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Upload 2.5MB PNG logo | 400; size-limit error; nothing stored. |
| 2 | Upload ~2MB PNG logo | 200; accepted (at boundary). |
| 3 | Upload 600KB favicon | 400; size-limit error; nothing stored. |
| 4 | Upload ~480KB ICO favicon | 200; accepted. |
| 5 | Upload a valid GIF as logo | 400; type-not-allowed error. |
| 6 | Upload a valid JPEG as favicon | 400; type-not-allowed error. |
| 7 | Inspect `{tenantId}/branding/` after rejects | No oversize/partial/wrong-type file written. |

## 6. Postconditions
- Only the at-limit valid files are stored; rejected uploads leave no residue.
