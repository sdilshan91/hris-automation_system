# TC-ADM-005-17: Audit completeness (NFR-2) — every mutating user-management action writes actor/action/before-after/IP/timestamp

## 1. Test Objective
Verify NFR-2: all user-management mutations are recorded in the tenant `audit_log` with actor, action, before/after state, IP, and timestamp. This is a cross-action sweep that asserts the audit envelope is complete (not just present) for each mutating operation in this story.

## 2. Related Requirements
- User Story: US-ADM-005
- Acceptance Criteria: AC-2, AC-3, AC-4, AC-5
- Functional Requirements: FR-4, FR-5
- Non-Functional: NFR-2

## 3. Preconditions
- Tenant Admin "Dana" authenticated on Acme with a known client IP.
- A target member and a pending invitation exist.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| actions under test | invite, bulk-invite, role-edit, deactivate, force-reset, end-sessions, resend, revoke | each must audit |
| required fields | actor, action, before, after, IP, timestamp | NFR-2 envelope |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Perform an invite, then read its `audit_log` row | Row present with actor=Dana, action=user.invite, before=null, after={invited member}, IP, timestamp. |
| 2 | Perform a role edit, then read the audit row | before={old roles}, after={new roles} both populated; actor/IP/timestamp present. |
| 3 | Perform a deactivate, then read the audit row | before status=active, after=disabled; full envelope present. |
| 4 | Perform a force-password-reset, then read the audit row | action recorded; actor/IP/timestamp present; sensitive token/password values NOT stored in the log. |
| 5 | Perform end-sessions, resend, revoke, then read each audit row | Each writes a distinct envelope-complete entry. |
| 6 | Assert every audited row is scoped to Acme `tenant_id` | No audit rows leak to/from another tenant. |

## 6. Postconditions
- Every mutating action in US-ADM-005 has a complete, tenant-scoped audit trail; no secrets in the log.
