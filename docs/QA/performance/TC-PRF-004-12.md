# TC-PRF-004-12: Clone a completed cycle as a template — all settings copied with new dates (FR-8)

## 1. Test Objective
Verify FR-8: the HR Officer can clone an existing (e.g. completed) cycle as a template for the next period. The clone copies all configuration — phases (relative durations), participant scope rules, rating scale, weight ratio, 360/calibration/anonymity toggles — into a new Draft cycle with new dates, without carrying over participant progress or review data.

## 2. Related Requirements
- User Story: US-PRF-004
- Acceptance Criteria: AC-2
- Functional Requirements: FR-6, FR-8
- Business Rules: BR-1, BR-5

## 3. Preconditions
- Tenant "acme" active; a Completed cycle "FY26 Annual Review" exists with its full configuration + submitted reviews.
- HR Officer Maya authenticated with cycle permissions.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Source cycle | FY26 Annual Review | Completed |
| New name | FY27 Annual Review | |
| New period | 2027-07-01 .. 2027-12-31 | shifted +1 year |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | On the source cycle choose "Clone", set new name + new period — `POST .../cycles/{id}/clone` | 201 Created; a NEW cycle id is returned with status Draft, tenant_id=acme. |
| 2 | Compare configuration | The clone copies: phase structure + relative durations (re-anchored to the new period), participant scope rule (e.g. Engineering+Sales), rating scale, self:manager weight ratio, 360 + calibration + anonymity toggles (FR-6/FR-8). |
| 3 | Confirm phase dates are re-anchored | Cloned phase dates fall within the NEW period 2027-07-01..2027-12-31, sequential and non-overlapping (no stale 2026 dates). |
| 4 | Confirm NO progress/review data copied | The clone has zero submitted self-assessments/manager reviews and zero completion stats — only configuration is copied. |
| 5 | Confirm scale is NOT locked on the clone | Because the clone is Draft, its rating scale is editable again (BR-5 lock applies only after the clone itself goes Active). |
| 6 | Attempt clone as an unauthorized user (Ravi `.Team`) | 403 (BR-1); no clone created. |

## 6. Postconditions
- A new Draft cycle exists with the source's configuration and fresh dates; no progress/review data carried over.
