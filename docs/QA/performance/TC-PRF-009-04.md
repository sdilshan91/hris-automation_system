# TC-PRF-009-04: Stale-goal nudge -> goal with no update for > X days (default 14) -> Hangfire nudge to employee + "Needs Attention" flag on manager dashboard; interval 0 disables

## 1. Test Objective
Verify AC-5, FR-6, and BR-4: a daily Hangfire job detects goals with no progress update for longer than the tenant-configurable stale interval (default 14 days) and, for each, sends a nudge notification to the employee with the exact substitution "You haven't updated progress on [Goal Title] in [X] days" and flags the goal as "Needs Attention" on the manager's dashboard. Setting the interval to 0 disables nudge notifications entirely. The job runs in tenant context, is idempotent, and is retried with Polly backoff.

## 2. Related Requirements
- User Story: US-PRF-009
- Acceptance Criteria: AC-5
- Functional Requirements: FR-6
- Business Rules: BR-4 (interval tenant-configurable, default 14, 0 disables)
- Non-Functional Requirements: NFR-2 (tenant-scoped job), NFR-5 (job performance, asserted in TC-PRF-009-14)

## 3. Preconditions
- Tenant "acme"; stale interval configured to the default 14 days.
- Goal A ("Reduce ticket backlog") for Sam Lee has its last update 15 days ago (stale).
- Goal B for Sam has an update 3 days ago (NOT stale).
- Goal C (a completed goal) had no update for 30 days but is Completed (should NOT nudge -- only active/in-progress goals).
- The Notification System (S25) and Hangfire are available (enqueue asserted; delivery conditional).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Stale interval | 14 days (default) | tenant config (BR-4) |
| Goal A | last update 15 days ago | stale -> nudge |
| Goal B | last update 3 days ago | not stale |
| Goal C | Completed, 30 days idle | not nudged |
| Interval override | 0 | disables nudges |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Trigger the daily stale-goal Hangfire job for acme | The job runs in acme tenant context and evaluates active goals against the 14-day interval (FR-6). |
| 2 | Inspect notifications enqueued | A nudge is enqueued to Sam for Goal A reading exactly "You haven't updated progress on Reduce ticket backlog in 15 days" (AC-5); enqueue asserted, delivery conditional on S25. |
| 3 | Confirm Goal B and Goal C | No nudge is enqueued for Goal B (within interval) or Goal C (Completed) -- only genuinely stale active goals nudge. |
| 4 | Open Dana's (manager) dashboard | Goal A is flagged "Needs Attention" on the manager's team view (AC-5); Goals B/C are not flagged. |
| 5 | Re-run the job same day (idempotency) | No duplicate nudge for Goal A; the flag remains, no double-notification. |
| 6 | Set acme's stale interval to 0 and re-run the job | NO nudge notifications are sent for any goal and no new "Needs Attention" flags are raised (BR-4 -- 0 disables). |
| 7 | Verify tenant scoping | The job processed only acme goals; a separate tenant's stale goals are untouched by this run (cross-tenant job isolation in TC-PRF-ISO-036). |

## 6. Postconditions
- Stale Goal A nudged the employee + flagged on the manager dashboard; non-stale/completed goals untouched; with interval 0, nudges are fully disabled. No cross-tenant leakage.
