# TC-PRF-004-05: Cycle dashboard — timeline + per-phase completion stats + overdue counts (AC-3)

## 1. Test Objective
Verify AC-3: for an active cycle the HR Officer sees a cycle dashboard with a timeline view of phases, completion statistics per phase (% of participants who completed goal-setting, self-assessment, manager-review), and overdue counts. All figures are computed over the tenant-scoped participant set only.

## 2. Related Requirements
- User Story: US-PRF-004
- Acceptance Criteria: AC-3
- Functional Requirements: FR-2 (phases), FR-3 (participants)
- Non-Functional Requirements: NFR-4 (dashboard load — measured separately in TC-PRF-004-13)

## 3. Preconditions
- Active cycle "FY26 Annual Review" in acme with 100 participants and the 5 phases from TC-PRF-004-01.
- Known progress seeded: 100/100 completed goal-setting, 60/100 submitted self-assessment, 25/100 manager-review done; 12 participants are past the self-assessment phase end without submitting (overdue).
- HR Officer Maya authenticated in acme.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Participants | 100 | acme-scoped |
| Goal-setting complete | 100/100 (100%) | |
| Self-assessment complete | 60/100 (60%) | |
| Manager-review complete | 25/100 (25%) | |
| Overdue (self-assessment) | 12 | past phase end, not submitted |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate to the cycle dashboard; observe `GET /api/v1/tenant/performance/cycles/{id}/dashboard` | Request carries acme tenant context; 200 OK. |
| 2 | Inspect the timeline view | All 5 phases render in order with their date ranges and a marker for "today"; the current/active phase is highlighted with its status badge. |
| 3 | Inspect per-phase completion stats | goal-setting 100%, self-assessment 60%, manager-review 25% — each computed as completed/total over the 100 acme participants (AC-3). |
| 4 | Inspect overdue counts | Self-assessment overdue count = 12; other phases show their respective overdue counts. |
| 5 | Confirm the denominator | All percentages and overdue counts are over the acme participant set only — no participants from other cycles or tenants are included. |

## 6. Postconditions
- Dashboard reflects accurate, tenant-scoped per-phase completion and overdue figures; no state changed.
