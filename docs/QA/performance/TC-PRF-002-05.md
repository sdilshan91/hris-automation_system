# TC-PRF-002-05: Save as draft and resume -- partial self-assessment persists across sessions (AC-3, FR-6)

## 1. Test Objective
Verify AC-3 and FR-6: an employee can save a partially completed self-assessment as a draft, log out, log back in (a new session), and find the draft fully restored with no data loss and status still `draft` (not submitted).

## 2. Related Requirements
- User Story: US-PRF-002
- Acceptance Criteria: AC-3
- Functional Requirements: FR-6
- Business Rules: BR-2 (partial set is draft-only)

## 3. Preconditions
- acme cycle FY26-H1 self-assessment window OPEN; Asha authenticated with `Performance.Read.Self`; 3 acknowledged goals; no draft yet.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Goal 1 | rating 4, achievement 80, comment "Met the revenue target." (24 chars) | saved in draft |
| Goal 2 | rating 3, comment in progress (15 chars, incomplete) | partial |
| Goal 3 | untouched | empty |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Fill Goal 1 fully, Goal 2 partially (15-char comment), leave Goal 3 empty; click "Save as Draft" | Save accepted; toast "Draft saved"; a self_assessment row persists with status `draft`, tenant_id=acme, employee_id=Asha. |
| 2 | Log out, then log back in as Asha (new session/JWT) and open My Review for FY26-H1 | The draft is restored: Goal 1 fully prefilled (rating 4 / achievement 80 / 24-char comment), Goal 2 rating 3 + the 15-char comment, Goal 3 empty. Status is still `draft`. |
| 3 | Confirm the record was not submitted | No manager notification fired; status != submitted; "Submit" remains disabled (Goal 3 unrated). |
| 4 | Complete Goal 2 and Goal 3 and submit | Submission succeeds and status flips to "Self-Assessment Submitted" (the same draft row is promoted, not duplicated). |

## 6. Postconditions
- A draft persists across sessions and resumes exactly; submission promotes the same record without duplication.
