# TC-PRF-004-16: Manager/HR can reopen a SUBMITTED self-assessment while the cycle window is open; employee cannot self-reopen (BUG-242 regression)

## 1. Test Objective
Verify the new `SelfAssessmentService.ReopenAsync` path (BUG-242): a manager (`Performance.Review.Team` + direct manager of the target) or HR (`Performance.Review.All`) can transition a `Submitted` self-assessment back to `Draft` (editable) **while the cycle's self-assessment window is still open**, with a `SelfAssessment.Reopened` audit row (actor + reason) written; the target **employee can never self-reopen** (403); and reopening after the window has **closed** is rejected (409). Regression guard for BUG-242: before the fix a submitted self-assessment was terminally locked with no reopen path.

## 2. Related Requirements
- User Story: US-PRF-004 (per the BUG-242 filing — reopen is gated by the cycle's open self-assessment window)
- Acceptance Criteria: AC-5 (phase-window controls); cross-reference US-PRF-002 (self-assessment lifecycle, BR-3 submitted-lock) and US-PRF-003 AC-5/BR-3 (the manager-review reopen this mirrors)
- Defect: BUG-242

## 3. Preconditions
- An active appraisal cycle; a manager and a direct report (with a submitted self-assessment); two rated goals.
- Automated: an xUnit integration test drives the real `SelfAssessmentService` over a real `AppDbContext` (InMemory) with the tenant global query filter — no service mock. The self-assessment window is toggled open/closed per case.

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Manager (Review.Team, direct manager) reopens the submitted assessment while the window is open, with a reason | Success; DTO status back to `Draft`; persisted status `Draft` with `SubmittedAt` cleared; a `SelfAssessment.Reopened` audit row (ResourceType `SelfAssessment`, reason in Detail) is written. |
| 2 | HR (Review.All) reopens (window open) | Success; status back to `Draft`. |
| 3 | The target employee (no review permission) attempts to reopen their own | Rejected: 403, `reopen_forbidden`; status stays `Submitted`; no audit row written. |
| 4 | Manager attempts to reopen after the self-assessment window has closed | Rejected: 409, `self_assessment_closed`; status stays `Submitted`. |

## 6. Postconditions
- A submitted self-assessment is reopenable only by manager/HR and only within the open window; unauthorized or out-of-window attempts leave it `Submitted` and unaudited.
