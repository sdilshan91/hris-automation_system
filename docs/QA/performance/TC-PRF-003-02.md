# TC-PRF-003-02: Submit Manager Review with one or more goals unrated -> validation error LISTING the unrated goals, submission blocked (client + server)

## 1. Test Objective
Verify AC-3 and the all-goals-rated rule: when the manager clicks "Submit Manager Review" without a manager rating (and/or comment) on every goal, the system displays a validation error that explicitly LISTS the unrated goals and prevents submission. The block is enforced both client-side and server-side (a crafted submit bypassing the UI is also rejected). No partial review is persisted as submitted.

## 2. Related Requirements
- User Story: US-PRF-003
- Acceptance Criteria: AC-3
- Functional Requirements: FR-3
- Business Rules: BR-1

## 3. Preconditions
- Same as TC-PRF-003-01: Ravi reviewing direct report Asha in FY26-H1, manager-review window open, Asha's self-assessment submitted, 3 goals.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Goal 1 | Revenue target | rated 4 + 26-char comment |
| Goal 2 | Code quality | UNRATED (no rating) |
| Goal 3 | Onboarding revamp | rated, but comment blank |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Rate Goal 1 fully; leave Goal 2's rating empty and Goal 3's comment empty; click "Submit Manager Review" | Submission is blocked. A validation error names the incomplete goals explicitly, e.g. "The following goals are not fully rated: Code quality, Onboarding revamp" (AC-3). Focus/scroll moves to the first offending goal. |
| 2 | Inspect the network tab | Either no submit request was sent (client gate) OR the server returned 400 with the same list of unrated goals. |
| 3 | Bypass the UI: POST the submit endpoint directly with Goal 2's manager_rating missing | Server returns 400 listing the unrated goal(s); status is NOT changed to "Manager Review Submitted"; nothing persisted as submitted (BR-1). |
| 4 | Complete Goal 2's rating and Goal 3's comment, then submit | Submission succeeds; status -> "Manager Review Submitted". |

## 6. Postconditions
- No submitted review exists until every goal carries a manager rating + comment; the unrated-goals error is shown and the block is server-enforced.
