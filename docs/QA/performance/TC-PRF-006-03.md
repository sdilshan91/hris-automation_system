# TC-PRF-006-03: Dispute submitted without comments is rejected; comments are mandatory (FR-4)

## 1. Test Objective
Verify FR-4: the employee sign-off offers two options -- "Acknowledge & Sign" or "Dispute" -- and a dispute requires MANDATORY comments. Submitting a dispute with empty or whitespace-only comments is rejected on the client AND re-enforced server-side; the review does NOT enter Disputed status and no notification is sent until valid comments are provided.

## 2. Related Requirements
- User Story: US-PRF-006
- Acceptance Criteria: AC-3 (Acknowledge or Dispute)
- Functional Requirements: FR-4 (dispute with mandatory comments)
- Business Rules: BR-4 (disputed reviews remain Disputed until HR resolves)

## 3. Preconditions
- Tenant "acme", Performance module enabled.
- Liam Carter's review is in "Pending Employee Sign-Off" (manager already signed, notes requested).
- Employee "Liam Carter" authenticated in acme.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Decision | Dispute | FR-4 |
| Comments (empty) | "" | rejected |
| Comments (whitespace) | "   " | rejected (trim then validate) |
| Comments (valid) | "I disagree with the rating on goal 2; the project shipped on time." | accepted |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Liam, open the sign-off screen and click "Dispute" | A comments text area appears with a "Submit Dispute" button; the button is disabled while the comment is empty (FR-4 client gate). |
| 2 | Submit the dispute with an empty comment via the API: `POST .../performance/reviews/{reviewId}/signoff` body `{decision:"Dispute", comments:""}` | Server rejects 422/400 -- "Dispute comments are required" (or equivalent); review status stays "Pending Employee Sign-Off"; NO dispute recorded; manager/HR NOT notified (FR-4 server gate). |
| 3 | Submit the dispute with whitespace-only comments `"   "` | Server trims then rejects identically; no dispute recorded. |
| 4 | Submit the dispute with the valid comment | 200; dispute captured with the comment text; status -> "Disputed"; manager + HR notified (full dispute flow asserted in TC-PRF-006-04). |

## 6. Postconditions
- No dispute is recorded for an empty/whitespace comment; the valid dispute transitions the review to Disputed.
