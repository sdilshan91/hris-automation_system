# TC-PRF-004-08: Cycle status transitions — Draft->Active->Paused->Active->Completed and Draft->Cancelled (FR-7)

## 1. Test Objective
Verify FR-7: the cycle supports the statuses Draft, Active, Paused, Completed, Cancelled, and only valid transitions are allowed. The valid happy-path lifecycle Draft -> Active -> Paused -> Active -> Completed works, the shortcut Draft -> Cancelled works, and invalid transitions are rejected.

## 2. Related Requirements
- User Story: US-PRF-004
- Acceptance Criteria: AC-2
- Functional Requirements: FR-7
- Business Rules: BR-2 (cannot delete with submitted reviews — see TC-PRF-004-09), BR-5 (rating scale locks on Active — see TC-PRF-004-10)

## 3. Preconditions
- Tenant "acme" active; HR Officer Maya authenticated with cycle permissions.
- A Draft cycle "FY26 Annual Review" and a second Draft cycle "Probation Q3" exist.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Cycle 1 | FY26 Annual Review | walks full lifecycle |
| Cycle 2 | Probation Q3 | Draft -> Cancelled |
| Statuses | Draft, Active, Paused, Completed, Cancelled | FR-7 enum |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Transition cycle 1 Draft -> Active — `POST .../cycles/{id}/status {Active}` | 200; status Active; phase-transition/reminder Hangfire jobs become live; status badge green. |
| 2 | Transition Active -> Paused | 200; status Paused (amber); scheduled reminder jobs are paused/suspended so no reminders fire while paused. |
| 3 | Transition Paused -> Active | 200; status Active again; jobs resume. |
| 4 | Transition Active -> Completed | 200; status Completed (blue); no further reminders scheduled; cycle is read-only for participants. |
| 5 | Transition cycle 2 Draft -> Cancelled (with a reason — see BR-6/TC-PRF-004-09) | 200; status Cancelled (red). |
| 6 | Attempt an invalid transition, e.g. Completed -> Active, or Cancelled -> Active, or Draft -> Completed | Each is rejected with 400/409; status unchanged (only the defined transitions are permitted). |
| 7 | Attempt a transition as an unauthorized user (Ravi `.Team`) | 403 (BR-1); status unchanged. |

## 6. Postconditions
- Cycle 1 is Completed via the full lifecycle; cycle 2 is Cancelled; no invalid transition succeeded.
