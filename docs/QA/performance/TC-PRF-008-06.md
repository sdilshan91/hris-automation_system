# TC-PRF-008-06: PIP duration < 30 days rejected; boundary exactly 30 days accepted -- minimum duration rule (BR-3, FR-1)

## 1. Test Objective
Verify BR-3 / FR-1: PIP duration must be a minimum of 30 days. A PIP whose end date is fewer than 30 days after the start date is rejected client-side AND server-side; exactly 30 days is accepted (inclusive boundary); the configurable presets (30/60/90 days, FR-1) are valid. Also verifies an end date before the start date is rejected.

## 2. Related Requirements
- User Story: US-PRF-008
- Business Rules: BR-3 (min 30 days)
- Functional Requirements: FR-1 (duration 30/60/90 configurable)
