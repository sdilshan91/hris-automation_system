# TC-PRF-007-06: Manager dashboard is scoped to direct reports only + shows a "team ranking" (NOT org-wide top/bottom)

## 1. Test Objective
Verify AC-5 + BR-1 + BR-3: when a Manager (holding `Performance.Read.Team`, NOT `Performance.Read.All`) opens Performance > Dashboard, the system renders the same widget set but scoped ONLY to the manager's direct reports (team-level view) -- average score, distribution, completion, cycle progress over the team -- and replaces the org-wide top/bottom performers list with a "team ranking" of the manager's own reports. The manager must NOT see org-wide aggregates or other teams' data.

## 2. Related Requirements
- User Story: US-PRF-007
- Acceptance Criteria: AC-5
- Business Rules: BR-1 (permission scope: managers see their team only), BR-3 (top/bottom only for `.All`; managers get a team ranking)
- Non-Functional Requirements: NFR-2 (tenant + scope isolation)

## 3. Preconditions
- Tenant "acme" / cycle "FY26"; Core HR org tree defines Manager "Maya Shah" with a known set of direct reports and OTHER managers with their own teams.
- Maya is authenticated in acme and holds `Performance.Read.Team` only (NOT `.All` / `Reports.View.All`).
- Seeded team scores so the team average + team ranking are deterministic.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Manager | Maya Shah | Performance.Read.Team |
| Direct reports | seeded team roster | BR-1 scope |
| Expected team avg | seeded team mean | scoped, not org-wide |
| Org-wide top/bottom | MUST NOT appear | BR-3 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Maya, navigate to `https://acme.yourhrm.com/performance` > Dashboard; observe `GET .../performance/dashboard/overview` | 200; the server derives the team scope from the org tree (acting user), NOT from a client-supplied scope param; widgets reflect ONLY Maya's direct reports (AC-5, BR-1). |
| 2 | Verify the average-score + distribution + completion widgets | All computed over Maya's team only; values equal the seeded team aggregates, never the org-wide values. |
| 3 | Verify the performers widget | A "team ranking" of Maya's direct reports is shown INSTEAD of the org-wide top/bottom-N list (BR-3); no employee outside Maya's team appears. |
| 4 | Verify the department-comparison chart | Either omitted or restricted to Maya's team scope; it does NOT expose other departments'/teams' averages (BR-1). |
| 5 | Attempt a drill-down into a department Maya does not manage (manipulate the dept id) | 403 / empty -- Maya cannot drill into employees outside her reporting line (BR-1; server-enforced, see TC-PRF-007-08). |
| 6 | Export as Maya | The export contains team-scoped data only -- never org-wide top/bottom or other teams (AC-5, BR-3). |

## 6. Postconditions
- Maya sees a fully team-scoped dashboard with a team ranking; no org-wide aggregate or other-team data is exposed via UI or export.
