# TC-PRF-002-16: Self-assessment evidence attachment — upload (scan→store→persist), list, download, caps (ISSUE-105 / FR-5)

## 1. Test Objective
Verify US-PRF-002 FR-5 / NFR-4 (ISSUE-105): an employee can upload a virus-scanned evidence file to one goal of their own self-assessment; the ordering is validate → SCAN → STORE → PERSIST (an infected file is rejected 400 `file_infected` with ZERO storage writes and ZERO persisted rows, proving scan precedes store); a submitted assessment is locked (409 `already_submitted`); the per-goal cap of 5 files is enforced (409 `attachment_limit_reached`); the list read returns only metadata; the owner can download the exact bytes.

## 2. Related Requirements
- User Story: US-PRF-002

- Non-Functional Requirement: NFR-4 (virus scan before persist)

## 3. Preconditions
- Active appraisal cycle with the self-assessment window OPEN; a goal assigned to the calling employee for that cycle; employee linked to the authenticated user.
