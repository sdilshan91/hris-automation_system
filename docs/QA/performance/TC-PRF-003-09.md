# TC-PRF-003-09: Submitted review is locked/read-only (edits prevented unless HR reopens); manager-review window enforced (cannot submit before/after the window)

## 1. Test Objective
Verify AC-5, BR-1: once a manager review is submitted it renders read-only and any edit attempt is blocked (UI disabled + server 403/409) until HR reopens it. Independently, the manager-review window is enforced: a manager cannot submit a review before the window opens or after it closes -- the form is read-only with a closed/not-yet-open message and a bypass submit is rejected server-side.

## 2. Related Requirements
- User Story: US-PRF-003
- Acceptance Criteria: AC-5
- Business Rules: BR-1
- Functional Requirements: FR-1

## 3. Preconditions
- acme cycle FY26-H1 with a manager-review window (US-PRF-004) whose dates can be set to: open / not-yet-open / closed.
- Ravi reviewing direct report Asha; a submitted review exists for the lock test.

## 4. Test Data
| Scenario | Window state | Expected |
|----------|--------------|----------|
| Locked after submit | open | read-only, edits 403/409 |
| Before window | not-yet-open | read-only + not-yet-open message, submit blocked |
| After window | closed | read-only + closed message, submit blocked |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open Asha's already-submitted review as Ravi | View is read-only; rating/comment inputs and "Submit" are disabled (AC-5). |
| 2 | Bypass the UI: PUT an edit to the submitted review | Server returns 403/409 "submitted review is locked"; no change persists (editable only after HR reopen, BR-3). |
| 3 | Set the manager-review window to not-yet-open; open a fresh review | Form read-only with a not-yet-open message; "Submit Manager Review" disabled. A bypass submit returns 403 (BR-1). |
| 4 | Set the window to closed (end date in the past); open the review | Form read-only with a window-closed message; submit disabled; bypass submit returns 403 (BR-1). |
| 5 | Set the window open and submit normally | Submission succeeds (control). |

## 6. Postconditions
- Submitted reviews are immutable until HR reopens; submissions are only accepted while the manager-review window is open; bypass attempts are server-rejected.
