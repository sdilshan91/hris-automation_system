# TC-PRF-002-09: Authorization -- employee sees only their OWN self-assessment; Employee A cannot view Employee B's (NFR-2, Performance.Read.Self)

## 1. Test Objective
Verify NFR-2 and the `Performance.Read.Self` authorization model within a single tenant: an employee can view and edit only their own self-assessment. Employee A cannot view or modify Employee B's self-assessment in the same tenant, including by tampering with employeeId / assessmentId in the request (IDOR). Unauthenticated access is rejected.

## 2. Related Requirements
- User Story: US-PRF-002
- Non-Functional Requirements: NFR-2 (own data only)
- Preconditions: `Performance.Read.Self` permission

## 3. Preconditions
- acme cycle FY26-H1 self-assessment window open.
- Employee A (Asha) and Employee B (Bala) are both acme employees, each with their own goals and a self-assessment (Bala's assessment id known).
- Asha authenticated in acme with `Performance.Read.Self`; Asha is NOT Bala's manager.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Employee A | Asha | the actor |
| Employee B | Bala | the victim record |
| Bala assessment id | known UUID | used for IDOR attempt |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Asha, open My Review | Only Asha's own goals and self-assessment load (NFR-2). |
| 2 | As Asha, `GET .../self-assessments/{bala_assessment_id}` | 403/404 -- the server scopes to the caller's own employee id; Bala's record is never returned (IDOR blocked). |
| 3 | As Asha, `GET .../employees/{bala_employee_id}/self-assessment?cycleId=FY26-H1` | 403/404; Asha cannot read another employee's assessment by employeeId. |
| 4 | As Asha, attempt `PUT`/submit against Bala's assessment id | 403; no modification to Bala's record. |
| 5 | Send the My Review request with the `Authorization` header removed | 401 Unauthorized; no data returned. |
| 6 | (Negative-permission) authenticate a user lacking `Performance.Read.Self` | The self-assessment endpoints return 403. |

## 6. Postconditions
- An employee accesses only their own self-assessment; cross-employee read/write within the tenant and unauthenticated access are blocked.
