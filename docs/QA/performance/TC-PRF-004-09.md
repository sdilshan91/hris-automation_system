# TC-PRF-004-09: Cannot delete a cycle with submitted reviews (cancel only); cancellation needs reason + notifies all (BR-2 / BR-6)

## 1. Test Objective
Verify BR-2 and BR-6: a cycle that has any submitted reviews cannot be deleted — only cancelled; and cancelling a cycle requires a reason and sends notifications to all participants. A Draft cycle with no submissions may still be hard-deleted.

## 2. Related Requirements
- User Story: US-PRF-004
- Acceptance Criteria: AC-2
- Functional Requirements: FR-7
- Business Rules: BR-2, BR-6

## 3. Preconditions
- Tenant "acme" active; HR Officer Maya authenticated with cycle permissions.
- Cycle "FY26 Annual Review" is Active and has >= 1 submitted self-assessment/manager review.
- Cycle "Empty Draft" is Draft with zero submissions.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Cycle with submissions | FY26 Annual Review | has submitted reviews |
| Empty cycle | Empty Draft | no submissions |
| Cancellation reason | "Reorg — review process suspended" | required by BR-6 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Attempt to DELETE "FY26 Annual Review" — `DELETE .../cycles/{id}` | 409 Conflict (or 400): cannot delete a cycle with submitted reviews; the UI offers Cancel instead (BR-2). The cycle and its review data remain intact. |
| 2 | Attempt to cancel "FY26 Annual Review" WITHOUT a reason | Rejected: cancellation reason is required (BR-6); status unchanged. |
| 3 | Cancel "FY26 Annual Review" WITH the reason "Reorg — review process suspended" | 200; status Cancelled (red); the reason is persisted on the cycle. |
| 4 | Check notifications after cancellation | ALL participants of the cycle receive a cancellation notification (in-app); email enqueue asserted (delivery CONDITIONAL on Notification System S25) (BR-6). |
| 5 | DELETE the "Empty Draft" cycle (no submissions) | 200/204 — a cycle with no submitted reviews can be hard-deleted (the BR-2 guard does not over-block). |
| 6 | Confirm submitted review data after cancellation | Submitted reviews from the cancelled cycle are retained (not purged) — cancellation is a status change, not a delete. |

## 6. Postconditions
- The cycle with submissions is Cancelled (reason stored, all participants notified), not deleted; the empty cycle is removed.
