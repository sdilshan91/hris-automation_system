# TC-PRF-009-14: Performance -> goal list with progress data <=400ms P95 (<=10 goals); stale-detection Hangfire job processes a 5,000-employee tenant <=60s (NFR-1/NFR-5)

## 1. Test Objective
Verify NFR-1 and NFR-5: the My Goals list (with progress/status/last-update data for up to 10 goals) returns within 400ms at P95, with no N+1 query, and the stale-goal detection Hangfire job processes all active goals for a tenant of up to 5,000 employees within 60 seconds.

## 2. Related Requirements
- User Story: US-PRF-009
- Non-Functional Requirements: NFR-1 (goal list <=400ms P95), NFR-5 (stale job <=60s @ 5,000 employees)
- Functional Requirements: FR-6 (stale detection)

## 3. Preconditions
- Tenant "acme" seeded in a performance-test environment.
- Employee "Sam Lee" has 10 active goals each with progress data + several updates.
- A separate large tenant seeded with ~5,000 employees, each with active goals (some stale, some fresh) for the job benchmark.
- A load harness can issue concurrent requests and record P95.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Goal list size | 10 goals | NFR-1 ceiling |
| List SLA | <=400ms P95 | NFR-1 |
| Job tenant | 5,000 employees | NFR-5 |
| Job SLA | <=60s | NFR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Drive concurrent `GET .../performance/my-goals` for Sam (10 goals + progress) under representative load | P95 latency <=400ms (NFR-1). |
| 2 | Inspect query execution | The list is fetched in set-based queries (goals + latest progress per goal) with NO per-goal N+1 round-trips. |
| 3 | Run the stale-detection Hangfire job against the 5,000-employee tenant | The job completes within 60s (NFR-5), evaluating all active goals against the stale interval. |
| 4 | Verify job correctness under load | Stale goals are nudged + flagged; non-stale/completed goals untouched (consistent with TC-PRF-009-04); the job stays tenant-scoped. |
| 5 | Verify idempotency under load | Re-running the job does not duplicate nudges (TC-PRF-009-04). |

## 6. Postconditions
- The goal list meets the 400ms P95 SLA with no N+1; the stale-detection job completes within 60s for 5,000 employees. (Requires a seeded performance environment; documented as a measurement, not a functional gap.)
