# TC-PRF-001-06: Team goals dashboard shows all members with goal-setting status and progress (AC-4)

## 1. Test Objective
Verify AC-4: after goals are saved for some employees, the manager's team goals dashboard lists all direct reports with their goal-setting status (draft, submitted, acknowledged) and progress indicators, scoped to the tenant and the manager's reporting line.

## 2. Related Requirements
- User Story: US-PRF-001
- Acceptance Criteria: AC-4
- Functional Requirements: FR-1
- Business Rules: BR-4

## 3. Preconditions
- Manager "Ravi Kumar" authenticated in acme with three direct reports: Asha (goals submitted), Ben (goals draft), Carol (no goals yet) for cycle FY26-H1.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Asha | status = submitted/acknowledged | goals saved |
| Ben | status = draft | goals started, not submitted |
| Carol | status = not started | no goals |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate to the Team Goals dashboard for FY26-H1; observe `GET /api/v1/performance/goals/team?cycleId={fy26h1}` | Response lists exactly Ravi's 3 direct reports, all tenant=acme. |
| 2 | Inspect each row | Asha shows "submitted/acknowledged", Ben "draft", Carol "not started"; each row shows a progress indicator (e.g. weight-allocated %). |
| 3 | Confirm scope | Only Ravi's direct reports appear — no peers' or other managers' reports are listed (BR-4 reporting-line scope). |

## 6. Postconditions
- The dashboard accurately reflects per-member goal-setting status and progress for the manager's team only.
