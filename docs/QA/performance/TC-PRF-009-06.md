# TC-PRF-009-06: Goal marked "Blocked" -> notifies manager + HR (BR-3)

## 1. Test Objective
Verify BR-3: when an employee posts a progress update that sets a goal's status to "Blocked", the system notifies BOTH the employee's manager and HR (so the impediment can be addressed). The notification identifies the goal and the blocking reason notes. Setting other statuses does NOT trigger the HR notification.

## 2. Related Requirements
- User Story: US-PRF-009
- Business Rules: BR-3 (Blocked notifies manager + HR)
- Functional Requirements: FR-5 (manager notified on update), FR-7 (Blocked status)
- Acceptance Criteria: AC-2

## 3. Preconditions
- Tenant "acme"; employee "Sam Lee" authenticated with `Performance.Read.Self`.
- Sam reports to manager "Dana Cole"; an HR Officer "Nadia Khan" exists in acme.
- Sam has an In-Progress goal in the active (open) window.
- Notification System (S25) available (enqueue asserted; delivery conditional).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Goal | "Integrate payment gateway" | In Progress |
| New status | Blocked | BR-3 trigger |
| Notes | "Blocked on vendor sandbox credentials." | impediment reason |
| Manager | Dana Cole | notified |
| HR | Nadia Khan | notified (BR-3) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Sam, add an update setting status = Blocked with the impediment notes | The update persists tenant-scoped with status=Blocked + notes; the goal card shows the red Blocked chip. |
| 2 | Inspect notifications | In-app + email notifications are enqueued to BOTH Dana (manager) AND Nadia (HR) identifying the goal "Integrate payment gateway" and the blocking notes (BR-3); enqueue asserted, delivery conditional on S25. |
| 3 | Post a separate update setting status = At Risk on another goal | Only the manager is notified (standard FR-5 update notice); HR is NOT specifically notified for At Risk -- the HR notification is specific to Blocked (BR-3). |
| 4 | Verify scoping | Both notifications carry acme tenant context; no other-tenant manager/HR receives them. |

## 6. Postconditions
- A Blocked status change notified both the manager and HR; non-Blocked statuses did not over-notify HR. No cross-tenant notification.
