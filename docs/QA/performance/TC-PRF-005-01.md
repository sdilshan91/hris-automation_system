# TC-PRF-005-01: HR configures a 360-enabled cycle, auto-assigns self+manager, nominates peers/reports, reviewers notified, all submit, results aggregated with composite + final score (happy path)

## 1. Test Objective
Verify the primary success flow across AC-1..AC-4 and FR-1/2/4/6: an authenticated HR Officer with `Performance.Review.All` opens the 360 configuration for an employee in a 360-enabled active cycle (AC-1), the system auto-assigns Self and the reporting Manager and auto-suggests Peers (same department) and Direct Reports (org tree), HR nominates the required peers/reports, the cycle enters the 360-feedback phase and each reviewer is notified (AC-2), each reviewer completes and submits competency-based feedback and is marked Completed (AC-3), and once all (or the minimum required) reviewers submit, HR views an aggregated 360 report with per-competency averages, a self/manager/peer/report radar comparison, the FR-6 weighted composite score, and that composite incorporated into the final performance score (AC-4 / BR-6).

## 2. Related Requirements
- User Story: US-PRF-005
- Acceptance Criteria: AC-1, AC-2, AC-3, AC-4
- Functional Requirements: FR-1, FR-2, FR-4, FR-6
- Business Rules: BR-1 (360 only when cycle toggle on), BR-6 (composite feeds final score)
- Data Requirements: S7 (feedback_360 with reviewer_id, reviewee_id, category, ratings JSON, comments, anonymity flag, tenant_id)

## 3. Preconditions
- Tenant "acme" exists, status Active, subdomain `acme.yourhrm.com`, Performance module enabled.
- An active appraisal cycle "FY26 Annual Review" exists for acme with the 360-degree toggle ENABLED (US-PRF-004) and competency-based questions + rating scale (1-5) configured.
- Employee "Liam Carter" (Engineering) has a reporting manager "Maya Shah" and at least two direct reports and several same-department peers in Core HR org tree.
- 360 reviewer-category weights configured: self 10% / manager 40% / peers 30% / reports 20% (FR-6).
- HR Officer "Nadia Khan" is authenticated in acme (valid JWT carrying acme `tenant_id`) and holds `Performance.Review.All`.

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate to `https://acme.yourhrm.com/performance` and open the 360 configuration for Liam Carter in FY26 Annual Review | The 360 nomination UI displays Self (auto-assigned) and Manager Maya Shah (auto-assigned from org tree), an auto-suggested list of same-department peers and direct reports, and the ability to add/remove reviewers manually (AC-1, FR-1/2). |
| 2 | Nominate peers Ava Reyes + Ben Cho and direct reports Sara Lin + Tom Diaz; click "Start 360 Feedback"; observe `POST .../performance/360/{revieweeId}/assignments` | Request carries `X-Tenant-Subdomain: acme` + bearer; 201; assignment rows created in `feedback_360` (or assignment table) for categories Self/Manager/Peer x2/Report x2, each stamped tenant_id=acme, status Pending. |
| 3 | Observe reviewer notifications | Each of the 5 reviewers (excluding self auto-task) receives an in-app + email notification with a link to their feedback form (AC-2; delivery CONDITIONAL on Notification System S25 — assert the enqueue + in-app push). |
| 4 | As each reviewer, open the feedback form | The form presents competency-based questions with the tenant rating scale (1-5) and an optional free-text comment per competency (FR-4). |
| 5 | Each reviewer rates all competencies + submits; observe `POST .../performance/360/feedback/{assignmentId}/submit` | Each submission 200; feedback saved tenant-scoped; that reviewer's status flips to "Completed"; the completion tracker updates submitted/pending per category (AC-3). |
| 6 | As HR, view the 360 results for Liam once all submitted | An aggregated report renders: average rating per competency, a radar chart comparing Self/Manager/Peer/Report perspectives, and per-competency comments (AC-4). |
| 7 | Inspect the composite + final score | The 360 composite is computed with the configured weights (self 10 / mgr 40 / peers 30 / reports 20, FR-6) and the composite is incorporated into Liam's final performance score (BR-6); server is authoritative. |

## 6. Postconditions
