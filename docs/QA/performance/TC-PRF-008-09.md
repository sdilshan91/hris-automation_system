# TC-PRF-008-09: PIP visibility restricted to employee + manager + HR + mentor; an unrelated employee is blocked; PIP data EXCLUDED from the general performance dashboard (FR-8, BR-5)

## 1. Test Objective
Verify FR-8 + BR-5: PIP visibility is restricted to exactly four parties -- the PIP's employee, their manager, HR, and the assigned mentor/coach. Any OTHER employee (a peer, a different manager, a different department's HR-less staff) cannot view the PIP via UI or API, including by direct id (no IDOR). Separately, PIP data is EXCLUDED from the general performance dashboard / analytics (US-PRF-007) and other general reports -- it appears only in the dedicated PIP management section.

## 2. Related Requirements
- User Story: US-PRF-008
- Functional Requirements: FR-8 (visibility restriction)
- Business Rules: BR-5 (excluded from general dashboards/reports)
- Non-Functional Requirements: NFR-2 (same-tenant authz here; cross-tenant in ISO TCs)
- Dependencies: US-PRF-007 (performance dashboard the PIP must be excluded from)

## 3. Preconditions
- An Active PIP for Sam Lee exists in acme: employee Sam, manager Dana, mentor Priya, HR Nadia.
- "Riya Sen" is an unrelated acme employee (NOT Sam's manager, NOT the mentor, NOT HR).
- The US-PRF-007 performance dashboard is available for acme.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| PIP | Sam Lee's Active PIP | restricted record |
| Allowed viewers | Sam, Dana, Priya, Nadia | FR-8 |
| Blocked viewer | Riya Sen | unrelated employee |
| Dashboard | US-PRF-007 overview / drill-down / export | BR-5 exclusion |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Sam (employee), Dana (manager), Priya (mentor), Nadia (HR) each `GET .../performance/pips/{id}` | 200 -- each of the four allowed parties can view the PIP (FR-8). |
| 2 | As Riya (unrelated employee), open the PIP in the UI and `GET .../performance/pips/{id}` | 403 / 404 -- access blocked; Riya never sees the reason, objectives, checkpoints, or escalation (FR-8); no IDOR by id. |
| 3 | As Riya, list PIPs `GET .../performance/pips` | Sam's PIP does NOT appear; only PIPs Riya is entitled to (if any). |
| 4 | As Nadia, open the general performance dashboard (US-PRF-007 overview, distribution, top/bottom, department drill-down, export) | Sam's PIP and PIP-derived data do NOT appear in any general dashboard widget or export (BR-5); the dashboard reflects only normal review data. |
| 5 | As Nadia, open the dedicated PIP management section | Sam's PIP appears HERE only (BR-5) -- the single surface where PIP data is visible. |
| 6 | Confirm exclusion holds with filters | Filtering the US-PRF-007 dashboard (by department/cycle) never surfaces PIP records or PIP escalation data. |

## 6. Postconditions
- Only the four entitled parties can view Sam's PIP; unrelated employees are blocked; PIP data is absent from general dashboards/exports and present only in the PIP section. No Tenant B data touched.
