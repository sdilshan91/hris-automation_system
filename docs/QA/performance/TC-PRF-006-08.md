# TC-PRF-006-08: Audit -- all sign-off actions immutably audit-logged with user id, timestamp, and IP address (FR-7)

## 1. Test Objective
Verify FR-7: every sign-off action -- manager sign-off, employee Acknowledge & Sign, employee Dispute, HR dispute resolution (amend/confirm), and auto-close to "No Response" -- is immutably audit-logged with the acting user's id, a server-side timestamp, and the originating IP address. Verify the audit entries are tenant-scoped and capture the digital-signature provenance (name + timestamp + IP) required for a formal, auditable record. The IP is captured server-side from the request, not trusted from a client-supplied field.

## 2. Related Requirements
- User Story: US-PRF-006
- Acceptance Criteria: AC-3, AC-4
- Functional Requirements: FR-7 (immutable audit log: user id + timestamp + IP)
- Data Requirements: S7 (review_signoffs immutable; tenant_id)

## 3. Preconditions
- Tenant "acme", Performance module enabled; audit logging seam (AuditInterceptor / audit module S24) wired.
- Liam Carter has a review progressing through sign-off; manager Maya, employee Liam, HR Nadia exist in acme.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Audited actions | manager sign / employee sign / dispute / HR resolve / auto-close | FR-7 |
| Captured fields | actor user id, server timestamp, request IP | FR-7 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Manager Maya requests sign-off (records her sign-off) | An audit entry is written: action=ManagerSignOff, userId=Maya, server timestamp, IP captured from the request, tenant_id=acme (FR-7). |
| 2 | Employee Liam "Acknowledge & Sign" | An audit entry: action=EmployeeSignOff, userId=Liam, timestamp, IP, tenant acme; the signature row stores name+timestamp+IP. |
| 3 | (Alternate review) Employee disputes with comments | An audit entry: action=Dispute, userId=Liam, timestamp, IP, comments reference, tenant acme. |
| 4 | (Alternate review) HR Nadia resolves a dispute (amend/confirm) | An audit entry: action=DisputeResolved (amend|confirm), userId=Nadia, timestamp, IP, tenant acme. |
| 5 | (Alternate review) Auto-close to "No Response" fires | An audit entry: action=AutoClose, actor=system, timestamp, tenant acme (no employee IP since system-initiated). |
| 6 | Spoof a client-supplied IP/timestamp in the sign-off body | The server IGNORES client-supplied IP/timestamp and records its own server-derived values (FR-7); the spoofed values do not appear in the audit/signature record. |
| 7 | Attempt to alter or delete an audit entry | Rejected -- the audit log is immutable (FR-7); entries cannot be edited or removed. |

## 6. Postconditions
- Every sign-off lifecycle action has an immutable, tenant-scoped audit entry with the correct actor, server timestamp, and server-derived IP.
