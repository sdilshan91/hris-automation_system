# TC-PRF-001-11: Team goal list for up to 50 members loads within 400ms P95 (NFR-1)

## 1. Test Objective
Verify NFR-1: the goal list for a team of up to 50 members loads within 400ms at the P95 latency, and remains tenant-scoped under load.

## 2. Related Requirements
- User Story: US-PRF-001
- Non-Functional Requirements: NFR-1, NFR-2
- Acceptance Criteria: AC-4

## 3. Preconditions
- acme has a manager with exactly 50 direct reports, each with a full goal set in the active cycle FY26-H1 (seeded performance dataset).
- A load harness (e.g. k6/JMeter) authenticated as the manager in acme.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Team size | 50 direct reports | NFR-1 ceiling |
| Endpoint | GET /api/v1/performance/goals/team?cycleId={fy26h1} | team goal list |
| Sample | >= 200 requests, warmed | for a stable P95 |
| SLA | P95 <= 400ms | NFR-1 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Warm the endpoint, then issue >= 200 sequential/concurrent reads of the 50-member team goal list | All responses 200; payload contains all 50 members with goals. |
| 2 | Record the latency distribution | P95 <= 400ms (NFR-1); no N+1 query explosion (verify a bounded query count). |
| 3 | Confirm tenant scope holds under load | Every response contains only acme members; no cross-tenant rows leak (NFR-2). |
| 4 | (If a list cache exists, S10) Confirm the cache key is tenant-scoped | Cache key includes `tenant:{tenantId}` and `cycleId`; CONDITIONAL — if no cache today, assert the DB read path meets the SLA with tenant-filtered queries. |

## 6. Postconditions
- The 50-member team goal list meets the 400ms P95 SLA with tenant isolation intact.
