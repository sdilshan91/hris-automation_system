# TC-PRF-004-14: Cycle creation form + timeline WCAG 2.1 AA + responsive (vertical stepper on mobile)

## 1. Test Objective
Verify the cycle creation form (multi-phase date entry, scope selector, rating-scale/toggles) and the cycle dashboard timeline meet WCAG 2.1 AA and are responsive from 360px to 1920px, with the horizontal timeline degrading to a vertical stepper on mobile (per the UI/UX notes).

## 2. Related Requirements
- User Story: US-PRF-004
- Acceptance Criteria: AC-1, AC-3
- UI/UX Notes: S8 (timeline/Gantt, donut charts, status badges, mobile vertical stepper + swipeable cards)

## 3. Preconditions
- Cycle creation form and an active cycle dashboard are reachable in acme as HR Officer Maya.
- Axe / screen reader (NVDA or VoiceOver) and responsive emulation available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Breakpoints | 360, 768, 1024, 1920 px | responsive range |
| Standard | WCAG 2.1 AA | |
| Tools | axe-core, keyboard, NVDA/VoiceOver | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run axe-core on the cycle creation form | Zero critical/serious violations; all date pickers, the scope tree picker, rating-scale select and toggles have accessible names/labels. |
| 2 | Navigate and complete the entire form by keyboard only | All fields (phase date ranges, scope, toggles, Create button) are reachable in a logical tab order with visible focus; date pickers and the department tree are keyboard-operable. |
| 3 | Test with a screen reader | Field labels, validation errors (overlap / out-of-range / reversed-date), and phase status badges are announced; errors are programmatically associated with their fields. |
| 4 | Verify status badge color contrast | Draft/Active/Paused/Completed/Cancelled badges meet >= 3:1 (non-text) / 4.5:1 (text) and do not rely on color alone (text label present). |
| 5 | Resize to 360px | The timeline renders as a vertical stepper and stat cards become swipeable; no horizontal scroll, no clipped content; the form remains usable. |
| 6 | Verify the dashboard donut charts | Completion-rate charts expose accessible text/data alternatives (e.g. percentages in adjacent text), not color-only. |

## 6. Postconditions
- The cycle form and timeline meet WCAG 2.1 AA across the responsive range.
