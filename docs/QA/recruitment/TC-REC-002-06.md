# TC-REC-002-06: Duplicate application with the same email to the same vacancy is rejected (negative)

## 1. Test Objective
Verify AC-3 / BR-1: an applicant is uniquely identified per vacancy by email; a second application with the same email to the same vacancy is prevented and the applicant is shown a clear "you have already applied" message. No duplicate `applicant` row is created and no second resume blob is persisted.

## 2. Related Requirements
- User Story: US-REC-002
- Acceptance Criteria: AC-3
- Business Rules: BR-1
- Data Requirements: index on `(tenant_id, email, vacancy_id)` for duplicate detection (S7)

## 3. Preconditions
- Tenant "acme" exists; vacancy "Senior Backend Engineer" is `Open` and publicly listed.
- An existing application from jordan.rivera@example.com to this vacancy already exists (e.g. created by TC-REC-002-01).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Vacancy | Senior Backend Engineer (Open) | Same vacancy |
| Existing applicant email | jordan.rivera@example.com | Already applied |
| Second attempt email | JORDAN.RIVERA@example.com | Same address, different case (verify case-insensitive match) |
| Resume | jordan-resume-v2.pdf | New file in the second attempt |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Submit a second application to the same vacancy with `jordan.rivera@example.com` and a new resume | Rejected (409 Conflict or 4xx) with a clear "already applied to this vacancy" message. |
| 2 | Submit again using `JORDAN.RIVERA@example.com` (different case) | Also rejected -- email uniqueness is case-insensitive for duplicate detection (BR-1). |
| 3 | Verify the database | Exactly ONE `applicant` row exists for (acme, this email, this vacancy); no duplicate row. |
| 4 | Verify blob storage | No second resume object was persisted for the rejected duplicate attempt. |
| 5 | Verify no duplicate confirmation email | No additional "Application Received" email is sent for the rejected duplicate. |

## 6. Postconditions
- Only the original application remains; the duplicate attempt produced no new record, blob, or email.
