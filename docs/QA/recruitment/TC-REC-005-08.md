# TC-REC-005-08: Form/field validation -- >=1 interviewer required; location required for in-person; video link required for video; type-conditional fields (FR-1)

## 1. Test Objective
Verify FR-1 field validation rules: the scheduling form requires at least one interviewer; for interview type IN-PERSON a location is required; for type VIDEO a video meeting link is required (and must be a valid URL); type PHONE requires neither location nor link. Missing required-by-type fields are rejected with field-level errors and nothing is persisted. Also covers boundary: exactly one interviewer is valid; duration default = 60.

## 2. Related Requirements
- User Story: US-REC-005
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1 (form fields + conditional requirements)
- Non-Functional Requirements: NFR-6 (form validation)

## 3. Preconditions
- Tenant acme; recruiter with `Recruitment.Manage.All`; applicant at "Interview"; >=1 active employee available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| No interviewers | interviewerIds=[] | Reject (>=1 required) |
| One interviewer | [empA] | Valid boundary |
| In-person, no location | type=in-person, location="" | Reject |
| In-person + location | type=in-person, location="Room 4B" | Valid |
| Video, no link | type=video, videoLink="" | Reject |
| Video, bad URL | type=video, videoLink="not-a-url" | Reject (invalid URL) |
| Video + URL | type=video, videoLink="https://meet.example/x" | Valid |
| Phone | type=phone | No location/link needed |
| Duration | omitted | Defaults to 60 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Submit with zero interviewers | 400; field error "at least one interviewer required"; nothing persisted (FR-1). |
| 2 | Submit with exactly one interviewer + otherwise valid | 201; accepted (boundary: one is enough). |
| 3 | Submit type=in-person with empty location | 400; "location required for in-person" (FR-1). |
| 4 | Submit type=in-person with a location | 201; accepted. |
| 5 | Submit type=video with empty link, then with a malformed URL | Both 400; "valid video link required for video" (FR-1, URL format). |
| 6 | Submit type=video with a valid URL; submit type=phone with neither location nor link; omit duration | video accepted; phone accepted (no location/link needed); duration defaults to 60 (FR-1). |

## 6. Postconditions
- Only schedules satisfying the type-conditional field rules are persisted; invalid submissions are rejected with field-level errors and no side effects.
