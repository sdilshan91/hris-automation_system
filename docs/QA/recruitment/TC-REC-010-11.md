# TC-REC-010-11: date_of_joining defaults to the offer start_date but is overridable; required employee fields validated before creation (BR-4, FR-3, FR-4)

## 1. Test Objective
Verify BR-4 + the required-field validation gate (FR-3, FR-4): the employee's `date_of_joining` is pre-filled from the offer's `start_date` and CAN be overridden by the HR Officer; and the "Create Employee" action validates the additional required fields not available from the application/offer (employee number, employment type, work location) and rejects submission until they are provided. Also asserts the employee-number behavior: auto-generated per the tenant pattern (FR-4) with the ability to override manually, and uniqueness enforced within the tenant.

## 2. Related Requirements
- User Story: US-REC-010
- Business Rules: BR-4 (date_of_joining defaults to offer start_date, overridable)
- Functional Requirements: FR-3 (review/modify/complete required fields), FR-4 (auto employee number per tenant pattern)
- Data Requirements: S7 (additional required fields: employee number, employment type, work location, bank details)

## 3. Preconditions
- Tenant "acme"; applicant {acme_applicantId} Hired with Accepted offer (start_date 2026-07-01).
- Tenant employee-number pattern configured (`EMP-2026-####`); employee number `EMP-2026-0042` not yet used.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Offer start_date | 2026-07-01 | default date_of_joining |
| Override DOJ | 2026-07-15 | HR overrides BR-4 |
| Required fields | employment type, work location, employee number | must be set before create |
| Duplicate emp number | EMP-2026-0001 (existing) | uniqueness check |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the convert form | `date_of_joining` is pre-filled 2026-07-01 from the offer start_date (BR-4). |
| 2 | Override `date_of_joining` to 2026-07-15 and submit (other required fields set) | Accepted; the created employee's date_of_joining = 2026-07-15 (HR override wins) (BR-4). |
| 3 | Attempt Create with a missing required field (e.g. work location blank) | Rejected with a field-level validation error; nothing persisted (FR-3). |
| 4 | Verify auto employee number | The employee number is auto-generated `EMP-2026-0042` per the tenant pattern; a lock/override affordance is present (FR-4). |
| 5 | Override the employee number to a duplicate (`EMP-2026-0001`) | Rejected — employee number must be unique within the tenant; nothing persisted. |
| 6 | Boundary: leave DOJ at the offer default and create | Succeeds; date_of_joining = 2026-07-01 (default path, no override). |

## 6. Postconditions
- Employee created with the chosen (default or overridden) date_of_joining and a unique number; incomplete submissions rejected pre-write.
