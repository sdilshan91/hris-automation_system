# TC-REC-005-06: Scheduling conflict detection -- same interviewer double-booked at an overlapping time WARNS the recruiter but ALLOWS override (soft conflict, FR-7)

## 1. Test Objective
Verify FR-7: when a recruiter schedules an interview for an interviewer who already has another interview at an overlapping time, the system DETECTS the conflict and WARNS (does not hard-block), and the recruiter MAY override and proceed. Conflict is computed per interviewer over the [start, start+duration) window in the same tenant. Non-overlapping times and different interviewers produce no warning.

## 2. Related Requirements
- User Story: US-REC-005
- Acceptance Criteria: AC-1 (scheduling flow)
- Functional Requirements: FR-7 (conflict detection + warn + override)
- UI/UX: S8 (highlight conflicting time slots)

## 3. Preconditions
- Tenant acme; interviewer {empA} already has Interview X scheduled 2026-06-25 10:00-11:00.
- Recruiter with `Recruitment.Manage.All` authenticated.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Existing booking | empA, 2026-06-25 10:00-11:00 | Interview X |
| Overlapping attempt | empA, 2026-06-25 10:30-11:30 | Overlaps X -> warn |
| Adjacent attempt | empA, 2026-06-25 11:00-12:00 | Back-to-back, no overlap -> no warn |
| Different interviewer | empB, 2026-06-25 10:30 | No conflict |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Attempt to schedule empA at 2026-06-25 10:30 (overlaps X) | The system returns a CONFLICT WARNING identifying the clashing interview/time for empA; the request is not auto-rejected (FR-7). |
| 2 | Confirm/override the conflict | The interview is saved despite the conflict (soft, overridable); both overlapping interviews now exist for empA. |
| 3 | Schedule empA at 11:00-12:00 (back-to-back, no overlap) | No conflict warning; saved normally (boundary: adjacent is not overlapping). |
| 4 | Schedule empB at 10:30 (different interviewer, same time as X) | No conflict warning (conflict is per-interviewer, not global). |
| 5 | Schedule a multi-interviewer slot where ONE of several interviewers conflicts | The warning names the specific conflicting interviewer(s) only; override still allowed. |
| 6 | Verify conflict check is tenant-scoped | The conflict check considers only acme interviews; a same-time interview in another tenant for a same-named employee does not trigger a warning. |

## 6. Postconditions
- Conflicts are surfaced as overridable warnings; no valid scheduling is blocked; non-overlapping/different-interviewer cases are silent.
