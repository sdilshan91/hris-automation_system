# TC-REC-004-08: Stage advancement blocked when the vacancy is Closed or Cancelled (FR-8)

## 1. Test Objective
Verify FR-8: when the parent vacancy has been Closed or Cancelled, the system PREVENTS stage advancement of its applicants. Existing applicant records and history are retained (no data loss), but new transitions are refused with a clear reason. Negative-path complement to the happy-path walk in TC-REC-004-01.

## 2. Related Requirements
- User Story: US-REC-004
- Functional Requirements: FR-8
- Dependencies: US-REC-001 (vacancy status lifecycle)

## 3. Preconditions
- Tenant "acme"; recruiter with `Recruitment.Manage.All`.
- Applicant "Quinn Park" at "Screening" under vacancy "Data Analyst".

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Applicant | Quinn Park ({acme_applicantId}) | At Screening |
| Vacancy states | Open -> Closed; Open -> Cancelled | Block triggers |
| Attempted move | Screening -> Interview | Should be refused when not Open |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | With vacancy = Open, move Quinn Screening -> Interview | 200; control case: advancement works while Open. |
| 2 | Set vacancy "Data Analyst" to Closed (US-REC-001) | Vacancy status = Closed; existing applicants retained. |
| 3 | Attempt to advance Quinn Interview -> Offer | Blocked (409/422); error states the vacancy is Closed; no stage change; no history row (FR-8). |
| 4 | Set vacancy to Cancelled and retry an advance | Blocked likewise; advancement refused for a Cancelled vacancy. |
| 5 | Verify rejection is still possible on a Closed vacancy | Per story intent, blocking applies to ADVANCEMENT; confirm the delivered behaviour for rejection on a closed/cancelled vacancy (rejection/withdrawal typically still permitted) -- assert whichever the increment implements, but advancement must be blocked. |
| 6 | Verify retention | Quinn's record and prior history remain intact and viewable; the block did not delete data. |

## 6. Postconditions
- Applicants under a Closed/Cancelled vacancy cannot advance; their records and history are preserved.
