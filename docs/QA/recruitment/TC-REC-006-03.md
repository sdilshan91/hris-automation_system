# TC-REC-006-03: Multiple interviewers store independent scorecards + a consolidated aggregate average across interviewers

## 1. Test Objective
Verify AC-3 / FR-3 / FR-8: when multiple interviewers are assigned to the SAME interview, each scorecard is stored separately (independent rows, independent per-criterion ratings, independent overall recommendations) and the system computes a CONSOLIDATED aggregate average across all submitted interviewers for that interview round, displayed alongside the individual breakdowns. The aggregate is computed over submitted scorecards only (a pending interviewer does not block the partial aggregate).

## 2. Related Requirements
- User Story: US-REC-006
- Acceptance Criteria: AC-3
- Functional Requirements: FR-3, FR-8
- Data Requirements: S7 (separate `interview_scorecard` rows per interviewer)

## 3. Preconditions
- Tenant "acme" active; interview {acme_interviewId} has two assigned interviewers empA, empB.
- 4 configured criteria.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| empA criterion scores | 4 / 5 / 3 / 4 | per-card average = 4.0 |
| empB criterion scores | 2 / 3 / 4 / 3 | per-card average = 3.0 |
| Expected aggregate | 3.5 | mean of card averages (4.0 + 3.0) / 2 = 3.5 (FR-3) |
| empA recommendation | Hire | independent |
| empB recommendation | No Hire | independent (not averaged) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | empA submits 4/5/3/4 + Hire; empB submits 2/3/4/3 + No Hire | Both 201; two distinct `interview_scorecard` rows persisted (one per interviewer), each with its own `scorecard_criterion_rating` set. |
| 2 | Verify independence | empA's card (avg 4.0, Hire) and empB's card (avg 3.0, No Hire) are stored separately; neither overwrites the other; recommendations are kept per-interviewer, not merged. |
| 3 | Retrieve the consolidated view for {acme_interviewId} | Aggregate average = 3.5 (mean of the two per-card averages); individual per-interviewer averages (4.0, 3.0) are also returned (AC-3, FR-3). |
| 4 | Verify partial aggregate (one pending) | On an interview where only empA has submitted, the aggregate equals empA's average (4.0) over the 1 submitted card; it does not error or treat empB's missing card as 0. |
| 5 | Verify visual comparison data (FR-8) | The applicant detail panel exposes per-criterion side-by-side data across interviewers (radar/bar chart input): Technical 4 vs 2, Communication 5 vs 3, etc., so the recruiter can compare. |

## 6. Postconditions
- Two independent scorecards persist for {acme_interviewId}; consolidated aggregate average = 3.5 with per-interviewer + per-criterion breakdowns available.
