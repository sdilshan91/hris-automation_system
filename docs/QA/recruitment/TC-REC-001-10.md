# TC-REC-001-10: Public careers page shows published Open vacancies anonymously; a vacancy with its public toggle disabled is NOT exposed

## 1. Test Objective
Verify FR-4/NFR-5 and BR-5: an `Open` vacancy whose public toggle is enabled is visible on the public careers page without authentication, while an `Open` vacancy that has been individually excluded from the public page (per-vacancy override of the tenant-level toggle) does NOT appear publicly even though it is on the internal listing.

## 2. Related Requirements
- User Story: US-REC-001
- Acceptance Criteria: AC-2
- Functional Requirements: FR-4, FR-5
- Non-Functional Requirements: NFR-5 (public page accessible without authentication)
- Business Rules: BR-5 (tenant-level toggle; per-vacancy exclusion)
- Test Hint: publishing with the public careers page disabled does not expose it publicly

## 3. Preconditions
- Tenant "acme" has the public careers page enabled at the tenant level.
- Vacancy "Public Role" is `Open` and inherits the public toggle (included).
- Vacancy "Internal Only Role" is `Open` but individually excluded from the public page.
- A separate tenant "beta" has the public careers page **disabled** at the tenant level, with an `Open` vacancy "Beta Role".

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| acme "Public Role" | Open, public toggle ON | Should appear publicly |
| acme "Internal Only Role" | Open, public toggle OFF | Should NOT appear publicly |
| beta "Beta Role" | Open, tenant public page OFF | Should NOT appear publicly |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | In a fresh anonymous browser session (no auth token), navigate to `https://acme.yourhrm.com/careers` | The public careers page loads without requiring login (NFR-5). |
| 2 | Inspect the public listing | "Public Role" is listed; "Internal Only Role" is NOT listed. |
| 3 | Directly request the excluded vacancy's public detail `https://acme.yourhrm.com/careers/{internal-only-slug}` anonymously | 404/Not Found -- the excluded vacancy is not exposed publicly even by direct slug. |
| 4 | As an authenticated recruiter, open the internal listing | BOTH "Public Role" and "Internal Only Role" appear on the internal listing (the exclusion is public-only). |
| 5 | Anonymously navigate to `https://beta.yourhrm.com/careers` | Either the public careers page is unavailable (feature off) or it loads but lists no vacancies; "Beta Role" is NOT exposed because beta's tenant-level public page is disabled (FR-4). |
| 6 | Anonymously attempt to fetch the public vacancy API for a `Draft`/`Closed` vacancy | Not exposed -- only `Open` + publicly-toggled vacancies are returned by the public endpoint. |

## 6. Postconditions
- The public careers page exposes only Open, publicly-enabled vacancies for tenants with the public page enabled.
- Per-vacancy exclusions and tenant-level disabling both keep vacancies off the public page.
