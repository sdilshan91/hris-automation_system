# TC-REC-008-09: Resume and offer-letter PDF downloads served via signed, short-lived, tenant-scoped blob URLs (no raw blob URL exposed)

## 1. Test Objective
Verify FR-4: the portal lets the applicant download their submitted resume and any offer-letter PDFs, and these are served via signed, short-lived blob storage URLs scoped to the resolved tenant -- never as a raw/permanent blob URL or a path that could be enumerated or reused after expiry. The signed URL must be bound to the applicant's own files within the tenant; it must not allow traversal to another applicant's or another tenant's blobs.

## 2. Related Requirements
- User Story: US-REC-008
- Functional Requirements: FR-4 (resume + offer PDF download via signed short-lived URLs)
- Non-Functional Requirements: NFR-3 (tenant-scoped storage)
- Cross-story: US-REC-002 (resume blob), US-REC-007 (offer PDF blob)

## 3. Preconditions
- Applicant {acme_applicantId} has a stored resume and an offer PDF at acme's tenant-scoped paths; valid magic link available.
- Another applicant {acme_applicantId2} has their own resume (target for traversal attempt).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Resume blob | {acmeTenantId}/recruitment/{vac}/{acme_applicantId}/{file} | own |
| Offer PDF | {acmeTenantId}/recruitment/{vac}/{acme_applicantId}/offers/{file} | own |
| Other resume | {acmeTenantId}/recruitment/{vac2}/{acme_applicantId2}/{file} | must NOT be reachable |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | On the portal, click "Download resume" | The resume downloads via a signed, short-lived URL; the underlying raw blob URL/path is not exposed in the page or response (FR-4). |
| 2 | Click "Download" on the offer PDF | The offer PDF downloads via a signed, short-lived URL (FR-4). |
| 3 | Copy a signed URL and re-use it after its expiry window | The expired signed URL is rejected (403/expired); it cannot be replayed indefinitely. |
| 4 | Tamper the signed URL to point at {acme_applicantId2}'s resume path | Denied; the signature does not authorize another applicant's blob; no cross-applicant download. |
| 5 | Confirm tenant scoping | All served files resolve only under acme's tenant-scoped namespace; no cross-tenant blob is reachable (NFR-3; see TC-REC-ISO-017). |

## 6. Postconditions
- Applicant downloaded only their own resume + offer PDF via signed short-lived URLs; no cross-applicant/cross-tenant blob access.
