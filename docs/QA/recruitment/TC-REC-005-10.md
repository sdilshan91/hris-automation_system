# TC-REC-005-10: Interview status lifecycle -- Scheduled -> Completed / Cancelled / No-Show; calendar filterable by status (FR-6, FR-5)

## 1. Test Objective
Verify FR-6 / FR-5: an interview tracks the status set Scheduled / Completed / Cancelled / No-Show, with valid transitions, and the calendar/agenda view can be filtered by status (and by interviewer, vacancy, date range). Marking an interview Completed or No-Show records the status; only Scheduled interviews keep an active reminder (completing/cancelling/no-showing removes/voids it). Invalid transitions are rejected.

## 2. Related Requirements
- User Story: US-REC-005
- Acceptance Criteria: AC-1 (calendar surfacing)
- Functional Requirements: FR-5 (calendar view + filters), FR-6 (status lifecycle)
- UI/UX: S8 (color-coded status blocks)

## 3. Preconditions
- Tenant acme with several interviews across statuses; recruiter with `Recruitment.Manage.All` authenticated.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Statuses | Scheduled, Completed, Cancelled, No-Show | FR-6 |
| Filters | status, interviewer, vacancy, date range | FR-5 |
| Color map | Scheduled=blue, Completed=green, Cancelled=gray | S8 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Mark a Scheduled interview as Completed (after its time) | Status=Completed; any pending reminder is void/removed; record retained (FR-6). |
| 2 | Mark another Scheduled interview as No-Show | Status=No-Show; reminder void; record retained (FR-6). |
| 3 | Attempt an invalid transition (e.g. Cancelled -> Completed) | Rejected with a clear error; status unchanged (FR-6 valid-transition enforcement). |
| 4 | Open the calendar view and filter by status=Scheduled | Only Scheduled interviews shown, color-coded blue; Completed/Cancelled/No-Show hidden (FR-5, S8). |
| 5 | Filter by interviewer, then by vacancy, then by a date range | Each filter narrows the calendar correctly; combined filters AND together (FR-5). |
| 6 | Clear filters | Full set of interviews for the tenant restored. |

## 6. Postconditions
- Interview statuses follow the defined lifecycle with reminders voided on terminal statuses; the calendar filters correctly by status/interviewer/vacancy/date.
