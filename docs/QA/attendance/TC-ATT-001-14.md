# TC-ATT-001-14: The attendance clock timestamps come from an injectable `TimeProvider` seam (deterministic clock), not a hardcoded `DateTime.UtcNow` — US-ATT-001 AC-1 (DF-43)

## 1. Test Objective
Verify the DF-43 clock seam in `AttendanceService`: the five previously-hardcoded `DateTime.UtcNow` sites (clock-in timestamp, clock-out timestamp, audit `CreatedAt`, and the idempotency-record `CreatedAt`/`ExpiresAt`) now read from an injected `TimeProvider` (trailing-optional ctor param, defaulting to `TimeProvider.System` so production behaviour is unchanged). This makes the date-dependent attendance logic — late detection, the FR-7 chronic-lateness month window, period locks, the idempotency window — deterministically testable, and unblocks the DF-44 real-Postgres chronic-lateness arm.

## 2. Related Requirements
- User Story: US-ATT-001 (clock-in; AC-1 records `clock_in` as the current UTC timestamp)
- Findings: DF-43 (no clock seam on `AttendanceService.ClockInAsync`); unblocks DF-44
- Design: seam mirrors the repo's `TimeProvider? = null → TimeProvider.System` convention (`LeaveDashboardService`, `NotificationPreferenceService`) — no DI registration, no behaviour change.

## 3. Preconditions
- An active seeded employee; `AttendanceService` constructed with a fixed `FakeTimeProvider` (hand-rolled test double). InMemory-through-real-EF.

## 4. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Construct `AttendanceService` with `FakeTimeProvider(2026-03-15T09:30:00Z)`; clock in. | The returned + persisted `ClockIn` equals `2026-03-15T09:30:00Z` exactly (not "now"); `Kind == Utc`. `ClockIn_TimestampComesFromInjectedClock`. |
| 2 | (Regression) The full 215-test Attendance suite under the default `TimeProvider.System`. | All green — the seam is behaviour-neutral in production. |

## 5. Postconditions
- Attendance timestamps flow from the injected clock; a fixed fake clock yields a fixed, asserted timestamp, enabling deterministic date-dependent tests without changing production behaviour.
