# TC-ONB-006-03: Duplicate exit interview per offboarding rejected

## 1. Test Objective
Verify BR-1: only one exit interview can be recorded per offboarding instance. Once an exit interview exists for OB-A300, attempting to record a second (whether HR-conducted or self-service) is rejected with a validation error and no second record or duplicate task-completion side effect is created.

## 2. Related Requirements
- User Story: US-ONB-006
- Business Rule: BR-1 (one exit interview per offboarding instance)
- Acceptance Criteria: AC-2 (single persisted record per offboarding)

## 3. Preconditions
- An exit interview already exists for offboarding OB-A300 in tenant `acme` (e.g. from TC-ONB-006-01).
- HR Officer authenticated with the record permission.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| offboarding_id | OB-A300 | already has an exit interview |
| interview_mode | hr_conducted | second attempt |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As HR, attempt to record a second exit interview for OB-A300 | Request rejected (409/422) with a clear message that an exit interview already exists for this offboarding (BR-1). |
| 2 | Attempt the same as the employee in self-service mode | Same rejection; no second record created (BR-1). |
| 3 | Inspect the data store | Exactly one exit interview record exists for OB-A300; no duplicate, no duplicate task-completion or audit event. |

## 6. Postconditions
- OB-A300 retains exactly one exit interview record; the duplicate attempt left no side effects.
