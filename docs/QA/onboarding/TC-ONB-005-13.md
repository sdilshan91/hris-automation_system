# TC-ONB-005-13: Initiating offboarding persists last-working-day + task due dates on real Postgres (BUG-290 — .Date Kind=Unspecified → timestamptz)

## 1. Test Objective
Verify that initiating offboarding for a Terminated/Suspended employee persists `LastWorkingDay` and each clearance task's `DueDate` on **real PostgreSQL**. Both are written to `timestamptz` columns — `LastWorkingDay` from `.Date`, and task due dates via `ClampDueDate` (a second independent `.Date` source). Kind=Unspecified is rejected by Npgsql, so the write used to throw on Postgres. Regression for BUG-290 (Offboarding compound site).

## 2. Related Requirements
- User Story: US-ONB-005 (Offboarding / Exit Checklist and Clearance)
- Finding: BUG-290 (PR #345), `OffboardingService.InitiateAsync` + `ClampDueDate`
- Class: `.Date`(Unspecified) → timestamptz write (two sites)

## 3. Preconditions
- Real PostgreSQL (Testcontainers `postgres:17-alpine`), migrations applied. Postgres-only.
- A **Terminated** employee (offboarding may only be initiated for Terminated/Suspended).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| `LastWorkingDay` | `new DateTime(2026,12,1)` — **Kind=Unspecified**, future | Unspecified so the mutant is caught; future to pass the LWD-in-past guard. |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Seed a Terminated employee (+ dept/job title). | — |

| 3 | Read the offboarding instance (+ tasks) from a fresh context. | `LastWorkingDay.Kind == Utc`; default clearance tasks present; every task `DueDate.Kind == Utc`. |

## 6. Postconditions
