# TC-ONB-006-07: Self-service deadline — access denied after last working day / account deactivated

## 1. Test Objective
Verify BR-3 and the S10 constraint: self-service exit interviews must be submitted before the employee's last working day. Once the LWD has passed and/or the offboarding has completed and deactivated the user account, the employee can no longer access or submit the self-service questionnaire.

## 2. Related Requirements
- US-ONB-006
- Business Rule: BR-3 (self-service must be submitted before LWD)
- Constraint (S10): self-service requires an active (not yet deactivated) user account
- Dependency: US-ONB-005 (offboarding completion deactivates the account)

## 3. Preconditions
- Employee E301 in tenant `acme` has an offboarding OB-A301 whose LWD is in the PAST (or whose offboarding completion has deactivated the account).
- No self-service exit interview was submitted before the deadline.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| offboarding_id | OB-A301 | LWD = 2026-06-10 (past) |
| account state | deactivated (post-completion) | self-service no longer permitted |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Attempt to log in / open the self-service exit interview as E301 after the deactivation | Login/access denied (401) because the account is deactivated (US-ONB-005, S10). |
| 2 | With a still-valid token but past-LWD offboarding, attempt to submit the self-service exit interview | Submission rejected with a "self-service exit interview window has closed (last working day passed)" message (BR-3); no record created. |
| 3 | Inspect the data store | No self-service exit interview was persisted for OB-A301 via this path. |
| 4 | Confirm HR can still record the interview on the employee's behalf (hr_conducted) | HR-conducted recording remains available (BR-3 restricts only the self-service window, not HR recording). |

## 6. Postconditions
- The self-service path is closed after the deadline/deactivation; the HR-conducted path remains available.
