# TC-ONB-006-13: Recording an exit interview persists interview_date on real Postgres (BUG-290 — .Date Kind=Unspecified → timestamptz)

## 1. Test Objective
Verify that recording an exit interview persists `InterviewDate` on **real PostgreSQL**. `InterviewDate` is written to a `timestamptz` column from a `.Date` (Kind=Unspecified) input, which Npgsql rejects — the write used to throw on Postgres (InMemory hid it). The `SpecifyKind(…, Utc)` fix makes it valid. Regression for BUG-290 (Exit-interview site).

## 2. Related Requirements
- User Story: US-ONB-006 (Exit Interview Recording)
- Finding: BUG-290 (PR #345), `ExitInterviewService.RecordAsync` → `interview_date`
- Class: `.Date`(Unspecified) → timestamptz write

## 3. Preconditions
- Real PostgreSQL (Testcontainers `postgres:17-alpine`), migrations applied. Postgres-only (InMemory ignores Kind).
- An `OffboardingInstance` for the interview to link to (the exit-interview template auto-seeds on first use).

## 4. Test Data
| Field | Value | Notes |

| `InterviewDate` | `new DateTime(2026,7,1)` — **Kind=Unspecified** | Unspecified so the mutant is caught. |

## 6. Postconditions
