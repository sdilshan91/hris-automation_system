# TC-ONB-002-05: Responsible-party resolution for Manager / HR / IT / Employee roles

## 1. Test Objective
Verify FR-3: when a checklist is assigned, each task's role-based responsible party is resolved to concrete user(s): "Manager" -> the employee's `reporting_manager_id`; "HR" -> the assigning HR Officer; "IT" -> users holding the IT role within the tenant; "Employee" -> the new hire. The resolution is tenant-scoped.

## 2. Related Requirements
- User Story: US-ONB-002
- Acceptance Criteria: AC-2
- Functional Requirements: FR-3, FR-7

## 3. Preconditions
- HR Officer "Maya Cole" authenticated in tenant `acme` with `Onboarding.Manage`.
- Employee "Alex Reed" has `reporting_manager_id` = "Dana Lee" (Manager role).
- Tenant `acme` has two users with the IT role: "Ivo Tan" and "Ima Singh".
- A template with one task per role (Manager / HR / IT / Employee) exists and is active.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Manager task | responsible = Manager | resolves to Dana Lee |
| HR task | responsible = HR | resolves to Maya Cole (assigner) |
| IT task | responsible = IT | resolves to IT-role users (Ivo Tan, Ima Singh) |
| Employee task | responsible = Employee | resolves to Alex Reed |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Assign the role-spanning template to Alex Reed | 201 Created; 4 task instances created. |
| 2 | Inspect the Manager task | Responsible party resolves to Dana Lee (`reporting_manager_id`) (FR-3). |
| 3 | Inspect the HR task | Responsible party resolves to Maya Cole, the assigning HR Officer (FR-3). |
| 4 | Inspect the IT task | Responsible party resolves to the tenant's IT-role users (Ivo Tan and/or Ima Singh per the resolution policy) (FR-3). |
| 5 | Inspect the Employee task | Responsible party resolves to Alex Reed, the new hire (FR-3). |
| 6 | Confirm tenant scoping | All resolved parties belong to tenant `acme`; no user from another tenant is selected (FR-7). |

## 6. Postconditions
- Each task instance carries a concrete, tenant-scoped responsible party matching its template role mapping.
