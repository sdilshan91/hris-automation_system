# TC-ONB-003-06: Role restriction — employee cannot complete IT / Manager / HR tasks

## 1. Test Objective
Verify AC-2, BR-1 and FR-7: tasks whose responsible party is IT, Manager, or HR are read-only for the new hire; any attempt by the employee to mark such a task complete is rejected; the task status is unchanged; and no completion/audit/notification is emitted.

## 2. Related Requirements
- User Story: US-ONB-003
- Acceptance Criteria: AC-2
- Functional Requirements: FR-7
- Business Rules: BR-1

## 3. Preconditions
- Employee "Alex Reed" authenticated in tenant `acme`.
- The checklist contains an IT task ("Provision laptop"), a Manager task ("Schedule 1:1"), an HR task ("Verify documents"), plus an Employee task.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| IT task | Provision laptop (responsible=IT) | read-only for employee |
| Manager task | Schedule 1:1 (responsible=Manager) | read-only for employee |
| HR task | Verify documents (responsible=HR) | read-only for employee |
| Employee task | Read handbook | completable control |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | View the checklist | IT/Manager/HR tasks render but have no "Mark Complete" control for the employee (read-only) (AC-2, BR-1). |
| 2 | Attempt `POST .../tasks/{itTaskId}/complete` directly (API bypass) | 403 Forbidden; task status unchanged; no completion recorded (FR-7, BR-1). |
| 3 | Repeat for the Manager task | 403 Forbidden; unchanged. |
| 4 | Repeat for the HR task | 403 Forbidden; unchanged. |
| 5 | Complete the Employee task "Read handbook" | 200; succeeds — confirms the restriction is role-scoped, not a blanket block (control). |
| 6 | Inspect audit + outbox | No completion audit events or HR notifications for the three rejected attempts. |

## 6. Postconditions
- IT/Manager/HR tasks remain in their prior status; only the Employee-role task is completed; no spurious audit/notification rows.
