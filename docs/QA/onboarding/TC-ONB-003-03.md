# TC-ONB-003-03: Checklist view grouped by category with status chips; overdue tasks highlighted red

## 1. Test Objective
Verify AC-2 and AC-5: the onboarding checklist renders tasks grouped into collapsible category sections, each task showing title, description, due date, status (pending / in-progress / completed / overdue), and responsible party; overdue tasks display a red highlight and warning icon; completed tasks show a completed status chip.

## 2. Related Requirements
- User Story: US-ONB-003
- Acceptance Criteria: AC-2, AC-5
- Functional Requirements: FR-1

## 3. Preconditions
- Employee "Alex Reed" authenticated in tenant `acme` with a checklist spanning >=2 categories (e.g. "Documentation", "IT Setup"), containing tasks in each status: pending, in-progress, completed, and one overdue.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| categories | Documentation, IT Setup | accordion sections with count badges |
| statuses present | pending, in-progress, completed, overdue | one of each |
| overdue task | "Submit signed contract", due yesterday | red highlight + warning icon |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open the checklist view | Tasks are grouped under collapsible category sections, each with a task-count badge (e.g. "Documentation 2/4") (AC-2). |
| 2 | Inspect a task card | Shows title, description, due date, status chip, and responsible party (AC-2). |
| 3 | Verify status chips | pending / in-progress / completed / overdue each render with the correct chip; completed shows strikethrough + green check (AC-2, UI notes). |
| 4 | Locate the overdue task | Rendered with a red border/highlight, warning icon, and "X days overdue" badge (AC-2, AC-5). |
| 5 | Collapse and expand a category | Section toggles; tasks hide/show; counts persist. |

## 6. Postconditions
- No state change; checklist is correctly grouped, statuses accurate, overdue items visually flagged.
