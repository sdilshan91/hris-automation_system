# TC-ONB-004-01: Issue laptop + ID card to a new hire — both linked, status assigned, onboarding task completed, audit before/after

## 1. Test Objective
Verify AC-1, AC-2 and FR-1/2/4/8: from an employee's onboarding "Asset Issuance" task, the HR Officer opens the issuance form, records a laptop (with serial + condition "New") and an ID card in a single session, and saves. Both assets are linked to the employee, their register status changes to "assigned", the onboarding task transitions to "completed", and audit records with before/after states are written.

## 2. Related Requirements
- User Story: US-ONB-004
- Acceptance Criteria: AC-1, AC-2
- Functional Requirements: FR-1, FR-2, FR-4, FR-8

## 3. Preconditions
- HR Officer authenticated in tenant `acme` (tenantId T-acme) with `Onboarding.Manage`.
- Employee "Mia Chen" (employeeId E200) exists with active/probation status and an onboarding checklist containing an `asset_issuance` task (taskId TK40, status "pending").
- Asset register has a laptop (assetTag LAP-001, serial SN-LAP-001) and an ID card (assetTag IDC-001), both in "available" status.
