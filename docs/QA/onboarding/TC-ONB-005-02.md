# TC-ONB-005-02: Exit task generation — tasks for HR/IT/Finance/Manager/Employee with due dates = LWD - offset

## 1. Test Objective
Verify AC-1 and FR-2/3: on initiation, the system auto-generates exit task instances from the tenant offboarding template across all built-in clearance categories (IT, Finance, Admin, Manager) plus HR and Employee tasks, each with a responsible party resolved and a due date computed as `last_working_day - offset_days`.

## 2. Related Requirements
- User Story: US-ONB-005
- Acceptance Criteria: AC-1
- Functional Requirements: FR-2, FR-3

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Offboarding.Manage`.
- Employee E301 has status "terminated" and a reporting manager (M50) set.
- Default offboarding template includes tasks: IT access-revocation (offset 0), IT asset-return (offset 1), Finance F&F (offset 3), Admin ID-card return (offset 0), Manager knowledge-transfer/handover (offset 5), Employee exit-formalities (offset 2), HR exit-interview (offset 2).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| employee_id | E301 | terminated (BR-1 ok) |
| last_working_day | 2026-07-10 | LWD |
| reason | Termination | valid enum |
| reporting_manager | M50 | resolves Manager-role tasks |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Initiate offboarding for E301 with LWD 2026-07-10 | 201; offboarding instance created with the full template task set generated. |
| 2 | List the generated tasks grouped by responsible party | Tasks exist for HR, IT, Finance, Manager (M50), and the Employee — every built-in clearance category (IT/Finance/Admin/Manager) is represented (FR-3). |
| 3 | Inspect the IT access-revocation task due date (offset 0) | due_date = 2026-07-10 (LWD - 0) (FR-2). |
| 4 | Inspect the Manager handover task due date (offset 5) | due_date = 2026-07-05 (LWD - 5) (FR-2). |
| 5 | Inspect the Finance F&F task due date (offset 3) | due_date = 2026-07-07 (LWD - 3) (FR-2). |
| 6 | Inspect each task's responsible party | IT->IT role, Finance->Finance role, Admin->Admin role, Manager->M50, Employee->E300's account, HR->HR officer (FR-3). |
| 7 | Inspect tenant_id on all generated tasks | All = T-acme (FR-8). |

## 6. Postconditions
- Offboarding instance E301 has a complete, correctly-dated, correctly-assigned exit checklist.
