# TC-ONB-006-12: Accessibility + responsive — questionnaire keyboard navigable, WCAG 2.1 AA; 360px touch-friendly rating selectors

## 1. Test Objective
Verify NFR-5 and NFR-4: the exit interview questionnaire and analytics views meet WCAG 2.1 AA — fully keyboard navigable (including the 1-5 rating selector, radio/chip multiple choice, free-text areas, and the progress bar), with correct labels/ARIA, focus order, and contrast — and are responsive from 360px to 4K with large touch-friendly rating selectors on mobile.

## 2. Related Requirements
- US-ONB-006
- Non-Functional Requirements: NFR-5 (WCAG 2.1 AA), NFR-4 (responsive 360px-4K)
- UI/UX (S8): one question per card, progress bar, mobile full-width cards with large touch rating selectors

## 3. Preconditions
- Exit interview questionnaire and analytics pages reachable in a tenant context.
- Keyboard-only operation, a screen reader, an axe-core accessibility scan, and viewport emulation (360px / 768px / 1920px / 4K) available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| viewports | 360 / 768 / 1920 / 3840 px | NFR-4 range |
| question types | rating, multiple choice, free text, yes/no | all must be operable |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate the entire questionnaire using Tab/Shift+Tab/Enter/Space and arrow keys only | All questions reachable in logical order; the 1-5 rating selector is operable via arrow keys/Space; radio/chips and yes/no toggles operable; no keyboard trap (NFR-5). |
| 2 | Run an axe-core scan on the questionnaire and analytics pages | No WCAG 2.1 AA violations: form controls labeled, rating value announced, chart data has a text/table alternative, contrast >= 4.5:1 (NFR-5). |
| 3 | Operate the form with a screen reader | Category headers, question text, current rating value, character count, and progress are announced; validation errors are associated with their fields (NFR-5). |
| 4 | Render at 360px width | Full-width single-column cards; rating selectors are large/touch-friendly; no horizontal scroll or clipping (NFR-4, S8). |
| 5 | Render at 768px, 1920px, and 4K | Layout adapts cleanly across the range with no overlap or clipping (NFR-4). |

## 6. Postconditions
- Questionnaire and analytics are keyboard/screen-reader accessible (WCAG 2.1 AA) and responsive 360px-4K with touch-friendly mobile rating controls.
