# TC-ONB-005-10: Audit trail — each clearance approval and the final offboarding completion are logged (FR-9)

## 1. Test Objective
Verify FR-9: every offboarding action is recorded in the tenant audit log — specifically each department clearance approval/pending-issue decision, the asset returns, and the final offboarding completion (with its termination + deactivation + F&F-trigger effects), each capturing actor, timestamp, and before/after where applicable.

## 2. Related Requirements
- User Story: US-ONB-005
- Functional Requirements: FR-9
- Acceptance Criteria: AC-2, AC-3, AC-4

## 3. Preconditions
- HR Officer authenticated in tenant `acme`; department heads can action their clearances.
- Offboarding instance for E300 with IT, Finance, Admin, Manager clearance tasks all pending.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| employee_id | E300 | being offboarded |
| clearance actions | IT approved, Finance approved, Admin approved, Manager approved | 4 audit events |
| completion action | Complete Offboarding | 1 audit event |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Approve each of the 4 department clearances in turn | Each approval produces a distinct audit entry: action="clearance_approved", department, actor, timestamp, tenant_id=T-acme (FR-9, AC-3). |
| 2 | Mark a clearance as "pending_issues" with remarks | An audit entry records the pending_issues decision and remarks (FR-9). |
| 3 | Click "Complete Offboarding" | An audit entry records the completion with before status -> "terminated", account deactivation, and F&F-trigger dispatch (FR-9, AC-4). |
| 4 | Query the audit log filtered to this offboarding instance | All clearance and completion events are present, ordered by timestamp, each attributed to the correct actor; none missing (FR-9). |
| 5 | Confirm audit entries are tenant-scoped | All entries carry tenant_id=T-acme and are not visible to other tenants. |

## 6. Postconditions
- A complete, attributable audit trail exists for every clearance decision and the final completion.
