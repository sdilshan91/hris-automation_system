# TC-ONB-005-08: last_working_day boundary/negative — today accepted, future accepted, past rejected; reason enum + notes length validated

## 1. Test Objective
Verify the initiation data requirements: `last_working_day` must be today or in the future (today inclusive, past rejected), `reason` must be one of the allowed enum values, and `notes` is capped at 2000 chars.

## 2. Related Requirements
- User Story: US-ONB-005
- Acceptance Criteria: AC-1
- Data Requirements: last_working_day (today-or-future), reason (enum), notes (<= 2000)

## 3. Preconditions
- HR Officer authenticated in tenant `acme` with `Offboarding.Manage`.
- Employee E313 has status "resignation_accepted" (eligible per BR-1). Current date = 2026-06-17.
