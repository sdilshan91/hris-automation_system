# TC-ADM-008-21: [DEFERRED] First-page load < 2s for tenants with millions of audit records

## 1. Test Objective

DEFERRED — status: blocked. The NFR-2 indexes ARE added (migration), but validating the <2s SLA at millions-of-rows scale requires a performance-representative environment that does not exist in CI today. Functional correctness of the list/filter is covered run-green by TC-ADM-008-01..08.
