# TC-ADM-004-07: Terminate from past_due and from suspended (alternative valid termination sources)

## 1. Test Objective
Verify BR-1's alternative valid termination entry points: `past_due -> terminating` and `suspended -> terminating`. The same termination effects as TC-ADM-004-06 apply (status, scheduled_at, jobs, read-only, lifecycle event), confirming AC-3 accepts all three documented sources (active | past_due | suspended).
