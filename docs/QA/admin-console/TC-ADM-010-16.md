# TC-ADM-010-16: [DEFERRED] Email delivery of download link + pre-signed/signed download URL

## 1. Test Objective
Cover AC-2 / AC-3 / FR-7 / BR-6: the time-limited download URL is a SIGNED URL (pre-signed S3 URL or equivalent) emailed to the requesting user AND the tenant's billing contact (and, for a System-Admin export, the System Admin + billing contact).

DEFERRED — status: blocked. Today the implementation logs the download link and serves the bundle from a LOCAL/tenant-scoped path; there is no real email DELIVERY and no pre-signed S3 / signed-link mechanics. The 72h expiry + cleanup + audited download ARE run-green (TC-ADM-010-12); only the signed-URL + email-delivery transport is deferred (same email-delivery family as US-ADM-001/-003/-004/-005 — delivery lands with US-NTF / a storage provider).
