# TC-ADM-001-06: Subdomain length boundaries (exactly 3 and exactly 50 chars) are accepted

## 1. Test Objective
Verify the AC-5 / FR-1 boundary condition: subdomains at the exact minimum (3 chars) and exact maximum (50 chars) are valid and provision successfully, confirming the 3-50 range is inclusive on both ends. Complements TC-ADM-001-05 (just-outside values 2 and 51 rejected).

## 2. Related Requirements
- User Story: US-ADM-001
- Acceptance Criteria: AC-5, AC-1
- Functional Requirements: FR-1

## 3. Preconditions
- System Admin authenticated at `admin.yourhrm.com` with the `SystemAdmin` role.
- Subdomains `abc` and the 50-char value below are free and not reserved.
- An active plan exists.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Min boundary subdomain | `abc` | exactly 3 chars (lower inclusive bound) |
| Max boundary subdomain | `a` + 48x `b` + `c` (50 chars total) | exactly 50 chars (upper inclusive bound) |
| Other fields | valid | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Provision a tenant with subdomain `abc` (3 chars) | Accepted by client + server; 201 Created; tenant `abc` provisioned. |
| 2 | Provision a tenant with the 50-char subdomain | Accepted by client + server; 201 Created; tenant provisioned with the full 50-char subdomain stored intact. |
| 3 | Cross-check against TC-ADM-001-05 | `ab` (2) and the 51-char value remain rejected, confirming the boundary is inclusive 3..50. |

## 6. Postconditions
- Two tenants exist at the exact length boundaries; both resolvable at `{subdomain}.yourhrm.com`.
