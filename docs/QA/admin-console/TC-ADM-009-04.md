# TC-ADM-009-04: Code format validation — lowercase alphanumeric + hyphens only

## 1. Test Objective
Verify FR-3 (code format): the `code` must be lowercase, alphanumeric plus hyphens. Codes with uppercase, spaces, underscores, leading/trailing hyphens, or other special characters are rejected; valid slug formats are accepted.

## 2. Related Requirements
- User Story: US-ADM-009
- Functional Requirements: FR-3 (code lowercase, alphanumeric + hyphens)

## 3. Preconditions
- System Admin "Pat" authenticated at `admin.yourhrm.com` with `SystemAdmin`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| valid | `growth`, `growth-plus`, `tier-2`, `acme-enterprise-2026` | accepted |
| invalid (uppercase) | `Growth` | rejected |
| invalid (space) | `growth plan` | rejected |
| invalid (underscore) | `growth_plus` | rejected |
| invalid (special) | `growth!`, `growth@x` | rejected |
| invalid (leading/trailing hyphen) | `-growth`, `growth-` | rejected (per slug rule) |
| invalid (empty) | `` | rejected (required) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | POST create with each VALID code (unique names) | 201 each; code persisted exactly as entered. |
| 2 | POST create with `Growth` (uppercase) | 400 — format validation error; no row created. |
| 3 | POST create with `growth plan` (space) | 400 — rejected. |
| 4 | POST create with `growth_plus` (underscore) | 400 — rejected. |
| 5 | POST create with `growth!` (special char) | 400 — rejected. |
| 6 | POST create with `-growth` / `growth-` | 400 — rejected. |
| 7 | POST create with empty code | 400 — required validation error. |

## 6. Postconditions
