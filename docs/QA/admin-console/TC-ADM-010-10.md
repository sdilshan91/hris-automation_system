# TC-ADM-010-10: Terminated tenant — export REJECTED for both personas

## 1. Test Objective
Verify the Preconditions status gate (BR-2/BR-3 boundary): a tenant in `Terminated` status is past the grace period (data deleted / tenant retained as terminated) and export is NOT available for either a Tenant Admin or a System Admin. Allowed statuses are only Active/Trial/PastDue/Terminating; Terminated is the closed boundary.

## 2. Related Requirements
- User Story: US-ADM-010
- Acceptance Criteria: AC-4 (allowed-status set; Terminated excluded)
- Business Rules: BR-3 (export available DURING terminating, not after termination)
- Preconditions: tenant must be active/trial/past_due/terminating

## 3. Preconditions
- Tenant "Delta" is in `Terminated` status.
- System Admin "Pat" authenticated; a Tenant Admin context for Delta is effectively closed.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| tenant | delta (Terminated) | post-grace; data deleted |

## 5. Test Steps

|------|--------|-----------------|
| 1 | As Pat (System Admin), attempt to initiate an export for Delta | Rejected by the status gate — Terminated is not an exportable status; no ExportRequest enters Processing. |
| 2 | Attempt as a Tenant Admin context for Delta | Rejected (terminated tenant access is closed). |
| 3 | Confirm no bundle was generated | No file under `{deltaTenantId}/exports/...` for this attempt. |

## 6. Postconditions
