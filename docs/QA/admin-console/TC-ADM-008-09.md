# TC-ADM-008-09: Detail view — before/after JSON, IP, user agent, trace id

## 1. Test Objective
Verify AC-3 / FR-2: opening an audit record detail returns the full record — `before` (JSON), `after` (JSON), `ip_address`, `user_agent`, and `trace_id` — for a row belonging to the current tenant. (The visual diff itself is computed on the frontend; see TC-ADM-008-16.)

## 2. Related Requirements
- User Story: US-ADM-008
- Acceptance Criteria: AC-3
- Functional Requirements: FR-2 (record fields), FR-3 (diff computed FE-side from before/after)

## 3. Preconditions
- Dana (`TenantAdmin`, Acme) authenticated.
- Acme has an audit row for an Employee update: `before` = `{"first_name":"John"}`, `after` = `{"first_name":"Jane"}`, with ip_address, user_agent, trace_id populated.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| audit_id | A1 (Acme) | Employee.Update |
| before | {"first_name":"John"} | |
| after | {"first_name":"Jane"} | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | GET audit detail for A1 | 200; full record returned. |
| 2 | Inspect before/after | `before` and `after` JSON returned verbatim (non-sensitive fields unmasked). |
| 3 | Inspect metadata | `ip_address`, `user_agent`, `trace_id` present and populated. |
