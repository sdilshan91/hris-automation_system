# TC-ADM-007-15: AC-5 delegation rule CONFIG is stored on a step (run-green); LIVE routing DEFERRED

## 1. Test Objective
Verify the DEFINITION-LAYER portion of AC-5: a Tenant Admin can enable delegation on a specific step ("If the approver is on leave, delegate to {backup approver}") and the delegation configuration — enabled flag + backup approver reference — is PERSISTED on the workflow step and read back correctly. This is the run-green half. The LIVE behavior (when a request reaches that step and the primary approver has an active approved leave, automatically routing to the backup and recording it on the workflow instance) is DEFERRED runtime-engine work and is covered as a blocked placeholder in TC-ADM-007-16.

## 2. Related Requirements
- User Story: US-ADM-007
- Acceptance Criteria: AC-5 (delegation — CONFIG storage portion)
- Functional Requirements: FR-2 (step config), FR-5 (backup approver must be a valid tenant user/role)
- Non-Functional: NFR-4 (audited)

## 3. Preconditions
- Dana (`TenantAdmin`) at Acme `active`.
- A valid backup approver (e.g. user "Carl") exists in Acme; a workflow with a target step exists.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| step.delegation_enabled | true | toggle on |
| step.delegation_backup | <Carl user id> | valid tenant user |
| bad backup | <foreign / non-existent id> | must be rejected (FR-5) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Dana, enable delegation on Step 1 with backup = Carl and save | 200; delegation config persisted on the step (enabled = true, backup = Carl). New workflow version per AC-3 if editing an active workflow. |
| 2 | GET the workflow step | `delegation_enabled = true`, `delegation_backup = Carl` returned exactly as configured. |
| 3 | Attempt to set the backup approver to a foreign/non-existent user | Rejected (FR-5 — invalid approver reference); delegation not saved with a bad backup. |
| 4 | Inspect tenant `audit_log` | The delegation-config change is audited before/after. |
| 5 | (DEFERRED — runtime) Submit a request where Carl's primary is on approved leave -> auto-route to Carl, recorded on instance | NOT executable today — see TC-ADM-007-16 (status: blocked). The CONFIG is stored and testable; the LIVE routing is deferred engine work. |

## 6. Postconditions
- Delegation config (enabled + valid backup) persists on the step and is audited; live routing deferred.
