# TC-ADM-002-13: Monitoring dashboard WCAG 2.1 AA + responsive 1024px–4K

## 1. Test Objective
Verify NFR-4 and the WCAG 2.1 AA bar for the monitoring surface: the dashboard, tenant usage table, breach queue, and tenant detail render correctly and remain operable from 1024px up to 4K, are fully keyboard navigable, are screen-reader friendly, and meet color-contrast requirements — critically, gauge/health status must not rely on color alone.

## 2. Related Requirements
- User Story: US-ADM-002
- Non-Functional Requirements: NFR-4
- Standard: WCAG 2.1 AA

## 3. Preconditions
- System Admin authenticated; dashboard populated with tenants spanning green/amber/red gauge states and at least one breach.
- Axe (or equivalent), a screen reader, and viewport-resize tooling available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Viewports | 1024px, 1440px, 1920px, 2560px, 3840px (4K) | NFR-4 range |
| Status colors | green 0-79 / amber 80-94 / red 95-100 | must not be color-only |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Render the dashboard at each viewport from 1024px to 4K | Layout reflows without clipping/overlap/horizontal scroll; cards/table/charts remain readable and usable (NFR-4). |
| 2 | Navigate the entire dashboard, usage table, breach panel, and tenant-detail using keyboard only | All controls reachable in logical order, visible focus ring, table sort/search/pagination operable via keyboard; no keyboard traps. |
| 3 | Traverse with a screen reader | KPIs, gauge values, health indicators, breach entries, and table cells have accessible names/roles; gauges announce their percentage and warning/breach state. |
| 4 | Run an automated axe scan | Zero critical/serious violations; color contrast >= 4.5:1 (text) / 3:1 (large/graphical). |
| 5 | Verify status is not color-only | Each gauge/health state also conveys meaning via text/label/icon (e.g. "80% — Warning", "Down"), so colorblind users can distinguish warning vs breach vs healthy. |

## 6. Postconditions
- Monitoring surface passes WCAG 2.1 AA and renders correctly across 1024px-4K with non-color-only status.
