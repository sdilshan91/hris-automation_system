# TC-ADM-010-21: Data-Export service targets `/tenant/data-exports` (BUG-104 regression)

## 1. Test Objective
Guard against **BUG-104** (HIGH): the Angular `DataExportService` built its API base as `/api/v1/tenant/exports` (and `/api/v1/system/tenants/{id}/exports`), omitting the `data-` segment. The backend routes are `/api/v1/tenant/data-exports` and `/api/v1/system/tenants/{id}/data-exports`. As a result the export-history GET 404'd (rendered a false "No exports yet.") and Start-Export POSTed to a dead route. This test verifies both persona bases include the `data-` segment and that the bare `/tenant/exports` route is never requested.

## 2. Related Requirements
- User Story: US-ADM-010
- Acceptance Criteria: AC-1 (Tenant-Admin initiate/history), AC-6 (System-Admin path)
- Functional Requirements: FR-9 (export status/history)
- Finding: BUG-104

## 3. Preconditions
- Angular unit test harness (`HttpClientTestingModule` / `HttpTestingController`).
- `environment.apiBaseUrl` = `/api/v1`.

| 4 | Call `initiate({scope:'full'},'t-9')` | Exactly one POST to `/api/v1/system/tenants/t-9/data-exports`; `expectNone` on `.../exports`. |
