# TC-ADM-009-02: Create plan with full FR-2 schema — all fields persisted, available for assignment, audited

## 1. Test Objective
Verify AC-2 + the "Create plan" Test Hint: creating a "Growth" plan with the complete `subscription_plan` schema (all limits, enabledModules, featureFlags, prices, currency, slaTier, trial_days, auditLogRetentionDays) persists every field correctly, makes the plan available for assignment to new tenants, and logs the create to the system audit log with full state.

## 2. Related Requirements
- User Story: US-ADM-009
- Acceptance Criteria: AC-2
- Functional Requirements: FR-1 (create), FR-2 (full field set exposed/persisted), FR-6 (enabledModules), Test Hints (Create plan)
- Non-Functional Requirements: NFR-3 (audit)

## 3. Preconditions
- System Admin "Pat" authenticated at `admin.yourhrm.com` with `SystemAdmin`.
- No plan with code `growth` exists.
