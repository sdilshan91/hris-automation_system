# TC-ADM-005-15: End All Sessions — revokes the user's refresh tokens in the CURRENT tenant only

## 1. Test Objective
Verify FR-5: the "End All Sessions" action revokes all refresh tokens for the selected user WITHIN THE CURRENT TENANT only — leaving their sessions in other tenants alive and their credential/`password_changed_at` untouched. This contrasts with force-password-reset (TC-ADM-005-14), which is global.

## 2. Related Requirements
- User Story: US-ADM-005
- Acceptance Criteria: AC-4 (session control)
- Functional Requirements: FR-5
- Non-Functional: NFR-2 (audit)

## 3. Preconditions
- Tenant Admin "Dana" authenticated on Acme.
- Target user "Sam" has live sessions in BOTH Acme and Beta; Sam remains `active` in both.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| target user | sam | dual-tenant |
| acting tenant | Acme | current tenant |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Dana, `POST /api/v1/admin/users/{sam}/end-sessions` | 200/204 success. |
| 2 | Query Sam's Acme refresh tokens | All revoked in Acme. |
| 3 | Query Sam's Beta refresh tokens | Still VALID — untouched (current-tenant scope only). |
| 4 | Query `users` for Sam | `password_changed_at` UNCHANGED — this is session-end, not a password reset. |
| 5 | Query Sam's Acme `user_tenant` | Still `active` — Sam is logged out of Acme but not deactivated. |
| 6 | Query `audit_log` | End-all-sessions entry: actor=Dana, target=Sam, tenant=Acme, timestamp (NFR-2). |

## 6. Postconditions
- Sam is signed out of Acme only; Beta sessions and the global credential are intact.
