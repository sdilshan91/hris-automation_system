# TC-ADM-002-11: Monitoring access is audited — Monitoring.Viewed and Monitoring.TenantViewed records

## 1. Test Objective
Verify AC-5 / NFR-5: viewing the monitoring dashboard writes a `system_audit_log` record (Action `Monitoring.Viewed`), and opening a specific tenant's detail writes a `system_audit_log` record (Action `Monitoring.TenantViewed`) that captures WHICH tenant was viewed. Each record carries the acting system user, timestamp, and IP.

## 2. Related Requirements
- User Story: US-ADM-002
- Acceptance Criteria: AC-5
- Non-Functional Requirements: NFR-5
- Test Hints: viewing a tenant's detail is recorded in `system_audit_log`

## 3. Preconditions
- System Admin "Olivia Park" authenticated at `admin.yourhrm.com`.
- `system_audit_log` is reachable; baseline row count recorded.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Acting user | olivia (SystemAdmin) | audited actor |
| Dashboard action | Monitoring.Viewed | overview load |
| Tenant-detail action | Monitoring.TenantViewed | includes tenant_id |
| Tenant viewed | acme | captured in record |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the Monitoring dashboard | A `system_audit_log` row is written with Action `Monitoring.Viewed`, acting `user_id` = olivia, timestamp, and source IP. |
| 2 | Open the tenant detail for "acme" | A `system_audit_log` row is written with Action `Monitoring.TenantViewed`, referencing the viewed `tenant_id` (acme), acting user, timestamp, IP (NFR-5 "which tenant details were viewed"). |
| 3 | Open a second tenant "globex" detail | A separate `Monitoring.TenantViewed` row is written referencing globex — each viewed tenant is individually recorded. |
| 4 | Verify no PII in the audit payload | The audit records contain identifiers/operational context only, no employee PII (consistent with BR-2). |
| 5 | (Negative, ties to TC-ADM-002-09) A denied Tenant-Admin attempt | The denied access attempt is also auditable per the platform's audit policy. |

## 6. Postconditions
- Each dashboard view and each tenant-detail view produces a distinct, attributable audit record.
