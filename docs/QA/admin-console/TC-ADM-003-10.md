# TC-ADM-003-10: BR-5 — impersonation of users in a TERMINATED tenant is rejected

## 1. Test Objective
Verify BR-5 and the precondition that the target tenant is not `terminated`: an attempt to impersonate any user in a terminated tenant is rejected, with no session/token/audit side effects. (Contrast with AC-5: SUSPENDED tenants ARE allowed but read-only — covered in TC-ADM-003-03.)

## 2. Related Requirements
- User Story: US-ADM-003
- Business Rules: BR-5
- Preconditions (target tenant not terminated)
- Test Hints: (derived from BR-5)

## 3. Preconditions
- Target tenant "Gamma" has `status = terminated`.
- A user previously belonged to Gamma.
- Initiator is a `SystemAdmin`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| target tenant | Gamma (terminated) | excluded |
| reason | "Post-termination investigation" | valid length, request must still fail |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | `POST /impersonation/start` targeting a user in the terminated Gamma tenant | Rejected (403/422) — terminated tenants are excluded from impersonation (BR-5). |
| 2 | Inspect side effects | No `impersonation_sessions` row, no token, no audit "Started", no notification. |
| 3 | Confirm the suspended-tenant path differs | (Cross-reference) a SUSPENDED tenant would be ALLOWED read-only per AC-5/TC-ADM-003-03 — terminated is a hard reject, suspended is read-only. |

## 6. Postconditions
- Terminated-tenant impersonation is impossible; no side effects from the rejected attempt.
