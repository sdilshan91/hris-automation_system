# TC-ADM-004-15: BR-7 access control — only SystemAdmin transitions; SystemSupport views lifecycle history only; tenant users 403; unauth 401

## 1. Test Objective
Verify BR-7: only the `SystemAdmin` role may initiate suspend/terminate/reactivate/restore. `SystemSupport` can VIEW lifecycle history but cannot initiate any transition. Tenant users (even Tenant Admin) and unauthenticated callers are denied the lifecycle endpoints entirely.

## 2. Related Requirements
- User Story: US-ADM-004
- Functional Requirements: FR-1, FR-2, FR-5, FR-6
- Business Rules: BR-7
- Test Hints: (access control)

## 3. Preconditions
- Users available: a `SystemAdmin`, a `SystemSupport`, a tenant `Tenant Admin`, and an anonymous (no token) client.
- An active, non-system target tenant "Acme".

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| reason | "access-control probe — valid length" | >= 10 chars |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As SystemAdmin, call suspend/terminate/reactivate/restore (each on an appropriately-staged tenant) | All permitted (subject to BR-1 state validity). |
| 2 | As SystemSupport, GET the tenant lifecycle history / event timeline | 200 — read access to lifecycle history is allowed. |
| 3 | As SystemSupport, attempt suspend / terminate / reactivate / restore | 403 Forbidden on each — SystemSupport cannot initiate transitions (BR-7); no state change. |
| 4 | As tenant Tenant Admin, attempt any lifecycle transition endpoint | 403/404 — tenant users have no access to the admin lifecycle API. |
| 5 | As an unauthenticated client, attempt any lifecycle transition endpoint | 401 Unauthorized. |
| 6 | After all denied attempts, re-read Acme | State unchanged; no lifecycle/audit rows from the denied attempts (denials may themselves be access-audited per platform policy). |

## 6. Postconditions
- Lifecycle transitions are SystemAdmin-only; SystemSupport is read-only on history; tenant/anon callers are rejected.
