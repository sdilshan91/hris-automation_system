# TC-ADM-006-16: Audit completeness sweep — every settings section writes a before/after audit row

## 1. Test Objective
Verify NFR-4 across ALL settings sections: each successful change to org profile, branding (logo/favicon/primary color), localization, password policy, and session policy writes exactly one tenant `audit_log` entry capturing actor identity, action, BEFORE and AFTER values, and timestamp. No section silently skips auditing; rejected changes write no settings-change row.

## 2. Related Requirements
- User Story: US-ADM-006
- Acceptance Criteria: AC-1, AC-2, AC-3, AC-4
- Functional Requirements: FR-1, FR-5, FR-6
- Non-Functional: NFR-4 (before/after audit, all sections)
- Test Hints: "Change the company name; verify the audit log records the old and new values with the Tenant Admin's identity."

## 3. Preconditions
- Tenant Admin "Dana" authenticated at `acme.yourhrm.com`; baseline values known for every section.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| org.name | change | audited |
| branding.primary_color | change | audited |
| branding.logo_url | upload | audited |
| locale.default_language | change | audited |
| security.password_policy | change | audited |
| security.session_policy | change | audited |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Change company name; read audit | One row: actor=Dana, action=org-profile update, before=old name, after=new name, timestamp set. |
| 2 | Upload a new logo; read audit | One row for the branding change (before/after URL). |
| 3 | Change primary color; read audit | One row (before/after color). |
| 4 | Change default language; read audit | One row (before/after locale). |
| 5 | Change password policy; read audit | One row (before/after policy). |
| 6 | Change session policy; read audit | One row (before/after session policy). |
| 7 | Verify tenant scoping of audit rows | All audit rows carry the current tenant id; none visible to another tenant. |
| 8 | Attempt one rejected change (invalid value) | No settings-change audit row added for the rejected attempt. |

## 6. Postconditions
- Each section produced exactly one before/after audit row; audit is tenant-scoped; rejects unaudited as changes.
