# TC-ADM-007-09: Archive and restore a workflow; archived workflows do not count toward the plan limit

## 1. Test Objective
Verify FR-6: archiving a workflow marks it `is_active = false`; it can be RESTORED back to active. Archived workflows do NOT count toward the `MaxWorkflows` plan limit — so a tenant at its limit can archive one workflow and then create a new one. (Per the Test Hint "Archive and restore": archive a workflow; verify it no longer applies to new requests; restore it; verify it becomes active.)

## 2. Related Requirements
- User Story: US-ADM-007
- Acceptance Criteria: AC-1 (status archived shown), AC-4 (plan-limit interplay)
- Functional Requirements: FR-6 (archive/restore; archived excluded from plan limit), FR-4
- Non-Functional: NFR-4 (audited)

## 3. Preconditions
- Dana (`TenantAdmin`) at Acme `active`.
- Acme `MaxWorkflows = 2`; Acme has exactly 2 active workflows (WF-A Leave, WF-B Expense) — at the limit.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| WF-A | entity=Leave, active | to be archived |
| WF-B | entity=Expense, active | |
| WF-C | entity=Offer, 1 valid step | created after archive |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Attempt to create WF-C while at limit (2 active) | Rejected with the plan-limit message (control; see TC-ADM-007-05). |
| 2 | Archive WF-A | 200; WF-A `is_active = false`; list shows it under status = archived. Audit row written. |
| 3 | Re-attempt to create WF-C | 201; succeeds — archived WF-A no longer counts toward MaxWorkflows (now 2 active: WF-B, WF-C). |
| 4 | Restore WF-A | 200; WF-A `is_active = true` again. Audit row written. |
| 5 | If restoring WF-A would exceed the limit OR collide with another active Leave workflow (BR-2) | The restore is governed by the same active-count / one-active-per-entity-type rules (restore rejected at limit, or restores by auto-archiving a conflicting active Leave workflow per BR-2) — assert the documented behavior, not a silent over-limit state. |

## 6. Postconditions
- Archive/restore transitions audited; archived workflows excluded from the plan-limit count.
