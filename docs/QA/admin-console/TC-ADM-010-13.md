# TC-ADM-010-13: System-Admin export — dual audit with System Admin as actor

> **ℹ GAP-L6 / 2026-08-10 — checked and CLEARED.** The gap register lists this TC as "marked passing against
> a `system_audit_log` the codebase says it deliberately does not have". **That does not hold.** This TC never
> names that table: step 3 says "Inspect the system audit log" as prose, and the platform satisfies exactly
> that via `audit_logs` with a system actor (`UserId` null) — the design `IAuditLogPurgeService.cs:6` states.
> Status left as `pass`. (I briefly demoted it on the register's claim before reading the file; the demotion
> was wrong and is reverted. The genuinely affected TCs are listed in ISSUE-366's sibling audit.)

## 1. Test Objective
Verify AC-6: when a System Admin exports a tenant's data, the bundle content matches a tenant-initiated export AND the action is recorded in BOTH the system audit log and the tenant's audit log with the System Admin as the actor. The System Admin passes an explicit `tenantId`.

## 2. Related Requirements
- User Story: US-ADM-010
- Acceptance Criteria: AC-6
- Business Rules: BR-1 (System Admin can export any tenant)
- (Email to System Admin + billing contact is DEFERRED — see TC-ADM-010-16)

## 3. Preconditions
- System Admin "Pat" authenticated at `admin.yourhrm.com`.
- Tenant "Acme" `Active` with data; ExportRequest path available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| actor | Pat (System Admin) | explicit tenantId = Acme |
| scope | full | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As Pat, initiate a full export with explicit `tenantId` = Acme | Accepted; ExportRequest Queued under Acme's tenant scope. |
| 2 | Let the job complete and open the bundle | Same content shape as a tenant-initiated export (CSVs + audit_log.jsonl + manifest for Acme). |
| 3 | Inspect the system audit log | An export row exists with actor = Pat and the target tenant = Acme. |
| 4 | Inspect Acme's tenant audit log | A corresponding export row exists attributing the action to Pat (System Admin as actor), not to a tenant user. |
| 5 | Confirm scope correctness | The bundle and manifest reflect Acme's data only (cross-tenant covered in TC-ADM-ISO-028). |

## 6. Postconditions
- Export Completed; dual-audited with System Admin attribution.
