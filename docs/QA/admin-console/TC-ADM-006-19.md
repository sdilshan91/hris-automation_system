# TC-ADM-006-19: [DEFERRED] Config-cache invalidation (Redis) + SignalR propagation to active sessions <60s

## 1. Test Objective
Verify FR-7 + NFR-3: a settings change invalidates the tenant config cache key `t:{tenantId}:config` and propagates to all active sessions within 60 seconds (via cache invalidation + SignalR notification or next page load). **DEFERRED** — Redis distributed cache and SignalR are NOT wired; the cache-invalidation call no-ops gracefully today and propagation is effectively "next page load."
