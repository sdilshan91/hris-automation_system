# TC-RPT-005-02: Manager dashboard is team-scoped to direct reports (8 via ReportsToEmployeeId); pending approvals + quick actions present (AC-2, FR-1/7, BR-1/3/6)

## 1. Test Objective
Verify that when a Manager loads the dashboard, `GET /api/v1/dashboard/widgets` returns `role:"manager"`
with team-scoped widgets (Team Size, Team Attendance Today, Pending Approvals, Team Leave Calendar,
Upcoming Team Reviews) and a Quick Actions panel, and that every team widget is scoped to the manager's
direct reports only. Anchors to the Test Hint: a manager with 8 direct reports (via `ReportsToEmployeeId`)
sees Team Size = 8 and team widgets computed over exactly those 8. Validates AC-2, FR-1, FR-7, BR-1, BR-3, BR-6.

## 2. Related Requirements
- User Story: US-RPT-005
- Acceptance Criteria: AC-2
- Functional Requirements: FR-1 (Manager dashboard), FR-7 (Quick Actions panel for managers)
- Business Rules: BR-1 (managers see team widgets), BR-3 (pending approvals assigned to this user), BR-6 (quick actions top 5)

## 3. Preconditions
- Tenant A active; Manager `mgr1` authenticated within Tenant A.
- `mgr1` has exactly 8 employees with `ReportsToEmployeeId == mgr1.EmployeeId`; the tenant also has
  other employees who do NOT report to `mgr1` (to prove scoping excludes them).
- At least 2 leave/attendance approvals are assigned to `mgr1`; additional pending items exist in the tenant assigned to OTHER approvers.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| role (derived) | manager | server-derived |
| team_size widget value | 8 | direct reports via ReportsToEmployeeId (Test Hint) |
| non-team employees | present | must NOT be counted in team widgets |
| pending approvals assigned to mgr1 | 2 | BR-3 counts only items assigned to logged-in user |
| expected widgetKeys | team_size, team_attendance_today, pending_approvals, team_leave_calendar, upcoming_team_reviews, quick_actions | Manager set |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `mgr1`, `GET /api/v1/dashboard/widgets` | 200; `role:"manager"`; manager widget set returned (FR-1) |
| 2 | Read the `team_size` widget | `value == 8` -- exactly the direct reports via `ReportsToEmployeeId` (AC-2, Test Hint) |
| 3 | Read `team_attendance_today` and `team_leave_calendar` | aggregated over the SAME 8 direct reports only; tenant employees who do not report to `mgr1` are excluded (BR-1) |
| 4 | Read the `pending_approvals` widget | counts only leave+attendance approvals ASSIGNED to `mgr1` (== 2), not all pending items in the tenant (BR-3) |
| 5 | Read the `quick_actions` widget/panel | a Quick Actions panel exists with approve/reject affordances (FR-7); surfaces at most the top 5 items (BR-6) |
| 6 | Confirm each manager widget contract | each has `value`/`items`, `label`, trend indicator where applicable, and a `miniChart` where applicable |

## 6. Postconditions
- Manager dashboard rendered scoped to the 8 direct reports; no data mutated.
