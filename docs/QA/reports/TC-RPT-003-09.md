# TC-RPT-003-09: Draft/in-progress run excluded; multiple runs per period selectable (FR-4); default = latest (BR-1, FR-4)

## 1. Test Objective
Verify (a) only FINALIZED payroll runs appear in reports — a draft/in-progress run contributes
nothing (BR-1) — and (b) when MULTIPLE runs exist for one period (e.g. a regular run + a supplementary
run), the user can select a SPECIFIC run via `payroll_run_id`, with the latest finalized run used by
default (FR-4). Validates BR-1, FR-4, and the Test Hint "create a payroll run but do not finalize;
verify it does not appear in reports".

## 2. Related Requirements
- User Story: US-RPT-003
- Acceptance Criteria: AC-1, AC-4 (run selection feeds Run Summary and Bank Advice)
- Functional Requirements: FR-1, FR-4 (multiple runs per period; select specific run)
- Business Rules: BR-1 (finalized only)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Payroll.Export`.
- For 2026-03 in Tenant A:
  - Run R1 (regular) — FINALIZED — gross=250,000.00, 50 emp.
  - Run R2 (supplementary) — FINALIZED — gross=5,000.00, 2 emp.
  - Run R3 (correction) — DRAFT / in-progress, NOT finalized — gross=9,999.00.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| payroll_period | 2026-03 | |
| payroll_run_id (R1) | uuid of regular run | finalized |
| payroll_run_id (R2) | uuid of supplementary run | finalized |
| R3 (draft) | NOT selectable / excluded | BR-1 |
| default run | latest finalized (R2 or R1 per recency) | FR-4 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, generate Run Summary for 2026-03 WITHOUT specifying a run | Defaults to the latest FINALIZED run (FR-4); draft R3's 9,999.00 NOT included anywhere |
| 2 | Open the run selector for 2026-03 | Lists ONLY finalized runs R1 and R2; R3 (draft) is absent |
| 3 | Select R1 explicitly; regenerate | Totals reflect R1 only (gross=250,000.00, 50 emp) |
| 4 | Select R2 explicitly; regenerate | Totals reflect R2 only (gross=5,000.00, 2 emp) |
| 5 | Attempt to pass R3's id as payroll_run_id | Rejected / treated as not-found (draft run not reportable, BR-1) |
| 6 | Finalize R3, then refresh the run selector | R3 now appears as selectable and its figures become reportable (BR-1 boundary) |
| 7 | Confirm statutory/CTC/bank-advice reports honor the same run selection | All payroll report types respect the selected run + exclude drafts |

## 6. Postconditions
- Draft run never appears; finalized runs selectable; latest finalized is the default.
