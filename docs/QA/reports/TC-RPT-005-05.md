# TC-RPT-005-05: Trend = current vs same-length previous period; trendIsPositive semantics (headcount-up=positive/green, turnover-up=negative/red) (AC-1, FR-2, BR-2)

## 1. Test Objective
Verify that a widget's trend indicator compares the current period to the SAME-LENGTH previous period
(BR-2), that `trendDirection`/`trendPercentage` are computed correctly from `value` vs `previousValue`,
and crucially that `trendIsPositive` encodes the BUSINESS meaning of the direction -- not the arithmetic
sign: a rising headcount is positive (green up-arrow) while a rising turnover rate is negative (red
up-arrow). Validates AC-1, FR-2, BR-2.

## 2. Related Requirements
- User Story: US-RPT-005
- Acceptance Criteria: AC-1
- Functional Requirements: FR-2 (trend indicator = comparison to previous period)
- Business Rules: BR-2 (current vs same-length previous period)
- UI/UX: S8 (green up = positive trend; red up = negative trend)

## 3. Preconditions
- Tenant A active; HR Officer `hr1` authenticated.
- Seed two months of data so trends are computable: headcount this month = 55, last month = 50;
  turnover rate this quarter = 8%, previous same-length quarter = 5%.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| headcount value / previousValue | 55 / 50 | +10% MoM |
| turnover value / previousValue | 8 / 5 | +60% (rate rose) |
| same-length window | month vs prior month; quarter vs prior quarter | BR-2 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, load the dashboard; inspect the `headcount` widget | `previousValue == 50`, `value == 55`, `trendDirection == "up"`, `trendPercentage == 10` (current vs same-length prior month, BR-2) |
| 2 | Inspect `headcount.trendIsPositive` | `true` -- headcount growth is a positive/green trend (UI/UX S8) |
| 3 | Inspect the `turnover_rate` widget | `previousValue == 5`, `value == 8`, `trendDirection == "up"`, `trendPercentage == 60` (BR-2) |
| 4 | Inspect `turnover_rate.trendIsPositive` | `false` -- rising turnover is a negative/red trend even though the arrow points up (UI/UX S8) |
| 5 | Seed a widget with no prior-period data (e.g. brand-new metric) | `previousValue` null and `trendDirection == "flat"` (or trend omitted); no divide-by-zero / no spurious percentage |
| 6 | Confirm the comparison window length | the previous period is the SAME length as the current (month vs month, quarter vs quarter), not an arbitrary baseline (BR-2) |

## 6. Postconditions
- Trend indicators reflect correct period-over-period comparison and correct positive/negative semantics.
