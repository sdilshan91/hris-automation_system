# TC-RPT-005-03: Employee dashboard returns personal widgets (leave-balance donut, attendance progress, onboarding, holidays, payslips link, pending-actions) (AC-3, FR-1/2/7, BR-1)

## 1. Test Objective
Verify that when an Employee loads the dashboard, `GET /api/v1/dashboard/widgets` returns `role:"employee"`
with the personal widget set: Leave Balance Summary (`miniChart.type == "donut"`), Attendance This Month
(`miniChart.type == "progress"`), Onboarding Progress (if an onboarding journey is active), Upcoming
Holidays, Recent Payslips (a link widget), and Pending Actions. All values reflect the logged-in
employee's OWN data. Validates AC-3, FR-1, FR-2, FR-7, BR-1.

## 2. Related Requirements
- User Story: US-RPT-005
- Acceptance Criteria: AC-3
- Functional Requirements: FR-1 (Employee dashboard), FR-2 (donut/progress mini visualizations), FR-7 (employee quick actions)
- Business Rules: BR-1 (employees see personal widgets)

## 3. Preconditions
- Tenant A active; Employee `emp1` authenticated within Tenant A.
- `emp1` has a known leave balance (entitlement/consumed), attendance records for the current month,
  an ACTIVE onboarding journey, upcoming public holidays in the tenant calendar, and at least one finalized payslip.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| role (derived) | employee | server-derived |
| leave_balance widget | donut | consumed vs remaining (FR-2) |
| attendance_this_month widget | progress | present/working days as a progress bar (FR-2) |
| onboarding_progress widget | present | shown because journey is active (AC-3 "if active") |
| expected widgetKeys | leave_balance, attendance_this_month, onboarding_progress, upcoming_holidays, recent_payslips, pending_actions | Employee set |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `emp1`, `GET /api/v1/dashboard/widgets` | 200; `role:"employee"`; employee widget set returned (FR-1) |
| 2 | Read the `leave_balance` widget | reflects `emp1`'s OWN balance; `miniChart.type == "donut"` (consumed vs remaining) (AC-3, FR-2, BR-1) |
| 3 | Read the `attendance_this_month` widget | `emp1`'s own attendance; `miniChart.type == "progress"` (AC-3, FR-2) |
| 4 | Read the `onboarding_progress` widget | present because `emp1` has an active onboarding journey; shows % complete (AC-3) |
| 5 | Read `upcoming_holidays` | upcoming tenant holidays listed in `items[]` (AC-3) |
| 6 | Read the `recent_payslips` widget | a link widget with `linkUrl` to the payslips page (AC-3, FR-7 affordance) |
| 7 | Read the `pending_actions` widget | `items[]` of tasks/forms assigned to `emp1` (AC-3) |
| 8 | Confirm no other employee's data appears in any widget | all values are `emp1`-scoped (BR-1) |

## 6. Postconditions
- Employee dashboard rendered with personal data only; no data mutated.
