# TC-RPT-003-12: Accessibility (WCAG 2.1 AA) + responsive 360px–4K — KPI cards scroll, tables scroll, variance not color-only (NFR-4, NFR-5)

## 1. Test Objective
Verify the payroll-report UI meets WCAG 2.1 AA (NFR-5) and is fully responsive from 360px to 4K
(NFR-4): charts expose alt text / a data-table alternative, KPI cards and tables remain usable on
narrow screens (KPI cards scroll horizontally, tables horizontally scrollable, charts stack), the
red/green variance highlighting is NOT conveyed by color alone, keyboard navigation works, and the
masked/reveal control is screen-reader announced. Validates NFR-4, NFR-5, and AC-1's FR-3 variance UI.

## 2. Related Requirements
- User Story: US-RPT-003
- Acceptance Criteria: AC-1, AC-2, AC-3, AC-4
- Functional Requirements: FR-3 (variance highlight), FR-5 (chart + table toggle), FR-6 (reveal toggle)
- Non-Functional: NFR-4 (responsive 360px–4K), NFR-5 (WCAG 2.1 AA)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Payroll.Export` (+ `Payroll.ViewSensitive` for the reveal-control check).
- Payroll reports rendered with representative data (KPI cards, stacked bar, statutory table, bank advice).
- Axe / screen reader (NVDA/VoiceOver) and responsive breakpoints (360 / 768 / 1920 / 4K) available.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| breakpoints | 360px, 768px, 1920px, 4K | NFR-4 |
| contrast ratio | >= 4.5:1 text | WCAG AA |
| variance cue | color + arrow/sign | not color-only (NFR-5) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run axe on each report tab | Zero serious/critical WCAG 2.1 AA violations |
| 2 | Navigate tabs, run selector, generate, reveal toggle with keyboard only | All controls reachable + operable; visible focus ring; logical tab order |
| 3 | With a screen reader, inspect the comparison chart and stacked bar | Charts expose alt text / accessible name + a data-table alternative (FR-5) |
| 4 | Verify the red/green variance indicator | Increase/decrease ALSO conveyed by arrow + sign + text label — not color alone (NFR-5) |
| 5 | Resize to 360px | KPI cards scroll horizontally; charts stack vertically; tables horizontally scrollable (UI/UX §8, NFR-4) |
| 6 | Resize to 768px / 1920px / 4K | Layout adapts without overflow/clipping; charts resize crisply at 4K |
| 7 | With a screen reader on Bank Advice | Masked vs revealed state announced; account masking communicated (e.g. "account ending 9012") |
| 8 | Check the statutory report print layout | Print-friendly layout renders (UI/UX §8) |

## 6. Postconditions
- UI passes WCAG 2.1 AA and is usable 360px–4K; variance not color-only.
