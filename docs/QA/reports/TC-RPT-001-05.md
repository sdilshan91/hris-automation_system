# TC-RPT-001-05: Demographics age calculated at the report date, not current date (BR-5)

## 1. Test Objective
Verify the Demographics report computes age AT THE REPORT DATE (date_to / report-as-of date), not
the current/system date, so historical reports remain accurate. Also verify gender distribution
(pie), age histogram in 5-year buckets, department-wise stacked bar, and location distribution
reflect the seeded data. Validates AC-4 and BR-5, plus the Test Hint on varied ages/genders.

## 2. Related Requirements
- User Story: US-RPT-001
- Acceptance Criteria: AC-4
- Functional Requirements: FR-1, FR-3
- Business Rules: BR-5 (age at report date)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Reports.View.All`.
- Seed an employee with DOB chosen so that age differs between a historical report date and today
  — e.g. DOB 1990-07-01: as of report date 2025-06-30 age = 34 (bucket 30-34); as of today
  2026-06-17 age = 35 (bucket 35-39). The bucket boundary makes the BR-5 difference observable.
- Seed varied genders (e.g. 6 female, 5 male, 1 undisclosed) and varied DOBs across buckets;
  varied locations (e.g. Colombo x4, Kandy x3, Remote x5).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | demographics | |
| report-as-of (date_to) | 2025-06-30 | historical date |
| boundary employee DOB | 1990-07-01 | age 34 as-of 2025-06-30; 35 today |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Generate Demographics with report-as-of date_to = 2025-06-30 | Report renders gender pie, age histogram (5-year buckets), department stacked bar, location distribution, diversity metrics (AC-4) |
| 2 | Locate the boundary employee in the age histogram | Counted in the 30-34 bucket (age 34 as of 2025-06-30), NOT 35-39 — confirms age computed at the report date (BR-5) |
| 3 | Re-generate Demographics with date_to = today (2026-06-17) | Same employee now appears in the 35-39 bucket (age 35) — age moved with the report date, proving it is not pinned to a single point |
| 4 | Verify gender pie | Segments match seed (6 female / 5 male / 1 undisclosed); percentages sum to 100% |
| 5 | Verify location distribution | Counts match seed (Colombo 4 / Kandy 3 / Remote 5) |
| 6 | Verify age histogram buckets are 5-year wide and contiguous | Buckets e.g. 20-24, 25-29, ...; no gaps/overlaps; all employees assigned to exactly one bucket |

## 6. Postconditions
- Age demonstrably computed at the report date; demographic charts reflect seeded data.
