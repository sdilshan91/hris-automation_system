# TC-RPT-001-07: Unauthorized user without Reports.View blocked; authentication required (negative / authz)

## 1. Test Objective
Verify report generation requires authentication and the `Reports.View` permission. A user lacking
any Reports.View permission (e.g. a plain Employee role) is blocked (403), and an unauthenticated
request is rejected (401), at the API layer — not merely hidden in the UI.

## 2. Related Requirements
- User Story: US-RPT-001
- Acceptance Criteria: AC-1, AC-2
- Business Rules: BR-2 (permission-gated access)
- Preconditions: HR Officer must hold Reports.View.All
- Dependencies: Authentication module — Reports.View permission required

## 3. Preconditions
- Tenant A active.
- `emp_noperm` is an authenticated Tenant A user with NO Reports.View / Reports.View.All /
  Reports.View.Team permission (e.g. base Employee role).
- `hr1` holds Reports.View.All (control).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| unauthorized user | emp_noperm | no Reports.View* |
| authorized control | hr1 | Reports.View.All |
| endpoint | POST /api/v1/reports/generate (or equivalent) | the report-generation endpoint |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `emp_noperm`, navigate to Reports > HR Reports | The Reports menu/catalog is not accessible (hidden or route-guarded) |
| 2 | As `emp_noperm`, call the report-generation endpoint directly with a valid body | 403 Forbidden; no report data returned |
| 3 | Call the report-generation endpoint with NO auth token | 401 Unauthorized |
| 4 | Call with an expired/invalid token | 401 Unauthorized |
| 5 | As `hr1` (control), call the same endpoint | 200 OK with report data — confirms the endpoint works and the blocks in steps 2-4 are authz/authn, not a broken endpoint |
| 6 | Confirm the 403/401 responses do not include any report payload or row counts | Bodies carry only an error; zero employee/aggregate data leaked |

## 6. Postconditions
- Reporting endpoints enforce authn + Reports.View server-side.
