# TC-RPT-004-04: CSV inline (100 employees) -- UTF-8 BOM, comma separator, header row, RFC-4180 escaping (AC-4, FR-2, FR-5)

## 1. Test Objective
Verify that selecting "CSV" for a small report (100 employees, < 1000 rows) generates the file
SYNCHRONOUSLY (status `Completed`, direct download) and that the file is UTF-8 with a BOM, uses comma
separators, places headers in the first row, and applies RFC-4180 escaping to special characters
(commas, double-quotes, embedded newlines, leading/trailing spaces). Validates AC-4, FR-2, FR-5
(sync routing), and the Test Hint "100 employees inline".

## 2. Related Requirements
- User Story: US-RPT-004
- Acceptance Criteria: AC-4
- Functional Requirements: FR-2 (UTF-8 BOM, comma, RFC-4180), FR-5 (<1000 -> sync)
- Test Hint: CSV 100-employee inline export

## 3. Preconditions
- Tenant A active; `hr1` has `Reports.Export`.
- A report with exactly 100 employee rows including names with edge characters:
  e.g. `O'Brien, John` (comma), `"Quoted" Name` (double-quote), a multi-line address field (newline),
  and a non-ASCII name (`Zoë Müller`).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | headcount_summary | valid key |
| format | csv | CSV |
| row_count | 100 | <1000 -> sync inline (FR-5) |
| edge row 1 | name="O'Brien, John" | comma must be quoted |
| edge row 2 | name=`"Quoted" Name` | inner quotes doubled |
| edge row 3 | name="Zoë Müller" | UTF-8 multibyte |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, select CSV on the 100-row report | Response `{exportId, status:"Completed", rowCount:100, format:"csv"}` -- generated inline, not queued (FR-5) |
| 2 | Browser behavior | A direct download of the .csv begins (UI/UX S8 sync path) |
| 3 | Inspect the first 3 bytes of the file | UTF-8 BOM `EF BB BF` present (FR-2) |
| 4 | Inspect the first line | Header row with column names, comma-separated (FR-2) |
| 5 | Inspect the `O'Brien, John` row | Field wrapped in double-quotes because it contains a comma: `"O'Brien, John"` (RFC-4180) |
| 6 | Inspect the `"Quoted" Name` row | Inner double-quotes are doubled and the field is quoted: `"""Quoted"" Name"` (RFC-4180) |
| 7 | Inspect the multi-line address field | Embedded newline is preserved inside a quoted field (RFC-4180) |
| 8 | Inspect `Zoë Müller` | Multibyte chars decode correctly as UTF-8 (no mojibake) |
| 9 | Confirm separator + line endings | Comma separators; consistent CRLF (or documented LF) line endings per RFC-4180 |

## 6. Postconditions
- A correct UTF-8-BOM, RFC-4180-compliant CSV downloaded inline; 100 data rows + header.
