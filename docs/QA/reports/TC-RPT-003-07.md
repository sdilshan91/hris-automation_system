# TC-RPT-003-07: Bank Advice export in tenant's configured format (CSV/text) with full accounts under permission (AC-4, FR-6, BR-4)

## 1. Test Objective
Verify the Bank Advice report can be EXPORTED in the tenant's configured bank-advice format (CSV /
text, BR-4) and that the exported file carries FULL account numbers only when the requester holds the
sensitive-access permission, with the export of full PII audited. Validates AC-4 (export in configured
format), FR-6 (mask vs full + permission), BR-4 (tenant format), and NFR-3 (PII audit on full
account export).

## 2. Related Requirements
- User Story: US-RPT-003
- Acceptance Criteria: AC-4
- Functional Requirements: FR-1, FR-6
- Business Rules: BR-2, BR-4 (tenant-configured bank-advice format)
- Non-Functional: NFR-3 (PII audit)
- Dependencies: US-RPT-004 (export mechanics)

## 3. Preconditions
- Tenant A active; `hrSens` (`Payroll.Export` + `Payroll.ViewSensitive`) and `hrPlain`
  (`Payroll.Export` only) authenticated.
- Tenant A bank-advice format configured (BR-4) — e.g. CSV with columns
  EmployeeName,BankName,AccountNumber,IFSC,NetPay.
- Latest finalized run for 2026-03 with KNOWN bank rows.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| export endpoint | GET /api/v1/payroll/reports/bank-advice/export?format=csv | configured format |
| configured format | CSV (or text) | BR-4 tenant-customizable |
| emp1 full account in file | 123456789012 | full only with ViewSensitive |
| expected audit action | PayrollReport.ViewSensitive | full-account export audited (NFR-3) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hrSens`, export Bank Advice in the tenant's configured format | File downloads in CSV/text matching the tenant's configured column order/format (BR-4) |
| 2 | Open the file; read emp1's row | Full account 123456789012 present; net pay and IFSC correct |
| 3 | Verify row count + totals reconcile with the finalized run | Every finalized payslip's bank row present; net column sums to the run total net |
| 4 | Query the audit log | A "PayrollReport.ViewSensitive" row recorded for the full-account export (NFR-3, exact action) |
| 5 | As `hrPlain` (no ViewSensitive), attempt the full-account export | EITHER blocked 403, OR the file is produced with accounts MASKED (last 4) — full PII never leaves without the permission |
| 6 | Request an unsupported/foreign format | Rejected with 400 (only the tenant's configured CSV/text formats accepted) |

## 6. Postconditions
- Bank advice exported in tenant format; full accounts gated by permission and audited.
