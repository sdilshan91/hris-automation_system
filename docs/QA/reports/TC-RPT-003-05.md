# TC-RPT-003-05: Bank Advice — account masked by default (last 4); table shows name/bank/account/IFSC/net (AC-4, FR-6)

## 1. Test Objective
Verify the "Bank Advice Report" for the latest payroll run renders a table with employee name, bank
name, account number, IFSC/SWIFT code, and net pay, and that account numbers are MASKED BY DEFAULT
showing only the last 4 digits (FR-6 default masking; BR-4 tenant bank-advice format). The reveal
path and its audit are covered separately (TC-RPT-003-06). Validates AC-4 (display) and FR-6 (default
mask), and the Test Hint "verify account numbers are masked".

## 2. Related Requirements
- User Story: US-RPT-003
- Acceptance Criteria: AC-4
- Functional Requirements: FR-1, FR-4, FR-6
- Business Rules: BR-1, BR-2, BR-4 (tenant bank-advice format)
- Non-Functional: NFR-3 (account numbers classified PII)

## 3. Preconditions
- Tenant A active; `hr1` authenticated with `Payroll.Export` but WITHOUT `Payroll.ViewSensitive`.
- A FINALIZED latest run for 2026-03 with employees having KNOWN bank details, e.g.:
  emp1 acct=123456789012 (masked ********9012), bank=Acme Bank, IFSC=ACME0001234, net=4,100.00.
- Tenant A's configured bank-advice format is known (BR-4).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | BankAdvice / bank_advice | valid key |
| payroll_run | latest finalized (2026-03) | FR-4 default = latest |
| emp1 full account | 123456789012 | NOT shown by default |
| emp1 masked account | ********9012 | last 4 only (FR-6) |
| emp1 IFSC | ACME0001234 | displayed |
| emp1 net | 4,100.00 | displayed |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1` (no ViewSensitive), open Bank Advice tab; Generate for latest run | Report renders; preview corresponds to GET /api/v1/payroll/reports/bank-advice/preview |
| 2 | Inspect the table columns | employee name, bank name, account number, IFSC/SWIFT, net pay (AC-4) |
| 3 | Read emp1's account-number cell | Masked: only last 4 visible (e.g. ********9012); full digits NOT present in DOM/response |
| 4 | Confirm masking applies to ALL rows by default | Every account number masked to last 4 (FR-6 default) |
| 5 | Confirm an eye-icon "Reveal" toggle is present but disabled/blocked for this user | Reveal not available without `Payroll.ViewSensitive` (see TC-RPT-003-06) |
| 6 | Read net pay and IFSC columns | Net amounts and IFSC/SWIFT shown un-masked (only the account number is PII-masked) |
| 7 | Verify net pay per row matches the employee's finalized payslip net | Exact match (BR-1 finalized only) |

## 6. Postconditions
- Bank Advice rendered with account numbers masked to last 4 by default; no full account exposed.
