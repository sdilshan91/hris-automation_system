# TC-RPT-004-01: Export dropdown shows CSV / Excel / PDF; selecting a format initiates an export (happy path)

## 1. Test Objective
Verify that an HR Officer with `Reports.Export` who has generated a report sees an "Export" button in
the report toolbar, that clicking it opens a dropdown with exactly three format options -- CSV,
Excel (.xlsx), and PDF (each with its file-type icon) -- and that selecting any format initiates an
export via `POST /api/v1/reports/{type}/export` with `{format, filters, includeCharts}` and returns
`{exportId, status, rowCount, format}`. Validates AC-1, FR-1.

## 2. Related Requirements
- User Story: US-RPT-004
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1, FR-5
- UI/UX: S8 (toolbar export button + dropdown + format icons)

## 3. Preconditions
- Tenant A active; HR Officer `hr1` authenticated with `Reports.Export`.
- A Headcount Summary report (US-RPT-001) has been generated with a known `filters` payload.
- Reporting module enabled for Tenant A's plan.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| report_type | headcount_summary | valid report key |
| formats offered | csv, xlsx, pdf | exactly three (FR-1) |
| filters | {as_of: 2026-06-01, department: all} | same filters as the report view |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, open the generated Headcount Summary; locate the toolbar (top right) | An "Export" button with a dropdown arrow is visible (UI/UX S8) |
| 2 | Click the Export button | A dropdown appears listing CSV, Excel (.xlsx), PDF -- exactly these three, each with a file-type icon |
| 3 | Select "CSV" | `POST /api/v1/reports/headcount_summary/export` fires with `{format:"csv", filters:{...as report}, includeCharts:...}` |
| 4 | Inspect the response body | `{exportId, status, rowCount, format:"csv"}`; status is `Completed` (sync, <1000 rows) or `Queued` (async) |
| 5 | Confirm the request carried the SAME filters used to render the report | filters in the export request match the report-view filters (FR data req) |
| 6 | Confirm no other format option (e.g. JSON/XML) is present | Only csv/xlsx/pdf are selectable (FR-1) |

## 6. Postconditions
- An export request was accepted and an exportId returned; report data unchanged.
