# TC-RPT-001-11: Report generation P95 < 3s for 5,000 employees; large-dataset boundary (NFR-1, NFR-3)

## 1. Test Objective
Verify report generation completes within 3 seconds at P95 for a tenant with up to 5,000 employees
(NFR-1), and that client-side chart rendering completes within 1 second for datasets up to 10,000
data points (NFR-3). Doubles as the large-dataset boundary test.

> PLATFORM NOTE / CONDITIONAL: NFR-1/NFR-3 (and NFR-6 read replicas / FR-6 materialized views)
> require a perf-representative environment. On a dev box record indicative numbers and do NOT
> relax the thresholds. The 3s P95 and 1s chart-render targets are the acceptance bar.

## 2. Related Requirements
- User Story: US-RPT-001
- Acceptance Criteria: AC-2, AC-3, AC-4
- Functional Requirements: FR-5 (cache), FR-6 (materialized views)
- Non-Functional: NFR-1 (P95 < 3s @ 5,000 emp), NFR-3 (chart render < 1s @ 10,000 points), NFR-6 (read replicas optional)

## 3. Preconditions
- Perf-representative Tenant A seeded with 5,000 employees across many departments/locations and a
  12-month history of hires/separations.
- Cache cleared before cold-path measurement.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| tenant population | 5,000 employees | NFR-1 ceiling |
| iterations | >= 50 per report type | for a P95 measurement |
| chart points | up to 10,000 | NFR-3 ceiling |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run 50+ cold (cache-bypassed) Headcount Summary generations; record latency distribution | P95 server generation time < 3s |
| 2 | Repeat for Employee Turnover (12-month, all departments) | P95 < 3s |
| 3 | Repeat for Demographics (all charts) | P95 < 3s |
| 4 | Render a chart with ~10,000 data points client-side; measure paint time | Chart render completes < 1s (NFR-3) |
| 5 | Run warm (cached) repeats of the same reports | Cached responses materially faster than cold; well under 3s |
| 6 | If read replicas are configured, confirm heavy reports route to a replica (NFR-6) | Heavy read load served from replica (CONDITIONAL on replica config; else primary, document) |
| 7 | Record cold vs warm P50/P95 numbers in the test report | Numbers captured; no threshold relaxed to pass |

## 6. Postconditions
- P95 generation < 3s at 5,000 employees; chart render < 1s at 10,000 points; numbers recorded.
