# TC-RPT-004-09: 7-day retention purge (BR-3) + max 100k rows (BR-4) + Excel "Filters Applied" header (BR-6)

## 1. Test Objective
Verify three business rules: (BR-3) a Hangfire cleanup job purges export files older than 7 days while
retaining newer ones and the download of a purged export returns gone/expired; (BR-4) a single export
of > 100,000 rows is rejected with a clear limit message while exactly 100,000 is accepted; (BR-6) an
Excel export header includes a "Filters Applied" section listing the filters used. Validates BR-3,
BR-4, BR-6.

## 2. Related Requirements
- User Story: US-RPT-004
- Acceptance Criteria: AC-2 (Excel header), AC-5 (retention/download lifecycle)
- Business Rules: BR-3 (7-day purge), BR-4 (max 100,000 rows), BR-6 (Excel "Filters Applied")
- Dependencies: Hangfire (cleanup job)

## 3. Preconditions
- Tenant A active; `hr1` has `Reports.Export`; Hangfire worker + recurring cleanup job configured.
- An export file with a backdated created-at of 8 days (`EXP-OLD`) and one 1 day old (`EXP-NEW`).
- A report source capable of resolving 100,000 and 100,001 rows.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| retention | 7 days | BR-3 |
| EXP-OLD age | 8 days | should be purged |
| EXP-NEW age | 1 day | should be retained |
| max rows | 100,000 | BR-4 boundary |
| over-limit | 100,001 | rejected (BR-4) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run (or wait for) the Hangfire export-cleanup job | EXP-OLD (8 days) is purged from storage; its history row marked purged/expired |
| 2 | As `hr1`, `GET /reports/exports/EXP-OLD/download` | Gone/expired response (404/410) -- file no longer retrievable (BR-3) |
| 3 | `GET /reports/exports/EXP-NEW/download` | 200 -- the 1-day-old export is still downloadable (only >7-day files purged) |
| 4 | Export a report resolving to exactly 100,000 rows | Accepted; export proceeds (BR-4 upper bound inclusive) |
| 5 | Export a report resolving to 100,001 rows | Rejected with a clear "max 100,000 rows" message; no oversized file produced (BR-4) |
| 6 | Export to Excel and open the header block | A "Filters Applied" section lists the exact filters used for the report (BR-6) |
| 7 | Confirm purge is tenant-scoped | Only the owning tenant's expired files are purged by its job context |

## 6. Postconditions
- >7-day files purged, newer retained; >100k rejected; Excel header shows applied filters.
