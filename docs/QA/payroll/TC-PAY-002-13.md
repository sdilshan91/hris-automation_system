# TC-PAY-002-13: CTC residual balancer absorbs a partial override into the Special/Basic residual (BUG-070)

## 1. Test Objective
Verify the BUG-070 fix: when an HR user overrides a SUBSET of a salary structure's components, the leftover (declared CTC − sum of all other earnings) is absorbed into ONE designated residual earning (a Special Allowance, else Basic) so the assignment balances instead of being rejected with `ctc_sum_mismatch` (FR-6). Exhaustively covers the balancer's money math and its three guards, plus the end-to-end assignment path.

## 2. Related Requirements
- User Story: US-PAY-002
- Acceptance Criteria: AC-3 (per-component override)
- Functional Requirement: FR-6 (sum-of-earnings must equal declared CTC within ±1)
- Defect: BUG-070

## 3. Preconditions
- A salary structure with a fixed BASIC + HRA + SPECIAL (residual) whose earnings total the target CTC.
- HR user authenticated in the tenant with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Structure | BASIC 240,000 + HRA 48,000 + SPECIAL 312,000 | Fixed, totals 600,000 |
| Annual CTC | 600,000 | Declared target |
| Override | HRA → 60,000 | +12,000 vs base |
| Expected residual | SPECIAL → 300,000 (monthly 25,000) | Absorbs −12,000 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Balance override-up: SPECIAL absorbs −12,000 delta | SPECIAL 300,000; sum(earnings) == 600,000 (tie-out) |
| 2 | Balance override-down / multiple overrides | Residual grows/shrinks by the combined delta; ties out exactly |
| 3 | No-SPECIAL structure | BASIC is the residual and absorbs the delta |
| 4 | Drive residual below 0 | Fail `residual_would_be_negative`, no partial mutation |
| 5 | Override the residual itself | Fail `residual_component_overridden` |
| 6 | No SPECIAL* and no BASIC present | Fail `no_residual_component` |
| 7 | Already balanced (delta ≤ tolerance) | No-op, input returned unchanged |
| 8 | Assign a fixed BASIC+HRA+SPECIAL structure with an HRA override via `SalaryAssignmentService` | 201 success; persisted breakdown ties to 600,000; previously `ctc_sum_mismatch` |
| 9 | Assign the same structure with a mismatched CTC and NO overrides | Still rejected `ctc_sum_mismatch` (balancer gated on overrides.Count > 0) |

## 6. Postconditions
- No change to the balancer contract or persisted data beyond the balanced residual line.
