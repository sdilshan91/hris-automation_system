# TC-PAY-011-02: Employee with no email on file -> Skipped with a logged warning, job continues for the rest, skipped employee surfaced in the summary (negative / continue-on-skip)

## 1. Test Objective
Verify AC-3 and BR-3/FR-5/BR-6: when an employee in the run has no email address on file (or has opted out of email notifications), the distribution job skips that employee -- writing a `payslip_email_log` row with status=Skipped and a logged warning -- and CONTINUES sending to the remaining employees; the run distribution summary shows the skipped count and an expandable list of skipped employees for HR; the employee's payslip remains available in the portal (US-PAY-005), they simply do not receive the email.

## 2. Related Requirements
- User Story: US-PAY-011
- Acceptance Criteria: AC-3
- Functional Requirements: FR-2, FR-5
- Business Rules: BR-3 (no email / opted-out -> skip, payslip still in portal), BR-6 (summary Total/Sent/Failed/Skipped)
- Data Requirements: S7 (payslip_email_log status=Skipped)

## 3. Preconditions
- Tenant "acme" Finalized run R for May 2026 with 4 employees, all with generated PDFs.
- EMP-001, EMP-002, EMP-004 have valid emails on file; **EMP-003 has NO email address** on file.
- (Optional opt-out variant) EMP-005 added with a valid email but `email_notifications=opted-out`.
- HR Officer authenticated with `Payroll.*.All`; SMTP sink capturing mail.
