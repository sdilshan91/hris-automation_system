# TC-PAY-002-06: numeric(18,2) precision and CTC-derivation boundary values

## 1. Test Objective
Verify FR-2 and the S7 data contract: component values derived from CTC are stored at numeric(18,2) precision with correct rounding (monthly = annual / 12), and that boundary CTC values (very large, fractional, zero per-component) are handled without overflow or precision loss.

## 2. Related Requirements
- User Story: US-PAY-002
- Functional Requirements: FR-1, FR-2, FR-3, FR-6
- Data Requirements: S7 (annual_amount/monthly_amount numeric(18,2))

## 3. Preconditions
- FT-IN active structure available; Ravi Kumar Active; HR authenticated with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| CTC (precision) | 1000000.00 | Basic 40% = 400000.00/yr, /12 = 33333.33/mo (rounding) |
| CTC (large) | 99999999999999.99 | Near numeric(18,2) max -- no overflow |
| CTC (fractional) | 600000.55 | Fractional CTC; sum must reconcile within +/-1 |
| Per-component zero | Conveyance override 0.00 | Allowed component value of zero |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Assign FT-IN with CTC 1000000.00; preview. | Basic monthly = 33333.33 (annual 400000.00 / 12, half-up rounding); residual cents reconciled by balancer so annual sum == CTC within +/-1. |
| 2 | Confirm and inspect persisted rows. | `monthly_amount` stored as numeric(18,2); no truncation; annual = monthly_amount-derived total reconciles to CTC. |
| 3 | Assign with CTC 99999999999999.99 (near max). | Accepted; values stored without overflow; UI renders without scientific notation. |
| 4 | Assign with CTC 600000.55 (fractional). | Components derived; sum within +/-1 of 600000.55 (FR-6). |
| 5 | Override Conveyance to 0.00 with the balancer absorbing the difference. | Accepted; zero is a valid component value; sum still == CTC. |
| 6 | Attempt CTC with 3 decimal places (600000.555). | Rejected/normalized to 2 decimals per numeric(18,2); clear validation message. |

## 6. Postconditions
- Derived component values are stored at numeric(18,2) with correct rounding across boundary CTCs.
