# TC-PAY-006-05: Removal of a mandatory statutory deduction component from a salary structure is blocked with a compliance error

## 1. Test Objective
Verify AC-5: when a statutory deduction component is flagged as mandatory for statutory compliance, an attempt to remove it from a salary structure is prevented and an error is displayed indicating the component is mandatory. The block applies via the structure-edit surface (US-PAY-001) and any direct structure-component delete API; the response is a 409 (or 422) with a clear message, and the component remains linked.

## 2. Related Requirements
- User Story: US-PAY-006
- Acceptance Criteria: AC-5
- Functional Requirements: FR-3 (statutory deduction types)
- Business Rules: BR-1
- Data Requirements: S7 (statutory_rule), US-PAY-001 salary_structure_component

## 3. Preconditions
- Tenant "acme" with a statutory deduction component (e.g. "Employee EPF") flagged mandatory and linked into salary structure STR-1.
- A non-mandatory deduction component (e.g. "Loan Recovery") also linked into STR-1 (control).
- User authenticated with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Structure | STR-1 | active |
| Mandatory statutory component | Employee EPF | cannot remove |
| Non-mandatory component | Loan Recovery | can remove (control) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open STR-1 in the structure editor; attempt to remove the "Employee EPF" mandatory statutory component. | Removal is prevented; an error is shown indicating the component is mandatory for statutory compliance (AC-5); the component stays in the structure. |
| 2 | Call the structure-component delete API directly for the mandatory component. | 409/422 with a clear "mandatory statutory component cannot be removed" message; no DB delete occurs. |
| 3 | Remove the non-mandatory "Loan Recovery" component (control). | Succeeds -- the mandatory flag, not the type alone, drives the block. |
| 4 | Attempt to deactivate the mandatory component link (soft-remove) as an alternative path. | Also blocked with the same compliance error (the rule is on the link, not just hard delete). |
| 5 | Verify the structure still computes the statutory deduction after the blocked attempts. | The mandatory statutory component remains linked and active in STR-1. |
| 6 | Confirm the error message contains no other tenant's / employee's data. | Message is generic compliance text; no PII or cross-tenant leakage. |

## 6. Postconditions
- The mandatory statutory component remains in the structure; only non-mandatory components can be removed.
