# TC-PAY-004-12: Per-slip generation status + timestamp recorded; status bar reflects partial progress and the Pending/Generated/Failed lifecycle (FR-7)

## 1. Test Objective
Verify FR-7 and the UI/UX status-bar behavior: each `payroll_slip` carries an accurate `pdf_status` lifecycle (Pending -> Generated, or -> Failed), `pdf_generated_at`, `pdf_storage_path`, and `pdf_file_size_bytes`; and the run detail's generation status bar reflects partial progress accurately during and after a run ("4,850 / 5,000 generated") including the failed count. Confirms the data the UI consumes is correct and consistent.

## 2. Related Requirements
- User Story: US-PAY-004
- Acceptance Criteria: AC-1
- Functional Requirements: FR-7 (record generation timestamp + status per payslip)
- Data Requirements: S7 (pdf_generated_at, pdf_storage_path, pdf_status, pdf_file_size_bytes)
- UI/UX Notes: generation status bar

## 3. Preconditions
- Run R (acme) with 5 employees; one (EMP-X) will fail render (fault injected); HR Maya with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Employees | 5 | one fails |
| pdf_status values | Pending / Generated / Failed | FR-7 |
| Status bar | "4 / 5 generated, 1 failed" | UI/UX |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Before generation, inspect slip rows. | `pdf_status` is null/Pending; `pdf_generated_at`/`pdf_storage_path`/`pdf_file_size_bytes` null. |
| 2 | Start generation; observe the status bar mid-run. | Status bar increments as slips complete (e.g. "2 / 5"); driven by per-slip status changes (live update or poll). |
| 3 | On completion, inspect each slip row (FR-7). | 4 rows Generated (timestamp + path + size set); 1 row Failed (EMP-X) with timestamp/path null and an error recorded. |
| 4 | Verify the status bar final state. | Shows "4 / 5 generated" + a distinct "1 failed" indicator; matches the DB counts exactly. |
| 5 | Retry EMP-X successfully; re-check. | EMP-X -> Generated with timestamp/path/size; status bar -> "5 / 5 generated, 0 failed". |
| 6 | Cross-check `pdf_storage_path` values. | Each equals `{acmeTenantId}/payroll/{R}/{EMP}.pdf`; no path points outside the tenant/run prefix. |

## 6. Postconditions
- Per-slip status/timestamp/path/size are recorded accurately and the status bar is a faithful reflection of them.
