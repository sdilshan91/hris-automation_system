# TC-PAY-009-04: Report totals == sum of individual payslips for the period; only Finalized runs included (BR-1)

## 1. Test Objective
Verify the golden reconciliation invariant (Test Hint #1, BR-1): for any reporting period, the Payroll Summary Report's totals (gross, allowances, statutory, other deductions, net) equal the arithmetic sum of the individual payslips of the Finalized run for that period -- and ONLY Finalized runs contribute. Non-Finalized runs (Queued / Processing / ReviewPending / AwaitingApproval / Approved / Rejected) for the same period must be excluded so figures never double-count or include unapproved data.

## 2. Related Requirements
- User Story: US-PAY-009
- Acceptance Criteria: AC-1
- Functional Requirements: FR-1a, FR-1c, FR-1b
- Business Rules: BR-1
- Data Requirements: S7

## 3. Preconditions
- Tenant "acme"; a Finalized May 2026 run with N payslips.
- A separate non-Finalized run also exists for a different period (e.g. an in-progress June 2026 run) to prove exclusion.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Finalized run | May 2026, N slips | included |
| Non-Finalized run | June 2026, ReviewPending | must be excluded |
| Invariant | report total == sum(payslip values) | per component |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Independently sum the per-payslip gross/allowances/statutory/other-deductions/net for the Finalized May run. | A reference total computed directly from `payroll_slip` rows. |
| 2 | Generate the Payroll Summary Report for May 2026; read its totals. | Report totals equal the step-1 reference totals to the cent (numeric(18,2)); no rounding drift (AC-1, FR-1a). |
| 3 | Generate the Employee Payroll Register (FR-1b) for May; sum its rows. | Register row sums equal the summary totals (cross-report consistency). |
| 4 | Generate a report for June 2026 (only a ReviewPending run exists). | The June report shows no Finalized data / empty state; the ReviewPending run does NOT contribute totals (BR-1). |
| 5 | Finalize the June run, then re-generate the June report. | June now reports its Finalized totals; the previously-excluded run is now included exactly once (BR-1). |
| 6 | Create a second (cancelled) run for May; re-generate the May report. | A Cancelled run does not alter May totals; only the single Finalized run is summed (no double count, BR-1). |

## 6. Postconditions
- Report totals provably equal the sum of Finalized-run payslips; non-Finalized/Cancelled runs are excluded; no double counting.
