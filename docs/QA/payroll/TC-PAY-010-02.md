# TC-PAY-010-02: Overtime earning -- 10h approved OT at tenant 1.5x rate, base hourly 200 -> overtime_amount = 3,000 (golden) (happy path)

## 1. Test Objective
Verify AC-2 / FR-1 / FR-4: when an employee has approved overtime hours in the finalized attendance summary, the payroll run adds an overtime earning component computed from the tenant's OT configuration (rate multiplier and base hourly derivation). With the golden data (10 approved OT hours, OT multiplier 1.5x, base hourly rate 200), the payslip shows `overtime_hours = 10` and `overtime_amount = 10 * 200 * 1.5 = 3,000`, added as an earning that increases gross and net.

## 2. Related Requirements
- User Story: US-PAY-010
- Acceptance Criteria: AC-2
- Functional Requirements: FR-1, FR-4
- Business Rules: BR-4
- Data Requirements: S7 (Attendance Summary.overtime_hours -> payroll_slip.overtime_hours / overtime_amount)

## 3. Preconditions
- Tenant "acme" Active; Payroll module enabled; OT salary component configured (US-PAY-001) with a tenant OT rule: multiplier 1.5x, base hourly rate derivation yielding 200/hour for Employee Y.
- Attendance for May 2026 FINALIZED; Y's summary: overtime_hours = 10, and those 10 hours are MANAGER-APPROVED overtime (BR-4 eligible).
- HR user `hr1` authenticated in acme with `Payroll.Run`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Period | May 2026 | finalized attendance |
| overtime_hours (approved) | 10 | FR-1 |
| OT multiplier | 1.5x | tenant config (FR-4) |
| base hourly rate | 200 | derived |
| Expected overtime_amount | 10 * 200 * 1.5 = 3,000 | golden |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As hr1, run May 2026 payroll for acme. | Engine fetches Y's attendance summary incl. overtime_hours=10 via the internal service (FR-1). |
| 2 | Confirm the 10 OT hours are approved. | Only manager-approved OT is counted as eligible; the summary's approved-OT figure = 10 (BR-4). |
| 3 | Inspect Y's payslip OT earning. | `overtime_hours = 10`; `overtime_amount = 3,000` shown as an OT earning component, computed via tenant OT config not hardcoded (FR-4). |
| 4 | Verify the calculation. | overtime_amount = applicable_hours * base_hourly_rate * multiplier = 10 * 200 * 1.5 = 3,000. |
| 5 | Verify gross/net impact. | Gross increases by 3,000; net increases accordingly; payslip totals reconcile (AC-2). |
| 6 | Change the tenant OT multiplier to 2.0x and re-run on a non-finalized run. | overtime_amount recomputes to 10 * 200 * 2.0 = 4,000 -- proving the rate is tenant-configurable, not hardcoded (FR-4). |

## 6. Postconditions
- Y's payslip carries overtime_hours=10 and a tenant-rate OT earning; gross/net increased; OT math sourced from tenant config.
