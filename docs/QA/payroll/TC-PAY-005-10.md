# TC-PAY-005-10: Payslip list loads within 1.5s P95 and the PDF download initiates within 2s (performance)

## 1. Test Objective
Verify NFR-1 / NFR-2: the My Payslips list page loads within 1.5 seconds (P95), within the 2.5-second page-load target, and the payslip PDF download initiates (first byte / download starts) within 2 seconds. Measured for a representative employee with a full year+ of payslips, under the tenant-scoped + self-scoped query.

## 2. Related Requirements
- User Story: US-PAY-005
- Acceptance Criteria: AC-1, AC-3
- Non-Functional Requirements: NFR-1, NFR-2
- Note: Requires a seeded performance environment; thresholds are P95 over a representative sample.

## 3. Preconditions
- Tenant "acme"; Employee EMP-001 with `Payroll.Read.Self` and 24+ Finalized payslips.
- Pre-generated PDFs available; performance harness configured to capture P95.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| List load target | <= 1.5s P95 | NFR-1 |
| Page-load budget | <= 2.5s | technical doc target |
| PDF download initiate | <= 2s | NFR-2 |
| Sample size | >= 100 list loads, >= 50 downloads | P95 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Drive >= 100 authenticated My Payslips list loads (warm cache) and capture latency. | P95 list-load latency <= 1.5s; within the 2.5s page-load budget (NFR-1). |
| 2 | Measure the GET my-payslips API latency separately. | API P95 well within the page budget; pagination keeps payload bounded (12/page). |
| 3 | Drive >= 50 PDF download requests for pre-generated payslips. | P95 time-to-download-initiation (first byte) <= 2s (NFR-2). |
| 4 | Capture cold-cache (first load) timing. | Cold load still meets the 2.5s page-load target; subsequent loads benefit from any tenant-scoped cache. |
| 5 | Confirm no N+1 query blow-up on the list/detail. | Query count is bounded per request (list and detail each issue a bounded, tenant+employee-filtered query). |

## 6. Postconditions
- No state change. List and download latencies meet NFR-1/NFR-2 at P95.
