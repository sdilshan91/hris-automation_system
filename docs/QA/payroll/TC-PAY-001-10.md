# TC-PAY-001-10: Default-structure single-instance rule and clone (BR-1, FR-6)

## 1. Test Objective
Verify BR-1 and FR-6: a tenant may have multiple salary structures but only ONE may be marked as default — marking a second structure default unsets the first; and an existing structure can be cloned to create a new one (components and overrides copied, new unique code, not default, inactive until validated).

## 2. Related Requirements
- User Story: US-PAY-001
- Acceptance Criteria: AC-3
- Functional Requirements: FR-2, FR-3, FR-6
- Business Rules: BR-1

## 3. Preconditions
- Tenant "acme" has two structures: "Full-Time India" (currently default) and "Part-Time India" (not default).
- HR Officer authenticated in acme with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Default structure | Full-Time India | is_default = true |
| Second structure | Part-Time India | is_default = false |
| Clone source | Full-Time India | -> "Full-Time India (Copy)" |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Mark "Part-Time India" as default (`PATCH .../structures/{id}` is_default=true) | 200; "Part-Time India" becomes default AND "Full-Time India" is automatically unset (is_default=false). Only one default remains (BR-1). |
| 2 | Verify the DB | Exactly one `salary_structure` row with is_default=true for acme. |
| 3 | Clone "Full-Time India" (`POST .../structures/{id}/clone`) | 201; a new structure is created with all component links + overrides copied, a new unique code, is_default=false, is_active=false. |
| 4 | Verify the cloned structure's components | The junction rows are duplicated with the same processing order and overrides, all stamped with acme `tenant_id` and the new structure id. |
| 5 | Attempt to clone with a duplicate target code | Rejected per BR-2 (code unique per tenant); CONDITIONAL on the clone API exposing a code field vs auto-generating one. |

## 6. Postconditions
- Exactly one default structure exists; a cloned structure with copied components exists, inactive and non-default.
