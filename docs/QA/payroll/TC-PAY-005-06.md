# TC-PAY-005-06: Pagination defaults to 12 per page; year filter and pay-period search return the correct subset, scoped to the employee (boundary)

## 1. Test Objective
Verify FR-6 plus the pagination assumption (12 per page = one year of monthly payslips): the My Payslips list paginates at 12 items/page by default, exposes a year filter (tabs/dropdown) and a pay-period search, and all filtering/searching/paging is applied within the authenticated employee's own Finalized slips. Covers boundary cases: page sizes at/over the page boundary, empty result for a year with no slips, and search by month/year.

## 2. Related Requirements
- User Story: US-PAY-005
- Acceptance Criteria: AC-1
- Functional Requirements: FR-6, FR-2, FR-8
- Constraints: 12 per page default (S10 - 8.10), most-recent-first sort
- Data Requirements: API Response - Payslip List (totalCount, page, pageSize)

## 3. Preconditions
- Tenant "acme"; Employee EMP-001 with `Payroll.Read.Self`.
- EMP-001 has 24 Finalized payslips spanning 2025 (12) and 2026 (12); no slips for 2024.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Total Finalized slips | 24 (2025: 12, 2026: 12) | two pages |
| Default pageSize | 12 | FR-6 / S10 |
| Year filter values | 2026, 2025, 2024(empty) | FR-6 |
| Search term | "May 2026" / "05/2026" | pay-period search |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open My Payslips with no filter. | Page 1 shows the 12 most-recent slips (all of 2026), pageSize=12, totalCount=24, page=1; a pagination control to page 2 is present. |
| 2 | Go to page 2. | The remaining 12 (2025) slips show; page=2; still scoped to EMP-001 only. |
| 3 | Apply year filter = 2026. | List shows only 2026 slips (12); totalCount reflects the filtered set; ordering most-recent-first. |
| 4 | Apply year filter = 2024 (no data). | Empty-state shown (no slips for 2024); no error; totalCount=0. |
| 5 | Search pay period "May 2026". | Only the May 2026 slip is returned (search by month/year). |
| 6 | Combine year=2025 + search "Dec". | Returns the Dec 2025 slip only; filters compose; result stays within EMP-001's Finalized slips (FR-2/FR-8). |
| 7 | Verify boundary: request page 3 (beyond data). | Returns empty items, no error; page/pageSize echoed correctly. |

## 6. Postconditions
- No state change. Pagination, year filter, and search behave correctly and never cross the employee/tenant boundary.
