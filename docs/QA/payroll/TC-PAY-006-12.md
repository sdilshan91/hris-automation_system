# TC-PAY-006-12: Statutory config -- tabbed sections, inline slab editor, Test Calculation panel, fiscal-year selector, and version timeline meet WCAG 2.1 AA

## 1. Test Objective
Verify the Statutory Configuration UI meets WCAG 2.1 AA (NFR-3 coverage context + UI/UX notes): tabbed sections (Income Tax / Provident Fund / Other Deductions), the editable inline tax-slab table with add/remove rows and real-time overlap highlighting, the Test Calculation panel, the fiscal-year selector/tab strip, and the collapsible version-history timeline are fully keyboard operable, screen-reader friendly, and meet contrast requirements -- including the red overlap highlight not relying on colour alone.

## 2. Related Requirements
- User Story: US-PAY-006
- Acceptance Criteria: AC-1, AC-2, AC-3
- Functional Requirements: FR-5, FR-6
- Non-Functional Requirements: NFR-3 (coverage; WCAG applied to config UI)
- UI/UX: tabbed config, inline slab editor, test-calc panel, FY selector, version timeline

## 3. Preconditions
- Statutory Configuration page reachable; axe-core / screen reader (NVDA or VoiceOver) available.
- User authenticated as Tenant Admin / `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Standard | WCAG 2.1 AA | target |
| Surfaces | tabs, slab editor, test-calc panel, FY selector, version timeline | all |
| Viewports | 360px - 1920px | responsive (mobile read-only) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate the tab strip (Income Tax / PF / Other) by keyboard only. | Tabs follow the ARIA tabs pattern (role=tab/tabpanel, arrow-key navigation, aria-selected); focus visible; no mouse needed. |
| 2 | Operate the inline slab editor by keyboard: add a row, edit slab_from/to/rate, remove a row. | All cells/controls are reachable and operable via keyboard; add/remove buttons have accessible names; focus is managed after row add/remove. |
| 3 | Trigger an overlapping-slab validation error. | The offending row is flagged with text/icon AND colour (not colour alone); the error is announced via aria-live / aria-describedby; contrast >= 3:1 for the highlight (FR-6). |
| 4 | Use the Test Calculation panel: enter a sample gross, read results. | Inputs have labels; computed tax/EPF/ETF/net are announced as a labelled results region; real-time updates use a polite aria-live region (FR-5). |
| 5 | Operate the fiscal-year selector and expand/collapse the version timeline. | Selector is a labelled combobox/tab; timeline disclosure uses aria-expanded; keyboard operable; reading order logical. |
| 6 | Run axe-core across the page; check 360px-1920px and the mobile read-only view. | Zero critical/serious violations; text contrast >= 4.5:1; layout reflows without loss of content/function; mobile shows the read-only current-rules view accessibly. |

## 6. Postconditions
- No state change; the statutory config UI is confirmed WCAG 2.1 AA conformant and responsive.
