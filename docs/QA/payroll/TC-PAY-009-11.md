# TC-PAY-009-11: Report filtering + CSV/PDF export formats + async generation with notify-when-ready (FR-2/3/4)

## 1. Test Objective
Verify FR-3 / FR-2 / FR-4: reports support filtering by pay period, department, designation, employment type, salary structure, and custom date ranges, with filters correctly narrowing the result set; export is supported in CSV and PDF (via QuestPDF) in addition to Excel (covered in TC-PAY-009-03); and large reports are generated asynchronously via Hangfire with a progress indicator and a "we'll notify you when it's ready" message, the file becoming available for download on completion.

## 2. Related Requirements
- User Story: US-PAY-009
- Acceptance Criteria: AC-4
- Functional Requirements: FR-2, FR-3, FR-4
- Non-Functional Requirements: NFR-3
- Business Rules: BR-1

## 3. Preconditions
- Tenant "acme"; Finalized May 2026 run spanning multiple departments, designations, employment types (Permanent/Contract), and salary structures.
- HR user `hr1` with `Payroll.*.All`.
- NOTE: async "notify when ready" DELIVERY is CONDITIONAL on the Notification System (S25) + Hangfire -- the enqueue + file-availability are asserted; full delivery owned by S25.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Filters | period, department, designation, employment type, salary structure, custom range | FR-3 |
| Formats | CSV, PDF (QuestPDF) | FR-2 |
| Async | large report -> Hangfire | FR-4 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Apply a department filter (Engineering) to the Payroll Summary Report. | Only Engineering rows/totals are shown; other departments excluded; summary recomputed for the filtered set (FR-3). |
| 2 | Apply designation + employment-type + salary-structure + custom-date-range filters (combined). | The result set narrows correctly to the intersection; an empty filter combination yields a clear empty state, not an error (FR-3). |
| 3 | Export the filtered report to CSV. | A valid CSV with the correct header + filtered rows + proper delimiter/quoting downloads; values match the on-screen filtered data (FR-2). |
| 4 | Export the filtered report to PDF. | A valid PDF (QuestPDF) renders the report with headers, rows, and totals; opens without errors (FR-2). |
| 5 | Generate a large report that crosses the async threshold. | The request returns immediately with a progress indicator + "we'll notify you when it's ready"; a Hangfire job is enqueued (FR-4). |
| 6 | On job completion, return to the reports area. | The completed report/file is available for download; a ready notification is enqueued (delivery CONDITIONAL on S25) (FR-4). |

## 6. Postconditions
- Filters correctly narrow reports; CSV + PDF exports are valid; large reports generate asynchronously with progress + notify-when-ready and become downloadable.
