# TC-PAY-004-06: Boundary -- PDF <= 200KB (NFR-2), BR-5 filename format, BR-4 YTD sums across prior months, BR-6 terminated-employee final-month payslip still generated

## 1. Test Objective
Verify the size, naming, YTD, and termination boundary rules: (a) NFR-2 each generated PDF is <= 200KB; (b) BR-5 the PDF file name follows `{EmployeeNo}_{PayMonth}_{PayYear}.pdf`; (c) BR-4 when the tenant enables YTD display, the YTD column for each component equals the sum of that component across all prior months' payslips of the same fiscal year PLUS the current month; (d) BR-6 an employee terminated mid-period but paid in their final month still gets a payslip generated.

## 2. Related Requirements
- User Story: US-PAY-004
- Acceptance Criteria: AC-1, AC-2
- Non-Functional Requirements: NFR-2 (<= 200KB)
- Business Rules: BR-4 (YTD sums), BR-5 (filename format), BR-6 (terminated final-month)
- Functional Requirements: FR-2 (content), FR-5 (storage)

## 3. Preconditions
- Tenant "acme" with YTD display ENABLED in the template (BR-4).
- Employee EMP-001 has payslips for Jan..Apr 2026 (same fiscal year) plus the current May 2026 slip in run R.
- Employee EMP-T was terminated 2026-05-20 (LWD) but is included in R's May 2026 slip (final-month pay).
- Run R (ReviewPending). HR Maya with `Payroll.*.All`.

| Field | Value | Notes |
|-------|-------|-------|
| YTD display | enabled | BR-4 |
| EMP-001 Basic (Jan..May) | 4 prior months + current | YTD sum target |
| EMP-T | terminated 2026-05-20, paid final month | BR-6 |
| Expected size | <= 200KB per PDF | NFR-2 |
| Expected name | EMP001_5_2026.pdf | BR-5 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Generate payslips for run R. | All slips (incl. EMP-001 and EMP-T) rendered to PDF and stored. |
| 2 | Check each PDF's file size (NFR-2). | Every generated PDF is <= 200KB; `pdf_file_size_bytes` recorded <= 204800. |
| 3 | Check the file name (BR-5). | EMP-001's payslip downloads/zips as `EMP001_5_2026.pdf` (the `{EmployeeNo}_{PayMonth}_{PayYear}.pdf` format); month/year are the run's pay period. |
| 4 | Open EMP-001's PDF; inspect the YTD column (BR-4). | For each component (e.g. Basic), the YTD amount = sum of that component across Jan,Feb,Mar,Apr + May 2026 payslips (same fiscal year); months from a different fiscal year are excluded. |
| 5 | Verify YTD for a component newly introduced mid-year. | YTD for a component first appearing in, say, March equals Mar+Apr+May (no phantom Jan/Feb amounts). |
| 6 | Verify EMP-T's final-month payslip (BR-6). | EMP-T's payslip IS generated and stored despite termination on 2026-05-20; PDF shows pro-rated final-month pay (composes with US-PAY-003 BR-5 separator logic); status Generated. |
| 7 | Verify a terminated employee NOT paid in May (LWD in April) is excluded. | No May payslip generated for that employee (not in run R); confirms BR-6 applies only to final-month-paid terminations. |

## 6. Postconditions
- PDFs are <= 200KB, BR-5-named, carry correct fiscal-year YTD sums, and terminated-but-paid employees receive their final-month payslip.
