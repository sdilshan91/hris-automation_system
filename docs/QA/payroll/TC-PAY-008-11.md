# TC-PAY-008-11: Approval review page loads <= 2s incl. summary + exception list (NFR-2); approval notifications delivered <= 30s (NFR-1)

## 1. Test Objective
Verify NFR-2 / NFR-1: the approval review page (left summary card with key metrics + variance + the exceptions/warnings list, and the right employee payslip list) loads within 2 seconds; and approval notifications (in-app via SignalR + email via the notification service) are delivered/enqueued within 30 seconds of the triggering action, with payroll approval treated at higher delivery priority than leave approval.

## 2. Related Requirements
- User Story: US-PAY-008
- Acceptance Criteria: AC-1, AC-2, AC-3
- Non-Functional Requirements: NFR-1, NFR-2
- Functional Requirements: FR-4
- Note: requires a seeded performance environment; SignalR/email DELIVERY depends on the Notification System (S25) -- the enqueue + in-app push are asserted.

## 3. Preconditions
- A seeded run in AwaitingApproval for acme with a realistic employee count (e.g., 1,000) and a populated exceptions list; a previous-month run for variance.
- Notification service + SignalR available (or the enqueue path observable).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Review page budget | <= 2s (P95) | NFR-2 |
| Notification budget | <= 30s | NFR-1 |
| Run size | 1,000 employees | seeded |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Load the approval review page (summary card + exception list + first page of employees) and measure load time over repeated runs. | Page (incl. summary + exception list) loads <= 2s at P95 (NFR-2). |
| 2 | Measure the summary aggregate computation specifically. | The summary totals + variance are computed/served within the 2s page budget; no unbounded N+1 over slips (NFR-2). |
| 3 | Submit a run for approval and measure time until the approver's in-app + email notifications are delivered/enqueued. | <= 30s (NFR-1). |
| 4 | Approve a run and measure time until HR's notification is delivered/enqueued. | <= 30s (NFR-1). |
| 5 | Reject a run and measure time until HR's notification (with reason) is delivered/enqueued. | <= 30s (NFR-1). |
| 6 | Confirm payroll approval notifications are prioritized over leave approval notifications under load. | Payroll approval notifications are dispatched at higher priority (assumption per US-PAY-008 S10); none exceed the 30s budget (NFR-1). |

## 6. Postconditions
- The review page meets the 2s budget and all approval notifications meet the 30s budget under seeded load.
