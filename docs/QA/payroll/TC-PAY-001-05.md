# TC-PAY-001-05: Activating a salary structure with no earning component is rejected (negative, FR-5)

## 1. Test Objective
Verify FR-5: the system must validate that at least one earning component exists in a salary structure before it can be marked active. A structure containing only deduction/statutory components cannot be activated; adding an earning then allows activation.

## 2. Related Requirements
- User Story: US-PAY-001
- Acceptance Criteria: AC-3
- Functional Requirements: FR-2, FR-3, FR-5

## 3. Preconditions
- Tenant "acme" has a draft (inactive) structure "Contractor-Only" containing only a Deduction component (PF) and a Statutory component (EPF) — no Earning.
- An Earning component "Basic Salary" (BASIC) exists in acme but is not yet linked.
- HR Officer authenticated in acme with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Structure | Contractor-Only | is_active = false |
| Linked components | PF (Deduction), EPF (Statutory) | No earning |
| Earning to add | BASIC | Earning |
| Expected error code | `no_earning_component` | Stable contract (HTTP status 400 is not) |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | `PUT /api/v1/payroll/salary-structures/{id}` with the full update body and is_active=true while the structure has no earning | Response 400 Bad Request with error code `no_earning_component` and message "A salary structure must have at least one earning component before it can be active." (FR-5). `is_active` remains false. |
| 2 | Verify the DB | `salary_structure.is_active` is still false. |
| 3 | Link the Earning component BASIC to the structure (`POST .../salary-structures/{id}/components`) | 201 Created; BASIC now in the structure's component list. |
| 4 | Retry `PUT .../salary-structures/{id}` with the full update body and is_active=true | Response 200; `is_active` = true — activation now permitted because an earning exists. |
| 5 | Verify the DB | `salary_structure.is_active` = true. |

## 6. Postconditions
- The structure can only be activated once it contains at least one earning component.
