# TC-PAY-007-11: Run-engine pickup correctness -- only Pending adjustments matching the run's tenant+period are selected; mixed-type aggregation (Bonus/Deduction/Reimbursement/Arrears) reconciles on the payslip

## 1. Test Objective
Verify FR-3 / FR-4 / FR-7 / BR-2 / BR-4 / BR-5: when a payroll run executes, the engine selects exactly the Pending adjustments whose applicable period matches the run period (and tenant), aggregates them correctly by type (Bonus + Reimbursement on the earnings/net-positive side per BR-2/BR-4, Deduction on the deductions side per BR-3, Correction as a labelled Arrears line per BR-5), and transitions each selected adjustment to Applied with the run reference. Cancelled and other-period adjustments are excluded.

## 2. Related Requirements
- User Story: US-PAY-007
- Acceptance Criteria: AC-1, AC-2, AC-4
- Functional Requirements: FR-3, FR-4, FR-7
- Business Rules: BR-2, BR-3, BR-4, BR-5

## 3. Preconditions
- Tenant "acme"; Employee X active structure; July 2026 run not yet executed.
- For Employee X targeting July 2026: a Pending Bonus (5,000, taxable), a Pending Reimbursement (1,500, non-taxable), a Pending Deduction (2,000), a Pending Correction/Arrears (3,000, references a finalized June payslip).
- Also present: a Cancelled deduction for July, and a Pending bonus targeting August 2026 (must NOT be picked up).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| July pending set | Bonus 5,000 / Reimb 1,500 / Deduct 2,000 / Arrears 3,000 | included |
| Excluded | Cancelled July deduction; Pending August bonus | must not appear |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Execute the July 2026 payroll run for acme. | Engine selects the 4 Pending July adjustments for Employee X; excludes the Cancelled July one and the Pending August one (FR-3). |
| 2 | Open Employee X's July payslip. | Bonus 5,000 (earning, taxable), Reimbursement 1,500 (non-taxable line), Deduction 2,000 (deductions side), Arrears 3,000 (labelled "Arrears", references June payslip) all appear (BR-2/3/4/5). |
| 3 | Verify net math. | net = base earnings + bonus + reimbursement + arrears - base deductions - 2,000 deduction; reconciles to the displayed net (no residual). |
| 4 | After finalization, inspect the 4 applied adjustments. | Each status=Applied with `applied_in_payroll_run_id`=July run id (FR-4); the Arrears one retains its `reference_payroll_slip_id` (FR-7). |
| 5 | Confirm the Cancelled and August adjustments are unchanged. | Cancelled stays Cancelled; August bonus stays Pending for its own period. |

## 6. Postconditions
- Only matching Pending adjustments applied and reconciled on the July payslip; excluded ones untouched.
