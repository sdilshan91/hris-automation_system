# TC-PAY-006-01: Configure income-tax slabs with effective date + EPF rules; fiscal-year versioning retains both versions and a payroll period uses the matching FY (happy path)

## 1. Test Objective
Verify AC-1 / AC-2 / AC-3 / FR-1 / FR-2 / FR-4: a Tenant Admin on the Statutory Configuration page configures income-tax slabs (0-250K@0%, 250K-500K@5%, 500K-1M@20%, 1M+@30%) with an effective date and a fiscal year (AC-1, FR-1); configures an EPF social-security rule with employee rate 12%, employer rate 12%, wage ceiling 15,000, applicable_on=Basic, effective date (AC-2, FR-2); then creates a NEW rule set for the next fiscal year with different slabs (AC-3, FR-4). Both versions are retained and a payroll run resolves the rule set whose `fiscal_year` / effective date range matches the run's pay period.

## 2. Related Requirements
- User Story: US-PAY-006
- Acceptance Criteria: AC-1, AC-2, AC-3
- Functional Requirements: FR-1, FR-2, FR-4
- Business Rules: BR-1 (one configured country)
- Data Requirements: S7 (statutory_rule, tax_slab, social_security_rule)

## 3. Preconditions
- Tenant "acme" Active, subdomain `acme.yourhrm.com`, Payroll module enabled, country/jurisdiction configured in tenant settings.
- User authenticated in acme as Tenant Admin (or `Payroll.*.All`).
- Statutory salary components exist (type=Statutory) per US-PAY-001.
