# TC-PAY-012-05: Payroll audit trail filtered by date range / action type / actor / resource returns ALL payroll actions in the last 30 days (happy path)

## 1. Test Objective
Verify AC-4 and FR-4: a Tenant Admin opens the payroll audit trail, searches for all payroll-related actions in the last 30 days, and the trail returns every matching payroll action (config changes, run events, approvals, adjustments) -- with working filters by date range, action type, actor, resource type, and resource id, combinable.

## 2. Related Requirements
- User Story: US-PAY-012
- Acceptance Criteria: AC-4
- Functional Requirements: FR-4, FR-2
- Business Rules: BR-4 (auditor can reconstruct the sequence)

## 3. Preconditions
- Tenant "acme" Active; over the last 35 days a known set of payroll audit entries exist spanning multiple action types (SalaryComponent.Updated, PayrollRun.Approved, PayrollAdjustment.Created, PayslipEmail.Sent) by two different actors, plus a few entries older than 30 days.
- Tenant Admin "Raj Admin" authenticated in acme with audit-view permission.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Date range | last 30 days | AC-4 |
| Action filter | PayrollRun.Approved | FR-4 |
| Actor filter | Maya Singh (U1) | FR-4 |
| Resource filter | resource_type=PayrollAdjustment | FR-4 |
| Out-of-range entry | 33 days old | must be excluded |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Open Payroll > Audit Trail; set date range = last 30 days, no other filter. | All payroll audit entries within the window are returned (config + run + approval + adjustment + payslip events); entries older than 30 days are excluded. |
| 2 | Confirm results are payroll-scoped. | Only payroll resource_types appear (the audit_log is a shared platform table filtered by payroll resource_type per S10); non-payroll module entries do not appear. |
| 3 | Add action-type filter = PayrollRun.Approved. | Only PayrollRun.Approved entries in the window remain. |
| 4 | Replace with actor filter = Maya Singh. | Only entries where actor_user_id=U1 remain, across action types. |
| 5 | Replace with resource filter = resource_type=PayrollAdjustment. | Only adjustment-related entries remain; resource_id sub-filter further narrows to a single adjustment. |
| 6 | Combine date range + action type + actor. | Filters AND together correctly; the result set is the intersection; ordering is chronological. |

## 6. Postconditions
- The audit trail returns the correct filtered payroll entries for each filter and combination; no out-of-window or non-payroll leakage.
