# TC-PAY-009-02: Generate Bank Advice File -- correct columns + correct net per employee, downloadable (happy path)

## 1. Test Objective
Verify AC-2 / FR-1e / FR-6: HR selects the Finalized payroll run and clicks "Generate Bank Advice"; the system produces a bank advice file (CSV/Excel) containing one row per paid employee with columns Employee No, Employee Name, Bank Name, Branch Code (IFSC/SWIFT/sort), Account Number, Net Amount, and Narration; every employee from the Finalized run is present with the exact net salary from their payslip; the file is available for download. Column order/delimiter is tenant-configurable (FR-6).

## 2. Related Requirements
- User Story: US-PAY-009
- Acceptance Criteria: AC-2
- Functional Requirements: FR-1e, FR-2, FR-6
- Non-Functional Requirements: NFR-4
- Business Rules: BR-1, BR-2
- Data Requirements: S7 (Bank Advice File Columns)

## 3. Preconditions
- Tenant "acme", Payroll enabled; Finalized May 2026 run with 13 paid employees, each with bank account master data.
- HR user `hr1` with `Payroll.*.All`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Run | May 2026, Finalized, 13 employees | source |
| Columns | Employee No, Employee Name, Bank Name, Branch Code, Account Number, Net Amount, Narration | S7 |
| Narration | "Salary May 2026" | payment reference |
| Tenant column config | custom order/delimiter | FR-6 |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As hr1, open the Finalized May 2026 run; click "Generate Bank Advice". | A bank advice file (CSV or Excel) is generated and a download is offered (AC-2, FR-1e). |
| 2 | Open the downloaded file; inspect the header row. | Columns present in the tenant-configured order: Employee No, Employee Name, Bank Name, Branch Code, Account Number, Net Amount, Narration (S7, FR-6). |
| 3 | Verify the row count and per-row net. | One data row per paid employee (13); each Net Amount equals exactly that employee's payslip net (numeric(18,2)); sum(Net Amount) == run total net (AC-2, FR-1e). |
| 4 | Inspect the Narration column. | Each row carries the payment reference "Salary May 2026" (S7). |
| 5 | Confirm the file is generated only from a Finalized run. | Attempting to generate bank advice for a non-Finalized run is rejected (BR-1). |
| 6 | Note the account-number representation in the downloaded file. | FULL account numbers appear in the downloaded file (masking applies only to the UI preview -- see TC-PAY-009-08, BR-2). |

## 6. Postconditions
- A bank advice file with correct columns, full account numbers, and correct per-employee net is available for download from acme's Finalized May run.
