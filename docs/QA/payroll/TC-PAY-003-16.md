# TC-PAY-003-16: Payroll rerun reconcile-marker sweep behaves correctly on real Postgres (DF-61-pg)

## 1. Test Objective
Verify on **real Postgres** that `PayrollRunReconcileJob` self-heals a stranded payroll rerun via the `ReprocessRequestedAt` marker: a `ReviewPending` run whose marker is older than the 10-minute `StaleThreshold` is re-enqueued and its marker is reset, and that the reset is **committed** (survives a fresh `DbContext` reload) — closing the InMemory-masks-Postgres coverage gap for the DF-61 marker.

## 2. Related Requirements
- User Story: US-PAY-003
- Acceptance Criteria: AC-3 (run processing/self-heal), payroll reprocess reliability
- Deferred follow-up: DF-61-pg (source: DF-61 / PR #432)
- Standard: IEEE 829

## 3. Preconditions
- Docker available; Testcontainers `postgres:17-alpine`; migrations applied on container start.
- A captured/spy `IPayrollRunJobScheduler` to assert enqueues.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| StaleThreshold | 10 min | reconcile cutoff |
| Aged marker | now − 20 min | stale → re-enqueue |
| Fresh marker | now − 2 min | not stale → skip |
| Run statuses | ReviewPending / Processing | sweep filters |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Seed a ReviewPending run with a stale `ReprocessRequestedAt`; run the reconcile sweep. | The run is re-enqueued (scheduler `Received(1)`) and `ReprocessRequestedAt` is reset. |
| 2 | Reload the run from a FRESH DbContext (`AsNoTracking`). | The marker reset is present on the committed row — not just the tracked instance. |
| 3 | Seed a ReviewPending run with a FRESH (non-stale) marker; sweep. | Not re-enqueued. |
| 4 | Seed a ReviewPending run with a NULL marker (already processed); sweep. | Not re-enqueued. |
| 5 | Seed a run in `Processing` with a stale marker; sweep. | Not re-enqueued (an already-started reprocess). |
| 6 | Two tenants (one Active, one Suspended), each with a stale-marker run; sweep. | Only the Active tenant's run is enqueued; tenant isolation holds. |

## 6. Postconditions
- The reconcile marker sweep is proven on real Postgres; a dropped rerun enqueue self-heals within one cadence.
