# TC-PAY-013-06: No double-pay boundary — the regular payroll run EXCLUDES an employee whose final period is owned by the settlement, and STILL PAYS one whose settlement does not own the period

## 1. Test Objective
Verify AC-6 / FR-7 / BR-8: when the effective policy makes the settlement own the final pay period (`FinalPeriodOwnedBySettlement` = true), the regular monthly payroll run (`PayrollRunProcessor`) excludes that terminated employee whose Last Working Day falls in the run period, so the final month is paid exactly once (no double-pay). Conversely, when a settlement does NOT own the period (`FinalPeriodOwnedBySettlement` = false), the run still pays that employee — proving the guard fires precisely on the ownership flag, in both directions.

## 2. Related Requirements
- User Story: US-PAY-013
- Acceptance Criteria: AC-6
- Functional Requirements: FR-7
- Business Rules: BR-8

## 3. Preconditions
- Tenant A Active, Payroll module enabled.
- A Queued `PayrollRun` for PayYear 2026 / PayMonth 6.
- A normal active employee with a BASIC 30,000 structure (control — must be paid).
- An active employee with a `FinalSettlement` covering the run month (LWD 2026-06-15), with `FinalPeriodOwnedBySettlement` toggled per arm.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| PayrollRun period | 2026-06 (Queued) | run under test |
| normal employee | BASIC 30,000, active | control — expects 1 slip |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Seed a normal active employee + an active employee with a settlement owning the final period (`FinalPeriodOwnedBySettlement` = true) covering the run month; process the 2026-06 run. | `ProcessAsync` succeeds (`IsSuccess` = true). |
| 2 | Count payroll slips for the settlement-owned employee in the run. | 0 slips — the settlement-owned employee's final period is NOT paid again by the run (AC-6, FR-7, BR-8 — no double-pay). |
| 3 | Count payroll slips for the normal employee in the run. | 1 slip — the normal employee is still paid (AC-6 — the guard is targeted). |
| 4 | Seed an active employee with a settlement whose `FinalPeriodOwnedBySettlement` = false covering the run month; process the run; count that employee's slips. | 1 slip — a not-owned settlement does NOT exclude the employee from the run (AC-6, FR-7 — the guard fires only on the ownership flag). |

## 6. Postconditions
- The final month of a settlement-owned leaver is paid exactly once; employees with a not-owned settlement are unaffected by the run guard.
