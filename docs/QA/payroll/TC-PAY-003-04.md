# TC-PAY-003-04: Employee without a salary structure is skipped with a warning; the run continues for the rest (AC-6)

## 1. Test Objective
Verify AC-6 and FR-5/FR-8: when one or more active employees have no salary structure assigned, the payroll run does NOT fail; each such employee is skipped with a warning entry in the run log, no payroll_slip is created for them, and the run continues and completes (ReviewPending) for all eligible employees. The run summary reports an accurate `skipped_employees` count and the skipped employees are excluded from the totals.

## 2. Related Requirements
- User Story: US-PAY-003
- Acceptance Criteria: AC-6
- Functional Requirements: FR-5, FR-8
- Business Rules: (resilience of the compute loop)
- Data Requirements: S7 (payroll_run.skipped_employees; run log)

## 3. Preconditions
- Tenant "acme"; 5 active employees: 4 with salary structures, 1 (employee "Noor") WITHOUT a salary structure.
- Attendance + leave for May 2026 finalized.
- HR Officer authenticated in acme with `Payroll.Run`.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| Total active employees | 5 | 4 eligible, 1 ineligible |
| Employee without structure | Noor | "Payroll Incomplete" |
| Expected processed | 4 | Slips created |
| Expected skipped | 1 | Warning logged |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Pre-run validation in the new-run modal. | Summary reads "4 employees ready, 1 missing salary structure" (Noor flagged). |
| 2 | Initiate the run for May 2026; let the worker complete. | Run completes with status=ReviewPending -- it does NOT fail or roll back because of Noor. |
| 3 | Verify slips. | Exactly 4 `payroll_slip` rows created (one per eligible employee); NO slip for Noor. |
| 4 | Verify run log + summary. | Run log contains a warning entry for Noor ("skipped: no salary structure"); summary shows total_employees=5, processed=4, skipped=1; totals exclude Noor. |
| 5 | Verify the warning is visible in the UI run summary. | The completion summary surfaces the skipped count + a link/list to skipped employees. |

## 6. Postconditions
- The run completes for eligible employees; Noor is skipped with a logged warning; counts are accurate.
