# TC-NTF-005-07: Export honors the active filters (CSV / JSON Lines) — synchronous export today; async Hangfire + signed URL DEFERRED

## 1. Test Objective
Verify AC-4 to the extent implemented today: clicking Export with filters applied produces a CSV or
JSON Lines file containing ONLY the filtered, tenant-scoped records. The synchronous export path works
today; the AC-4 async Hangfire job + in-app notification + 15-minute signed download URL (FR-5, NFR-6)
is DEFERRED and asserted conditionally. Base export coverage: US-ADM-008 TC-ADM-008-11.

## 2. Related Requirements
- User Story: US-NTF-005
- Acceptance Criteria: AC-4 (export filtered records; async + signed URL DEFERRED)
- Functional Requirements: FR-5 (CSV / JSON Lines export, async via Hangfire -- async DEFERRED)
- Non-Functional: NFR-6 (15-min signed URL -- DEFERRED), BR-4 (max 100,000 records/export)
- Base coverage (reference): US-ADM-008 TC-ADM-008-11 (sync export respects filters + self-audit),
  US-ADM-008 TC-ADM-008-19 [DEFERRED] (large async export)

## 3. Preconditions
- `adminA` (Audit.View, plus export permission) authenticated in Tenant A.
- A filter is applied (e.g. action = Employee.Update, last 7 days) yielding a known small result set.

| Step | Action | Expected Result |

| 1 | Apply the filter, then click Export -> CSV | A CSV is produced (synchronously today) |

Documented as DEFERRED; synchronous export is the path in force today (see US-ADM-008 TC-ADM-008-19) |
