# TC-NTF-002-08: Non-admin cannot view or edit email templates (authorization)

## 1. Test Objective
Verify that template management is restricted to Tenant Admins: a non-admin user (e.g. regular
employee, manager) cannot read, edit, save, reset, or send-test templates — at both UI and API layers.

## 2. Related Requirements
- User Story: US-NTF-002
- Acceptance Criteria: AC-1 (admin navigates to Templates), AC-3 (admin saves)
- Functional Requirements: FR-1, FR-8, FR-9
- Persona constraint: Tenant Admin only

## 3. Preconditions
- Tenant A is active. `adminA` is a Tenant Admin; `emp1` is a non-admin employee in Tenant A.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| non-admin user | emp1 | Tenant A, no admin role |
| target | template management endpoints | |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `emp1`, attempt to navigate to Settings > Notifications & Email > Templates | The menu/route is not available; direct navigation is blocked/redirected (no template UI rendered) |
| 2 | As `emp1`, call the list-templates API directly | 403 Forbidden (authenticated but not authorized) |
| 3 | As `emp1`, call the save/update-template API with a crafted payload | 403 Forbidden; no override is created or modified |
| 4 | As `emp1`, call the reset-to-default API | 403 Forbidden; no override removed |
| 5 | As `emp1`, call the send-test-email API | 403 Forbidden; no email sent |
| 6 | As `adminA`, perform the same operations | All succeed (positive control) |

## 6. Postconditions
- No template state altered by the non-admin; admin retains full access.
