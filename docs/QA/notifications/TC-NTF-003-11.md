# TC-NTF-003-11: Toggles keyboard-navigable with ARIA labels; responsive matrix collapses to cards at 360px

## 1. Test Objective
Verify the Notification Preferences page meets WCAG 2.1 AA: every toggle is reachable and operable by
keyboard with ARIA labels announcing category + channel + state, mandatory/disabled toggles announce
their locked state and reason, and the matrix is fully responsive -- collapsing to a per-category card
list at 360px while remaining usable up to 4K.

## 2. Related Requirements
- User Story: US-NTF-003
- Acceptance Criteria: AC-1 (matrix with toggle switches), AC-4 (mandatory toggle disabled with tooltip)
- Non-Functional: NFR-5 (WCAG 2.1 AA; toggle switches with ARIA labels), NFR-4 (responsive 360px-4K)

## 3. Preconditions
- Employee `emp1` (Tenant A) is on the preferences page with a mix of normal and mandatory categories
  and a Quiet Hours card.
- Test tools: keyboard only, a screen reader (NVDA/VoiceOver), an axe-core scan, and responsive
  viewport emulation (360px, 768px, 1920px, 4K).

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| viewports | 360px, 768px, 1920px, 4K | NFR-4 |
| categories | normal + mandatory (Security Alerts) | for locked-state announcement |
| browsers | Chrome, Edge, Firefox, Safari | cross-browser |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Navigate the whole page using Tab/Shift+Tab only | Every toggle, the Quiet Hours inputs, the timezone selector, and "Reset to Defaults" are reachable in a logical order with a visible focus indicator |
| 2 | Toggle a channel using Space/Enter | The toggle changes state via keyboard alone; auto-save fires; the "Saved" toast is announced (e.g. via an ARIA live region) |
| 3 | Move focus to each toggle with a screen reader | Each control announces category name + channel + on/off state (e.g. "Leave Updates, Email, on, switch") |
| 4 | Focus the mandatory "Security Alerts" toggle | Screen reader announces it as disabled and conveys "required by your organization" (matching AC-4 tooltip); cannot be toggled |
| 5 | Run an axe-core scan; verify color contrast of on/off toggle states | No WCAG 2.1 AA violations; toggle colors (green=on/grey=off) meet contrast; state is not conveyed by color alone |
| 6 | Resize to 360px | Matrix collapses to a per-category card list, each card showing its channel toggles inline; no horizontal scroll; all controls operable |
| 7 | Resize to 768px, 1920px, and 4K across the listed browsers | Layout adapts (card list -> table), remains usable and visually correct on each browser |

## 6. Postconditions
- The preferences page is keyboard-operable, screen-reader-friendly, and responsive across 360px-4K.
