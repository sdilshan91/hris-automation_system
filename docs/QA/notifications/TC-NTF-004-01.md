# TC-NTF-004-01: INSERT audit -> entity create produces "{Entity}.Create" row with after-JSON populated, before null (happy path)

## 1. Test Objective
Verify that creating a tenant-scoped business entity through EF Core `SaveChanges` automatically
produces an audit record with action "{Entity}.Create", the `after` JSONB containing the new field
values, and `before` null. Validates the primary INSERT capture path of the SaveChangesInterceptor.

## 2. Related Requirements
- User Story: US-NTF-004
- Acceptance Criteria: AC-1 (automatic audit record on save with action/resource/before/after)
- Functional Requirements: FR-1 (auto-capture INSERT via SaveChangesInterceptor), FR-2 (record fields)
- Business Rules: BR-2 (`before` is null for INSERT)

## 3. Preconditions
- Tenant A is active; an HR Officer `hr1` is authenticated within Tenant A.
- The EF Core audit SaveChangesInterceptor is registered and enabled.
- The `audit_log` table is reachable and empty (or row count is captured) for the assertion baseline.

## 4. Test Data
| Field | Value | Notes |
|-------|-------|-------|
| entity | Employee | a tenant-scoped BaseEntity |
| firstName | "Nimal" | new value |
| jobTitleId | "jt-100" | new value |
| actor | hr1 | authenticated HR Officer |
| tenant_id | Tenant A | from session context |

## 5. Test Steps
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | As `hr1`, create a new Employee with the test data and save via the API | The Employee row is persisted; HTTP 201 |
| 2 | Query the `audit_log` table for the new resource_id | Exactly one new audit row exists for that Employee |
| 3 | Inspect the audit row `action` and `resource_type` | action = "Employee.Create"; resource_type = "Employee"; resource_id = the new Employee id |
| 4 | Inspect the `after` JSONB | Contains the created field values (e.g. firstName="Nimal", jobTitleId="jt-100") |
| 5 | Inspect the `before` JSONB | `before` is null (BR-2 -- no prior state for an INSERT) |
| 6 | Inspect actor + tenant fields | actor_user_id = hr1; actor_employee_no populated if available; tenant_id = Tenant A (FR-2/8) |

## 6. Postconditions
- One immutable audit row exists describing the create; the Employee is persisted in Tenant A.
