US-RPT-004 (export the GENERIC reports at `api/v1/reports` to CSV/Excel/PDF). SEPARATE surface from payroll
export (US-PAY-009, untouched) and the US-ADM-010 tenant data export.

Key reuse + decisions to recall before touching report exports:
- **New entity `HrReportExport`** (`hr_report_exports`, migration `20260617135359_AddHrReportExport`): own
  lifecycle Queued→Processing→Completed/Failed→Expired, owner = RequestedByUserId. Did NOT reuse US-ADM-010's
  ExportRequest (different scope/shape).
- **`HrReportRenderer`** (Infrastructure, PURE static, parallel to PayrollReportRenderer): takes
  `(HrReportExportFormat, HrReportResult, tenantName?)` → `(bytes, fileName, contentType)`. Renders the generic
  envelope's `Table` (object?[] rows). Adds over the payroll renderer: BR-6 Excel "Filters Applied" section,
  AC-2/AC-3 title+timestamp header, BR-5 PDF footer "Generated by {TenantName} via HRM SaaS" + page numbers.
  CSV writes the UTF-8 BOM MANUALLY (3 bytes) then a no-BOM StreamWriter so there's exactly one BOM.
- **`HrReportExportService`**: InitiateAsync regenerates via IHrReportService to learn rowCount; **FR-5 routing
  threshold = 1000 rows** (`AsyncRowThreshold`). <1000 → render inline + Completed + ExpiresAt=+7d (BR-3);
  >=1000 → Queued + enqueue via optional `IHrReportExportJobScheduler` (Hangfire in Api, null in tests). **FR-10
  concurrency = 3 per user** (`MaxConcurrentPerUser`) → 429 `export_limit_reached`. Audits "HrReport.Export" on
  init, "HrReport.ExportDownloaded" on download (FR-9).
- **Download isolation (AC-5)**: tenant via global filter + explicit owner (RequestedByUserId) check. Missing/
  cross-tenant/not-owner → `null` (controller 404); expired/purged → `HrReportExportDownloadDto.Expired=true`
  (controller 410). Storage is the existing `IReportExportStorage` LOCAL stub (writes temp path); download reads
  bytes back with `File.ReadAllBytesAsync`.
- **Pinned FE contract** (3 endpoints on HrReportsController, `Reports.Export` perm):
  `POST {type}/export` → JSON `{exportId,status(Completed|Queued),rowCount,format}` (never bytes);
  `GET exports` → list `{id,reportType,format,status,requestedAt,completedAt,rowCount,fileSizeBytes,expiresAt,downloadReady}`;
  `GET exports/{id}/download` → FileContentResult bytes (the ONLY byte-returning endpoint).
- **Jobs**: `HrReportExportJob` (restores tenant ctx, delegates to GenerateAsync, FR-8 notify via
  INotificationService type "ReportExportReady"); `HrReportExportCleanupJob` daily (BR-3 7-day purge, mirrors
  US-ADM-010 ExportCleanupJob). Both registered in Program.cs.
- **DEFERRED (documented in code)**: charts-as-PNG in the PDF (no server-side chart renderer — PDF has
  branding+title+filters+table+pagination+footer, NO chart images; FR-4/AC-3 chart-image part); signed URLs +
  15-min expiry (FR-7/NFR-4 — local storage stub; authenticated tenant+owner /download + 7-day retention satisfy
  AC-5). **BR-2 sensitive-masking is N/A** — these reports carry no bank/national-id PII (that's payroll).
- Tests: HrReportRendererTests (CSV BOM/escaping/100-row hint, XLSX bold-headers+filters+numeric, PDF %PDF sig)
  + HrReportExportIntegrationTests (sync/async routing via a FakeReportService row-count knob, 429, download
  tenant+owner isolation, expired→410, audit rows, cleanup). InMemory provider ([[feedback-integration-tests-inmemory]]).
